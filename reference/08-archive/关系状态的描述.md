# 关系状态的描述

> 适用对象：家长
> 生态层：纵向（时间）（记录与追踪）
> 适用时机：预防促进
> 一句话范围：状态描述档：只做参照，不评分、不与常模比较。
> 相关文件：08-archive/对话档案（每次一条记录）.md；08-archive/时间线与状态演变.md；00-frame/亲子沟通判断维度.md；00-frame/沟通等级与封顶.md

## 机制

### 一、状态词表

八个取值，选一个，或留空：

| 状态 | 指的是这一次沟通落在什么位置 |
|---|---|
| 顺畅 | 双方都在说，话能接上 |
| 还行 | 聊完了，基本没卡 |
| 有点卡 | 中间有停顿或绕开，但推得下去 |
| 卡住 | 卡在某一处，推进不动 |
| 对抗 | 来回顶着，互相不听 |
| 回避 | 一方（常是孩子）退出或绕开 |
| 没说上 | 没形成对话（一句就没接上） |
| 说不清 | 你自己也难归类 |

八个值都不含评价。"对抗"不是差，"顺畅"不是好——它们描述的是这一次能不能往下走。

### 二、状态是描述档，不是评分

它没有分数、没有排序、没有"及格线"。理由：给状态打分会立刻把"这一段对话怎么样"变成"我这个人怎么样"，而后者不是这个工具要问的。把人当人、不当评判对象，是关系能起作用的前提［B1］，也是法律对尊重未成年人人格尊严的要求［L1］。

### 三、不和常模比较

不能拿你的状态词去跟"别的家长""平均家庭"比。三个原因：

1. 这个词表是本工具自定的，没有标准化样本，没有信效度，不能当量表用。
2. 同一个孩子的表现，不同来源之间一致性常常不高、主要是情境特异性，不等于谁不可靠［1］［2］。
3. 比较会引入羞耻，而羞耻是求助的障碍之一［3］。

### 四、等级只在粗粒度上参照

系统另有一组更粗的等级：**稳 / 需调整 / 需重点关注**。它挂在"这一段时期"上，不挂在某一次对话上，也只做参照。它和单次逐字材料的 S–D 等级不是一回事（后者见 `00-frame/沟通等级与封顶.md`）。

### 五、描述的是这一次，不是孩子

状态词描述"这一次沟通"，不描述孩子这个人，也不给关系定性。做法上就一句：**主语是"这次"，不是"他"。**［B3］

## 识别

### 一、从一个模糊感受落到一个词的方法

| 你的直觉 | 多半对应 |
|---|---|
| "聊挺好" | 顺畅 |
| "聊完了，没什么" | 还行 |
| "中间顿了一下" | 有点卡 |
| "怎么都绕不出来" | 卡住 |
| "互相在顶" | 对抗 |
| "他不说／走开了" | 回避 |
| "根本没聊起来" | 没说上 |
| "说不上" | 说不清 |

不确定时，选更中性的那个；两个都像，选"说不清"，不要为了好看选"顺畅"。

### 二、用等级的时机

只有当你积累了成段时间线、想看总体走向时，才用到"稳／需调整／需重点关注"。单次对话就用状态词。

### 三、描述档和判断工具的分流

| 你手里的材料 | 用哪个 |
|---|---|
| 只有回忆 | 状态词（本份） |
| 有逐字材料、想看细节 | `00-frame/亲子沟通判断维度.md` |
| 有逐字材料、想要等级 | `00-frame/沟通等级与封顶.md` |

## 做法

### 一、落词三步

1. 回想这次沟通：话接上了吗？谁在说？
2. 对词表，选一个最贴近的。
3. 写完停手，不加解释。

### 二、写"家长的感受"用感受词，不用评价词

| 感受词（可用） | 评价词（不可用） |
|---|---|
| 累、急、烦、平静、无力、松了一口气 | 他不懂事、我失败、这关系没救 |

区分感受与评价，是"对自己诚实、对对方不指责"的基础［B2］。

### 三、一个中性描述的例子

> 状态：有点卡
> 家长的感受：有点急

（不写："他就是不肯好好说"——那是评价，不是感受。）

## 边界

- **不评分、不打分、不排序。** 状态词不是分数。
- **不与常模、别人家比较。** 没有标准样本，比较无意义［1］。
- **不给孩子贴标签。** 描述的主语是"这次"。
- **不给关系定性。** "这一次对抗"不等于"我们的关系就是对抗的"。
- **不用它评判自己。** 连续"卡住"是提示方法要换，不是提示你不行。
- **不向孩子展示。** 它是你的复盘工具。
- **等级只在粗粒度参照，不等于诊断。** 涉及孩子权益与尊严，任何描述都不给孩子贴标签，相关口径见 `07-safety/法律与权利边界.md`。

## 升级信号

- 等级长期落在"需重点关注"，或状态线长期停在"对抗／回避／没说上" → 见 `07-safety/就医与专业转介指征.md`。
- 出现自伤、被欺凌、被不当触碰、动手致伤、持续"活着没意思" → 走 `07-safety/危机信号识别.md`；紧急 **110／120**，热线 **12356**。
- 你因为一个状态词反复自责 → 见 `02-parent/自己的防御信号.md`。

## 依据说明

本份属档案层，词表与读法为本套材料自定。

- **证据分级 A**：不同来源之间一致性不高、主要是情境特异性［1］［2］——元分析与经典评估研究；《未成年人保护法》关于尊重未成年人人格尊严、不得歧视的要求［L1］——现行法律；羞耻感是阻碍儿童青少年求助的因素之一［3］（系统综述）。
- **证据分级 C**：无条件接纳、观察而非评价，对应到书［B1］［B2］［B3］。
- **证据分级 D**：状态词表八个取值、感受词／评价词的区分规则、等级只作粗粒度参照的做法，均为本套材料自定。
