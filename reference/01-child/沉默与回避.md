# 沉默与回避

> 适用对象：家长
> 生态层：个体层（孩子自身）
> 适用时机：预防促进
> 一句话范围：两种沉默（在等／换了环境）、支持外移是怎么发生的、怎么把门留住。
> 相关文件：06-scenes/青春期关门对抗.md；01-child/孩子的表达方式与信号.md；01-child/说谎与说真话.md；01-child/情绪风暴还是要挟.md；03-bond/倾听与提问的技术.md；03-bond/事后修复话术.md；07-safety/危机信号识别.md

## 机制

### 一、沉默有两种，功能完全不同

同样是"不说"，背后的状态不一样。先分清是哪一种，才知道该等还是该动。

| 类型 | 他的状态 | 判断依据 | 你的方向 |
|---|---|---|---|
| **在等** | 还在这一段关系里，等一个安全的开口时机 | 你不在场时他照常说话；过一阵他会自己来找你 | 给时间和出口，不推进 |
| **换了环境** | 已经不指望从这里得到回应，话拿到别处说 | 他在别的大人、同伴面前什么都讲；对你只剩"嗯""还行" | 先修复"说了有没有用"，再谈内容 |

第二种叫**支持外移**：他把需要的支持，从你这里搬到了别人那里。这不是他变坏了，是他做过评估——在你这里说，成本太高。有研究提示，家长对孩子的了解主要来自孩子**主动说出来**，而不是靠监控和追问［1］。

### 二、支持外移的发生过程

不是一次事件，是一串小经验累积出来的。每开口一次，他都在做一次低成本判断：

| 他开口后遇到 | 他记下的结论 |
|---|---|
| 被驳回（"这有什么好说的"） | 说了没用 |
| 被评价（"你就是想太多"） | 说了会被否定 |
| 被拿去处理（转头告诉老师、告诉亲戚） | 说了不安全 |
| 被追问到底（"那你还做了什么"） | 说了会被挖 |
| 被当成问题（"你怎么老想这些"） | 说了我就是有毛病 |

攒够几次，他就把话收到别处去了。依恋关系会形成相对稳定的内部模式，影响一个人后来在关系里怎么反应、"什么事能说给谁听"［B1］。回避型的孩子情绪反应往往偏低，看起来像"没反应"，容易被读成"他没事"［3］。同一个孩子在家沉默、在外面话多，是常见现象：行为在不同情境下表现不一致，本来就是常态，不能只凭一个场合的观察下结论［4］。

### 三、沉默的三个功能

沉默不等于空白，它通常在做一件事：

1. **保护自己**：不暴露就不受伤。常见于被批评过、被嘲笑过、被出卖过的孩子。
2. **争空间**：青春期要一块不归你管的地方。这个需求本身正常，见 `06-scenes/青春期关门对抗.md`。
3. **已经放弃**：说了很多次都没有用，索性不说。这一种最容易被误判为"懂事""省心"。

第 2 种会自己过去；第 1、3 种不会，需要你这一端先变。

### 四、分龄：同一句"不想说"，在不同年龄是不同的东西

| 学段 | 沉默常见的样子 | 你该改的那一环 |
|---|---|---|
| **学前 3–6** | 不是"不说"，是还没能力说清；常表现为躲、黏、闹 | 别追问，用玩和画画替他说；你替他说出来，他点头就行 |
| **小学低年级 6–9** | 怕挨说；被追问会紧张 | 把问题换成选择句，"是今天不想说，还是等会儿说？" |
| **小学高年级 9–12** | 开始要面子，怕说了被比较 | 不在人前问；私下、边走边说，比面对面坐着好开口 |
| **初中 12–15** | 独处需求上来，不喜欢被盘问 | 不追问细节，留门；说事实和倾听，不评价 |
| **高中 15–18** | 更会藏，常常是觉得"你帮不上" | 尊重他的判断力，摆出"需要什么我来配合"的位置 |

青春期的独处需求有发育基础：负责情绪与奖励的系统先成熟，负责控制与规划的前额叶要到二十岁出头才逐步成熟［B3］。他不说，很多时候不是针对你。

## 识别

### 一、先分是"在等"还是"换了环境"

只问三个问题：

1. **他只对你沉默，还是对所有人都沉默？** 只对你 → 关系问题；对所有人都沉默 → 先排查有没有具体的事（见下）。
2. **他在别人面前说不说？** 说 → 支持外移；不说 → 更可能是情绪低落或有事压着。
3. **这个状态是最近才有的，还是一直这样？** 最近才有的，先找变化点；一直这样，是长期形成的模式。

### 二、沉默背后要排除的三件事

在把它当作"青春期正常"之前，先排除：

| 要排除的 | 线索 |
|---|---|
| **有具体的事不敢说** | 被欺凌、被威胁、被不当触碰、犯了怕被罚的错——这类沉默带着怕 |
| **情绪已经低下去** | 不只是不说，还睡不好、吃不下、对以前喜欢的事没兴趣、常说累 |
| **关系里长期没人接** | 他试着说过，被打断、被否定、被拿去处理过 |

第二类见 `07-safety/危机信号识别.md`。孩子愿不愿意求助，很大程度取决于他预期"说出来会不会被接住、会不会有后果"［2］。

### 三、"沉默"和"危机性沉默"要分开

出现下列任一项，不在本份范围，直接走安全流程：持续说"活着没意思"、有自伤痕迹、突然不上学、把东西送人、交代"后事"式的话。见 `07-safety/危机信号识别.md`、`07-safety/求助渠道与转介.md`。

## 做法

### 一、把"审问"换成"留门"

盘问会验证他的判断"说了会被挖"。换法是把门打开、把选择权交出去，让他决定什么时候进。

> ❌ "今天在学校到底怎么了？你说话呀，你不说我怎么知道。"
> ✅ "看你今天不太想聊。我先不问了，你想说的时候我都在。"

关键是**说完就停**。追问会立刻把这句话变成压力。不评判地接住对方的处境，是让一个人愿意继续开口的前提［B4］；把感受说出来、先不评价，也是让孩子把话讲下去的直接方式［B2］。

### 二、可以直接照说的原句

**他一句话不说（6–9 岁）**
> "不想说就先不说。我在这儿，等你想说了再讲。"

**他"嗯""还行"（9–12 岁）**
> "行。那我就先不问了。要是哪天有件事你觉得憋着难受，跟我说一声，我不问细节，先陪你待着。"（注意：说了不问，就不要问。）

**他明显有事但不说（12–15 岁）**
> "我感觉你今天不太一样。我不逼你说，就是想让你知道我看见。需要我的时候喊我。"

**你把他的事处理过头了，想修（各年龄）**
> "上次你跟我说的事，我没经你同意就告诉别人了。这是我的错。以后你说的事，我先问你'这个能不能跟别人讲'。"

**他嫌你问太多（12–18 岁）**
> "好，我少问。你只要答应我一件事：真遇上自己扛不住的，让我知道。"

### 三、开三个不用开口的通道

沉默的孩子，往往在"不直接对话"的形式里反而说得出来：

1. **并排做的事**：开车、散步、一起做饭、拼图。并排时不用对视，开口成本低。
2. **写和画**：留一张便条、放一个本子在桌上、让他发消息。文字给了缓冲。
3. **第三方在场**：有时候他跟另一位讲得出来。别去追问那位"他跟你说什么了"——那会同时弄坏两条通道。

同一种沉默在不同年龄要换成不同形式，见 `01-child/孩子的表达方式与信号.md`。

### 四、他从别人那里得到支持时，你的反应

**这一步最容易办砸。** 支持外移之后，他会去信别人——同伴、老师、别的大人。你的第一反应若是"你怎么什么都跟外人说""我才是你妈／爸"，等于把他推得更远。

> ✅ "你愿意找人说，挺好。只要那个人是安全的，我不吃醋。"

你要争的不是"必须跟我说"，是"他身边有能接住他的人"。一个孩子有一个可靠的成人，就是保护性因素（见 `01-child/孩子的保护性因素.md`）。

### 五、你自己的那一端

沉默很多时候答案不在孩子身上，在"你收到坏消息时的反应"。家长怎么回应他的情绪，与他以后怎么处理自己的情绪有关［5］。先给自己立一条：

- 他说的实话，哪怕你不爱听，**先接住、不处理**。"我知道了，谢谢你告诉我。"——先别急着怎么办。
- 处理要动手时，先问他一句："这件事我要不要跟别人讲？"把决定的参与权还给他。
- 你想让他开口的心越急，语气里的压力越藏不住。他先感受到的是压力，不是关心。

## 边界

| 不要做 | 原因 |
|---|---|
| 一直问，问到他说为止 | 会把沉默升级成对抗，或让他学会敷衍 |
| 用"你不说我就……"逼他 | 用恐惧换来的话，是假话或半真话 |
| 把他跟你说的事转头讲给别人 | 一次就够他记很久，是支持外移最快的一步 |
| 把沉默一律读成"叛逆"或"没事" | 两个极端都会漏掉真正的问题 |
| 让另一位家长去"撬" | 拉人围堵会同时破坏两条通道 |
| 用你自己小时候"我那时候也不说"来合理化 | 你当年不说，可能正是你现在该避免复制的模式 |

**核心：你要的是"他身边有能接住他的人"，不是"他必须跟我说所有事"。**

留门这件事，短期看像是"退让"，其实是在攒"说了有用"的经验。经验攒够了，门才真的开。

沉默的当下不要推进话题；他进入情绪时，先按 `03-bond/风暴中的当场话术.md` 处理。倾听和提问的具体技术见 `03-bond/倾听与提问的技术.md`。

## 升级信号

- **身边一个能说话的人都没有**（对同伴、老师、家长全都沉默）→ 优先处理，见 `07-safety/就医与专业转介指征.md`。
- **沉默伴随睡眠紊乱、食欲变化、对爱好失去兴趣、常说累或"没意思"**，持续两周以上 → 见 `07-safety/危机信号识别.md`。
- **沉默是怕被罚、怕报复**（被欺凌、被威胁、被不当触碰）→ 先保安全，见 `07-safety/危机信号识别.md`。
- **你每次尝试都以冲突收场，你自己也快撑不住** → 先看 `02-parent/家长情绪急救.md`。

## 依据说明

本份属机制层。

- **证据分级 A**：行为在不同情境下表现不一致，单一信息源判断不足［4］（跨信息源一致性的权威综述）；求助意愿受"说出会不会被接住、会不会有后果"影响［2］（系统综述）；依恋风格与孩子情绪反应／恢复的差异，回避型反应偏低易被误读［3］（系统综述）。
- **证据分级 B**：家长对孩子的了解主要来自孩子主动披露，监控与追问不是主要来源［1］（单项研究，样本为 703 名 14 岁青少年及家长）；家长回应方式与孩子的情绪处理有关［5］（综述）。
- **证据分级 C**："在等／换了环境"两类沉默、沉默的三个功能，属经验框架，用于分类，不对孩子作任何定性。
- **证据分级 D**：三个排查问题、"开三个不用开口的通道"、给家长立的自我规则，为本套材料自定。
