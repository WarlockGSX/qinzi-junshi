# 出门与消费

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：当场应对
> 一句话范围：超市／公共场所要东西就哭闹：出门前约好，当场四步。
> 相关文件：03-bond/风暴中的当场话术.md；01-child/情绪风暴还是要挟.md；03-bond/设边界的句式.md；04-family/家庭规则的制定与执行.md；06-scenes/游戏充值与非理性消费.md；06-scenes/打人咬人的现场.md

## 机制

超市、商场、公园门口这一幕，一半的结果在出门前那两分钟就定了。当场哭闹只是结果，不是原因。

### 一、出门前那两分钟，决定当场的一半

孩子的自控（抑制冲动、等待、记住约定）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［1］。所以指望他在货架前临时忍住，超出了他这个年龄的能力。能改的是你出门前做的准备：说清这次买什么、不买什么，把"临时决定"变成"事先说好"。事先说好，他记的是约定；临时拒绝，他记的是"我一哭你就能改"。

### 二、当场哭闹分两种

- **要挟**：目标是那件东西。你不在他就不闹，事后记得很清楚。
- **风暴**：真的过载了——人多、累、饿，加上"想要没拿到"，他停不下来。

两种当场处理不同：要挟按约定平静执行；风暴先接情绪，东西的事往后放。判断不了时按风暴处理，见 `01-child/情绪风暴还是要挟.md`。

### 三、当场让步会让他更常闹

孩子向家长索求东西时，会同时用"讲道理"和"闹情绪"两类手段。一项对 10–18 岁孩子家长的问卷调查显示，孩子更常用讲道理这类方式，家长对情绪类手段（撒娇、哭、闹）的屈服程度最低——"闹"并不比"好好说"更管用（单项调查，属关联）［2］。当场的让步会让"闹"看起来有效，于是下次他先闹。反过来，一次清楚、平静地执行约定，比十次临时妥协更能减少以后的当众哭闹。

孩子的索求还有一部分是被外部带出来的。一项面向 6–11 岁儿童与家长的纵向研究（529 对）发现：家长限制孩子接触食物广告，与"因广告索求"减少相关；媒体接触总量本身与索求没有总体关联，而边看边和孩子聊食物反而与索求增多相关（属关联）［3］。他要的一些东西，是广告放进去的，不全是冲着你来。

### 四、分龄差异

| 学段 | 索求的样子 | 你该改的那一环 |
|---|---|---|
| **学前 3–6** | 想要就要，讲不通道理，当场就躺地 | 出门前只说一条：今天买一样你选的 |
| **小学低年级 6–9** | 会讲条件、会磨，开始在意同伴 | 约定写成看得见的清单，让他自己划 |
| **小学高年级 9–12** | 开始要"面子"，会和同伴比 | 给零用钱额度，让他自己决定怎么花 |
| **初中 12–15** | 要品牌、要同伴同款 | 谈预算，不谈"该不该"，不加道德评价 |
| **高中 15–18** | 基本按预算自理 | 退到后勤：额度内他自己安排 |

## 识别

### 一、先看是在要东西还是在打滚

| 现象 | 属于 | 当场处理 |
|---|---|---|
| 指着东西说"我要这个" | 索求 | 按出门前的约定回应 |
| 说不通就开始哭、喊、躺地 | 升级 | 蹲下、认感受，不认要求 |
| 哭到喘不上气、看不见你 | 风暴 | 先接情绪，东西的事放后面 |
| 只要你在场才闹 | 多半是要挟 | 平静执行约定 |
| 事后他自己也说不清为什么哭 | 多半是风暴 | 按风暴处理 |

### 二、判断这一次能不能让

| 情况 | 处理 |
|---|---|
| 出门前说好了不买 | 平静执行，不让 |
| 临时冒出来、情有可原（渴了、饿了、必需的） | 可以让，但说清"这次是例外，因为……" |
| 你自己也不知道该不该买 | 先不买，回去再决定；当场别被推着决定 |
| 是家里人当众塞给他的 | 当场别争，回家和家里人对齐规则，见 `04-family/家庭规则的制定与执行.md` |

### 三、判断你是"按约定"还是"怕丢脸"

旁人看着，你想尽快结束。这一秒的让步通常不是为他，是为面子。认出来之后，把话说给孩子听，不必解释给旁人。

## 做法

### 一、出门前：三句约定

> "今天我们买两样：你的牛奶和我的青菜。"
> "你可以自己挑一样你想要的零食，就一样。"
> "要是有别的东西你特别想要，我们今天不买，你先记住，回去再告诉我。"

三个要点：**给一个额度**（让他有得选）、**只约一条他能记住的**、**允许他有愿望但不等于答应**。

### 二、当场四步

1. **蹲下，和他平视**：不走开，也不拖拽。身体先降下来。
2. **认感受、不认要求**："你特别想要那个，我知道。"
3. **给出口、给选择**："你可以再站这儿一分钟，或者帮我拿牛奶。你选。"
4. **到点执行约定**，平静，不解释第二遍。把结果和他的选择连起来，比你反复施压更少引发对抗［B1］。

四个字概括前三步：**蹲、认、给、守。**

### 三、可以直接照说的原句

**他指着东西要**
> "哦，这个你特别想要。我们说好今天买两样，这个不在里面。"

**他开始哭**
> "我知道你很难受。难受可以哭，我们先把东西买完。"

**他躺地**
> "我不会把你抱起来拖走。我在这儿等你起来，我们一起走。"（不围观、不骂、也不哄着买）

**他磨、讲条件**
> "今天不行。你可以把它写下来，周末我们再看。"

**旁人看着你**
> 不必对旁人解释，把话说给他听："我们按来时说的做。"

**你确实让步了**
> "今天买这个，是因为你饿了，不是因为哭。哭不改变约定。"

### 四、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "别人都有！" | 不辩论别人家 | "别人家怎么买我不知道。我们家今天是这个约定。" |
| "你就是不舍得给我花钱。" | 不接道德指控 | "今天买不买，跟舍不舍得没关系，跟约好的有关系。" |
| "你上次就买了！" | 承认那次，不翻账 | "上次是上次。今天按今天的来。" |
| "不买我就不走了。" | 不接条件 | "那我陪你站着。走的时候我们一起走。" |
| 有人在旁边说"就买一个吧" | 不接旁人 | "谢谢，我们家有约定。"（把决定留在你手里） |

给有限的选择、和善而坚定地执行约定，是这类说法能收场的前提［B2］［B3］。

## 边界

- **不要当场在货架前辩论"该不该买"**，那会变成比谁更持久。
- **不要用吓的**：不说"你不乖我就不要你了""我把你丢在这儿"。前一句否定爱，后一句让他以为会被丢下。
- **不要一边说"不行"一边买**，这比直接答应更伤约定——他学到的是"坚持久一点就能改"。
- **不要为了面子临时让步**，也不要让旁人替你做决定。
- **不要把"不买"说成他人不好**（"你怎么这么不懂事"），对事不对人。
- **约定要小、要能记住**：一次约三条以上，等于没约。
- **不因一次哭闹就加一整套新规矩**，改的是这一次的做法，不是给他定新罪。

## 依据说明

本份属做法层。

- **证据分级 B**：自我调节随发育逐步形成并受环境影响［1］（机制综述）；家长对孩子不同索求手段的屈服分布［2］、家长限制接触食物广告与"因广告索求"减少相关［3］——均为单项研究，只读成关联，不能读成因果。
