# 孩子说我不想学了

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：事后修复
> 一句话范围：他说"我不想学了"，先别表态——先弄清是哪一层不想学：内容、关系，还是方式。
> 相关文件：05-outside/兴趣班与课外负担.md；05-outside/上课走神与学习困难.md；01-child/孩子的保护性因素.md；06-scenes/写作业与拖延.md；02-parent/原生家庭与自己的成长课题.md

## 机制

### 一、"不想学"至少有三层，用同一种办法处理必然有一层治不好

| 层 | 他的真实意思 | 要动的是 |
|---|---|---|
| **内容** | "这个东西我不感兴趣／不是我要的" | 换内容、换方向，不是停学 |
| **关系** | "老师／同学／你们让我在这儿难受" | 处理关系与压力，不是处理懒惰 |
| **方式** | "太难、太快、老被纠正，我学不动" | 调难度、调方法、调反馈方式 |

三层之外的第四种要单独认：**状态**——"我现在什么都不想学"。这通常不是对这一件事的评价，是耗竭或情绪处在低位，见识别二。

**先分层，再决定说什么。** 分层错了，后面全是白费。

### 二、动机有两种来源，指向不同结果

| 来源 | 内心常说的话 | 长期结果 |
|---|---|---|
| **内在（自主）** | "我想弄明白""这个有意思" | 能自己启动、能扛住难 |
| **外在（被推着）** | "不做会挨骂""做完有奖励" | 外部一撤走就停 |

可预期的、有形的外部奖励会系统性削弱本来就存在的内在动机，这种负面影响对孩子的程度比成人更大；但不是所有奖励都有害［1］。所以用"学完给你买"来救"不想学"，通常越救越糟。

### 三、肯定落在哪里，决定他能不能扛住难

肯定落在"聪明"这类能力评价上，会在遇到难题时削弱动机和表现；落在过程与努力上，才维持得住［2］。一个被夸"聪明"的孩子，遇到不会做的题时会倾向于避开——因为做不出来就等于"我不聪明"。

这条几乎解释了相当一部分"我不想学了"：他不是不爱这个内容，是不想再站在"证明我行不行"的位置上。

### 四、管得越紧不一定越好

教养方式与孩子的学业成绩存在稳定关联（元分析，效应量偏小），但关联不等于因果，更不能反过来当家长的评分［3］。用内疚和控制推动（心理控制），与 10–20 岁孩子的抑郁、焦虑水平相关（属关联）［4］。介入越细、自主空间越小，表面上的服从可能上升，但内驱力会下去。

所以你能改的是**回应方式和节奏**，不是替他学。

### 五、分龄：同一句"我不想学了"，在不同年龄是不同的东西

| 学段 | 常见的"不想学" | 你的重点 |
|---|---|---|
| **学前 3–6** | 多为任务超出当下能力，表现为坐不住、闹 | 缩短单次时间，把学习放进玩里 |
| **小学低年级 6–9** | 怕做错、怕被比较，容易一句"我不会"退缩 | 拆小、看过程、不评价人 |
| **小学高年级 9–12** | 开始有偏好，也怕在同辈里落后 | 让他参与选择；区分"不喜欢"和"跟不上" |
| **初中 12–15** | 科目多、量确实大；也常是情绪或关系的出口 | 先分清哪一层；不接管、不当监工 |
| **高中 15–18** | 基本自理；常连着方向与意义问题 | 退到后盾位置：问需要，不给安排 |

## 识别

### 一、四层分流：他的话对应的问法

| 他说 | 更像哪一层 | 你该问 | 方向 |
|---|---|---|---|
| "这个没意思，另一个我想试试" | 内容 | "如果换一个，你会想试什么？" | 换，不是停 |
| "我就是不喜欢这门课／这个老师" | 内容或关系 | "是内容的问题，还是这个老师／这个班的问题？" | 分开问，别替他合在一起 |
| "我一进那个班就烦" | 关系 | "在那个班上，最让你难受的是哪一刻？" | 处理关系与压力 |
| "反正我也学不好" | 方式或自我评价 | "哪一步开始跟不上？" | 调难度、调反馈 |
| "我什么都不想学了" | 状态 | "最近是不是特别累？睡觉怎么样？" | 先处理状态，见识别二 |

### 二、先排除两种不能当"懒"的情况

1. **耗竭或情绪低落**：不只是不想学，还睡不好、吃不下、对以前喜欢的事也没兴趣、常说累。持续两周以上要走 `07-safety/危机信号识别.md`。
2. **学习困难**：某一科长期远低于其他科、读题明显吃力、上课也坐不住、写字或计算持续出错。这一种不是"不想"，是"跟不上"，走 `05-outside/上课走神与学习困难.md`。

**这两类被当成"态度问题"骂一顿，是最常见的误判。**

### 三、分清"这一件事"和"所有事"

- 只对某一科、某个班、某项课外——是这一层；
- 对所有学习都提不起劲，且伴随状态变化——是整体状态。

只对一件，不要扩大成大事；所有都这样，不要缩成小事。

## 做法

### 一、当场三步：先不表态

1. **接住话，不接住结论。** 不说"不行""你能有什么不喜欢的"，也不立刻说"好，那就不上了"。

> "嗯，我听到了。你说说看，是哪一部分让你不想学了？"

2. **让他把昨天和今天说清楚，你别补话。** 你插一句"那你以后怎么办"，他就不会再往下讲。
3. **给一个不长不短的复查点。**

> "我们先不改任何安排。你留意一下，是这次课让你想放弃，还是这阵子一直这样。周末我们坐下来聊。"

给具体时间点，孩子会理解为"我说的话有用"，而不是被敷衍；给一个可预期的复查，比你当场答应或拒绝都稳。

### 二、四层分别的处理

**内容层：换，不是停。**
先弄清他在同一领域里有没有想试的方向。换班、换老师、换科目侧重，都不等于放弃。不要用"你都学三年了"堵他。

**关系层：先把关系里的伤处理掉。**
被老师当众否定、被同学笑、被比较，这些会让人把"那个地方"和"学习"整体绑起来。这时谈"要不要坚持"没有意义。先处理他在这段关系里的感受，再谈去留；必要时走 `05-outside/与老师沟通（被请家长）.md`。

**方式层：调难度、调反馈。**
如果卡点是"跟不上"，你要动的是量和难度（见 `06-scenes/写作业与拖延.md`），以及**你自己给的反馈方式**——少用"这都不会？"，改成描述具体动作，比给评价更能维持动机［B1］。

**状态层：先不谈学习。**
耗竭的时候，任何关于"意义"和"前途"的谈话都是加码。先把睡眠、吃饭、有没有能放松的事拉回来，见 `01-child/孩子的保护性因素.md`。

### 三、可以直接照说的原句

**第一句，各年龄通用**
> "你说不想学了，我不会当场拍板。我想先弄清楚是哪里不对。"

**分内容还是关系（9–12 岁）**
> "是这门课本身不吸引你，还是上课的人、上课的方式让你难受？"

**分方式还是态度（12–15 岁）**
> "是内容太难，还是这事现在对你没意义？这两个不一样，你说哪个更接近。"

**他一口咬定"就是不想"（12–15 岁）**
> "那我们先不做决定。你再上两次，回来告诉我一个具体的瞬间——哪一刻你特别不想去。"

**你想知道是不是状态问题（12–18 岁）**
> "我先问一句，跟学习没关系：最近睡得怎么样，吃饭怎么样，还有没有你觉得开心的事？"

**你自己也有落差要说（各年龄）**
> "我确实希望你继续。这是我的想法，我可以说。但要不要继续，不是我一个人定。"

**谈"要不要停"的规则（9–18 岁）**
> "我们这样定：这个问题一个月后重新看一次。到时候我们把'你现在的感受'和'这一个月的实际情况'一起摆出来。"

### 四、谈"停"的边界

停或换不是被禁止的选项，但需要几个前提：

1. **不是情绪最高点做的决定**，至少等一次课、一个周末；
2. **有一个复查时间**，不是就此翻篇；
3. **让他参与**：停什么、换什么、空出来的时间怎么用，写下来；
4. **不拿"钱"和"我们为你牺牲了多少"来压他**——用内疚推动与焦虑抑郁相关［4］。

把决定权交给他一部分、给出有限的选择，比用条件驱动更能让他真的投入［B2］。让后果由他自己的选择带来，比家长单方面施压更能减少对抗［B3］。

### 五、把动机从外部挪回内部的三件事

1. **少用奖励和条件**：把"坚持到期末就买XX"换成"这几次里，哪儿你觉得最没意思？"（可预期的有形奖励会削弱内在动机［1］）；
2. **把控制感还给他**：顺序、方法、要不要考级、参不参加比赛，让他自己选；
3. **肯定落在过程上**：不说"你真聪明""你比他强"，说"这个地方你上次卡住，这次自己过了"［2］。描述具体做到的动作，比给评价更能维持动机［B1］。

## 边界

| 不要做 | 原因 |
|---|---|
| 当场表态"不行／随你" | 他没说完，你已经把话堵死 |
| 把"不想学"一律读成懒 | 三层原因不同，读成懒就治错层 |
| 一口咬定是"同学／老师带坏" | 那是你的推测，先问再说 |
| 用"我们花了多少钱"施压 | 用内疚推动与抑郁、焦虑相关［4］ |
| 用奖励和条件换他继续 | 可预期的有形奖励会削弱内在动机［1］ |
| 只夸聪明、只夸能力 | 遇到难题时动机下降［2］ |
| 直接接管（替他排计划、替他决定） | 自主空间越小，内驱力越下去 |
| 把"不想学"扩大成"这孩子以后完了" | 一次评价变成整个人生判断 |
| 也把消耗当小事（"就这几天，忍忍"） | 状态层的信号不接住，会一路低下去 |
| 反复翻同一笔旧账 | 每次都在"上次你也没坚持"开场，关系就停在那场没结束的对话里 |

**核心：先分层，再回应。你要找的是"哪一层"，不是"该不该骂"。**

无条件接纳他现在的样子，是改变有可能发生的前提［B4］。这不是让你认同"不学了"，是让你先不把他当成一个需要被修好的人。

## 升级信号

- **持续两周以上情绪低落、拒学、躯体不适（头疼、肚子疼、失眠）** → 走 `07-safety/危机信号识别.md`。
- **某一科长期远低于其他科、读题明显吃力、上课也坐不住** → 走 `05-outside/上课走神与学习困难.md`。
- **提到"活着没意思""不想活了"或出现自伤** → 立即停止学习议题，走 `07-safety/危机信号识别.md`；打 **110／120**。
- **长期拒学、连续多天不上学** → 走 `07-safety/就医与专业转介指征.md`。
- **你自己因为他的学习长期焦虑、睡不着，反复与伴侣争吵** → 先处理你这一侧，见 `02-parent/撑不住时的自我照顾.md`、`02-parent/原生家庭与自己的成长课题.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：可预期的、有形的外部奖励削弱内在动机（对儿童更强，但并非所有奖励都有害）［1］（128 项实验的元分析）；教养方式与学业成绩的关联［3］（元分析，效应量偏小，属关联）；心理控制与 10–20 岁孩子抑郁、焦虑水平的关联［4］（元分析）。
- **证据分级 B**：能力表扬削弱动机、过程／努力表扬更维持［2］（412 名 10–12 岁儿童实验；未检验"结果表扬"）。
- **证据分级 C**：内在／外在动机的区分、自然后果与逻辑后果、给有限选择，属成熟育儿框架，对应到书［B1］［B2］［B3］；无条件接纳自己的处境是改变的前提［B4］。
- **证据分级 D**：内容／关系／方式／状态四层分流表、当场三步、四层分别做法、"要不要停"的四条前提、可照说原句，为本套材料自定。
