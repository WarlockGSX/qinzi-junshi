# 记忆同意与启停

> 适用对象：家长
> 生态层：纵向（时间）（记录与追踪）
> 适用时机：预防促进
> 一句话范围：同意门禁与可撤销：查看、暂停、撤销、删除。
> 相关文件：08-archive/可写入字段与黑名单.md；08-archive/对话档案（每次一条记录）.md；07-safety/法律与权利边界.md

## 机制

### 一、默认关闭，明确同意才启用

档案默认不启用。启用需要一个明确的、可追溯的同意动作（程序里是带确认的启用指令），不是"你没反对所以默认开着"。这就是同意门禁。

### 二、同意是可撤销的，不是一次性的

启用之后，你随时可以：

- **查看**：看当前存了什么；
- **暂停**：停止写入，已存的保留；
- **撤销**：撤回同意，之后不再写入；
- **删除**：撤得更彻底，连已存的一起清掉。

撤销不是"违约"，是这项权利本身的组成部分。《个人信息保护法》规定，基于同意处理个人信息的，个人有权撤回同意［L1］。把决定权留在当事人自己手里，是尊重自主的底线［B1］［B2］［B3］。

### 三、四个动作的区别

| 动作 | 对以后写入 | 对已经存的数据 | 什么时候用 |
|---|---|---|---|
| 查看 | 不影响 | 不动 | 想知道存了什么 |
| 暂停 | 停止 | 保留 | 暂时不想记，但不想丢 |
| 撤销 | 停止 | 默认保留（可同时选删除） | 不想再用，但暂不确定是否清空 |
| 删除 | 停止 | 永久清掉 | 彻底不用了 |

### 四、撤销之后，同意可以重新给

撤销不等于永久封存。你之后想再启用，重新给一次同意即可。若选了"连数据一起删除"，重新启用时是空的。

### 五、撤回同意和删除数据是两件事

撤回同意解决的是"以后还写不写"；删除解决的是"已经写的要不要留"。程序把两者分开：可以先撤销、保留数据，也可以撤销的同时删除。

### 六、数据的位置与查看范围

档案存在本地（你的机器上），不上传。记录由你本人持有和决定，隐私与个人信息受法律保护［L2］。未成年人信息属于需要特别保护的范围，处理时要符合"最有利于未成年人"的原则［L3］；本工具的做法是把控制权完全交给家长，不向第三方流转。

## 识别

### 一、该暂停而不是删除的时候

| 你的想法 | 动作 |
|---|---|
| "最近不想记了，但怕以后要用" | 暂停 |
| "我要换个方法，旧的留着没意义" | 删除 |
| "我只是想看看都存了什么" | 查看 |
| "我不放心它一直存着" | 撤销＋删除 |
| "我不用了，但想留个备份" | 撤销（不删除） |

### 二、不确定时先暂停

暂停是可逆的（可以恢复），删除不可逆。**拿不准就暂停。** 删除是最后一个选项。

### 三、先别启用的时候

- 你自己最近状态很差，记录会加重自责 → 先处理状态（见 `02-parent/恢复路线图.md`），再决定是否启用。
- 你不确定这些字段将来给谁看 → 先读 `08-archive/可写入字段与黑名单.md` 弄清存什么。
- 家里有第三方能接触这台设备、你不希望被看到 → 先想清楚再启用。

## 做法

### 一、四个动作的执行

以本地程序的动作（含义对所有人一致）：

| 想做 | 动作 |
|---|---|
| 看当前状态（是否启用、存了几条） | 查看状态 |
| 看具体存了什么 | 查看内容 |
| 停止写入、保留数据 | 暂停 |
| 恢复写入 | 恢复 |
| 撤回同意、保留数据 | 撤销 |
| 撤回同意并清空 | 撤销＋删除 |
| 只清空数据 | 删除 |
| 撤销上一步写入 | 回退（可回退最近若干次操作） |

### 二、把同意讲清楚的三句话

对你自己（或在共同决策时对伴侣）说明白：

1. **存什么**：只存结构化字段，不存原话、录音、可识别信息。
2. **存在哪**：本机，不上传。
3. **怎么停**：随时可暂停、撤销、删除，删除不可恢复。

### 三、删除的确认要慢一步

删除不可逆。执行前先确认：真的不需要了吗？如果只是暂时不想用，选暂停。程序对删除要求额外确认，就是为了让这一步慢下来。

### 四、做一次"回头看"

每隔一段时间（比如换季，或你感觉记录开始变成负担时）做一次：

1. 看一遍存了什么；
2. 问一句"这些还有用吗"；
3. 没用就暂停或删。

控制权不是给出去就收不回——你随时能收回。

## 边界

- **默认不启用。** 没有明确同意，就不写入。
- **不把"没反对"当同意。** 同意是主动给的。
- **撤销不设门槛。** 不需要理由、不需要解释，也不需要说服自己"值不值"。
- **删除不可逆。** 删了就是删了，程序无法找回。
- **不向第三方流转。** 记录只在本地、只由你掌握。
- **不把记录当孩子的档案。** 记录反映的只是"你一侧看到的"，不同来源之间一致性常常不高［2］［3］，它没有资格被当成关于孩子的权威材料；它的作用对象是你自己，处置权也应归你。涉及未成年人的信息要按"最有利于未成年人"处理［L3］，任何情况下都不给孩子贴标签。
- **不因记录而中断该做的求助。** 难堪与污名这类顾虑，不应成为求助的障碍［1］；若你正需要专业帮助，先求助，记录可停可删。

## 依据说明

本份属档案层，合规部分依据现行法规，动作设计为本套材料自定。

- **证据分级 A**：《个人信息保护法》关于同意与撤回同意的规定［L1］；《民法典》关于隐私权与个人信息保护的规定［L2］；《未成年人保护法》关于最有利于未成年人的原则［L3］——均为现行法律。儿童青少年不求助的障碍，如难堪与污名［1］（系统综述）；多信息源评估中不同来源一致性不高［2］［3］（元分析）。
- **证据分级 C**：把决定权交给当事人、尊重自主，对应到书［B1］［B2］［B3］。
- **证据分级 D**："查看／暂停／撤销／删除"四个动作的划分、"不确定先暂停"、定期"回头看"，均为本套材料自定。
