# 当场校准

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：当场应对
> 一句话范围：冲突现场那几十秒你自己要做的减法动作、怎么从对抗里撤出来、失控之后怎么向孩子交代。
> 相关文件：03-bond/风暴中的当场话术.md；03-bond/事后修复话术.md；03-bond/平复后的修复话术.md；03-bond/三种时机剧本.md；02-parent/家长情绪急救.md；02-parent/自己的防御信号.md；01-child/情绪爆发的机制.md

## 机制

### 一、升级在几十秒内完成，不在几分钟内

冲突里真正决定走向的是开头那几十秒：你声音抬高、身体前压、说出一句带评价的话，对方立刻进入对抗，两边一起往上走。等双方都已经喊起来，方法就都用不上了。

这几十秒里，你的身体先反应。心跳加快、呼吸变浅、下巴咬住、声音发颤，这些都在你"想清楚该怎么做"之前发生。在急性、不可控的压力下，负责抑制冲动和做判断的前额叶功能会被抑制，自控力下降、人更容易一点就着，这和你是不是一个"脾气差的人"无关［1］。

所以现场的第一件事是处理身体，不是处理道理。先让身体稳下来、再讲道理，顺序反了道理就进不去［B2］。

### 二、现场你能控的只有你自己这一侧

现场有四样东西你可以直接控制，而且不需要孩子配合：**音量、身体位置、句子长度、要不要离开。**

孩子的情绪你控制不了；他的态度、他的认错、他"想通"，你更控制不了。把力气放在自己这一侧，是当下唯一有回应的动作。你这一侧稳下来，他那一侧通常自己会降一段——反过来不成立。

### 三、"校准"校的是动作，不是心态

很多人把"冷静"当成一种要先有的状态：先不生气了，再好好说话。现场做不到——情绪已经上来了，你没法先命令它下去。

能马上做到的只有动作层面的调整：闭嘴、降低、后退、缩短。动作先变，身体跟着变，情绪跟着降。顺序是**先做动作，情绪随后**，不是反过来。

### 四、你的失控常常不是当天造成的

长期处在睡眠不足、工作压力、长期冲突里，前额叶本来就更容易被压住，一件小事就能点着［1］。家长的情绪调节与孩子的情绪调节之间存在纵向关联（98 对母子、孩子 6–8 岁；属关联，不能读成因果）［3］，家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［4］。

所以在"当场校准"之前，往往要先看一件更实际的事：**你最近是不是一直处在低电量上运转。** 如果每一场都是你被点着、你失去控制，那么要改的不只是当场那一句，还有你最近的状态。

（这一份只处理当场那几十秒。孩子已经在情绪风暴里的应对，见 `03-bond/风暴中的当场话术.md`；你自己长期的状态，见 `02-parent/家长情绪急救.md`。）

## 识别

### 一、你自己的失控信号

出现任何一个，当场先做减法，不要再推进一步：

| 信号 | 含义 |
|---|---|
| 太阳穴发紧、下巴咬住、肩膀耸起 | 身体已经进入对抗状态 |
| 声音发颤或明显拔高 | 音量在失控 |
| 手抬起来、伸手指人、身体往前压 | 身体位置在施压 |
| 脑子里冒出"我今天非得治治他" | 已经从处理事情变成处理面子 |
| 说完了还想补一句"你听见没有" | 想用语言压住对方 |
| 开始搬出"我为你付出多少" | 已经在用内疚施压 |

最后两条最常被漏掉。**收不住最后一句**，是把一件小事推成大事最直接的原因。

### 二、三种当下

| 当下 | 判断依据 | 走哪一节 |
|---|---|---|
| 你还能正常说话 | 只是有分歧，语气还在 | 第一节：做减法，继续谈 |
| 你发现自己要上来了 | 出现上面任一信号 | 第二节：撤出来 |
| 两个人都停不下来 | 都在说，没人听 | 第三节：拆场 |

**"你自己要上来了"排在最前。** 很多升级的真正起点不是孩子，是你的失控。

### 三、"这一轮停下来了"的判断

出现两个以上，才算可以往下走：

1. 声音从喊变成说；
2. 呼吸和肩膀松下来；
3. 内容从攻击你变成说他自己的事。

在这之前只做减法，不推进任何话题。

## 做法

### 一、几十秒内的四件减法

1. **停嘴。** 说到一半也停。半句停下，比说完再走好。
2. **降音量。** 他高你低，降到比他还小。
3. **松身体、退半步。** 不正对、不用手指、不往前压。
4. **缩短句子。** 从一段话缩到一句，从一句缩到五个字以内。

四个动作只服务一个目标：**不让这一轮升级。** 不是赢，不是让他认错，不是把道理讲通。

### 二、撤出来：离开并交代

你已经要上来了，就离开。离开必须带一句交代，不带他理解为被丢下。

> "我现在有点上来了，我出去待一会儿。十分钟，我回来的时候还是在的。"

三个要点：说清**你自己**的状态（不是"你把我气成这样"）、给一个**具体时间**、说一句**你会回来**。

- 走之前不要留最后一句评价。"你自己好好想想""等我想通再说"会把"我去冷静"变成"我在罚你"。
- 离开后做一件打断身体的事：洗脸、喝凉水、下楼走两圈、数呼吸到二十。不要刷手机——刷手机不降级，只是把情绪往后推。
- 到了时间就回来，哪怕还没完全平静。**"回来"这件事本身，比"完全想通"重要。**

**不要一个人硬留在现场"忍住"。** 忍住是压住动作、情绪还在累积，下一句往往更重。离开不是退让，是给自己一个能回来的位置。

### 三、拆场：把两个身体分开

两个人都停不下来时，分开空间。

- 各回一个房间，或一个人出门。这是让两个身体降下来，不是冷战。
- 当下不要求任何一方先道歉、先说清楚。
- 给一个明确的再谈时间：

> "今晚都先睡，明天吃完晚饭我们再说这件事。"

给了具体时间，孩子会理解为暂停；不给，他会理解为被丢下。差别就在那个时间点。

- **给一个时间点，孩子才有清楚的暂停。** 没有时间点的"以后再说"，他会理解成你在拖着不解决。
- 如果是肢体冲突，先保人的安全，把两个人分开比对错重要；有人受伤先处理伤。

### 四、自己失控后向孩子交代的说法

当场失控过之后，平静下来要自己先说这一段。**交代不是求原谅，是认领自己那一部分。**说清自己那一句、不加"但是"，是情绪辅导类做法的通用形式［B1］。

> "刚才我吼你了。那不是你的错，是我没管好自己。"
> "我说的话太重了。我收回那一句。"

三件不要做：

| 不要 | 为什么 |
|---|---|
| 交代完加一句"但那也是因为你……" | 等于把责任又推回去，前面的交代白做 |
| 说"我也是为你好" | 用动机替代行为，孩子收不到道歉 |
| 要求他回答"你原谅我吗" | 把安抚你的任务交给了他 |

孩子可能的反应，以及怎么接：

| 他说／做 | 你接什么 |
|---|---|
| 不理你、转身走 | "你不想理我可以。这段话我说完就行，你不用回答。" |
| 说"你每次都这样" | "你说得对，这不是第一次。"（承认，不辩解） |
| 哭，或者更委屈 | "你可以哭。刚才是我不好。" |
| 顺势提条件 | "今天我确实错了。你要的那件事我们另外说，不混在一起。" |
| 说"没关系"但明显有事 | "你嘴上说没关系，我看你还憋着。想说了再跟我说。" |

更完整的修复流程见 `03-bond/事后修复话术.md`、`03-bond/平复后的修复话术.md`；发现自己总在同一种情境下失控，见 `02-parent/发火之后的修复.md`、`02-parent/自己的防御信号.md`。

### 五、你自己这一侧的现场对照表

| 你看到自己 | 通常的冲动 | 这一秒改做 |
|---|---|---|
| 声音开始拔高 | 说完这最后一句压住他 | 停嘴，降下来 |
| 手抬起来、身体前压 | 再逼近一点 | 退半步，手放下 |
| 脑子里冒出"非得治治他" | 现在就把他治住 | 离开并交代 |
| 已经吼出来了 | 继续吼到他认错 | 停下，先认自己这一句 |
| 想搬出"我为你付出多少" | 用内疚让他服 | 闭嘴，把这句话咽回去 |
| 他在房间里不出来 | 拍门逼他出来 | 留一句"我在门外，你想说的时候我听着"，走开 |
| 他沉默到底 | 一直问到他说 | 停下，给一句出口："不想说就先不说，我在这。" |

### 六、现场结束后，给自己收个尾

一轮结束（不管是谁先停的），先别急着复盘对错，做一件小事就好：**认出刚才你是从哪一句开始上来的。** 把那一句记住，下次只改那一句。

一次只改一句话。旧反应是很多年形成的，不要指望一次改掉。挑一个高频场景（比如他一顶嘴），连续两周只盯这一句。改成了再动下一句。

## 边界

- **这一份只改你自己，不要求孩子改。** 你能现场调整的只有你自己的动作。
- **减法不是冷处理。** 离开一定要带交代和时间点，不带就是把他丢在原地。
- **不要拿离开当惩罚。** "我不管你了"不是撤出来，是升级。
- **半句停下不是失败。** 说到一半能停，已经比说完再走好。
- **当场不需要把事说清楚。** 说清楚是平复后那一段的事。
- **"忍住"不等于降级。** 压住动作、情绪还在，下一句更重。要么真降下来，要么离开。
- **不要把他刚才的态度带进你后面的每一句话。** 每一句都加一句"就你这态度"，等于把一件事变成一场总账。把话落在事上、不落在人身上，是这类说法的基本形式［B3］。
- **如果每次冲突都由你的失控触发**，问题不在"当场怎么接"，在你最近的状态——见 `02-parent/家长情绪急救.md`、`02-parent/撑不住时的自我照顾.md`。
- **这一份不用于危机场景。** 出现自伤、动手致伤、持续威胁时直接走 `07-safety/危机信号识别.md`。

## 升级信号

- **当场**：有伤害自己或他人的动作、你说什么都不停且持续超过半小时、出现"我不想活了"这类话 → 停止一切话术，先保安全，见 `07-safety/危机当下的应对.md`。
- **事后**：同一模式每周多次、持续两周以上，或你每次都以失控收场 → 见 `07-safety/就医与专业转介指征.md`。情绪调节方式与心理健康存在稳定关联——习惯"重新理解"事情的人心理健康指标更好，习惯把情绪"压住"的人指标更差；长期处理不好时优先求助，不要硬撑［2］。

## 依据说明

本份属做法层。

- **证据分级 A**：情绪调节方式与心理健康的关系［2］（元分析，48 项研究）。
- **证据分级 B**：急性、不可控压力下前额叶功能被抑制、自控力下降［1］（机制综述）；家长与孩子情绪调节的纵向关联［3］（单项纵向研究，98 对母子，间接路径未达显著，只能读成关联）；家长的情绪社会化行为与孩子的情绪处理方式［4］（评论／综述性文章）。
- **证据分级 C**：先安顿状态再讲道理、撤出前要交代、说事实不评价人、失控后修复时认领自己那一部分，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：四件减法、三种当下分流、交代脚本、"只改一句话"的收尾，为本套材料自定。
