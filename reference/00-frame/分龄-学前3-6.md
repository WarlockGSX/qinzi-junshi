# 分龄-学前3-6

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：预防促进
> 一句话范围：3–6 岁该段沟通特点：讲道理基本无效，靠可见的量立规则、靠人在场接情绪。
> 相关文件：00-frame/分龄-小学低年级6-9.md；00-frame/关键过渡期.md；00-frame/情绪共调节.md；01-child/情绪爆发的机制.md；06-scenes/日常配合（刷牙洗澡穿衣）.md；06-scenes/入园适应.md

## 机制

### 一、能听懂和能做到，中间隔着发育

3–6 岁的孩子语言理解发展很快，"听懂了"经常是真的；但从"听懂要求"到"记住、压住当下冲动、动手去做"这条链还没长好。自我调节能力（注意力、抑制冲动、自己启动）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［2］。

情绪一上来，负责理性与控制的前额叶功能会被抑制，这是生理过程，不是态度问题［1］。所以这个年龄讲道理，常常不是他不想听，是当下这条通道暂时不通。

### 二、规则要靠看得见的量

这一段能执行的规则，都带一个能看见、能数清的对照物：三块积木、两次、数到十、一个沙漏、一集动画。抽象的要求（"快一点""乖一点""不许乱""你要懂事"）没有对照物，孩子无法判断什么时候算做到。

### 三、情绪先由大人接住

孩子还不能自己把情绪降下来，他借大人的状态来降。成人先接住、再处理行为，是这一段能起作用的前提［B3］。家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［5］；稳定、敏感的回应与依恋安全感相关（元分析，效应量为小到中等）［3］。

### 四、温和而明确，好过高压

学前阶段用吼、贬低、拿内疚和收回关爱施压、严厉体罚、随意惩处这类压制做法，当场能把行为压下去，但一项从学前追踪到青春期的研究（87 个家庭）显示，这类做法与孩子到青春期时更差的发展结果相关；相对地，"有要求 + 有回应"的做法结果更好［4］。"温和"说的是你的身体和音量，"明确"说的是规则本身不摇摆，两者都要有。

### 五、"讲道理"和"讲远后果"这一年龄都用不上

用"再不穿好衣服，迟到了老师会批评你"来推他，他接不住这么远的后果。这一年龄能起作用的，是当下、看得见的东西：现在出门，就能赶上公园；不收拾，玩具就先收起来，明天再玩。后果要短、要近、要能当场兑现。

## 识别

### 一、这一份的使用时机

- 你反复讲道理，他每次都"知道"，下次照旧；
- 他只在你在场时才照做，你一走就不做；
- 你越说"不要"，他越要做；
- 发脾气的时候，你说什么他都听不进去。

### 二、先分清"不愿"还是"还不会"

这一年龄，多数是"还不会"。判断口径：把要求切成一小步、给他一个能看见的量，他就能做——说明是能力问题，不是态度问题。切了还完全不动，才考虑是当下情绪或身体状态（困、饿、累）。

### 三、情绪来了先接，不在这时候谈规则

他正在哭闹、喊叫时，先按"人在场"处理，规则放平复后再说。怎么分辨情绪过载和有目的的要挟，见 `01-child/情绪爆发的机制.md`。

### 四、不同气质的孩子，处理的节奏不同

同一句要求，慢热、敏感的孩子需要更多预告和缓冲；冲动的孩子需要更明确的边界和更快的反馈。判据和做法见 `01-child/孩子的气质类型.md`。不要拿别的孩子的速度当标准。

## 做法

### 一、总是先做这四件

1. **走到他面前，蹲到和他差不多高。** 隔空喊在这个年龄几乎无效。
2. **用能看见的量说规则。** 不说"再玩一会儿"，说"再玩两次"。
3. **给两个你都能接受的选项。** 让他有得选，但选项都在你的边界内。
4. **情绪先命名，再讲动作。** 说他看到的事，不评价他这个人。

### 二、可以直接照说的原句

**给看得见的量：**
> "再滑两次，我们就回家。你数着，到二就走。"

**给两个都能接受的选项：**
> "你可以自己走到门口，或者我抱你走到门口。你选。"

**命名情绪，不说教：**
> "你很生气，因为积木倒了。"

**把要求说成可以做的动作：**
> "小车是慢慢推的，不是扔出去的。"

**预设过渡和预告：**
> "还有五分钟收玩具。我数到三就开始，你也可以自己数。"

**把要求做成游戏：**
> "我们来比赛，看谁先把外套挂好。"

**人在场、不追问：**
> "你现在很气。我在这儿，等你哭完。"

**把大任务拆成一步：**
> "我们一起收。你收积木，我收书。"

给身体在场、少用语言，是这一年龄情绪能用得上的通道［B1］；把要求做成游戏，是他愿意配合的入口［B2］。

### 三、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| 躺地上大哭 | 不说话，坐近 | "我在这儿，等你好了再说。" |
| "不要！" | 不辩论，只给选项 | "你可以自己穿，或者我帮你穿。哪个？" |
| 打人、咬人 | 先拦住动作，不羞辱 | "我不会让你打人。我知道你现在很气。" |
| 抢玩具 | 只处理动作，不评人格 | "你可以问他，不能直接拿。" |
| 一听"该走了"就逃 | 提前预告 + 给量 | "再玩两次，我们就走。" |

### 四、把一天里最容易炸的几个点固定成流程

固定说法能减少临场拉扯。下面是常见几件事的固定句式，把你家的词换进去就行：

| 场景 | 固定说法 |
|---|---|
| 起床 | "再躺两分钟，我数到三就抱你起来。" |
| 出门 | "穿鞋、拿包、按电梯，三步。我们先做第一步。" |
| 吃饭 | "再吃三口，就可以下桌。" |
| 洗澡 | "你脱衣服，我放水，谁先好谁先说。" |
| 睡觉 | "讲一个故事，关灯。故事讲完就睡。" |

固定的顺序比每次临时商量有效；孩子的预期稳了，拉扯会少。

## 边界

| 不要做 | 原因 |
|---|---|
| 把讲道理当主要工具 | 这个年龄听不进，而且他会感到被否定 |
| 当众批评、威胁"再这样我就不要你了" | 威胁不制造行为，只制造害怕 |
| 要求"你说对不起，说清楚" | 他没有能力说清动机，只会背话 |
| 用没收最喜欢的东西长期惩罚 | 他记不住关联，只记住你把它收走了 |
| 一次立很多条规则 | 记不住，等于没立 |
| 指望一次就改好 | 新习惯要重复很多次，反复是正常的 |
| 在孩子情绪里翻旧账 | 只谈当下这一件 |

**核心：这一段的规则，靠"看得见的量 + 你在场"，不靠"你说得对"。**

另：本份聚焦 3–6 岁的**沟通**。0–3 岁以照护为主，遇到时说明本 skill 聚焦沟通、先给方向即可。

## 升级信号

- **发育偏离**：接近 4 岁仍几乎没有口语、听不懂简单指令、不与人对视、走路跑跳明显落后，或已会的能力明显退回去 → 先看儿科或儿童保健科。
- **持续高频的攻击或自伤**：反复打人咬人致伤、撞头、抓自己 → 走 `07-safety/就医与专业转介指征.md`。
- **入园后长时间极端分离反应**：连续数周每天剧烈哭闹、不吃不睡 → 见 `06-scenes/入园适应.md`，必要时走专业转介。
- **疑似被不当对待、家里正在发生暴力** → 立即走 `07-safety/危机信号识别.md`；紧急情况拨 110／120，心理援助热线 12356。

## 依据说明

本份属机制层，是分龄五份中的学前一段。

- **证据分级 A**：敏感回应与依恋安全感的关系（元分析）［3］。
- **证据分级 B**：情绪唤起抑制前额叶功能（机制综述）［1］；自我调节随发育逐步形成并受环境影响［2］、家长情绪社会化与孩子的情绪处理有关［5］、学前压制型做法与后来发展结果的关系（单项追踪研究，87 个家庭）［4］。
- **证据分级 C**："温和而明确""先接情绪再讲规则"，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**："看得见的量"这一立规则方式、"不愿／还不会"的区分、本段的原句与边界，为本套材料自定。
