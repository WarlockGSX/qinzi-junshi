# 日常配合（刷牙洗澡穿衣）

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：当场应对
> 一句话范围：游戏化 + 给选择；不可让步但方式可让步。
> 相关文件：03-bond/设边界的句式.md；03-bond/奖励与惩罚的分寸.md；06-scenes/睡觉与起床.md；06-scenes/出门与消费.md；07-safety/危机信号识别.md；01-child/恐惧与焦虑.md；01-child/高敏感孩子.md

## 机制

刷牙、洗澡、穿衣、上厕所、收玩具——这些每天要重复好几遍的事，是家长和孩子最频繁的摩擦点。它们的特点是：**事必须做，但做法可以谈。** 认清这一点，一半的冲突就不成立。

### 一、拆成两栏：底线与可让

把这件事拆成两栏，你会发现可让的部分远比想的多。

| 不让步（底线） | 可以让他选（方式） |
|---|---|
| 牙要刷 | 用哪支牙膏、先刷牙还是先洗脸、他刷还是你补刷一遍 |
| 澡要洗 | 水温、放什么玩具、先洗头还是先洗身子 |
| 衣要穿 | 穿哪一件、什么颜色、先穿哪只袖子 |
| 睡前要收玩具 | 先收哪一类、用盒子还是袋子 |

底线是"高要求"，方式可让是"高回应"。教养方式与孩子的适应结果存在关联（单项研究，139 名青少年，属关联）："高要求 + 高回应"优于"高要求 + 低回应"［3］。**两者都给，才不是靠压制。**

### 二、孩子拖的是"被安排"，不一定是这件事本身

支持自主的做法（给有限的真实选择、说明理由、承认他的感受），与幼儿（2–3.5 岁）把规则内化——也就是**自愿配合**而非被迫服从——正向相关（单项前瞻观察研究，属关联）［1］。反过来，被全程安排、被盯着做完的孩子，配合只在你看得见时出现。

同时要记得：自我调节（抑制冲动、按顺序做事、自己启动）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［2］。三岁的孩子做不到"自己记得去刷牙"，不是不听话。

### 三、游戏化有效的原因

把任务变成游戏，降低了"被命令"的感觉。孩子是在玩里发展的，用他愿意进入的方式进入任务，比命令更容易启动［B1］。注意：游戏是**过程**，不是"刷完给你糖"的交易。

### 四、分龄差异

| 学段 | 配合的样子 | 你该改的那一环 |
|---|---|---|
| **学前 3–6** | 靠游戏、模仿、身体带动 | 把任务变成游戏；给两个都行的选项；用身体带着做 |
| **小学低年级 6–9** | 能协商顺序，开始要"我自己来" | 让他按计时器、自己说下一步 |
| **小学高年级 9–12** | 可以自己负责一整件 | 你只做最后检查，不再盯过程 |
| **初中 12–15** | 基本自理 | 保留底线（如刷牙、作息），其余交给自主 |
| **高中 15–18** | 完全自理 | 退到后勤：只提供条件，不安排流程 |

## 识别

### 一、先分清"必须的底线"和"可以商量的部分"

拿这件事问自己两句：**不做会伤身体或伤规则吗？** 会——底线，不让。不会——给他两个都行的选项。凡是你自己都无所谓选哪个的，就让他选。

### 二、分清是"不想"还是"不会／怕"

| 表现 | 判断 | 做法 |
|---|---|---|
| 拖，但哄一下就做 | 不想（动机问题） | 游戏化 + 给选择 |
| 一进浴室就紧张、洗澡就哭 | 可能是怕水、怕洗发水进眼 | 先处理怕，见 `01-child/恐惧与焦虑.md` |
| 衣服一穿就扯、说扎人 | 可能是感官敏感 | 换材质、剪标签，见 `01-child/高敏感孩子.md` |
| 这个年龄确实做不到全程 | 能力还没到 | 你补做后半段，不骂他 |

### 三、判断你今天还有多少耐心

如果你已经很累，就**只做底线那一件**，其余今天可以松。硬撑着做完一套，最后往往以你发火收场，得不偿失。

## 做法

### 一、三个能立刻用的手法

1. **游戏化**：给任务起个名字，加一个计时——"我们抓细菌，数到二十。"
2. **给选择**：只给两个都能接受的选项。
3. **让他当主角**：让他按、让他数、让他宣布"我刷好了"。

### 二、可以直接照说的原句

**刷牙**
> "我们比赛看谁刷得久，我数到二十。"
> "你想用草莓的还是薄荷的？"

**洗澡**
> "你是想让小鸭子先下水，还是你先下水？"
> "你自己搓前面，后面我帮你。"

**穿衣**
> "今天冷，要穿长袖。你想穿蓝色那件还是黄色那件？"

**不想做**
> "这个得做。你想现在做，还是看完这集（还剩五分钟）再做？"

**做完了**
> "你自己刷的，刷得挺干净。"

外部奖励能免则免——把"刷完给糖"当常规，会让配合变成交易，见 `03-bond/奖励与惩罚的分寸.md`。肯定落在他自己做的过程上，比落在结果上更稳。

### 三、一个可复制的流程（以刷牙为例）

1. **提前一分钟预告**："再玩五分钟就刷牙。"
2. **给两个选项**："你自己走过去，还是我数三下你走？"（底线不让、只给他方式上的选择，是和善而坚定的常规做法［B2］［B3］）
3. **一起做，或让他先做**：你在旁边，不接管。
4. **收尾肯定过程**："你今天自己刷的。"

### 四、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "我不要！" | 不辩论要不要，只问选哪个 | "得做。你想现在还是过两分钟？" |
| "再看一会儿" | 给具体时间，让他自己按 | "好，两分钟。到点你自己关。" |
| 装听不见、跑开 | 走到身边，不隔空喊 | "（走到跟前）刷牙了。你想先去还是我先去？" |
| 一边哭一边做 | 做完再处理情绪，不边哭边骂 | "你不想刷，我知道。先刷完，我们再聊。" |
| "我不会" | 拆到最小一步 | "今天只要把牙刷放进嘴里数到二十，剩下的我来。" |

## 边界

- **底线不让，方式可让**：这一段就记这一句。
- **不要让"游戏化"变成贿赂**：游戏是过程，不是"做完给你糖"。用外部奖励换配合，会把这件事变成交易。
- **不要一次改所有事**：一周只盯一件，改成了再动下一件。
- **不要在他强烈抗拒时硬按住身体完成**（安全必需的除外）。按住洗澡、按头刷牙，容易把这件事和"被控制"绑死，也伤到他的身体自主感。
- **不要用"你怎么这么懒"这类评价人**：对行为不对人。
- **不要今天必须、明天随便、后天又严**：一致比严厉有用。
- **不要用"再不去就把你的玩具扔掉"威胁**，后果不相关会让他觉得规则是随机的。

## 升级信号

- 对洗澡、换衣、被触碰表现出**极度恐惧或强烈回避**，尤其针对特定部位 → 不要只当成"不配合"，先排除不当接触，走 `07-safety/危机信号识别.md`。
- 抗拒持续两周以上、影响到吃饭和睡眠 → 走 `07-safety/就医与专业转介指征.md`。
- 你每天因这些事动手或失控 → 先走 `02-parent/家长情绪急救.md`。
