# 重复性小动作

> 适用对象：家长
> 生态层：个体层（孩子自身）
> 适用时机：预防促进
> 一句话范围：咬指甲、吃手、拔毛：替而不禁，先看它什么时候发生。
> 相关文件：01-child/行为是需求的信号.md；01-child/退行行为.md；01-child/情绪爆发的机制.md；03-bond/奖励与惩罚的分寸.md；07-safety/就医与专业转介指征.md

## 机制

### 一、这是身体动作，不是态度问题

咬指甲、吃手、拔毛这一类，属于重复的身体动作。多数出现在无聊、紧张、困倦的时候，是身体在自己找事做、或在安抚自己，不是坏习惯，也不是故意对抗。它和"听话不听话"没有直接关系。

研究里，这类动作被归在"聚焦于身体的重复行为"（body-focused repetitive behaviors）一类。其中咬指甲在儿童和青少年里很常见，通常 3–4 岁以后出现，在青少年期达到最多，之后随年龄逐渐减少［1］。也就是说，很多孩子都会经过这么一个阶段，不需要专门处理。

有一件事要先说清：**盯着它纠正，通常会加重。** 提醒、纠正、当众指出，常常反而让它更明显、更频繁。

### 二、发生的场合决定它的性质

同一个动作，出现在不同时机，含义不一样。先看时机，再决定动不动、怎么动。

| 出现时机 | 更可能是什么 | 你该做的 |
|---|---|---|
| 看电视、坐车、等餐等空白时间 | 无聊，手上要有事做 | 给一个手能忙起来的替代动作 |
| 被催促、被批评、考试或分离前 | 紧张、压力 | 提前预告变化、减少催促、先帮他降下来 |
| 困了、累了、睡前 | 自我安抚，帮助入睡 | 提前入睡、固定睡前程序 |
| 专注或放松时反而减少 | 与紧张相关 | 不加关注、不纠正 |

**关键判断：如果它只在某几类时机出现，处理那几类时机就够了，不需要全面禁止。**

### 三、"禁"会加重的原因

提醒和纠正，既带来关注，也带来"我做错了"的感觉，两者都可能让动作更频繁。用内疚、收回关爱去控制（心理控制），与孩子的抑郁、焦虑水平相关［2］；把它当成"必须马上戒掉"的毛病去管，等于在紧张之上再加一层紧张。

长期处在压力状态（睡眠不足、被催得多、持续冲突），负责自控的前额叶功能会下降，越催越难自己停下来［3］。所以"你能不能别咬了"这句话本身，就在增加它发生的条件。

### 四、多数会自己减少，少数需要看

- 咬指甲、吃手的多数情况：学前后常见，之后逐步减少。不破皮、不影响吃饭和交朋友，只需要给替代、降压力。
- 拔毛、抠皮这一类：起病常在青春期前后。少数会持续，并且影响到生活、情绪。能配合的行为治疗（习惯逆转训练）在一项针对 9–17 岁孩子的自然观察研究中显示出效果，改善维持到一年以后［4］。
- 判断分界不在"有没有这个动作"，在三个问题上：**有没有造成伤害、能不能被打断、影响不影响生活。**

### 五、自己停下来这件事，是长出来的

"别咬了"这类要求，默认孩子已经具备"察觉冲动→踩住→换个动作"的能力。但自我调节（注意、抑制冲动、自己回到基线）是随发育逐步长出来的能力，受环境和经历影响，不是"说过一次就该会"［5］，负责自控的这部分还在慢慢长［B3］。所以要求他"靠意志力戒掉"，本身就是用错了工具。

## 识别

### 一、先看它什么时候发生

不需要一上来就定性。只记一周，记三列：**发生前在做什么 → 动作 → 之后发生了什么**。连续记，最集中的那几类时机自己会显出来。记录方式见 `08-archive/对话档案（每次一条记录）.md`。

### 二、分三类，决定动不动

| 情况 | 判断依据 | 做什么 |
|---|---|---|
| 只在特定时机出现、不破皮 | 空白时间／紧张前／睡前，其它时候很少 | 只做替代与减压，不专门干预 |
| 每天多次、难以被打断 | 叫他停也停不下来，换个场合照旧 | 记录 + 降背景压力，几周仍无变化走评估 |
| 已经造成伤害 | 手指破皮出血、拔发成片、皮肤破损 | 走 `07-safety/就医与专业转介指征.md` |

### 三、不把它变成"人品问题"

不要用"脏""难看""没出息""控制不住自己"这类话。它是一次身体动作，不是性格。单次表现推不出"他就是这样的人"，同一件事换一个情境常常就不一样，见 `01-child/行为是需求的信号.md`。

### 四、分清是习惯还是别的

一个动作，放在不同背景下意义不同。多数是习惯性的身体动作；如果它明显跟着压力起落、又同时出现情绪或身体的其它变化，方向就从"改习惯"转成"看压力源"，见下面"升级信号"。

## 做法

### 一、替而不禁：六步

1. **先减关注。** 停止提醒、纠正、当众指出。这一条效果最快，也最容易被跳过。
2. **找触发点。** 连续记 1–2 周"什么时候出现"，只针对最集中的那几类时机动手，不做全面禁止。
3. **给替代动作，在那一刻递上去。** 不是事后讲道理，是在他刚要咬、刚要伸手的那一刻，把东西放到他手里。
4. **降背景压力。** 提前预告变化（"再五分钟出门"）、减少催促、先保证睡眠。压力降下来，频率常常跟着降。
5. **约定优于禁止。** "我们试试让手忙起来"比"不许咬手"更可行［B1］［B2］。用看得见的进步（今天比昨天少三次）替代"彻底戒掉"。
6. **家长自查纠正频率。** 这类动作常和"一天里被纠正的次数"同步。先把你纠正的频率降下来，再看动作变没变。

### 二、可以直接照说的原句

**不点破、直接给替代物（3–9 岁）**
> （把减压球放到他手里，什么都不说。）

**他自己发现了、有点不好意思（6–12 岁）**
> "手一闲下来就想找点事做，很正常。给你个东西捏着，好不好？"

**他问"我这样是不是有病"（9–15 岁）**
> "不是。就是手上闲不住。我们不去想它，想得越多反而越多。手上有事做的时候，它自己就少了。"

**想约定，不给压力（9–15 岁）**
> "我们要不要试试，看电视的时候手里拿点东西？试两周，看看有没有不一样。不行也没关系。"

**你想改自己老是提醒（各年龄）**
> （在心里说）"我少说一次，比多提醒十次有用。"

### 三、给手一个替代动作

- 捏减压球、握小积木、搓一小团纸；
- 撕纸、折纸、转笔（注意别影响上课）；
- 摸衣角、搓手指、按手指关节；
- 睡前：抱一个东西睡、听一段固定的音频。

选择的依据只有一个：**这个动作要和他原来的动作"手占不上"的冲突。** 手被占住，就咬不了，也拔不了。

### 四、分龄

| 学段 | 常见样子 | 你先要做的 |
|---|---|---|
| **学前 3–6** | 吃手、咬指甲多在无聊或困时 | 只做替代和作息，不提醒、不讲道理 |
| **小学低年级 6–9** | 上课、写作业、看电视时出现 | 减关注 + 给替代物；多问他一天里发生了什么，少盯这个动作 |
| **小学高年级 9–12** | 开始在意"别人会不会看我" | 私下说，不当众说；讲成"手闲不住"，不是毛病 |
| **初中 12–15** | 拔毛、抠皮这一类更多见，压力大时加重 | 不当成态度问题；先减压力源；造成伤害就走评估 |
| **高中 15–18** | 多为长期形成的习惯，他自己也在意 | 尊重他愿意自己处理；要方法就给方法，不代管 |

## 边界

| 不要做 | 原因 |
|---|---|
| 当众指出、当众教育 | 把身体动作升格成"丢脸的事"，频率反而上升 |
| 贴标签（"脏""难看""没出息"） | 把它从行为变成"我这个人不行" |
| 全面禁止、下死命令 | 越禁越频繁；目标是减少，不是清零 |
| 追求一次改掉 | 这是长期形成的动作，反复是正常的 |
| 事后讲道理、算总账 | 讲道理进不去；只在那一刻给替代才有用 |
| 忽略你自己的纠正频率 | 你提醒的频率，常常是它的一部分原因 |
| 因为它整体否定他 | 一个动作推不出一个人的样子 |

**核心：替而不禁。给它一个出口，而不是给一个禁令。**

另外两点：

- **不是每一次出现都值得处理。** 只在特定时机、不破皮、不影响生活时，不必插手。
- **不只盯着动作，看背景。** 如果它明显跟着压力起落，先处理压力源，动作常会自己退下去。

## 升级信号

- **每天多次、难以被打断**，用替代和减压几周仍无变化 → 走 `07-safety/就医与专业转介指征.md`。
- **已经造成身体伤害**：手指破皮出血或反复感染、拔发成片或出现斑秃、抠皮破溃、撞头致伤 → 走 `07-safety/就医与专业转介指征.md`。
- **同时伴随明显的焦虑或低落**，或已经影响到吃饭、睡觉、上学、交朋友 → 走 `07-safety/就医与专业转介指征.md`。
- **伴随自伤，或出现"不想活了"这类话** → 立即走 `07-safety/危机信号识别.md`，不要停在"改习惯"上。

紧急情况拨 110／120，心理援助热线 12356。

## 依据说明

本份属机制层。

- **证据分级 A**：心理控制与孩子抑郁、焦虑的关系［2］（元分析）。
- **证据分级 B**：长期压力与负责自控的前额叶功能下降之间的关系［3］（机制综述，非系统综述）；咬指甲在儿童青少年中的年龄分布与随年龄减少的趋势［1］（综述）；聚焦于身体的重复行为在 9–17 岁人群中的起病与行为治疗效果［4］（单项自然观察研究，非随机对照）；自我调节随发育逐步形成并受环境影响［5］（发展心理学综述）。
- **证据分级 C**："替而不禁""先看它什么时候发生"属常见育儿说法与经验框架，盯着纠正常会加重也归在这一类，对应到书［B1］［B2］［B3］，用于判断，不作诊断依据。
- **证据分级 D**：三类分流表、六步做法、替代动作清单、分龄处理表，为本套材料自定。
