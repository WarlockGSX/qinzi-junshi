大多数育儿建议只给两个答案："你要多共情"，或者"你得立规矩"。听完你更不知道下一句该说什么。亲子沟通军师不会只凭一句话替你下结论：它先接住情绪，再把事实、推测和未知拆开；既看这个年龄的孩子能做到什么，也看你此刻还剩多少力气、这件事值不值得今晚较真、长期会把关系带向哪里，最后给出可以真正执行的下一步。

它不只是一个话术库。它能读你们的录音、聊天截图，或者只是你的转述，并且区分素材来源与事实边界——有原话时逐句看，只有回忆时开口就说"依据是回忆"，不假装精确。它会指出谁说了什么、在哪一句拐了弯、你哪几处其实做对了，然后给你一句可以直接照着说出口的话，连孩子可能有哪几种反应、每种怎么接，一起给你。

它是一套**以 8–15 岁为主、覆盖 3–18 岁**，面向亲子关系、能够解释建议理由的 Skill。

## 它能帮你解决什么

你来找它的时候，手里多半是一件具体的事：他又顶回来了、门一关不出来、作业拖到十一点。**但那件事通常只是表面。**&#x5B69;子要长大，得在三件事上一点点攒起来：**自己说了算（自主）、我做得到（胜任）、我在这里是被接纳的（归属）**。这是自我决定理论的核心，也是这套材料看行为的角度——不是"缺什么补什么"的清单，而是看这三样东西，他现在长到哪儿了。

### 一、自主：他在练习自己做主

被安排、被指挥、没有选择余地的时候，反抗看起来就像"不听话"。这一组要处理的不是压住他，是**怎么给选择，又不让边界塌**。

| 常见的情形      | 军师会怎么帮                                    |
| ---------- | ----------------------------------------- |
| 催三遍才动，越催越慢 | 先拆开是任务太难、启动不了，还是在争"这件事谁说了算"；是前者降难度，是后者给选择 |
| 手机说多少遍都不听  | 先看规则有没有真的定过、有没有一致执行，再给设边界的具体说法和违约后果       |
| 门一关，什么都不让问 | 按青春期沟通特点给退半步的说法，不靠讲道理赢；同时给"哪些事必须管"的清单     |

### 二、胜任：他在攒"我做得到"

做不到、总失败、被比较久了，孩子会用"我不干了"保护自己。这一组要处理的不是逼他努力，是**把难度和他的能力接上**。

| 常见的情形           | 军师会怎么帮                        |
| --------------- | ----------------------------- |
| 作业写到半夜，一错就哭     | 分"不会"还是"怕做不好"，分别给降难度和接挫败的说法   |
| 一考试就崩，考前睡不着     | 先接住怕，再给考前对话和考后复盘的句子，不给"下次努力"  |
| "我就是学不好""我不想学了" | 分辨是耗竭、方法不对，还是被比较太久，给重新起步的最小一步 |

### 三、归属：他在确认"我在这里是被接纳的"

不被看见、位置被抢、怕说了更糟的时候，孩子会闭嘴。这一组要处理的不是让他开口，是**让他相信开口是安全的**。

| 常见的情形        | 军师会怎么帮                            |
| ------------ | --------------------------------- |
| 问什么都答半句      | 先分清是青春期正常、发展还没到，还是这次真有事，再给撬开话头的说法 |
| 跟弟弟妹妹抢，说我们偏心 | 不判谁对，先处理"位置"这件事，给两个孩子都能听见的说法      |
| 撒谎、偷拿钱、改分数   | 先看他怕的是什么，再给"说真话不会毁掉你"的收场          |

### 四、你自己也在里面

长年做这件事，得先有得用。这一组不是孩子的事，是你还剩多少力气。

| 常见的情形              | 军师会怎么帮                                    |
| ------------------ | ----------------------------------------- |
| 吼完就后悔              | 先给你自己的情绪急救和退场话术，再谈孩子那边——你在气头上时，最好的建议也执行不了 |
| 被老师找、被婆婆说、跟他爸理念不一致 | 先分清是家校、隔代还是夫妻分歧，再给合作而不是对抗的说法              |

### 五、看得见变化，才走得下去

一次谈话看不出方向，跨几次的走向才是信息。

| 常见的情形        | 军师会怎么帮                                |
| ------------ | ------------------------------------- |
| 想知道最近是不是好一点  | 每聊一次记一条：当时的沟通状态、你的感受、他当时的表现，按时间连起来看走向 |
| 每次都要重讲一遍我家情况 | 明确同意后跨次记住精简字段；可随时查看、暂停、撤销、删除          |

> 任何一个话题里出现自伤、被欺凌到不敢上学、动手致伤、需要就医用药，**先停下常规分析**：紧急 110／120，心理援助 12356。

## 每一个家庭都是独一无二的

同样的年龄、同样的顶嘴，在不同的家里是完全不同的事。差别不只在家庭结构，更在这三样：

- **关系现在是什么状态。** 有的家里话很多，但都停在"吃了吗、作业写完没"；有的家里话很少，可关键时候说一句就管用；有的正在变好，有的刚经历完一场大事还没缓过来。
- **孩子长到哪儿了。** 8 岁和 14 岁，同一个行为背后的东西完全不同；同一个孩子，这半年和半年前也可能像两个人。
- **家里外面是什么环境。** 学校风气、同伴、老人帮不帮得上、经济紧不紧、在一线城市还是县城、有没有异地和留守——这些不直接决定你怎么说话，但决定了哪句话在你家可行、哪句不可行。

**这阵子说不到一块儿去，不代表往后一直这样。** 孩子在长，你也在变，过两个月可能完全是另一回事。所以这套材料不判"你家这样对不对"，也不套任何一种家庭模板，只问：**眼下这个样子，哪一句可以先换掉。**

它服务的对象是**家长**——爸爸、妈妈、爷爷奶奶外公外婆、继父继母、单亲、异地、留守，以及被叫去学校的老师。**不追问你和孩子是什么关系，也不给你贴身份标签**；不问孩子姓名、学校、生日，不要求你上传任何可识别信息。

我们相信这几件事：

- **先接住人，再解决事。** 情绪没被看见时，最正确的建议也执行不了。
- **不给孩子打分、不贴人格标签。** 他的表现只作为沟通效果的证据，不作为对他的定性。
- **不越过孩子的意愿。** 孩子回避、沉默、明确拒绝时停止推进——沟通不是让孩子服从的手段。
- **关系是可以变好的。** 判据不是"感觉好点了"，是下一次他愿不愿意多说一句。
- **目标是让你越来越不需要它。**

## 一套跨学科的亲子沟通知识库

亲子沟通军师基于**布朗芬布伦纳（Bronfenbrenner）生态系统理论**分层：孩子不是孤立的个体，而是嵌在层层环境里，每一层都在影响他。依据落到可维护的单元，就是九个**域**：五层各对应一个域，另加一个底座、两个横切、一个纵向。

| 域                  | 对应哪一层        | 内容                                                     |
| ------------------ | ------------ | ------------------------------------------------------ |
| `00-frame` 原理与分龄   | 底座（各层共同引用）   | 教养底层框架、五段分龄、关键过渡期、依恋底色、情绪共调节、判断维度与等级、卡点清单              |
| `01-child` 孩子自身    | 个体层·孩子       | 情绪爆发、说谎、恐惧、沉默、讨好、攻击、退行、羞耻、韧性、高敏感、气质、小动作、保护性因素          |
| `02-parent` 家长自身   | 个体层·家长       | 情绪急救、发火后的修复、认知误区、自我照顾、原生家庭、打破代际循环、防御信号、产后情绪            |
| `03-bond` 亲子之间     | 关系层          | 互动机制、倾听与提问、话术总原则与禁语改口、分龄说法、三种时机、设边界、顶嘴对抗、开口演练、修复道歉     |
| `04-family` 家庭内部   | 家庭层          | 氛围与尺度、规则的制定与执行、手足冲突、争宠、隔代、夫妻理念、离异单亲、重组、留守、丧亲、经济状况      |
| `05-outside` 学校与外部 | 外圈层          | 与老师沟通、走神与学习困难、欺凌、被孤立、转学升学、考试、兴趣班、游戏网络、早恋               |
| `06-scenes` 情景脚本   | 横切·按一幕一幕组织   | 写作业、手机、出门、二胎、青春期、入园、考试、睡觉起床……一幕一份：当场怎么做 + 可照说原句 + 反应分支 |
| `07-safety` 安全兜底   | 横切·覆盖全层，最高优先 | 危机信号识别、危机当下的应对、求助渠道、就医指征、法律边界、欺凌处理                     |
| `08-archive` 记录与追踪 | 纵向·跨时间       | 对话档案、时间线与状态演变、关系状态的描述、同意与启停、字段与黑名单                     |

**域是分层的落地，不是另立一套分类。** 五层回答"这件事发生在谁身上"，域回答"这份材料该放在哪、该去哪儿找"；两者一一对应，所以同一件事只落在一个域里，不重复。两个横切域不按层切，是按使用的场合切：`06-scenes` 收的是一幕从头到尾的完整脚本，`07-safety` 收的是任何一层出现危险信号时都要走的那条路。

分开维护换来的是**最小加载**：一次只读 1–2 份，不整库预读，也不设二级索引——单轮上下文成本很小，响应也快。9 个域、120 份、约 64 万字，一份一个窄主题（3.5–15.5KB，平均约 11.4KB）。每份开头标了适用时机（预防促进／当场应对／事后修复），五段分龄的说法集中在 `00-frame` 的五份 `分龄-*.md` 里，方便一眼知道该翻哪一份。

**分域是本套材料的组织方式，不是理论主张。** 不拿它判断某个家庭"属于哪一层"，更不据此给孩子或家长定性。完整依据与出处见 `references/00-frame/生态层次与参考依据.md`。

## 参考资料

这套材料的知识来自七类：**依恋与发展心理学**（依恋的形成、情绪调节随年龄的发展、分离与重聚对安全感的影响）、**教养方式与家庭研究**（"高要求 + 高回应"优于"只提要求"的证据、心理控制与过度管控的长期代价）、**情绪与脑发育**（情绪上来后讲道理失效的原因、青春期冲动在前自控在后的时间差）、**亲子沟通与冲突解决**（倾听、提问、设边界、奖惩分寸、道歉与修复里哪些做法有证据）、**学校、同伴与网络**（学业压力、校园欺凌、同伴排斥、短视频与游戏的影响边界）、**家庭结构与变故**（离异、重组、留守、丧亲、经济压力下孩子的适应差异）、**危机干预与儿童保护**（自伤、虐待、伤害事件的处理顺序，以及现行法律下的权利与义务）。

每份文件的末尾都有 `## 依据说明` 与 `## 参考文献`：这一份的结论**强在哪里、弱在哪里**写得清清楚楚（例如"这是元分析，但关联不等于因果，效应量偏小"），并按 A／B／C／D 标证据强度。不是"专家说"。

## 安装

将下面的安装口令发送给你使用的 AI 助手：

```text
请把本地 skill 目录安装为 Skill：<把本目录的完整路径填在这里>
```

安装完成后，可以输入：

```text
请使用亲子沟通军师，帮我看看刚才这段对话。
```

装好之后直接说话就行，**不需要点名"用亲子沟通军师"**：

```text
你："气死我了，这孩子一放学就把门关上，问什么都不说。"
军师：（先接住你的火 → 帮你挑一个话题、给你开场的话 → 提醒你录下来 → 等你带材料回来复盘）
```

首次使用时，它会问五项，**每一项都可以跳过**，也可以直接讲故事、让它从叙述里整理：

```text
孩子：年龄 / 生理性别
你：年龄 / 最近一个月你和孩子的关系（很好／还不错／一般／有点难／很困难）
这次：你想从哪儿说起（解决一个问题／修复关系／看清刚才发生了什么／找句话去跟他聊）
```

### 录音与聊天记录（可选）

家长录了和孩子的一段对话，回来上传即可。**录音默认在本机离线转写**（faster-whisper），不需要账号、密钥或付费，录音不上传。转写要先装依赖：`pip install faster-whisper`（非 wav 的音频再加 `av numpy`），首次运行会下载模型（small 约 500MB）；装不上或想省流量的，可以按 `requirements.txt` 里的说明手动指定模型目录。装了腾讯云密钥的话可以走云端路径（能区分说话人编号，但录音会上传、按量计费）——由你自己决定。

聊天截图、导出的聊天记录、老师发的消息、孩子的日记与作业本，都可以作为材料。长记录会先锁定"家长／孩子"的说话人映射再分析，映射不明时会先问你，不按左右、语气或性别猜。

> 录音前提示：录制他人对话请符合当地法律与孩子的知情同意。本 skill 只分析家长合法持有并主动提供的材料。

## 一次完整对话的六个阶段

```text
你说一句话（可能是抱怨、可能是一段录音、可能只是"这句怎么说"）
  → 判定：你要的是能直接说的一句话、一次复盘、一个判断，还是只是撑不住了
  → 建档：只问五项，每一项都可以跳过，也可以直接讲故事
  → 首轮：照见哪一句转折 → 一句首选 → 2–3 条能照说的 → 一个现在能做的动作
  → 中间轮：一句话判断 + 我为什么问这个 + 一个动作（控制在 5 行以内）
  → 收束：完整链条 → 你做对的地方 → 要改的 1–2 条 → 下次直接说的话 → 仍不确定的部分 → 观察窗口
  → 记一条档案；下一次回来，按时间看走向
```

**中间轮故意说得少，这是设计。** 过程中的家长只想知道"这一句能不能用"，给他一份读不完的报告是加负担。详细说明集中在收束那一次——那时材料齐了，说得准，也听得进去。

**追问一定带理由。** 每次提问前会先用一句话讲清"这个问题会改变哪个判断"，你不用在被连续追问里猜我们到底想干什么。追问有额度（首轮最多 2 个、之后每轮最多 1 个、一次对话不超过 5 个），额度用完就转收束，**不会告诉你还剩几个**。

## 设计原则

1. **先接住人，再解决事。** 情绪没被看见时，最正确的建议也执行不了。
2. **行为比标签可靠。** 不凭一次表现推断"他就是这样的人"，看的是在什么条件下出现、在什么条件下不出现。
3. **一句能照说的话，胜过一段正确分析。** 它的效用不在说完那一刻，而在下一次他愿不愿意多说一句。
4. **一条线胜过一个点。** 单次谈话看不出方向，跨次的走向才是信息。
5. **证据分两边。** "你做对的地方"和"要改的地方"都要给证据，两边都不省。
6. **过程中少说，收束时说透。** 认知负担也是成本，省在过程里，花在关键处。

## 三条边界

1. **不诊断、不测评未成年人、不替代专业帮助**——它给判断标准和能照说的话，不给诊断，也不给孩子打分。
2. **不制造焦虑，也不虚假安慰**——不说"没事的"，也不吓唬你。
3. **不替你做决定。** 给的是能执行的说法和各自的代价，不是"你必须这样做"。
