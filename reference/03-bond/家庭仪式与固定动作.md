# 家庭仪式与固定动作

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：预防促进
> 一句话范围：固定仪式与短句库：保持一致、反复用同一套。
> 相关文件：03-bond/平静期的预防与预演.md；03-bond/话术总原则.md；03-bond/设边界的句式.md；04-family/家庭规则的制定与执行.md；04-family/夫妻理念不一致.md；04-family/祖辈与隔代育儿.md

## 机制

### 一、固定动作的作用是"不用每次重新谈"

同一件事，如果每次都临时决定，孩子每次都来试一次边界，你也每次都费一遍口舌。固定下来之后，孩子知道"接下来就是这一步"，冲突的回合数就少了。有稳定常规和仪式的家庭，孩子的适应更好、行为更有序（综述研究，属关联）［1］。

### 二、一致 = 可预期 = 安全感

可预期的、敏感的回应与依恋安全感相关（元分析，效应量为小到中等）［2］。孩子不用靠试探来确认"今天行不行"，就能把精力放到别的事上。一条规则今天行、明天不行，比一条严一点的规则更耗人。稳定一致的回应，也是情绪辅导的共同前提［B3］。

### 三、短句库：反复用同一套话

一组固定短句反复用，有两个好处：孩子不用每次重新解码你的意思；你也少想、少费劲。这类"固定触发—固定回应"的写法，与"如果—那么"计划的思路一致——有具体计划，比只有目标更可能按计划做到（元分析）［3］。

### 四、"仪式"不等于"节日"

仪式是重复的固定动作，多小都行：每天出门前的一句话、每周一次的一起做饭、每年一次的同一张合影。它靠的是重复和稳定，不是花钱和规模。

## 识别

### 一、最值得固定的环节

优先固定**高频**和**最容易冲突**的环节：

| 环节 | 值得固定成什么 |
|---|---|
| 早晨 | 出门前的固定三步、固定一句话 |
| 吃饭 | 一餐不吃手机的约定、开动前的一句话 |
| 睡前 | 固定的顺序（洗漱→聊两句→关灯） |
| 出门／回家 | 固定的问候语和交接动作 |
| 一周一次 | 固定的共同活动（做一顿饭、走一圈） |
| 一年几次 | 生日、节日里固定的一个动作 |

### 二、判断当前缺的是"流程"还是"意义"

| 表现 | 缺的是 | 先做 |
|---|---|---|
| 每天早晨都在赶、都在吵 | 流程 | 固定动作顺序，把它写在门上 |
| 一家人各做各的，很久没有"一起"的时刻 | 意义 | 先加一周一次的固定共同活动 |
| 规则说不清、总在临时定 | 规则 | 走 `04-family/家庭规则的制定与执行.md` |

### 三、家里不止一个大人的时候

固定动作要**所有大人都用同一套**，否则孩子很快就学会"找谁有用"。谁带孩子多，谁就少一点改动；标准以主要照护者那一套为准。祖辈参与照护时，见 `04-family/祖辈与隔代育儿.md`；大人之间不一致时，见 `04-family/夫妻理念不一致.md`。

## 做法

### 一、从一件开始，跑两周

不要一次改一整套。挑一个环节，写下来，做两周。

**示例：睡前流程**

> 洗漱（他做）→ 关大灯、开小灯（他做）→ 聊两句（你可以问）→ 说晚安（一句话）→ 关灯（你来做）

写下来贴在墙上，前几天你带着走，之后他自己走。一个固定的、随时能回去的位置，是孩子敢往外的底气［B1］。

### 二、天／周／年，三层各一个

| 层 | 一个例子 | 说什么／做什么 |
|---|---|---|
| 天 | 出门前 | "今天顺顺利利，晚上见。" |
| 周 | 一次共同做饭 | "这顿你选菜、我来做，或者反过来。" |
| 年 | 生日／节日固定动作 | "每年这天我们都拍一张一样的照片。" |

一层一个就够，不用排满。小一点的孩子，固定动作做成固定的玩法更留得住，比如把收拾玩具变成每次都玩的同一个游戏［B2］。

### 三、短句库

固定说法，分类反复用。**同一类只留一到两句，用你家的口气。**

**① 开场／交接**

> "我回来了。"／"我出去一趟，几点回，你记得。"

**② 提醒（不带评价）**

> "还有十分钟。"／"时间到了。"

**③ 边界（说清、不商量）**

> "这条不变。"／"东西可以摔，人不能碰。"

**④ 给出路（不逼表态）**

> "你想说就说，不想说就先放着。"／"我在客厅，你想聊再叫我。"

**⑤ 收尾／修复**

> "这件事就这样，翻篇了。"／"刚才是我急了，对不住。"

**⑥ 连接**

> "今天有想跟我讲的吗？"／"这十分钟我陪你，你说干嘛就干嘛。"

这些短句与 `03-bond/话术总原则.md`、`03-bond/设边界的句式.md` 里的原则一致。这一份的重点是**保持一致、反复用同一套**，不要今天这句、明天那句。

### 四、让某一句话固定下来（示范）

选一件你最常冲突的事，配一句话，固定说：

| 事 | 固定一句话 |
|---|---|
| 叫他吃饭不动 | "吃饭了。"（不再加第二句，也不隔空吵） |
| 要他关屏幕 | "时间到了，屏幕给我。" |
| 他情绪上来 | "我们停一下。" |
| 突然沉默 | "不想说就先不说。" |
| 要出门了 | "穿鞋，我们走。" |

**关键不是这句话多好，是每次都用同一句。** 用同一句，孩子很快知道这句话的分量；每次换一种说法，他才需要一次次试。

### 五、两个完整的固定流程（可以直接抄）

**早晨流程**

> 起床（叫一声，不叠喊）→ 洗漱 → 吃早饭 → 穿鞋 → 门口说一句话 → 出门

**吃饭流程**

> 叫一声"吃饭了" → 放下手机 → 坐下 → 开动前问一句"今天怎么样" → 吃完各收各的碗

写出来贴好，谁在家谁照着走，不额外解释。

### 六、让家里的大人都用同一套的做法

1. 把最要紧的三条写下来，贴在大家都看得到的地方；
2. 只改你能改的那部分，别人的说法先不动；
3. 老人用的说法不一样时，先在你这一侧统一，再去沟通，见 `04-family/祖辈与隔代育儿.md`。

### 七、分龄差异

| 学段 | 固定动作的形态 | 注意 |
|---|---|---|
| 学前 3–6 | 靠顺序和身体动作，越具体越好（他要知道"下一步做什么"） | 少用语言要求，多用固定的动作和顺序 |
| 小学低年级 6–9 | 作息和出门最值得固定 | 把流程画出来贴在墙上 |
| 小学高年级 9–12 | 让他参与一起定，参与了他才认 | 让他自己选一个环节负责 |
| 初中 12–15 | 仪式要"不打扰"：留给空间，保住一两个固定动作 | 不要用仪式去查行踪 |
| 高中 15–18 | 固定动作退到很少，但要保住（比如每周一顿一起吃的饭） | 尊重他的时间表，宁可固定得少 |

### 八、家里结构特殊时的调整

- **单亲**：固定动作可以少，但**不能今天这个标准、明天那个标准**。见 `04-family/离异与单亲.md`。
- **长期不在身边（留守、两地）**：把固定动作变成固定时间的固定通话。见 `04-family/留守与长期分离.md`。
- **重组家庭**：新成员加入后先只保留一两个共同动作，别一次统一所有规矩。见 `04-family/重组家庭.md`。

## 边界

- **仪式不是打卡。** 一旦变成"必须完成"，它就开始消耗关系。做到了就做到了，漏一天不补、不罚。
- **短句不是咒语。** 同一句话，语气比字面重要。用冷脸说"我在客厅"，和用平常的语气说，效果不一样。
- **标准要保持一致。** 同一件事今天骂明天笑，比一直严更让孩子无所适从。
- **不为仪式加负担。** 一次要花两小时的"仪式"，第二次就没人愿意做。宁可小而固定。
- **不在仪式里夹带要求。** 固定的一起做饭，就一起做饭，不要在桌上翻作业。
- **别用固定动作绑住大一点的孩子。** 到了初高中，他不愿意的部分要能商量，否则仪式会变成他要挣脱的东西。

## 依据说明

本份属做法层。

- **证据分级 A**：敏感的、一致的回应与依恋安全感相关（元分析，效应量为小到中等）［2］；预先形成固定的"如果—那么"计划能提高目标达成（94 项研究的元分析）［3］。
- **证据分级 B**：家庭常规与仪式同养育胜任感、孩子适应之间有稳定关联（50 年研究、32 篇文献的质性综述）［1］。
- **证据分级 C**："安全基地""固定的家庭时间""游戏中建立关系"属成熟育儿框架，对应到书［B1］［B2］；情绪辅导中的一致性做法见［B3］。
- **证据分级 D**：天／周／年三层划分、短句库的分类与选句、分龄形态表、特殊结构的调整方式，为本套材料自定。
