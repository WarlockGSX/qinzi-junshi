# 卡点清单

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：事后修复
> 一句话范围：对关系有害的具体言行清单；判定看位置不看数量，可以为空。
> 相关文件：00-frame/亲子沟通判断维度.md；00-frame/沟通等级与封顶.md

## 机制

### 一、卡点

卡点是**对这段沟通关系有负面影响的具体行为**。它是一个行为，不是一种性格，也不是"不会说话"。

三件事必须分开：

| 表现 | 是不是卡点 |
|---|---|
| 孩子问了什么，你其实不想答，用反问顶回去 | 可能是卡点（行为） |
| 这件事你不知道该怎么回应，还在学 | 不是卡点（能力） |
| 孩子说了一半停下，因为他在组织语言 | 不是卡点（还在发展） |

一句话：**"不愿意说"可能是卡点；"还在学、还不会"不是卡点。**

卡点的判断对象是**一句话落在关系里产生的效果**，不是这句话好不好听、够不够客气。同一句"你先听我说完"，落在两人抢话时是打断，落在孩子已经说完、你请求轮到自己时是承接。所以判卡点先看它站在哪儿，再看它说了什么。

卡点也不是"这次没聊好"本身。"这次没聊好"是结果，卡点是造成结果的那个**具体动作**。报告里给的是动作，不是结果标签。

### 二、判定看位置，不看数量

你说了多少次祈使句，不如这些句子**落在哪里**重要。

判断某一句是不是卡点，把它、孩子在这句之前的一条、之后的一条，**三条放一起看**。三条同时成立才算：

1. 孩子在这句之前是愿意说的；
2. 这句之后他变短、变沉默或开始敷衍；
3. 之后**没有恢复**主动表达。

缺一条，就不是这一次沟通里"影响走向"的卡点。同一句"你怎么又这样"，落在孩子刚开口时，和落在他已经说完之后，意义不一样。同一表现随情境和观察者而变，只看一次不足以下结论［4］。

### 三、卡点可以为零

不是每一次沟通都非得找出卡点。一次对话里没有任何对关系造成负面影响的具体行为，是正常、而且是值得说出来的结果。

卡点为零时，报告要**明确写出来**，不能含糊带过，也不能硬凑一个。它是这次沟通的亮点，和"做得好的地方"一起讲。

卡点和等级各算各的：卡点为零只说明这次没有出现伤人的具体行为，不代表这一次整体评价一定高；等级由五维分算（见 `00-frame/沟通等级与封顶.md`）。两者同时出现时如实都写，例如：

> "这段对话基本没聊起来（孩子多数时候没接话），但你全程没有否定或打断他。"

## 识别

### 一、常见类型

| 类型 | 长什么样 |
|---|---|
| 否定式说教 | "你应该……""你不能……""我跟你说过多少遍" |
| 无视孩子的表达 | 孩子说了感受或请求，你接的是别的事 |
| 话题终结 | 一句把孩子的话堵回去，让他没有下一句可以接 |
| 抑制表达 | "这有什么好说的""别想那么多" |
| 不文明用语 | 骂人、羞辱性称呼 |
| 音量或语气失控 | 吼、冷笑、拖长音讽刺 |
| 打断 | 孩子还在说，你的话已经接上去 |
| 否定孩子的感受 | "你不该生气""这有什么好怕的" |
| 命令式表达 | 只给指令，不给选择或理由 |
| 转移话题 | 孩子说这件，你拐到你更想谈的那件 |
| 打压式比较 | "你看看××""你怎么就不如人家" |
| 忽略孩子的情绪 | 他情绪已经上来了，你继续讲道理或继续追问 |

这些行为对关系的影响有研究线索支撑：用内疚、收回关爱去控制（心理控制）与孩子抑郁、焦虑水平相关［1］；侵入式管控与孩子内化、外化症状相关［2］；你怎样回应孩子的情绪，与他怎样处理自己的情绪有关［3］。

### 二、不算卡点的

- 孩子思考时的停顿；
- 问答里的简短确认（"对""嗯"）；
- 对话自然收尾（"好的""知道了"）；
- 孩子因为知识或能力不够答不上来；
- 你自己口误、说错一个字，后面立刻改了。

### 三、先分"行为"和"人"

| 写法 | 属于 |
|---|---|
| "刚才那句话把孩子堵回去了" | 行为 → 可以写进卡点 |
| "你不太会共情" | 对人的判断 → 不写 |

### 四、位置判定示例（三条一起看）

下面几组都是"这一句算不算卡点"的例子。判定的关键是它落在孩子哪一条之后。

| 孩子前一条 | 你的这一句 | 孩子后一条 | 判定 |
|---|---|---|---|
| "今天老师批评我了……" | "你肯定又没做好。" | （不再说话，低头） | 是：他刚开口就变沉默，且没恢复 |
| "我今天不想去，好热。" | "热什么热，车上有空调。" | "……算了。" | 是：反驳的是"热不热"，没接住"不想去"，之后出现放弃表达信号 |
| （已经把事说完） | "你是说，老师当着全班说的？" | "对，就是那儿……"（继续说） | 不是：他之后继续表达 |
| （正在想怎么讲） | （你安静等着） | （他接着说完了） | 不是：停顿是组织语言，不是被堵 |

## 做法

### 一、定位一个卡点的三步

1. **找那一句。** 从孩子由积极参与转向沉默、变短或敷衍的位置，往前找一句。
2. **看前后。** 把这一句、孩子之前一条、之后一条放在一起读。
3. **定结论。** 三条都成立，写明"是哪一句、在这句之后发生了什么"；缺一条，不算。

### 二、报告里的写法

- 落到**具体原句**，不写笼统评价；
- 只描述发生了什么，不评价家长这个人；
- 每条卡点后给一句**可以直接照说的话**（见 `03-bond/禁语与改口对照.md`）。

> ❌ "你这句话很伤人。"
> ✅ "孩子说完'我不想上学'之后，你回的是'不想上也得上'；这句之后他就不说话了。下次可以先把他的话复述一遍：'你今天不想上学。'"

说观察到的事实而不是评价，说请求而不是命令，是这类说法能起作用的前提［B1］。回应孩子的情绪时先接住、不否定，是情绪辅导与忽视、反对式回应之间的分界［B2］；把评价性、审判性的语言换掉，是沟通类做法反复强调的一条［B3］。

### 三、卡点为零时的写法

> "这次没有出现打断、否定、堵话这类行为。孩子中间有一处停顿，是他在想怎么说，不算卡点。这是一段可以照着复制的对话。"

### 四、一次只改一处

挑**一处**高频卡点（比如他一开口你就接"你应该"），只改这**一句**，连续两周只盯这一句。旧说法是很多年形成的，一次改一句改得动，一起改改不动。

### 五、卡点密集时最先改的一处

一次对话里可能出现不止一个卡点。不要一起改。优先顺序：

1. **先改"让孩子停下"的那一处**：打断、否定感受、堵话，这一类直接关掉了他的表达；
2. **再改"以要求和评判为主"的那一处**：命令式表达、打压式比较；
3. **最后改语气和音量**：吼、讽刺，这一类多半是前两类的结果。

一次只动一处，改到不出现为止，再动下一处。

## 边界

- **不把"还不会"当卡点。** 正在学、能力还没到的，说成卡点会变成给人定性。
- **不给家长贴标签。** 卡点说明"这个行为有影响"，不说明"你是个不合格的家长"。
- **不硬凑卡点。** 可以为空，为空时要写出来。
- **不复述没被讲到的对话，不编造引用。** 只有口述、没有逐句材料时，不复述具体对话。
- **单次卡点不等于这个人。** 与 `00-frame/沟通等级与封顶.md` 一样，判据只对这一段对话，不做人格定性；同一表现随情境而变，单次片段不足以定性［4］。
- **不把卡点当成"孩子不配合"的替罪羊。** 孩子的沉默、敷衍是效果证据，不是给孩子的评分。

## 依据说明

本份属判据层，**卡点清单与判定规则是本套材料自定的判据**。

- **证据分级 A**：心理控制与孩子抑郁、焦虑的关系［1］（元分析）、侵入式教养与内化外化症状的关系［2］（元分析，样本为 13–25 岁）、同一表现随情境与观察者而变、只看一次不足以定性［4］（对 119 项研究的元分析）。
- **证据分级 B**：家长的情绪社会化行为与孩子处理情绪的方式有关［3］（综述）。
- **证据分级 C**：把评价换成观察、把否定感受换成先接住，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：十二类卡点清单、"看位置不看数量"的三条判据、"卡点可以为零"的写法，均为本套材料自定。
