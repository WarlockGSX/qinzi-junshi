# 孩子说我不行

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：事后修复
> 一句话范围：孩子说"我不行""我笨""我做不好"时，接纳—重构—分解—看过程四步怎么走。
> 相关文件：01-child/挫折耐受与韧性.md；03-bond/鼓励与表扬（落在过程上）.md；01-child/羞耻感与自我价值.md；03-bond/风暴中的当场话术.md；07-safety/危机信号识别.md；07-safety/就医与专业转介指征.md

## 机制

### 一、这句话多数不是结论，是一句信号

孩子说"我不行"，通常分三种，处理方式不一样（分流见"识别"）：

- **当下卡住**：一件事做不下来，他说的其实是这件事难。
- **提前认输**：怕再失败，先说不行，这样"不做"就有了理由。
- **长期自我否定**：把很多次不好拼成一个关于自己的结论（"我就是笨"）。这一层连着羞耻感，见 `01-child/羞耻感与自我价值.md`。

前两种是这场对话能处理的；第三种要长期往回攒"我被接住过"的经验，见 `01-child/挫折耐受与韧性.md`。这一份只讲这一幕怎么走。

### 二、情绪还在的时候，讲道理进不去

他刚失败、还在难受时，你说"你不笨、你很聪明"，他听到的是"你嫌我弱"。强烈的情绪唤起会暂时削弱负责理性与控制的那部分脑功能，这是生理过程，不是态度［1］。所以第一步永远不是说服，是让他从情绪里出来。

### 三、反驳"你不笨"，本身也是一句评价

"你才不笨"和"你真笨"是同一类句子：都在评价他这个人。肯定落在"聪明"这类能力评价上，会让他在遇到难题时更不愿意试；落在努力和做法上，才维持得住。这项实验的对象是 10–12 岁儿童，只比较了"夸聪明"与"夸努力"，没有检验"夸结果"［2］。所以这一份的做法不是把"你不行"改口成"你行"，是把落点从"你这个人"挪到"这件事、这一步"。

### 四、能力可以长，这个想法要由你传给他

孩子愿意再试，前提是他相信"能力靠努力能长出来"。他的自我调节能力（注意、坚持、从挫折里回来）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［3］。抗挫力也不是一个人硬扛出来的，是摔了有人接着的时候一点点长出来的［4］。这两条决定了第四步为什么落在"过程"上，而不是"结果"上。

## 识别

### 一、先分是哪一种（决定你说哪一句）

| 他说的话 | 更像 | 第一句往哪儿靠 |
|---|---|---|
| "这题我不会"（还在做） | 当下卡住 | 接住 + 切小一步 |
| "反正我也做不好"（还没开始） | 提前认输 | 接住 + 只谈这一步 |
| "我就是笨""我什么都做不好"（反复、泛化） | 长期自我否定 | 接住 + 长期往回攒，见 `01-child/羞耻感与自我价值.md` |
| "我是不是很没用"（看着你） | 要一个确认 | 不急着否定，先问他怎么想到这儿 |

最后一种要小心：他问"我是不是很没用"，多数不是要你下断语，是要你看见他此刻的低落。

### 二、判断这一刻能不能谈事

他还在哭、还在气、身体绷着 → 只做第一步（接纳），谈事往后放；他能听进一句话了 → 进入第二、三、四步。顺序错了，后面全废。

### 三、分龄：同一句"我不行"，分量不同

| 学段 | 常见样子 | 你的重心 |
|---|---|---|
| **学前 3–6** | 搭不好就摔、输不起；"我不行"多半是当下难受 | 只接情绪，不讲道理 |
| **小学低年级 6–9** | 怕错、怕被笑；一难就说不会 | 接住 + 把任务切到能做完 |
| **小学高年级 9–12** | 开始把成绩和自我价值挂钩 | 把肯定从结果移到努力和办法 |
| **初中 12–15** | 一点否定就放大成"我整个人不行" | 接情绪，不接"我就是差"的结论 |
| **高中 15–18** | 常连着方向和自我怀疑 | 摆后盾：问需要，不替他安排 |

## 做法

### 四步（按顺序）

1. **接纳**：把他的话复述一遍，不反驳。
2. **重构**：把"你这个人不行"换回"这件事、这一次"。
3. **分解**：挑出一个他做得到的最小一步。
4. **看过程**：把他做到的部分指出来，落点在过程不在结果。

### 第一步 · 接纳：先说"我听见了"

不要第一句就反驳。先让他知道你没打算说服他。先把情绪接住、再说别的，是这一类对话能继续下去的前提［B1］。

> "你现在觉得自己不行。我听见了。"
> "这件事把你难住了，你很难受。"

**不要接的**："你才不笨。""这有什么难的。""你就是想太多。"这三句会让他觉得你在否认他的感受，然后闭嘴。

### 第二步 · 重构：把"人"换回"事"

把结论句式换回信息句式——只描述发生了什么、下一步动哪里，不给出"你是谁"的结论。

> ❌ "你就是不擅长这个。"
> ✅ "这次卡在最后那一步，说明这一步要再过一遍。"

> ❌ "你怎么这么笨。"
> ✅ "这块你还没弄熟。我们再走一遍。"

重构不是硬说"你可以的"。他要的是这件事有出口，不是被夸。

### 第三步 · 分解：给一个"能做完"的最小一步

> "我们不谈全部。就先从这一道开始。"
> "这一步你打算先动哪里？"

步子的标准是"他能做完"，不是"做得多"。做完一小步，他自己会拿到"我能动"的经验；自我调节就是这样在一次次实际做到里慢慢长出来的［3］。这一步也可以做得活一些：把它当成一个小关卡、做完给个击掌；对这个年龄的孩子，身体动作和玩常常比讲道理更快让他回到状态［B3］。

### 第四步 · 看过程：把做到的部分指给他

他动了之后，把落点放在过程上，具体说清你看到了什么。

> "你刚才卡住了，没摔笔，还想了一下。"
> "这道你自己检查出来了一个错。"
> "比昨天多做了两道。"

他做得一般的时候别硬夸，承认就行——"这次确实没做好，我不硬夸你"。硬夸他会更确信你在敷衍。说话前过一遍：这句话说的是"他是什么"，还是"他做了什么"［B2］。这个过程里落点的规则，见 `03-bond/鼓励与表扬（落在过程上）.md`。

### 他说这些时的接法

| 他说 | 接法 | 可以照说 |
|---|---|---|
| "我不会" | 接住 + 切小一步 | "那就先做这一道。做不完也没关系，我们先看看它难在哪。" |
| "反正我做不好" | 不辩论，只谈这一步 | "你现在是这么觉得。我们先不说做得好不好，就说下一步动哪。" |
| "我真笨" | 不接结论，接事 | "你有这一件事卡住了。'笨'是另一件事，我们不说它。" |
| "你只是安慰我" | 不哄，说具体 | "我不是安慰你。我刚才看到的是——你重做了三遍。" |
| "我不想再试了" | 允许停，留门 | "可以今天不试，先歇着。等你想动的时候叫我。" |
| "为什么别人都行" | 不比较，回到他自己 | "你和他不一样。你比上星期多会了什么？" |

### 事后补一句

过一两天，找个平静的时候提一句他当时做到的地方。事后的一句，比当场十句记得住。他还在情绪里时，先停在这里，走 `03-bond/风暴中的当场话术.md`。

## 边界

| 不要做 | 原因 |
|---|---|
| 用"你才不笨"反驳 | 那也是一句评价，他会觉得你在否认他 |
| 当场讲道理、摆证据 | 情绪里听不进，还会觉得被嫌弱 |
| 硬夸"你已经很棒了" | 他会更确信你在敷衍 |
| 把"我不行"当预言 | 你越担心，越容易替他做、替他挡 |
| 翻旧账、拿他跟别人比 | 把一件事变成对人的判断 |
| 用"我为你付出这么多"施压 | 把难受换成欠债，也是羞耻 |
| 逼他当场再来一次 | 先把情绪接住，试不试由他定 |

**核心：不要跟他争"你行不行"，把话题从他的"人"挪到"这件事、这一步"。**

## 升级信号

- **持续自我贬低**（"我什么都做不好""没有我更好"）或出现自伤 → 立即走 `07-safety/危机信号识别.md`。
- **一次挫折后明显退缩**（不想上学、回避同伴、失眠、身体不适）持续两周以上 → 见 `07-safety/就医与专业转介指征.md`。
- **长期硬撑、从不在人前露情绪，同时出现身体症状** → 见 `07-safety/就医与专业转介指征.md`。

## 依据说明

本份属情景做法层，机制依据来自 `01-child/挫折耐受与韧性.md`。

- **证据分级 B**：情绪唤起暂时削弱前额叶功能［1］（机制综述）；表扬落点与动机、遇挫表现有关——412 名 10–12 岁儿童的实验，只证明"夸聪明"有害、"夸努力／过程"有益，未检验"夸结果"［2］；自我调节随发育逐步形成并受环境影响［3］（发展心理学综述）；韧性来自可用的保护系统、有人接住的挫折才成经验［4］（经典综述）。
- **证据分级 C**：把"我不行"分成当下卡住／提前认输／长期自我否定，属常见框架，用于分流，不对孩子作定性；先接情绪再谈事、描述事不评价人，对应到书［B1］［B2］。第三步里把最小一步做得活一些，对应到［B3］。
- **证据分级 D**：接纳—重构—分解—看过程四步、"他这样说你接什么"对照表、分龄重心表，为本套材料自定；
