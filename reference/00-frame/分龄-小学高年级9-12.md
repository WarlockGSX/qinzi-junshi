# 分龄-小学高年级9-12

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：预防促进
> 一句话范围：9–12 岁：命令式换教练式，是关系调整的最佳窗口。
> 相关文件：00-frame/分龄-小学低年级6-9.md；00-frame/分龄-初中12-15.md；03-bond/顶嘴与对抗的应对.md；04-family/家庭规则的制定与执行.md；05-outside/考试焦虑与成绩落差.md

## 机制

### 一、自主需求已经起来，命令式开始失灵

9–12 岁的孩子在推着自己往前走：想自己决定穿什么、怎么排时间、跟谁玩。同一句要求，前一两年他一听就做，现在他会先问"为什么""凭什么"。这不是态度变差，是自主需求上来了。你还用"我说了算"的方式说，他就用顶、拖、沉默来回应这件事本身。

### 二、有自我管理的意愿，但计划能力还不够

他想自己管，也确实管不好：知道该写作业，但排不出顺序；知道快到时间了，但估不准要多久。所以这一段的做法不是替他管，也不是完全放手，而是**把管理者换成教练**——你不再下指令，你把决定权还给他，同时留在旁边让他能问。

### 三、这是关系调整最佳窗口的原因

三个条件在这一段同时成立：他还愿意跟你说话；他生活上、情绪上仍然需要你；但他的自主意识已经起来了。这时候把"我定、你听"换成"你定、我陪"，成本最低。等进入初中，情绪强度和同伴影响再上一档，同一件事要花的力气会更大。所以窗口的逻辑是：**现在改，比以后改容易。**

### 四、控制越多，问题越多

用内疚、撤回关爱、替他做所有决定去控制（心理控制），与孩子的抑郁、焦虑水平相关［4］；侵入式管控与青少年（13–25 岁）的内化、外化症状也存在稳定关联，管得越紧并不等于结果越好［5］。反过来，"高要求 + 高回应"的做法，长期适应结果优于"高要求 + 低回应"［1］。教养方式与学业成绩之间也有稳定关联，但这是关联，不是因果［2］。

### 五、肯定的落点仍然决定动机

这一年龄同样如此：肯定落在"聪明""名次"上，遇到难题时动机反而下降；落在过程与努力上，才守得住［3］。

### 六、面子和同伴，开始压过家长的评价

这一年龄，同伴的评价第一次和家长的评价差不多重，他要在同伴面前维持一个"我说了算"的样子。同一句批评，私下说和当众说的效果差很多——当众说，他为了保住那个样子，会加倍顶回来。这不是他更不尊重你，是他不敢在同伴面前输。

## 识别

### 一、这一份的使用时机

- 你一给命令，他就顶、就拖、就沉默；
- 他还愿意跟你讲学校里的事——这就是窗口正在开；
- 你替他什么都安排好，他反而越来越不动；
- 你一当众说，他的反应比私下大得多。

### 二、这件事的目标："听我的"还是"学会自己管"

| 事情性质 | 你的位置 | 做法 |
|---|---|---|
| 涉及安全和底线（作息、安全、去哪个地方） | 你定，但说清理由 | 立规则并执行，见 `04-family/家庭规则的制定与执行.md` |
| 是他自己的事（作业顺序、零花钱怎么花、房间怎么收） | 你退到教练位 | 把决定权还给他，你只问和陪 |
| 是关系里的话（顶嘴、态度） | 先处理情绪，不处理对错 | 见 `03-bond/顶嘴与对抗的应对.md` |

### 三、私下说，别当众说

这一年龄开始要面子，当众被说的反弹是私下的数倍。同一句话，回家关起门说，效果完全不同。

## 做法

### 一、把命令换成提问

教练式不是不要求，是换一种说法：把"你要怎样"换成"你打算怎样"。一个问题交回决定权，他就少了对抗的理由。

### 二、可以直接照说的原句

**把决定权交回去：**
> "这件事你打算怎么办？需要我做什么？"

**让他自己排、自己报：**
> "今天几样作业？你自己排个顺序，排完告诉我大概几点能收工。"

**给两个都在边界内的选择：**
> "现在做，还是七点开始？你自己定。"

**看流程，不盯细节：**
> "我不看你写什么，我看你有没有按自己说的做到。"

**允许有不同意见，但限定表达方式：**
> "你可以有不同意见，我们用说的，不是用摔门。"

**承认他懂的地方，让他先讲：**
> "这部分你比我清楚，你先说说你的想法。"

**示范修复，不当场翻脸：**
> "刚才那句话我说重了，我收回。这件事我们重新说。"

**给台阶、留时间：**
> "你不想现在聊也行。晚饭后你想说的时候，我随时在。"

给有限的选择、把决定交回给他，是这一段能减少对抗的关键［B1］［B2］；让他对自己的事有参与和选择，也是阿德勒式取向里养自主的做法［B3］。

### 三、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "凭什么？" | 给理由，不压他 | "我说下为什么，你听完可以提你的想法。" |
| "不用你管！" | 不退到零，也不顶着 | "行，这件事你自己来。要我帮的时候叫我。" |
| 答应了自己没做到 | 按约定，不翻旧账 | "我们说好的这条，现在怎么处理？" |
| 当众顶你 | 不当场升级 | "回家再说。"（当场一句带过） |
| "你就是偏心" | 不辩论偏心不偏心 | "你觉得我哪儿偏了，你说一件，我听着。" |
| 考砸了不吭声 | 先接情绪，不问名次 | "这次你自己也知道。你先说说怎么回事。" |

### 四、一直是命令式时的逐步退法

不要一天全退，按这个顺序，每退一步观察一两周再退下一步：

1. **先换语气，不换决定。** 还是你定，但用商量的位置说，不用压的位置说。
2. **再把范围里的选择给他。** 结果你保证，路径他决定。
3. **再把整件事交给他，你只问进度。** 事先说好一个反馈时间点。
4. **最后只保留安全和底线这一部分由你定。**

退的位置是"怎么决定"，不是"有没有边界"。底线部分不退。

## 边界

| 不要做 | 原因 |
|---|---|
| 还用"我说了算"的命令式 | 自主需求已上来，命令只会换来顶和拖 |
| 当众批评、当众比较 | 这一年龄要面子，当众说会加倍反弹 |
| 用内疚、撤回关爱去控制 | 心理控制与孩子的抑郁、焦虑相关［4］ |
| 替他安排每一分钟 | 侵入式管控与青少年内化外化症状相关［5］ |
| 把成绩当成评价他这个人 | 他会把做事和"我行不行"绑在一起［3］ |
| 只在他考砸时才出现 | 关心只连着成绩，他就只报成绩 |
| 现在不改，等初中再说 | 窗口会关：现在改比初中改容易 |

**核心：从"我定、你听"退到"你定、我陪"。退的是位置，不是原则。**

## 升级信号

- **明显退缩与孤立**：长期不愿出门、不和朋友来往、总说身体不舒服躲开学校 → 走 `05-outside/校园欺凌与同伴冲突.md`、`05-outside/被孤立与社交困难.md`。
- **持续两周以上的低落或易怒**：兴趣减退、睡眠饮食明显改变、拒绝上学 → 走 `07-safety/就医与专业转介指征.md`。
- **家里控制越收越紧、亲子冲突每周多次且持续两周以上** → 先处理你这一侧：`02-parent/家长情绪急救.md`。
- **出现自伤或说"活着没意思"** → 立即走 `07-safety/危机信号识别.md`；紧急情况拨 110／120，心理援助热线 12356。

## 依据说明

本份属机制层，是分龄五份中的小学高年级一段。

- **证据分级 A**：教养方式与学业成绩的关系（元分析，关联非因果）［2］、心理控制与抑郁焦虑的关系（元分析）［4］、侵入式教养与内化外化症状的关系（元分析，样本为 13–25 岁青少年／青年）［5］。
- **证据分级 B**：教养方式与青少年适应结果的关系（高要求 + 高回应优于高要求 + 低回应）［1］——Baumrind 对青少年的研究；评价性反馈削弱内在动机［3］——以 10–12 岁儿童为对象的实验研究。
- **证据分级 C**：教练式提问、把决定权交回、先私下后当众，属成熟育儿框架与阿德勒取向，对应到书［B1］［B2］［B3］。
- **证据分级 D**："窗口"这一判断、按事情性质分三种位置、本段的原句与边界，为本套材料自定。
