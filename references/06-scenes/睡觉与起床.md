# 睡觉与起床

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：当场应对
> 一句话范围：睡前那半小时怎么不再拉锯、第二天早上怎么把起床气接住——这一幕从头到尾怎么走。
> 相关文件：06-scenes/日常配合（刷牙洗澡穿衣）.md；03-bond/家庭仪式与固定动作.md；06-scenes/屏幕与手机.md；06-scenes/早上出门磨蹭.md；01-child/分离焦虑与重聚.md

## 机制

### 一、睡前冲突的起点常常在睡前一到两小时

睡前固定流程指的是入睡前约一小时里那串固定动作。它对孩子的意义是**给出"接下来会发生什么"的预期**，让入睡这件事从"你说让我睡"变成"顺序走到这一步了"。这类流程与更早入睡、更快入睡、夜醒更少，以及孩子情绪、家庭功能更好之间存在关联（综述证据，多为横断面与家长报告，属关联）［1］。

流程对年龄小的孩子作用最明显。进入小学高年级以后，流程要缩短、交给他自己执行；否则它会变成又一件你催他做的事。

### 二、晚上少睡的一小时，会在第二天还回来

前一晚少睡的那一小时，通常会在第二天以更难带的形式还回来。急性、不可控的压力，会快速削弱前额叶负责抑制冲动、保持信息、做判断的功能，人更容易被当下的反应带走［3］；晚睡造成的疲劳，会让这套本来就吃紧的自控更不好用，第二天以起床气、白天冲突、写作业更慢的形式出现。**你处理的是前一天晚上，看到的却是第二天早上。**

孩子的自我调节能力（包括自己安静下来、自己按顺序做事）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［4］。

### 三、青春期晚睡有一部分是生理的

进入青春期后睡眠相位后移，孩子客观上要更晚才有睡意，而上学时间不变。有元分析（28 项研究、177 万余人）显示，更晚的上学时间与青少年睡眠时间更长、负面情绪更少相关；这种关联对高中生的**困倦感**比对初中生更强。多数研究靠自我报告，效应量偏小，属关联［2］。

也就是说，**他躺在床上很晚还醒着，不完全等于玩手机或对抗。** 睡眠相位后移与这个阶段的大脑发育有关［B4］。这个阶段要守的是"总睡眠时长"和"固定起床点"，不是"必须几点闭眼"。

### 四、起床气的机制

起床那一刻同时发生两件事：睡眠被打断，负责情绪控制的前额叶还没有完全上线。表现出来就是哭、发火、不说话、赖着不动。**这是他还没醒，不是他针对你。**

你在这个时间点讲道理、翻旧账、说"又要迟到了"，只会把起床这件事和"早上要挨一顿"绑起来，第二天更不愿意起。妈妈自己的情绪调节，与 6–8 岁孩子的情绪调节之间存在纵向关联（单项纵向研究，98 对母子）［5］，所以早上那句话的**语气**比内容更管用。

### 五、分龄：睡前和起床的主导方

| 学段 | 睡前流程 | 起床 |
|---|---|---|
| **学前 3–6** | 你全程主导，4–5 步固定顺序 | 你叫，允许 5–10 分钟过渡，用身体接触 |
| **小学低年级 6–9** | 你定顺序，他执行，用图片或闹钟提示 | 你叫一次 + 一个闹钟；前一晚约定好 |
| **小学高年级 9–12** | 他自己排，你只看有没有按时开始 | 他自己按闹钟，你只在他明确求助时叫 |
| **初中 12–15** | 他主导，你守"设备不进卧室" | 起床归他；你只负责不再兜底 |
| **高中 15–18** | 完全归他；你守住睡眠底线不再逐条查 | 完全归他；迟到后果由他承担 |

### 六、把起床交回去的原因

家长管得越细、越拿后果施压，孩子越难长出自己管自己的能力；侵入式管控与青少年的内化、外化问题相关（三层元分析，样本为 13–25 岁青少年与青年，属关联）［6］。起床是他自己生活里最容易交回的一件事，代价只是"迟到一次"。

## 识别

### 一、先分清是哪一种"不睡"

| 现象 | 更像 | 方向 |
|---|---|---|
| 上床前越玩越兴奋、不肯结束今天 | 没有流程，缺结束信号 | 用自己的流程，见做法一 |
| 一关灯就说怕、要人陪、反复出来 | 怕分开，不是不困 | 走 `01-child/分离焦虑与重聚.md` |
| 躺很久不睡、白天也晚起 | 可能是睡眠相位后移 | 守固定起床点，不逼"几点闭眼" |
| 到点还在用手机／平板 | 屏幕占了睡前 | 走 `06-scenes/屏幕与手机.md` |
| 长期入睡困难、打鼾、夜里醒很多次 | 可能不是沟通问题 | 见升级信号 |

### 二、再分清是哪一种"起不来"

| 现象 | 更像 | 处理方向 |
|---|---|---|
| 叫醒后哭闹几分钟，然后是清醒的 | 起床气，没睡够 | 前一晚提早就寝、给过渡时间 |
| 醒了但不动，直到你发火才起 | 责任在你手里 | 把闹钟和后果交回他 |
| 每天都起不来、白天也困、上课走神 | 睡眠量确实不足 | 先算总时长，再谈方法 |
| 一起来就说肚子疼、不想上学 | 可能是回避上学 | 走 `05-outside/上课走神与学习困难.md` |

### 三、先算一笔睡眠账

把他平时几点上床、几点真正睡着、几点起、周末补多久，摊在纸上。**大多数"起床气"在这一步就有答案了**，不用先归到态度上。

## 做法

### 一、睡前固定流程：四步，全程不超过一小时

1. **定一个"今天到此为止"的信号**：收玩具、关屏幕、拉窗帘，动作要固定。
2. **排 3–4 步不会变的事**：洗澡／刷牙／换睡衣／读一段书，顺序固定，别天天换。
3. **把选择留在小处**：不问"睡不睡"，问"今天先刷牙还是先换衣服""读一本还是两本"。给有限的选择，比直接命令更能让他配合［B1］。
4. **结束语固定**：同一句话、同一个动作，说完就离开。反复回去会让他把"再叫一次"当成流程的一部分。

### 二、一个可复制的睡前开场

> （到点，站在门口，不隔空喊）"还有十分钟今天收工。你想先洗澡还是先挑明天穿的衣服？"
> （他讨价还价）"今晚就两本，说好了。明天想看，我们早点开始。"

要点：**提前给时间点、只在小处给选择、说好的数量不临时加。**

### 三、可以直接照说的原句

**还没玩够（3–6 岁）**
> "我们再玩最后两次，然后就去刷牙。你来数。"

**躺下又爬起来（3–6 岁）**
> "我知道你还不想睡。我在这儿坐三分钟，三分钟以后我关灯走。"
> （说完就走，不因为他又叫一次而回来。）

**他嫌流程幼稚（9–12 岁）**
> "流程你自己排，排完贴在墙上。我只提醒一次，剩下的你自己看着办。"

**已经很晚还在拖（12–15 岁）**
> "现在十一点，你要继续我也拦不住。但明早七点我叫一次，起不来迟到的是你。"

### 四、起床这一幕的走法

**前一晚先说好，早上的话越少越好。**

1. **前一晚定好三件事**：闹钟几点、谁按、起不来多久之后你再叫一次。
2. **早上先开灯、拉开窗帘、给他一个身体过渡**，不隔空喊话。
3. **第一次叫，只报事实加时间**，不评价：

> "七点了。还有四十分钟出门。"
> "我九分钟后再进来一次。"

4. **起床气上来了，先不讲道理、不追进度**。他已经情绪起来时，按 `03-bond/风暴中的当场话术.md` 处理，出门的事等平复后再说。
5. **到点你该走就走**。不是威胁，是把时间表交给他——他就是要为一个明确的后果负责，而不是为你的情绪负责［B2］。

**分龄可以说的话：**

**6–9 岁**
> "早上好。我先把窗帘拉开，你在床上再躺两分钟，然后自己穿。衣服在这儿。"

**9–12 岁**
> "七点十分了。你的闹钟响过了，我不再叫第二次。早饭在桌上。"

**12–15 岁**
> "七点二十。今天要不要我在车上给你带点吃的？出门时间是你自己定的。"

### 五、把责任交回去的三个动作

1. **把"叫醒"和"催出门"拆开**。你可以叫他，但不负责把他推起来。
2. **允许一次真实的后果**：迟到一次、被老师记一次，比你说一百遍有用。让后果由他自己的选择带来，比家长单方面施压更能减少对抗［B3］。
3. **不再兜底**：不再帮他找迟到的理由、不再替他收拾。

### 六、流程养成的节奏

新流程头一周一定会有反复。**只改一件事、连续两周只盯这一件**，改成了再动下一件。不要第一晚就上全套，第二天没做到就判定"没用"。

## 边界

| 不要做 | 原因 |
|---|---|
| 睡前临时加戏（"再读一本""再聊五分钟"） | 会让流程失去结束点 |
| 关灯后又回去回应每一次叫唤 | 他会把"再叫一次"当成流程 |
| 早上用"要迟到了"催起床 | 把起床和恐慌绑在一起，第二天更难 |
| 掀被子、开大灯、泼冷水 | 用身体手段让他起床，换来的是更激烈对抗 |
| 用"今天不许玩手机"罚晚睡 | 会把它变成长久的战场（见 `06-scenes/屏幕与手机.md`） |
| 一直替他兜底（叫五遍、帮他找借口） | 他就永远不需要自己起 |
| 拿别人的孩子比 | 比较不产生习惯，只产生对抗 |
| 一次没做到就加码惩罚 | 把"起不来"这件事变成你和他之间的一次输赢 |

**核心：晚上守的是"顺序"，早上守的是"时间点"，两件事都不要变成当天早上现谈。**

另外：小学低年级以下，孩子的自我调节还在发育中，起不来多半不是态度问题［4］；这个阶段你叫他是应该的，只是别把情绪也搭进去。

## 升级信号

- **长期入睡困难、夜里反复醒、明显打鼾或呼吸停顿、白天极度困倦** → 先到医院看睡眠相关的问题，不当作沟通问题处理（见 `07-safety/就医与专业转介指征.md`）。
- **持续两周以上因为睡眠严重不足影响上学、情绪明显低落** → 走 `07-safety/危机信号识别.md`。
- **每天早上都以你失控收场**（吼、摔东西、动手）→ 先处理你这一侧：`02-parent/家长情绪急救.md`。
- **孩子说"活着没意思"或出现自伤** → 立即停止作息议题，走 `07-safety/危机信号识别.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：更晚上学时间与青少年睡眠更长、负面情绪更少相关［2］（28 项研究、177 万余人、元分析；对高中生困倦感的关联强于初中；效应量偏小、多为自我报告，属关联）；侵入式管控与青少年的内化、外化问题相关［6］（三层元分析，样本为 13–25 岁青少年与青年，属关联）。
- **证据分级 B**：睡前固定流程与更早、更快入睡及孩子情绪、家庭功能更好的关联［1］（叙述性综述，多为横断面与家长报告，属关联）；急性、不可控压力快速削弱前额叶的抑制冲动、保持信息等功能［3］（机制综述，未给具体时长）；自我调节能力随发育逐步形成、受环境影响［4］（综述）；妈妈的情绪调节与 6–8 岁孩子情绪调节的纵向关联［5］（单项纵向研究，98 对母子，间接路径未达显著）。
- **证据分级 C**：固定流程四步、把起床责任交回、自然后果与逻辑后果、给有限选择，属成熟育儿框架，对应到书［B1］［B2］［B3］［B4］。
- **证据分级 D**："不睡""起不来"的分流表、睡眠账、可复制睡前开场、分龄照说句、三个把责任交回去的动作，为本套材料自定。
