# 丧亲与重病

> 适用对象：家长
> 生态层：家庭层（家庭内部）
> 适用时机：预防促进
> 一句话范围：怎么告诉孩子、怎么陪他度过；如实但有分寸。
> 相关文件：06-scenes/难以启齿的真相（死亡疾病争吵）.md；04-family/家庭结构与孩子的适应.md；01-child/恐惧与焦虑.md；01-child/孩子的表达方式与信号.md；02-parent/撑不住时的自我照顾.md；07-safety/危机信号识别.md；07-safety/就医与专业转介指征.md

## 机制

### 一、孩子对"死亡"的理解是分年龄长出来的

死亡不是一个单一概念，它由几个成分组成：**普遍性**（所有活的东西都会死）、**终结性**（死了不能回来）、**功能性停止**（身体不再运作）、**因果性**（死亡由某些原因造成）［3］。孩子是分步掌握这些成分的：5 岁前先理解"普遍性"，大约 5 岁前后理解身体功能停止，6 岁左右理解死亡有各种原因；掌握的顺序和快慢有个体差异，不是一条直线。

孩子对这些的理解，主要来自**和家人对话、问问题、接触文化产品和参加仪式**；对死亡的生物性理解和宗教／灵性解释可以在他脑子里并存，不一定互相排斥［3］。

给家长的直接含义：

- **幼儿常把死亡看成暂时的、可逆的**——像睡觉或出门，所以会反复问"他什么时候回来"。反复回答同一个问题，是这一段的正常任务，不是他没听进去；
- **小学生开始明白不可逆**，也正是最容易**把责任揽到自己身上**的阶段（"我上次说讨厌他"会被他当成原因）；
- 年龄越大，理解越接近成人，但情绪表达可能越藏。

### 二、孩子怕的往往是"不知道"和"没人管我了"，不是真相本身

对父母患绝症的家庭做的一项系统综述（14 项研究、4–18 岁的孩子 654 名）得到的一致结论是：**孩子想被告知、想参与、想为将要发生的事做准备；"把他保护起来、什么都不说"并不是他需要的**；诚实、开放的沟通，和"把日常维持住"，对孩子有帮助［4］。

也就是说，问题的关键不是"要不要说"，而是"怎么说、说多少"。孩子在信息真空里会自己填空，而填出来的版本通常比事实更可怕——尤其当大人表现得很反常却什么都不说的时候。

### 三、哀伤不是一条直线，会反复

哀伤反应有个体差异，也会反复：好一阵、差一阵，遇到纪念日、节日、生日、开学、看到类似场景，可能又来一次［1］。**这不是"退步"，也不是"还没走出来"，是哀伤本来的样子。** 哀伤会随时间慢慢缓和，但快慢因人而异，不要拿时间表去卡他。

### 四、孩子的状态，很大程度由剩下的大人决定

系统综述看到：当**家长本人得到支持**时，会更有能力支持孩子；同时，在孩子这边的干预里，改善最明显的是"创伤性哀伤"，而对家长来说，改善的是"被支持感""温暖""正面教养"和自身心理健康［2］。权威指南也指出：孩子的情绪和行为，与剩下那位家长和其他大人的反应有关［1］。

结论很实际：**先照顾大人，是大人的任务，也是对孩子最直接的一件事。** 大人绷着、崩塌着、或一直回避不谈，孩子就没有可以参考的稳定点。依恋关系为理解一个人在丧失后的反应提供了框架［B1］。

### 五、孩子会把责任揽到自己身上

小孩子的思维常带"自我中心"：他会把"我生过他的气""我没好好听话"这类普通的事，跟死亡连起来，认定是自己造成的。这个错误归因不会自己消失，需要大人主动、明确地解除。

## 识别

### 一、先分清现在是什么情境

| 情境 | 你要处理的核心 |
|---|---|
| **家人重病（还在治）** | 给确定的信息、维持日常、给他参与的机会 |
| **家人刚去世（几天内）** | 用清楚的话告知、说清他接下来怎么办 |
| **去世一段时间后** | 允许反复、接住纪念日的情绪、不装作没事 |
| **孩子自己在问"你会不会也死"** | 接住恐惧，给诚实的安慰，不糊弄 |

### 二、孩子不同年龄能理解的程度

| 学段 | 大致理解 | 你的话往哪儿靠 |
|---|---|---|
| **学前 3–6** | 常以为死亡是暂时的、可逆的；会反复问 | 简短、具体，反复回答同一个问题，用"死"这个词 |
| **小学低年级 6–9** | 开始明白不可逆；容易自我归因 | 明确说"不是因为你"，给出日常安排 |
| **小学高年级 9–12** | 理解接近成人，会关心细节，也可能藏情绪 | 给信息、允许提问、给他一件能做的事 |
| **初中 12–15** | 明白，但可能表现为愤怒、疏离、否认 | 不逼谈，留一句"你想说的时候我在" |
| **高中 15–18** | 理解完整，会担心"这对我的将来意味着什么" | 给关于以后的确定信息，允许他悲伤也允许他继续生活 |

### 三、正常的哀伤，和需要额外关注

| | 正常哀伤 | 需要额外关注 |
|---|---|---|
| 时间 | 一阵好一阵差，随时间逐步减轻 | 持续半年以上不见好转，或越来越重 |
| 功能 | 还能上学、吃饭、睡觉、和人来往 | 明显拒学、吃睡长期紊乱、退到不出门 |
| 情绪 | 有波动，也能被安慰 | 长期麻木、说"活着没意思" |
| 行为 | 发脾气、黏人、退行、反复问 | 自伤、动手伤人或被伤 |

右边占两条以上，见 `07-safety/就医与专业转介指征.md`。

## 做法

### 一、把坏消息告诉孩子：分步，附可照说的原句

1. **找个安静的时间，用平常的语气。** 不要铺垫太久、不要先哭一场再开口；他需要能听清楚。
2. **用"死"这个词。** **不要用"睡着了""走了""去很远的地方旅行了"**——幼儿会字面理解，然后怕上床睡觉、怕你出门。
3. **只说能确定的事。** 不知道的不说；不确定的说"还不确定，知道了我会告诉你"。**不承诺你做不到的。**
4. **说清楚"接下来你怎么办"。** 他真正想知道的常常是：住哪、谁管我、还上不上这个学。
5. **说完停下来。** 允许他哭、允许他没反应、允许他接着问，也允许他转身去玩——**当场没有大哭，不等于不难过。**

重病（人还在）：

> "有件事我要告诉你。奶奶生病了，是癌症，这个病很重。现在正在治，医生说会尽力。我会一直把进展告诉你，你有任何问题都可以问，不管多难回答。"

去世：

> "我要告诉你一件很难过的事。爷爷今天去世了。去世就是，身体不再工作了，不会再醒过来，也不会再回来。这件事不是因为你，也不是你做错了什么。"
> "接下来你还是跟我一起住，还是上原来的学校，周末照样可以去找朋友。有变化我会提前告诉你。"

### 二、重病期间能做的三件事

- **保持日常。** 上学、吃饭、睡觉的节奏尽量不变；"维持正常"对孩子是有帮助的［4］。
- **给参与的机会。** 孩子想帮忙、想去看、想问，允许；他想做点小事（画画、陪着说话），比把他支开更好［4］。
- **诚实，但按他的年龄给量。** 不隐藏"这件事很严重"，也不把成人的恐惧和全部细节倒给他。他问什么答什么，答不上就说"我还不知道"。

可以照说：

> "你想去医院看他，可以。但你要先知道，他现在看起来很累、身上有管子，可能不太能说话。你要是待不住，随时可以出来。"

### 三、去世之后能做的

- **让他参与告别。** 多数情况下，让孩子参加某种形式的告别是有帮助的：**提前告诉他现场会是什么样**（有哪些人、会发生什么），并给他一个可以随时退出的选项。不强迫。
- **允许他反复问、反复难过。** 同一个问题问十遍，就答十遍。这是他在慢慢消化［1］。
- **不装作没事。** 你可以说"我今天也很难过"，但要接一句"我会照顾好自己，也有人帮我"。
- **留一个可以纪念的动作。** 一起看照片、留一件东西、在某个日子做一件固定的事——固定的纪念动作，能让"想起他"有一个去处。

### 四、他这样反应，你这样接

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| 反复问"他什么时候回来" | 不敷衍、不解释过多，平静重复 | "他死了，不会回来了。我知道你很想他。" |
| 说"是不是因为我" | 直接、明确地解除归因 | "不是因为你。这不是你做错什么造成的。" |
| 完全不哭、照常玩 | 不催他哭，也不说他"冷血" | "你什么时候想说他，我都听。" |
| 突然发脾气、打人 | 接住情绪，不惩罚情绪 | "你特别气、特别难过。气可以，打人不行。" |
| 退行（尿床、要抱、不敢独处） | 当成需要的信号，多陪 | "这几天你想跟我睡就跟我睡。" |
| 问"你会不会也死" | 诚实、给具体安慰，不空口保证 | "我暂时很健康。我会照顾好自己，就为了陪着你。" |

接住情绪、不评价情绪，是这些接法的共同点［B2］；把强烈情绪当成一个需要，而不是一个问题，是这一段的底线［B3］。

### 五、剩下的大人，先照顾自己

你稳不住，孩子就没有可以参考的稳定点；而"家长得到支持后更有能力支持孩子"是有证据的［2］。所以找大人接住你自己（伴侣、亲友、咨询），不要让孩子接住你。

> （孩子看你难过，过来安慰你）"谢谢你。这是大人的难过，我自己会处理，也有人陪我。你不用管。"

你自己长期撑不住时，见 `02-parent/撑不住时的自我照顾.md`。

## 边界

| 不要做 | 原因 |
|---|---|
| 用"睡着了""去远方了"代替"死" | 幼儿会字面理解，产生睡怕、分离怕 |
| 说"你要坚强，不许哭" | 情绪被堵住，会从别处冒出来 |
| 把孩子支开、什么都不告诉他 | 他会在信息真空里编一个更可怕的版本［4］ |
| 让孩子替你扛（"你要照顾好妈妈"） | 把成人的重量压到他身上 |
| 用你自己都不信的宗教说法硬灌 | 他会混淆，且以后不信任你说的话 |
| 承诺做不到的（"我永远不会离开你"） | 空头保证一旦落空，破坏信任 |
| 葬礼上让他独自面对一群陌生人的追问 | 提前说清现场、给他退出的出口 |
| 把"他看起来很坚强"当成他没事 | 藏起来的情绪也会累积 |

**核心：如实，但有分寸——不隐瞒事实，也不把成人的恐惧和细节全交给他。**

## 升级信号

- **立即（当天）**：孩子说"活着没意思""我想去找他"，或出现自伤动作 → 先保安全，联系 **110／120**；心理援助热线 **12356**。见 `07-safety/危机信号识别.md`。
- **尽快（一周内）**：持续半年以上功能明显受损（拒学、吃睡长期紊乱、退到不出门）、长期麻木或强烈回避与逝者有关的一切 → 见 `07-safety/就医与专业转介指征.md`。
- **大人自己长期撑不住** → 见 `02-parent/撑不住时的自我照顾.md`。

## 依据说明

本份属机制层。

- **证据分级 A**：哀伤反应会反复、遇纪念日与重要节点易再起、随时间缓和，孩子的情绪和行为与在世家长的反应有关［1］（权威机构指南）；孩子想被告知、想参与、诚实开放沟通与维持日常有帮助［4］（系统综述，14 项研究、654 名 4–18 岁孩子）；家长得到支持后更有能力支持孩子、相关干预对家长温暖与心理健康的改善［2］（系统综述，17 项研究，含 15 项随机对照研究）。
- **证据分级 B**：儿童对死亡各成分的理解分步获得、主要通过与家人对话与参与仪式形成［3］（综述，Child Development Perspectives）。
- **证据分级 C**："让孩子参与告别""留一个固定的纪念动作"，属常见框架与经验说法，没有统一规则，按孩子的意愿与家庭情况选择。五步告知法及重病／去世两套可照说原句、"他这样反应你这样接"对照表、分年龄说法差异，为本套材料自定。依恋关系为丧失后的反应提供框架，对应［B1］；接住情绪再谈事，对应［B2］；把强烈情绪当作需要而非问题，对应［B3］。
