# 平静期的预防与预演

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：预防促进
> 一句话范围：平时怎么打底，把冲突提前化解掉一部分。
> 相关文件：03-bond/开口与演练.md；03-bond/家庭仪式与固定动作.md；03-bond/依恋互动与安全感.md；03-bond/亲子互动的底层机制.md；03-bond/风暴中的当场话术.md；02-parent/家长情绪急救.md

## 机制

### 一、平时互动的质量决定冲突时好不好谈

平时正向互动多，遇到分歧时两个人更容易谈下去；平时只有要求和批评，一件小事就会升级。日常有稳定常规和仪式的家庭，孩子的适应更好（综述研究，属关联）［1］。所以预防的重点不是冲突时多说什么，是平时把关系基础铺好。

### 二、打底的做法与消耗的做法

| 在打底 | 在消耗 |
|---|---|
| 只跟人、不跟事的相处时间 | 见面就检查、催促、纠错 |
| 他说话时你听完 | 他说一半你就接过去 |
| 主动的、不带条件的接近 | 只在有事、有要求时才找他 |
| 一致、可预期的回应 | 同一件事今天行、明天不行 |

一致的敏感回应与依恋安全感相关（元分析，效应量为小到中等）［2］；依恋安全与孩子从情绪里恢复的能力关系更稳定（系统综述）［3］。孩子敢于往外走，是因为他知道有一个随时能回去的、稳定的位置［B4］。

### 三、"预演"是提前把可预见的冲突排掉

预演分两种，分工不同：

| 谁练 | 练什么 | 去哪里 |
|---|---|---|
| 你自己练 | 要谈一件事，先把话练顺 | `03-bond/开口与演练.md` |
| 和孩子一起练 | 提前把会起冲突的场景走一遍 | 这一份 |

和孩子一起预演，就是把"如果—那么"提前说给他听。预先约定"到什么条件做什么"，到了现场不用再临时谈判；有具体计划，比只有目标更可能按计划做到（元分析）［4］。

### 四、打底不等于补课

打底是平时持续的；补课是冲突后回头处理。这一份只讲打底。冲突当场走 `03-bond/风暴中的当场话术.md`，事后修复走 `03-bond/平复后的修复话术.md`。

## 识别

### 一、"平静期"的判定

没有正在烧的事、两个人都没有情绪上来的时候，就是平静期。它不需要整块时间，五分钟、睡前、接送路上都算。

### 二、先看平时关系够不够

问自己三个问题，哪个答不上来就补哪个：

1. 最近一次不为任何事、只是在一起待着，是什么时候？
2. 最近一次他主动跟你说一件事，你说完"我听着"，是什么时候？
3. 最近一周，他有没有主动来找过你（不是有求于你）？

三个问题有两个答不上来，先别急着"谈大事"，先用几天把关系补齐。

### 三、分清是"平时关系不够"还是"规则不清"

| 表现 | 更像是 | 先做什么 |
|---|---|---|
| 平时关系还行，一遇到某件事就冲突 | 规则不清 | 走 `04-family/家庭规则的制定与执行.md` |
| 什么都容易起冲突，一点就着 | 平时关系不够 | 先补关系，用这一份 |
| 只有你自己特别上头 | 你这一侧 | 走 `02-parent/家长情绪急救.md` |

## 做法

### 一、每天留一段"只跟人、不跟事"的时间

五到十分钟，不检查作业、不谈表现、不提要求。做什么由他定。

> "这十分钟不聊作业，你想干嘛都行，我陪你。"

关键：这段时间里他说的任何事，你都先不纠正。这不代表你同意，只代表这段时间不处理问题。孩子情绪在的时候，先把感受接住、再往下讲，比先讲道理有效［B3］；日常稳定的连接，是情绪辅导这类做法的共同前提［B1］。

### 二、把连接放进已有的固定动作里

不必新增一件事。洗漱、吃饭、送他上学的路上，都可以拿来连接。

> （睡前）"今天有一件事你还想说吗？没有就睡，有就说两句。"

> （接送路上）"今天有什么想跟我讲的？"

可照抄的连接短句：

- "今天有没有哪一下挺开心的？"
- "要是能重来一遍今天，你想改哪一件？"
- "我不用你讲得清楚，你就随便说说。"

固定动作怎么选、短句库怎么用，见 `03-bond/家庭仪式与固定动作.md`。

### 三、和孩子一起预演（提前排掉可预见的冲突）

四步：**说场景 → 说约定 → 让他复述 → 说好提醒方式。**

**出门买东西前**

> "等会儿去超市，你要是看到想买的，我们先记下来，回家商量。你可以先拍照存着。你记住了吗？说给我听听。"
> "要是我说你忘了，你怎么提醒我行？"

**去医院或打针前**

> "等会儿要打一针，会疼一下，可能几秒钟。你可以抓我的手。疼的时候你想数数，还是捏我手？"

**开学、转学、换班前**

> "换新班级谁都会有点不熟。第一周我们不聊成绩，你先告诉我认了谁、坐哪儿。要是有人欺负你，你回来告诉我。"

**假期作息要变前**

> "明天开始放假，晚上可以晚半小时。但十点以后不玩手机，这条不变。"

预演的要点是**提前说、说具体、让他复述一遍**。到时候就按说好的执行，不再临时加条件。

### 四、开学、生病、搬家这类大变动前，多做三步

1. 提前几天就告诉他，不要当天宣布；
2. 告诉他哪些**不变**（谁会陪他、哪顿饭一起、哪个习惯照旧）；
3. 告诉他一个他自己能做的小事（收拾书包、自己挑一件衣服）。

孩子对变化的反应，很大一部分来自"不知道接下来会怎样"。把不变的说清楚，能减少一部分不安。

### 五、预演可以缩成一句话

| 场景 | 一句话约定 |
|---|---|
| 出门 | "想买的先拍照，回家再商量。" |
| 打针 | "疼就捏我手，几下就过去。" |
| 写作业 | "先做三道，做完叫我。" |
| 关屏幕 | "时间到了，屏幕给我。" |
| 见亲戚 | "被问成绩，你可以说'还行'，不想答就看我。" |
| 睡前 | "聊两句就睡，有话说就说。" |

这些一句话约定，与固定短句库配套用，见 `03-bond/家庭仪式与固定动作.md`。

### 六、连接的三件小事（不用额外花时间）

1. **接一次他的"报告"。** 他放学回来说"今天美术课……"，你正在忙，也回一句："哦？然后呢？"
2. **记住一个细节并跟进。** 他上次说同桌借了他的笔，你隔两天问一句："笔还了没？"
3. **主动一次身体接触。** 路过时拍一下肩、出门前抱一下，不用配一句话。

这三件事的特点是：只花几秒，也不需要话题。它们的作用是让他知道"你一直在"。

### 七、分龄差异

| 学段 | 打底重点 | 预演怎么用 |
|---|---|---|
| 学前 3–6 | 靠身体在场和稳定作息；用玩的方式连接［B2］ | 用玩偶或角色演一遍，比讲道理有效 |
| 小学低年级 6–9 | 固定作息 + 每天一小段专属时间 | 提前把具体规则说出来，让他复述 |
| 小学高年级 9–12 | 让他参与定规则，参与感就是关系基础 | 和他一起排计划，让他提方案 |
| 初中 12–15 | 少要求、多尊重独处；连接要"不打扰" | 提前把边界说清（几点回家、能不能过夜） |
| 高中 15–18 | 退到后盾位；连接靠"随时在"而非"天天问" | 把可预见的现实条件摊开一起看 |

## 边界

- **打底不能替代当场处理。** 平时关系再好，也会被一次激烈冲突消耗掉，当场该走 `03-bond/风暴中的当场话术.md`。
- **不搞成任务。** "今天必须陪够十分钟"会把连接也变成考核，宁可真陪五分钟。
- **连接时不要夹带要求。** 一边陪一边讲"你要是把字写快点就好了"，这段时间就作废了。
- **不许愿、不威胁。** 预演不是"你到时候要是不听话，我就……"。
- **一次不用全做。** 先挑一个动作（睡前那两句话）连续做两周，再动下一个。
- **补关系不是让孩子听话的手段。** 做这些是为了关系本身，不是为了换他配合。

## 依据说明

本份属做法层。

- **证据分级 A**：敏感、一致的回应与依恋安全感相关（元分析，效应量为小到中等）［2］；依恋安全与孩子从情绪里恢复的能力关系更稳定（系统综述）［3］；预先形成"如果—那么"计划能提高目标达成（94 项研究的元分析）［4］。
- **证据分级 B**：家庭常规与仪式同养育胜任感、孩子适应之间有稳定关联（50 年研究、32 篇文献的质性综述）［1］。
- **证据分级 C**："先连接再引导""游戏中建立关系""安全基地"属成熟育儿框架，对应到书［B1］［B2］［B3］［B4］。
- **证据分级 D**："平时关系"自查三问、两类预演的分工、五类场景预演脚本、变动前多做三步，为本套材料自定。
