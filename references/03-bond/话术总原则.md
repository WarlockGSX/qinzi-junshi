# 话术总原则

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：预防促进
> 一句话范围：五条核心原则、三类句式公式、身体语言比措辞更重要。
> 相关文件：03-bond/禁语与改口对照.md；03-bond/设边界的句式.md；03-bond/风暴中的当场话术.md；03-bond/倾听与提问的技术.md；03-bond/亲子互动的底层机制.md

## 机制

### 一、孩子接收一句话，先接身体，再接内容

同一句话，换个音量、换个距离说出来，效果不同。孩子接收的顺序是：先看你此刻的样子（音量、表情、离他多近、手在干什么），再处理这句话的内容。

所以调话术的第一步不是换词，是先换姿态。当人还在激动（负责警觉与情绪的部分在主导）时，语言说服基本进不去，先把状态安顿下来再说话，顺序才成立［B2］。

### 二、同一句话在三层中的落点

| 落点 | 例子 | 他接收到的 |
|---|---|---|
| **落在人身上**（评价、定性） | "你就是懒" | 我这个人有问题 |
| **落在事上**（描述事实） | "作业还没动" | 有一件事没做 |
| **落在感受上**（命名） | "你是不是特别不想写" | 有人看见我现在很难 |

把话从"人"这一层挪到"事"或"感受"这一层，是这类做法最核心的一步。家长对青少年情绪的接纳回应与否定回应，与孩子之后的情绪失调、外化行为、关系满意度分别相关（观察研究，样本小，N = 29，12–18 岁，属相关）［1］——同一句话，是"接住"还是"否掉"，结局不同。

### 三、话术的作用是改变循环的下一步，不是当场说服

一句话说出口，真正的作用不是"让他立刻懂"，而是改变他下一步会做什么。家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［2］。所以检验一句话好不好，不看"我说得对不对"，看"他听完，下一步是更靠近还是更防"。

### 四、最该避开的话有一个共同点

它们要么制造内疚，要么收回关爱，要么比较，要么贴标签。用内疚和收回关爱来管（心理控制），与孩子的抑郁、焦虑水平相关［3］。这类话当场可能"有效"，代价是关系一直往下走。

## 识别

### 一、开口前先问自己一句

**这句话，我是要连接，还是要赢？**

要赢的话通常带这些特征：一定要他承认、一定要有结尾、说的时候声音往上走。

### 二、判断你的话落在哪一层

把自己要说的话写下来，看它落在哪一层。落在"人"上的，先改成"事"或"感受"再说出口。

## 做法

### 一、五条核心原则

| 原则 | 不要 | 要 |
|---|---|---|
| **1. 说事实，不评价人** | "你怎么这么邋遢" | "衣服在地上" |
| **2. 说自己的感受，不替他定感受** | "你就是懒" | "我看到这样有点急" |
| **3. 给有限选择，不给命令** | "马上去洗澡" | "现在洗，还是再看五分钟洗？" |
| **4. 说具体，不说笼统** | "好好写" | "先做这三道题" |
| **5. 说这一件，不翻旧账** | "你每次都这样" | "刚才这一件是怎么回事" |

原则 1 和 2 对应"描述问题、不攻击人"的基本做法［B3］［B4］。原则 3 的有限选择，让配合来自他自己的选择，而不是你压出来的［B3］。

### 二、三类句式公式

**公式 A · 说行为链条**
> 描述事实 ＋ 说出影响或你的感受 ＋ 给出方向
>
> "玩具在地上（事实），我差点踩到（影响），你收进箱子里（方向）。"

**公式 B · 先接后设限**
> 命名感受 ＋ 允许 ＋ 设边界
>
> "你现在特别气（命名）。可以生气（允许）。但不能打人（设边界）。"

**公式 C · 有限选择**
> 给两个你能接受、他也能选的选项
>
> "现在关掉，还是看完这一集关？你定。"

三类公式的共同结构是：把观察、感受、需要、请求分开说，不把它们混成一句指责［B1］。

### 三、身体语言清单（比措辞更重要）

| 项目 | 更容易接住的 | 更容易起火的 |
|---|---|---|
| **高度** | 蹲下、坐下，和他平视 | 站着低头看他 |
| **距离** | 走近半步，或并排 | 正面逼近、堵在门口 |
| **朝向** | 侧身、并排做事时说 | 正面对峙、用手指 |
| **手** | 手空着、自然放着 | 叉腰、指人、抬手 |
| **表情** | 放松，允许沉默 | 皱眉、撇嘴、翻白眼 |
| **音量** | 比平常低一点 | 比他高 |
| **时机** | 他停下来的时候说 | 他正上头的时候说 |

七项里，**音量最容易改，也最见效**：你先降，他通常会跟着降。其余六项，一次能改一项就够。

### 四、同一句话的改法对照

| 原句 | 改成 | 为什么 |
|---|---|---|
| "你怎么又把房间弄这么乱！" | "地上有三样东西，收一下。" | 从骂人改成描述 |
| "你太不懂事了。" | "刚才那件事，我不太舒服。" | 从定性改成说感受 |
| "你必须现在就写作业。" | "先写数学那三道，还是先写语文？" | 从命令改成选择 |
| "你再这样我就不要你了。" | "我不会不管你。但这件事不能就这么过。" | 从收回关爱改成给边界 |
| "我为你付出这么多，你对得起我吗？" | "我有点累，因为这件事我很在意。" | 从内疚改成说感受 |
| "你看人家孩子。" | "你上次比这次快，我们照那个来。" | 从比较改成跟他自己比 |
| "这有什么好哭的。" | "你现在挺难受的，我陪你一会儿。" | 从否掉感受改成接住 |
| "你每次都这样。" | "这次是怎么回事？" | 从翻旧账改成只说这一件 |

### 五、可以照说的原句

| 场景 | 可以照说 | 他可能的反应 | 你怎么接 |
|---|---|---|---|
| 他又来一遍老毛病 | "这一件我们说过。今天只说今天这一次。" | "你又要翻旧账。" | "今天这次是真的只算今天。" |
| 他顶你 | "你这句话我听见了。等你说完我再说我的。" | 停了一下又继续说 | 不抢话，等他说完 |
| 他做错了，你很想定性 | "这件事做错了。跟你是什么人，是两件事。" | "你就会这么说。" | "我可以生气，但我没说你是坏孩子。" |
| 他什么都不肯做 | "我不逼你。你可以选现在做，或者吃完晚饭做。" | "我都不选。" | "那说明现在不行。等你选。" |
| 你正要发火 | （先说身体那句）"我现在有点上来，先停一下。" | 愣住 | 停了就真停，不再补刀 |
| 他反驳"你说话真难听" | "你说得对，我刚那句不好。我重说一遍。" | 意外，语气软下来 | 真的重说，不找补 |

### 六、分龄：同一原则的不同落点

| 学段 | 话该怎么改 | 例子 |
|---|---|---|
| **学前 3–6** | 句子短、靠身体、给两选一 | "你想先穿袜子，还是先穿鞋？" |
| **小学低年级 6–9** | 说具体、给示范，少讲抽象道理 | "先做这三道，做完告诉我。" |
| **小学高年级 9–12** | 让他自己排、自己定，你只核流程 | "你自己排个顺序，排完跟我说。" |
| **初中 12–15** | 说一句事实就撤，不辩论、不当场定对错 | "我听见了。这事晚点说。" |
| **高中 15–18** | 问需要、给建议但不安排 | "你需要我做点什么吗？" |

同一句要求，年龄越小越要靠身体和具体动作，年龄越大越要留出他自己决定的空间。孩子的自我调节能力是随发育逐步长出来的，不是"说过一次就该会"［4］。

## 边界

- **不说禁语，不等于从不生气。** 允许生气，改的是表达方式，不是取消情绪。
- **改口不是表演话术。** 用你平时会用的词说，背来的台词他一听就出来。
- **不是要求永远准确。** 说错了当场重来一次，比说对一百句更让孩子放心。
- **别用"我就是这么一说"开脱。** 说出口的话，对他就是真的。
- **不在情绪里背公式。** 公式是平时练的；当下只用得上一条——降音量。
- **有些话不是话术问题。** 如果每次一开口就成冲突，问题可能在关系或你的状态，先处理那一层。

## 依据说明

本份属做法层。

- **证据分级 A**：心理控制（内疚、收回关爱）与孩子抑郁焦虑的关系［3］——元分析。
- **证据分级 B**：家长接纳回应与否定回应的差别及与青少年功能的相关［1］（观察研究，样本小，N = 29，12–18 岁，属相关）；家长情绪社会化与孩子情绪处理的关联［2］（评论／综述性文章）；自我调节随发育逐步形成并受环境影响［4］（综述）。
- **证据分级 C**：五条原则、三类句式公式、身体语言清单，属成熟沟通与育儿框架，对应到书［B1］［B2］［B3］［B4］。
- **证据分级 D**：改法对照表、可照说原句、身体七项清单，均为本套材料自定的做法。
