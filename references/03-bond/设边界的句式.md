# 设边界的句式

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：预防促进
> 一句话范围：把一条边界说明白的句式——有效句和无效句的对照，以及哪些事不能让、哪些事可以变通。
> 相关文件：03-bond/顶嘴与对抗的应对.md；03-bond/话术总原则.md；03-bond/禁语与改口对照.md；04-family/家庭规则的制定与执行.md；06-scenes/写作业与拖延.md

## 机制

### 一、边界要能被预期，才不是看心情

同一条规则，今天管、明天不管，孩子会反复试探边界到底在哪儿。反复试探本身，就是冲突的来源。

清楚、稳定的边界（哪些能做、哪些不能、违反了会怎样），和孩子更清楚"自己的行为会带来什么"（控制理解）相关；再加上不替他做主的自主支持，还与更好的自我调节相关［4］。反过来，只靠你当时的心情松紧来定，孩子学到的不是规则，而是"怎么看你的脸色"。

### 二、有效的一条边界句，有三个部件

| 部件 | 作用 | 例子 |
|---|---|---|
| **具体行为** | 说清做什么、不做什么 | "写完作业再看屏幕" |
| **范围或时间** | 限定到可执行 | "九点前""就这一集" |
| **后果（可选）** | 让结果可预期 | "到点没停，明天就不看了" |

三个部件缺一个，句子就会被他钻空子。"你该少玩点手机"只有态度，没有行为、没有时间，没法执行。

### 三、不可让步和可变通是两件事

把两种边界混在一起，每件事都会变成权力斗争。**不可让步**的，是安全、健康、基本道德和法律；**可变通**的，是时间、顺序、偏好。

举例：能不能玩到深夜是安全（不可让步）；先玩还是先写是顺序（可以变通）。如果你把"先写还是先玩"也当成不能动，孩子会用全部力气来争这个顺序，把本该用在事情上的注意力，全用在跟你较劲上。

### 四、"说不"要短

拒绝的话一长，就变成一场辩论，而辩论是给协商开的门。不可让步的事，句子要短、要稳、要不再补充：

> "这个不能商量。你可以不高兴。"

短，不是冷，是让边界清楚；不再补充，是不给他"再多说一句也许就能改"的空间。

### 五、边界不是控制

边界和控制的区别：边界管的是**行为**，控制管的是**这个人**。管行为的边界与孩子更好的适应相关（"高要求 + 高回应"）［1］［3］；用内疚、收回关爱去控制这个人（心理控制），与孩子更高的抑郁、焦虑水平相关。给自主支持、同时给清楚的结构，与孩子更好的自我调节和胜任感相关［4］。所以好的边界句是"我把线划在这儿，你的情绪我接着"，不是"你得变成我想要的样子"——边界立在行为上、态度保持和善，是这类做法的基本形式［B1］。

## 识别

### 一、先分：这件事属于哪一类

| 类别 | 判断 | 句式倾向 |
|---|---|---|
| **不可让步** | 涉及安全、健康、法律、伤害他人 | 短句，一句到底，不协商 |
| **可变通** | 涉及时间、顺序、方式、偏好 | 给两三个选项，让他挑 |
| **可以商量** | 涉及他自己的事、资源分配 | 一起定，定了就执行 |

### 二、自检：你这句话立不立得住

三个问题，过不了就得重说：

1. **有没有具体行为？** （"别老玩手机"——没有；"看完这集关掉"——有。）
2. **有没有范围或时间？** （"饭前""九点前""就一次"。）
3. **后果是不是你能做到的？** （"再这样我就再也不管你了"——做不到；"到点没停，明天不看"——做得到。）

### 三、分龄：同样的边界，句式不同

| 学段 | 句子的样子 |
|---|---|
| **学前 3–6** | 一句话 + 身体动作：蹲下、指给他看。"脚不能放桌上。" |
| **小学低年级 6–9** | 一句话 + 简单理由："现在关电视，因为要到睡觉时间了。" |
| **小学高年级 9–12** | 给选择 + 让他复述："你打算怎么安排？说给我听。" |
| **初中 12–15** | 说清底线 + 给空间："几点回、去哪儿，告诉我。别的你自己定。" |
| **高中 15–18** | 谈条件 + 谈后果："这件事我担心的是……决定你做，后果自负。" |

## 做法

### 一、有效 / 无效句式对照

| 场合 | ❌ 无效句 | ✅ 有效句 |
|---|---|---|
| 到点关屏幕 | "你还要看多久？！" | "这集看完就关。" |
| 拒绝要买的东西 | "你怎么什么都想要！" | "今天不买。你可以不高兴。" |
| 催出家门 | "你到底走不走？" | "八点出门。现在七点五十。" |
| 制止打人 | "你怎么这么坏！" | "我不会让你打人。人不能打。" |
| 立作业规则 | "你再不好好写试试。" | "九点前写完，写完还能玩十五分钟。" |
| 拒绝无理要求 | "不行，少废话。" | "不行。你要生气可以，我们就先到这儿。" |
| 边界被试探 | "你再说一遍？" | "这条不变，说几次都一样。" |
| 他自己决定的事 | "听我的准没错。" | "这是你的事，你定。需要我出主意就说。" |

对照里的规律：

- 无效句多在**问态度**（"你怎么……""你到底……"），有效句在**说行为**。
- 无效句常用**威胁**（"试试""看我不……"），有效句用**能做到的后果**。
- 无效句给的是**命令**，有效句常给**有限的选择**。

### 二、不可让步清单（一句话到底，不协商）

- 安全：没人照看不能下水、不坐副驾、骑车戴头盔、深夜不出门。
- 健康：吃药、生病时的忌口、必要的就医。
- 伤害他人或自己：打人、咬人、伤人的话、自伤。
- 基本的诚实与财产：偷拿、说谎到影响别人、损坏别人东西。
- 法律规定的事：未成年人不能做的事、必须做的事。

这类事的标准句式只有一句：

> "这个不行。你可以生气，但这条不变。"

### 三、可变通清单（给两三个选项，让他挑）

- 时间：现在写还是吃完饭写。
- 顺序：先做数学还是先做英语。
- 方式：自己走还是我送你到路口。
- 形式：今天读纸质书还是听书。
- 地点：在客厅写还是在房间写。

句式：

> "这件事你自己挑：现在做，还是吃完饭做？"
> "先做哪个你自己定，做完告诉我。"

给有限的选择，比下命令更能让他配合，也比放开自由更能让他做得到［B2］。选择要**真**（两个都能接受），不要给一个假选项（"你想现在写，还是想挨说？"）。

### 四、立边界可以照做的四步

1. **说行为**："写完作业再看屏幕。"
2. **给范围**："九点前。"
3. **说后果，且是你做得到的**："九点没写完，今天就到此，明天继续。"用孩子能预期的、你又做得到的结果，而不是随机惩罚，是这类做法的共同点［B3］。
4. **说定就不再改口**：他试一次、两次、三次，你的回答都是同一句。

第四步最关键。边界不是靠第一次说得多重立住的，是靠**每一次都一样**立住的。家长教养方式与孩子的外部化问题有关联：温暖、有要求、给自主的方式，孩子的外化问题更少（元分析，效应量偏小）［2］。

### 五、他试探边界时的接法

| 他说／做 | 不接 | 接什么 |
|---|---|---|
| "就这一次，好不好？" | "好啦好啦，就这一次。" | "不行，这条不变。" |
| "妈妈以前都答应我的。" | "那不一样……"（开始解释） | "以前怎样都不影响现在这一条。" |
| 哭、闹、赖地上 | 当场改规矩 | "你可以哭。哭完我们再看这条要不要调——今天不变。" |
| "你偏心！" | 掉进辩论 | "你会有这个感觉。这事我们另外说，今天这条不变。" |
| 拖着不动，试探你会不会松 | 一遍遍催、声音越来越大 | "到点了。按我们说的来。"（平静执行） |
| 顶嘴："凭什么！" | "你敢这样跟我说话？" | "这条为什么这么定，我说一遍；说不通也不改今天。" |

接法只有一句核心：**允许情绪，不改边界。**

### 六、边界句用完的收尾

- 他接受了：一句轻的确认就够——"好，那就这样。"不要趁机加一句表扬或道理。
- 他没接受但停了：不追问态度，不再补刀——"行，就这样。"
- 他接受了但显然不服：给一个将来能说的口子——"你有意见，明天冷静了再跟我说，我听着。"

## 边界

- **边界是给行为的，不是给情绪的。** 可以规定"不能打人"，不能规定"不许生气"。
- **不要一次立太多条。** 同时在改的边界，最多两条。多了他记不住，你也执行不动。
- **不把"可以商量"的事说成"不能商量"。** 顺序、时间这类是可变的，硬说成不能让，只会制造没必要的对抗。
- **不用边界泄愤。** "你今天别想出门"如果是气头上说的、且你做不到，这条边界就废了。
- **不威胁你做不到的后果。** 说了就要做到；做不到的，别出口。
- **不用边界拿孩子的东西做人质。** 把他的私人物品、朋友、兴趣爱好拿来当作交换条件，超出边界范围，属于控制。
- **不给假选择。** 两个选项都要是你真能接受的。
- **这一份只给句式。** 为什么先连接再提要求、对抗怎么接，见 `03-bond/顶嘴与对抗的应对.md`；一条规则在全家怎么统一执行，见 `04-family/家庭规则的制定与执行.md`。

## 升级信号

- **同一件事立了边界、执行了两周以上仍天天冲突**，且换过方法 → 先看 `04-family/家庭规则的制定与执行.md` 检查规则本身和一致性；仍无改善，考虑外部评估。
- **边界冲突伴随持续两周以上的低落、易怒、不上学、失眠、自伤** → 走 `07-safety/就医与专业转介指征.md`。
- **每次立边界都以你失控收场** → 先处理你这一侧，见 `02-parent/家长情绪急救.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：教养维度与孩子外部化问题的关系［2］（元分析，1,435 项研究，效应量偏小）。
- **证据分级 B**：教养方式与青少年胜任、物质使用的关系［1］（单项纵向研究，139 名青少年，中产、受教育程度较高家庭为主，属关联）；家庭教养类型与青少年胜任、适应的关系［3］（约 4,100 名 14–18 岁青少年，属关联）；清楚的结构同时给自主支持，与孩子更清楚行为结果、更好的自我调节相关［4］（单项访谈研究，小学 3–6 年级学生的家长）。
- **证据分级 C**：给有限选择、说行为不说态度、边界一致执行、后果要可预期，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：三个部件的拆分、不可让步／可变通清单、四步立边界、收尾话术，为本套材料自定。
