# 情绪共调节

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：预防促进
> 一句话范围：家长当"情绪容器"的机制：孩子的情绪先被别人接住，才学得会自己接住。
> 相关文件：01-child/情绪爆发的机制.md；03-bond/风暴中的当场话术.md；03-bond/平复后的修复话术.md；00-frame/教养底层框架.md

## 机制

### 一、共调节

孩子的情绪调节不是自己长出来的，是先在关系里学会的。过程是：他的情绪先由别人（最早是你）帮他降下来——你抱着他、你命名他的感受、你稳定的身体状态影响他的身体状态；重复足够多次之后，他慢慢把"这套动作"收到自己身上。这叫共调节先于自我调节。

孩子负责自我调节的能力（注意力、抑制冲动、从情绪里回来）是随发育逐步长出来的，受环境和经历影响，不是"教一次就会"［1］。在能力还没长出来的阶段，靠的不是他，是你。

### 二、"容器"不是不让他有情绪

容器的意思：**能承接情绪的强度，不让它外溢成伤害，也不把它推回去。**

| 不是容器 | 是容器 |
|---|---|
| "别哭了""这有什么好哭的" | 让情绪存在，同时接住它 |
| 跟他的情绪一起升级（他哭你吼） | 你的强度留在他之下 |
| 立刻解决、转移、给道理 | 先陪，等他降下来再说事 |
| 假装没看见 | 在场，不带要求 |

家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［2］。这就是"容器"背后的机制：你的回应方式，是他学情绪处理的样板。

### 三、情绪上来后听不懂道理的原因

情绪冲上来之后，会有一段时间孩子的"听见→理解→回应→想到后果"这条链无法正常工作；情绪唤起会直接抑制前额叶的功能，这是生理过程，不是态度［3］。所以在这段时间里，你说话的作用不是教育，是影响他的身体状态。先接住情绪、再谈行为，是情绪辅导类做法的共同前提［B1］。

### 四、家长自己的状态决定能不能当容器

当容器需要你自己先稳。如果你睡眠不足、长期压力大，负责自控的那部分功能会下降，你会更容易一点就着，和眼前这件事关系不大［3］。家长的情绪调节和孩子的情绪调节之间存在纵向关联（样本为 98 对母子、孩子 6–8 岁；属关联，不能读成因果，间接路径未达显著）［4］。所以"接不住孩子"常常不是方法问题，是你这一端已经满了。满的时候先处理自己的状态。

### 五、共调节的目标是逐步交接

共调节不是一直由你托着。目标是随年龄逐步把调节的活儿交回给他：

- 学前：几乎全靠你；
- 小学：你托一半，他开始自己命名、自己找办法；
- 青春期：多数靠他自己，你在旁边当后盾。

托得太多、太久，自主感会缺（见 `00-frame/教养底层框架.md`）；给得太早，他接不住，会反复缴。

## 识别

### 一、判断现在是"需要共调节"还是"可以自己来"

| 现象 | 判断 | 你做什么 |
|---|---|---|
| 哭喊、身体绷紧、开口就攻击 | 需要共调节 | 先降强度，不做别的 |
| 能说出"我有点烦" | 半自主 | 接一句，问要不要帮忙 |
| 自己走开、一会儿回来说事 | 基本自主 | 不打扰，事后肯定他处理的方式 |

### 二、判断你自己还剩多少容量

出现以下任何一条，先处理你自己：

- 太阳穴发紧、下巴咬住、声音开始抖或拔高；
- 脑子里冒出"我今天非得治治他"；
- 手已经抬起来。

具体处理见 `02-parent/家长情绪急救.md`。

### 三、分清"情绪"和"要挟"

不确定时按情绪处理（先接住）。把真的情绪过载当成要挟来对待，代价更大：孩子会形成"我说什么你都不信"。区分见 `01-child/情绪风暴还是要挟.md`。

## 做法

### 一、共调节的四步（当场）

1. **先降你自己的强度**：他喊，你用比平常低的音量。
2. **身体在场、不推进**：坐近或退半步，不用手指，不讲道理。
3. **命名情绪**：只说他此刻的状态，不评价。
4. **给一个出口**：一句最短的话，或一个具体的动作。

可以直接说：

> "你现在特别生气。我知道了。"（命名，不评价）
> "我在这儿，不走。"（在场）
> "先不说话，我陪你坐一会儿。"（给出口）

### 二、四个常见场景的接法

| 他说／做 | 不要 | 可以照说 |
|---|---|---|
| 哭得厉害 | "这有什么好哭的" | （不说话，递纸巾，把手放他背上） |
| "我恨你" | "你怎么能这样说" | "你现在特别气我。我知道了。" |
| 摔东西 | "你再摔一个试试" | "我不会让你摔东西。你想发火可以，东西不能摔。" |
| 沉默、不理你 | 一直追问 | "不想说就先不说。我在这儿。" |

接情绪的字面、不接字面的攻击，是给孩子示范"情绪可以被说出来"的最直接方式［B2］［B3］。

### 三、把活儿交回给他的时机

- 他降下来了（声音从喊变说、肩膀松了、开始说自己的事）→ 进入"事后"这一段，见 `03-bond/平复后的修复话术.md`。
- 他主动说出感受 → 先接，不急着纠偏："嗯，你现在很委屈。"
- 他自己走开了、又回来 → 事后说一句："你刚才自己缓过来了，这个办法不错。"

### 四、按学段调整托的力度

| 学段 | 你要做的 | 可以照说 |
|---|---|---|
| 学前 3–6 | 靠身体在场，少说话，只命名 | "你很生气。"（蹲下来，抱着） |
| 小学低年级 6–9 | 命名 + 给两个具体选项 | "你可以去房间待一会儿，或者坐这儿喝口水。" |
| 小学高年级 9–12 | 少说、别当众，给台阶 | "等你想说的时候，我随时在。" |
| 初中 12–15 | 不接球，说一句事实然后撤 | "我听见了。这事我们晚点说。" |
| 高中 15–18 | 尊重独处权，门开着 | "我在客厅，你想聊再叫我。" |

### 五、容器先照顾好自己，才有容量

想长期接得住孩子，得先管住自己的睡眠、压力和恢复时间。这不是自私，是让容器不空。自己的状态怎么调，见 `02-parent/撑不住时的自我照顾.md`、`02-parent/家长情绪急救.md`。

## 边界

- **容器不是无底洞。** 你可以承接他的情绪，但不必承接他的攻击。拦动作、接情绪，是两件事。
- **共调节不是替他感受。** 不要替他说"你就是想偷懒"，那是你的判断，不是他的情绪。
- **接住不等于答应。** 可以接住"你很想要那个玩具"，同时不给买。
- **不要一直当容器。** 每次都由你降下来，他就没有练的机会。目标是随年龄逐步交回给他。
- **你自己满了就先处理自己。** 空着的时候硬接，通常以你失控收场。
- **这一份讲机制。** 具体某一场风暴怎么走的完整脚本在 `03-bond/风暴中的当场话术.md`。

## 升级信号

- **你自己的状态持续不好**（情绪低落或焦虑两周以上、睡不好、靠酒精缓解）→ 先走 `02-parent/家长情绪急救.md`、`07-safety/就医与专业转介指征.md`。
- **孩子的情绪持续两周以上、几乎每天爆发，且换过方法不变** → 见 `07-safety/就医与专业转介指征.md`。
- **出现自伤、动手致伤、"我不想活了"这类话** → 停止本节做法，先保安全，见 `07-safety/危机信号识别.md`、`07-safety/危机当下的应对.md`。

情绪调节的方式与心理健康之间存在稳定关联——以"重新理解"（认知重评）为主与更好的指标相关，以"压住"（表达抑制）为主与更差的指标相关［5］；长期处在上面这些状态时，优先按渠道求助，而不是停在自我调节上。

## 依据说明

本份属机制层，讲"共调节"为什么成立、怎么执行。

- **证据分级 A**：情绪调节方式与心理健康的关系（以"重新理解"为主与更好的指标相关，以"压住"为主与更差的指标相关）［5］——均为综述、元分析或权威机制研究。
- **证据分级 B**：自我调节随发育逐步形成并受环境影响［1］；情绪唤起对前额叶功能的抑制［3］；家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［2］；家长与孩子情绪调节的纵向关联（98 对母子，间接路径未达显著，只能读成关联）［4］。
- **证据分级 C**：先连接再讲理、情绪命名、共调节先于自我调节，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：四步当场做法、四场景接法、分龄托的力度表、把调节逐步交回给他的判断，为本套材料自定。
