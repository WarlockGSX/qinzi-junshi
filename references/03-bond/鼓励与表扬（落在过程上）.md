# 鼓励与表扬（落在过程上）

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：预防促进
> 一句话范围：肯定落在过程与努力上，不落在结果、更不落在"你这个人"上——以及各种场合可以照说的原句。
> 相关文件：03-bond/奖励与惩罚的分寸.md；03-bond/话术总原则.md；03-bond/禁语与改口对照.md；01-child/挫折耐受与韧性.md；01-child/羞耻感与自我价值.md；06-scenes/写作业与拖延.md

## 机制

### 一、表扬的落点决定他做这件事的动机

同一句夸奖，落在不同的地方，效果相反。

- 夸**智力**（"你真聪明"）的实验（412 名 10–12 岁儿童）：孩子在后续遇到难题时，动机和表现都会下降，更不愿挑战，遇到挫折更容易归因到"我不够聪明"［1］。
- 夸**过程**（努力、方法、选择、进步）的孩子，更愿意挑难题，遇到挫折更愿意再试［1］。

所以关键不是"夸不夸"，是"夸在哪儿"。夸在人身上（聪明、棒、好孩子），会让他的自我价值取决于结果；夸在过程上，才落得稳。要注意：这一组实验比的是"夸智力"和"夸努力、夸过程"，并没有检验"夸结果"。

### 二、落在"你这个人"上，代价最大

"你真聪明""你真乖""你是好孩子"这类话，评价的是**这个人**，不是这件事。它带来两个后果：

1. **他必须一直表现得配得上这个标签。** 一旦有做不好的时候，他会觉得"我不是好孩子了"，于是回避、说谎、或干脆不试。
2. **自我价值取决于结果。** 做得好才有价值，做不好就没有——这是很多孩子"一失败就崩"的来源之一［B2］。

用评价、内疚、收回关爱去控制这个人（心理控制），与孩子更高的抑郁、焦虑水平相关［3］。所以夸奖里如果夹着"你要还是好孩子就这样做"，它其实已经从鼓励变成了控制。

### 三、鼓励和表扬不是一回事

| | 表扬 | 鼓励 |
|---|---|---|
| 看的是 | 结果、成绩、表现 | 过程、努力、选择、进步 |
| 说话的位置 | 评价者（我做裁判） | 见证者（我看到了） |
| 典型句子 | "你真棒""考得真好" | "你昨天自己坐到桌前了" |
| 孩子学到 | 我要好，才被认可 | 我的努力被看见了 |

鼓励不等于不表扬，而是**把肯定的落点从"人"和"结果"移到"过程"**。孩子做得好时，仍可以说"做得好"，但要接上"好在哪、你怎么做到的"［B3］。

### 四、表扬不是越多越好

- **空洞的表扬没有信息。** "你真棒"说 100 次，孩子学不到任何具体的东西，久了还会觉得你只是在哄他。
- **不真诚的表扬会失效。** 明明做得一般也说"太厉害了"，孩子能识别，之后连你真心的肯定也不信了。
- **过度表扬会让他依赖外部评价。** 每做一件小事都等一句夸，一旦没人夸就不做。

有效的鼓励是**少而具体**：说清你看到了什么、他做了什么。

### 五、能力是练出来的，不是天生的

孩子愿意挑战难题、遇到失败还能再试，前提是他相信"能力可以靠努力长出来"。孩子的自我调节能力（包括注意、抑制冲动、坚持）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［4］。家长给自主支持、同时给结构，与孩子更好的自我调节和胜任感相关［2］。所以你的肯定要落在"可以变的这一部分"（努力、方法、下一步），而不是"固定不变的那一部分"（聪明、天赋、行不行）。

## 识别

### 一、分清三种落点

| 落点 | 例子 | 孩子的理解 | 换成什么 |
|---|---|---|---|
| **结果** | "考了 95 分，真厉害！" | 只有好成绩才有价值 | "这次你把错题都订正了。" |
| **人** | "你真聪明""你是好孩子" | 我必须一直是这个标签 | "你想了不少办法才做出来。" |
| **过程** | "你自己坚持下来了" | 努力是有用的 | 保留这句 |

不是不能提结果，而是**别让结果成为唯一的落点**。可以说"考得不错"，但把肯定放在他做了什么上。

### 二、最需要落在过程上的时候

| 时机 | 为什么 |
|---|---|
| 他第一次尝试、做得不完美 | 此时只有过程可夸，夸结果就是夸假的 |
| 他遇到困难、想放弃 | 肯定努力和"已经做到的部分"，比夸结果有用 |
| 他做得好、但很快 | 夸结果会让他以为"快就是好"，反而怕难题 |
| 他失败了、正在低落 | 先接情绪，再找过程里真实的一点，不硬夸 |
| 他问"我是不是很聪明" | 把落点从"是不是"移到"怎么做到的" |

### 三、自检：这句话在评价人，还是在描述事

问自己一句：**这句话说的是"他是什么"，还是"他做了什么"？**

- "你真是个懂事的孩子"——说"他是什么"。
- "你把弟弟的玩具捡回来了"——说"他做了什么"。

前一句多，他依赖你的判定；后一句多，他自己知道该看什么。［B1］

### 四、分龄：同样的鼓励，说法不同

| 学段 | 说着力点 |
|---|---|
| **学前 3–6** | 描述具体的动作，越具体越好："你把积木一块一块摆上去了。" |
| **小学低年级 6–9** | 描述过程 + 简单命名："你刚才卡住了没放弃，这叫坚持。" |
| **小学高年级 9–12** | 让他自己说："这道题你是怎么想出来的？"（把评价权还给他） |
| **初中 12–15** | 少当众夸，多私下具体地讲："我看到你这周自己安排了时间。" |
| **高中 15–18** | 尊重他的独立：多认可他的判断和选择，少评价他的表现。 |

青春期对当众表扬更敏感，甚至会把表扬当成"被当小孩看"。这个年龄的肯定，更适合私下、具体、就事论事。

## 做法

### 一、把"你真棒"换成三句话

描述式的鼓励，通常由三部分接起来：

1. **我看到了什么**（事实）；
2. **你做了什么**（努力、方法、选择）；
3. **带来什么**（影响，或他的感受）。

例："我看到你这张画从昨天画到今天（看到）——你昨天把不满意的地方重画了一遍（做了什么）——难怪现在这块看起来清楚多了（影响）。"

不用每次都三段齐全，但**要有"看到"和"做了什么"**，不能只有一句"你真棒"。

### 二、可以照说的原句

**努力／坚持**
> "这道题你试了好几种办法。卡了那么久还在弄。"
> "你昨天说不写了，今天自己又坐回来了。"

**方法／策略**
> "你把大任务拆成一小块一小块，这个办法挺管用。"
> "你先做了简单的那几道热身，再啃难的——这个顺序是你自己想的？"

**选择／自主**
> "刚才那个是你自己决定的。"
> "你说到做到，按自己定的时间开始了。"

**进步（和自己比，不和别人比）**
> "比上次多了三行。"
> "上星期这道题你还得问，今天你自己做出来了。"

**遇到失败时**
> "这次没做出来，不是白搭——你知道哪种方法不行了。"
> "你已经把会做的都做了。剩下的难，我们看看卡在哪儿。"

**分享他的事时**
> "听你讲得这么细，你是真喜欢这件事。"

### 三、他说这些时的接法

| 他说 | 你接什么 |
|---|---|
| "我是不是很聪明？" | "你认真想了很久，才想出来。"（把落点从"是不是"移到"怎么做的"） |
| "我这次才考了 70。" | "你自己觉得哪部分没吃到？……那部分你打算怎么办？"（不问名次，先问过程） |
| "某某比我厉害多了。" | "你和他不一样的地方在哪儿？你这次比你自己上次好在哪儿？" |
| "你只是哄我。" | "我不是哄你。我说的是刚才那件事——你重画了三遍。"（具体，不空洞） |
| "我做不好，我笨。" | "你现在是卡住了，不是笨。我们挑最简单的一步先做。" |
| "你怎么不夸我？" | "你很想被我知道，对吗。那你说说这次你自己觉得哪儿做得好。" |

孩子把"我做不好"当成"我笨"时，先接住这个感受，再给一个具体的小步骤，不要当场反驳"你才不笨"——那也是在评价人。更完整的处理见 `01-child/羞耻感与自我价值.md`、`01-child/挫折耐受与韧性.md`。

### 四、失败时肯定过程又不虚假的说法

三件事按顺序：

1. **先接情绪**："没做出来，挺难受的吧。"
2. **只找真实的那一点**：不夸大、不编。真找不到就承认——"这次确实没做好，我不硬夸你。"
3. **把目光放到下一步**："你想先歇一会儿，还是看看卡在哪儿？"

**不要硬夸。** 失败时硬说"你已经很棒了"，他更确信你在敷衍，也更清楚自己没做好。

### 五、写作业场景里的用法

写作业时的肯定，最容易滑到结果上（"写完了没""对了没"）。落到过程上：

> "你已经写了三行了，不错的开始。还剩几道？"
> "刚才那二十分钟你没站起来，一直在写。"
> "这道你自己检查出来了，比上次细心。"

更多写作业现场的说法见 `06-scenes/写作业与拖延.md`。

## 边界

- **不夸天赋、不夸人。** "聪明""天才""好孩子""乖"这类评价人的词，尽量不用。
- **不虚假表扬。** 做不到就承认；硬夸会让他不再信你的肯定。
- **不用夸奖当交换条件。** "你考进前三我就夸你"——这不是鼓励，是交换，见 `03-bond/奖励与惩罚的分寸.md`。
- **不比较着夸。** "你看人家……"把鼓励变成比较，孩子学到的是"我要压过别人"。
- **不在他做的事上替他下结论。** "你真是个有毅力的孩子"也是贴标签，换成"你卡住了还接着做"。
- **不当众夸到让他尴尬。** 尤其小学高年级以后。
- **不是只夸不纠。** 该说的问题照说，只是把"评价人"换成"描述事"：不说"你怎么这么马虎"，说"这两道是抄错数了"。
- **不为了鼓励而回避真实。** 他做错了，先就事论事；鼓励是让他知道努力被看见，不是让他以为怎么做都对。

## 升级信号

- **孩子长期把失败等同于"我不好"、明显回避挑战**：先按这一份改肯定落点；若伴随持续两周以上的低落、回避上学、自我否定 → 走 `07-safety/就医与专业转介指征.md`。
- **出现"我就是没用""我不配"这类话，或自伤** → 立即走 `07-safety/危机信号识别.md`。
- **你发现自己只会用"你真棒"、或刻意疏于肯定** → 见 `02-parent/错位与盲区.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：心理控制与孩子抑郁、焦虑的关系［3］（元分析）。
- **证据分级 B**：表扬智力削弱动机与表现、表扬努力与过程维持动机［1］（系列实验研究，412 名 10–12 岁儿童）；家长给自主支持与孩子更好的自我调节和胜任感相关［2］（单项研究，样本为小学 3–6 年级学生的家长）；自我调节随发育逐步形成并受环境影响［4］（综述）。
- **证据分级 C**：鼓励优于表扬、描述事实不评价人、不贴标签，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：三种落点的分类、三句式鼓励、失败时的三步、分龄着力点，为本套材料自定。
