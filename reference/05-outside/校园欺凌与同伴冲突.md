# 校园欺凌与同伴冲突

> 适用对象：家长
> 生态层：外圈层（学校与外部）
> 适用时机：当场应对
> 一句话范围：分清冲突／孤立／欺凌；先信先谢，不教打回去。
> 相关文件：07-safety/校园欺凌与人身伤害的法律处理.md；05-outside/被孤立与社交困难.md；03-bond/倾听与提问的技术.md；07-safety/危机信号识别.md；06-scenes/被老师请家长.md

## 机制

### 一、冲突、孤立、欺凌是三件事，处理方式完全不同

孩子回家说"同学对我不好"，先别急着定性。三种情况混在一起谈，方向一定错。

| 类型 | 三个判断问题 | 特征 | 你该做的 |
|---|---|---|---|
| **冲突** | 力量对等吗？偶发吗？事后还能一起玩吗？ | 双方都有份，因为一件具体的事吵起来或动手；过后还能和好 | 教他自己处理，你不介入 |
| **孤立** | 是被排挤，还是没人主动带他？ | 没有明显的施害者，只是他进不了群体；换班、转学、性格偏静时常见 | 帮他把关系搭起来（见 `05-outside/被孤立与社交困难.md`） |
| **欺凌** | 是故意的吗？重复吗？力量不对等吗？ | 三个同时成立：故意针对、反复发生、力量明显不对等（人多对一人、个头、年级、人缘、掌握把柄） | 家长必须介入，走流程 |

**力量不对等是分界线的核心。** 判断标准：他是不是打不过、躲不开、在群体里没有盟友、还怕说了被报复。只要有这条，就不是"小孩打闹"。

判错方向的代价是双向的：把冲突当欺凌去闹，孩子会失去本来能修复的朋友，以后不敢再跟你说；把欺凌当冲突让他自己解决，他会更孤立，也不再告诉你第二次。

### 二、被欺凌的孩子不说，是常态不是例外

孩子不主动说，常见原因：觉得说出去难堪、怕被贴上"有问题"的标签、倾向自己扛、不知道该找谁帮忙、对能获得哪些帮助了解太少［4］。被欺凌的孩子往往还多一层怕：怕对方报复、怕事情闹大。这是求助行为里反复出现的障碍类型。

所以"他没跟我提"不等于"没事"。要看的不是他说不说，是行为和身体有没有变化（见识别一节）。也别指望一次问出全部——被欺凌的孩子常分几次、隔几天才一点点说出来。

### 三、不能让孩子"自己扛过去"的原因

同伴受害（被欺凌）与后来的社交焦虑之间存在双向关联：同伴受害能预测之后更高的社交焦虑水平（23 项前瞻研究的元分析，同伴受害与后续社交焦虑的关联 r=.23）［3］。也就是说，长期被欺凌不是"过一阵就好"，它会改变孩子对"关系安不安全"的预期。

反过来，师生之间的情感关系与学生的投入和成绩存在稳定相关［2］。一个愿意留意、愿意护着他的老师，本身就是保护因素。所以"找一个能靠的老师"是做法里很重要的一步，不只是"告状"。

### 四、学校层面的干预是有效的

学校反欺凌项目整体上能降低欺凌的发生率［1］。这意味着：家长的目标不是自己冲到学校把事摆平，而是**推动学校启动它该走的流程**。你越清楚流程该长什么样，越不容易被"我们再看看"打发。

### 五、分龄：同一个"被欺负"，在不同年龄是不同的事

| 学段 | 常见样子 | 你的重点 |
|---|---|---|
| **学前 3–6** | 多是抢玩具、推搡，谈不上"故意重复"；也可能只是不会加入游戏 | 教他找老师、教他说"轮到我了"，不上升为"欺凌" |
| **小学低年级 6–9** | 起绰号、不跟他一组、推打；重复性开始出现 | 找班主任，教"停／走／找老师"三步 |
| **小学高年级 9–12** | 开始有排挤、传话、小团体；面子问题变重 | 保护他不被当众处理；私下和老师对情况 |
| **初中 12–15** | 排挤、造谣、网络上的持续骚扰明显增多；他不愿家长出面 | 先和他商量"我做什么你才觉得可以"，保护他的自主感 |
| **高中 15–18** | 更隐蔽，常发生在校外和线上；他可能自己处理 | 做后盾：给证据、给流程、给退路，不越位替他做决定 |

## 识别

### 一、先问三个问题分流

1. **力量对等吗？** 他能不能躲开、能不能自己解决？
2. **是第一次还是重复？** 偶发一次，和每周发生，是两件事。
3. **是故意针对，还是碰巧冲突？** 对方是"冲着这个人"还是"因为这件事"？

三问里"力量不对等 + 重复 + 故意"同时成立，按欺凌走。缺一条，先按对应那一类处理，同时保持观察。

### 二、孩子不说时，看这些信号

- 身上出现不明原因的青紫、抓痕，或衣物破损；
- 文具、钱、物品反复丢失或被"借走不还"；
- 突然不愿上学、绕路走、装病、到校门口情绪就变差；
- 要的零花钱变多，或偷拿家里的钱（可能被索要）；
- 睡眠变差、做噩梦、食欲下降、回家就沉默；
- 从原来有朋友变成独来独往，或手机一响就紧张；
- 放学后情绪明显比早上差，周末却正常。

单看一条都有别的解释。**出现两条以上，并且伴有"不愿上学"或"身上有伤"，就要往欺凌方向问**。

### 三、冲突和欺凌的现场对照

| 你听到／看到 | 更像 | 怎么接 |
|---|---|---|
| "我们俩抢球吵起来了，后来和好了" | 冲突 | 教方法，不介入 |
| "他们都不跟我玩"（没有明显加害者） | 孤立 | 见 `05-outside/被孤立与社交困难.md` |
| "他每次都这样，还叫别人一起" | 欺凌 | 进入做法，走流程 |
| "我不敢跟你说，说了他们会知道我告状" | 可能已被威胁 | 先做安全承诺，不追问细节 |

## 做法

### 一、孩子主动说的时候：先信、先谢、先问感受

第一句话决定他还会不会说第二次。可以照说：

> "谢谢你告诉我，说这个需要勇气。"
> "你说的我都信。"
> "这不是你的错。"

**不要问的**："你是不是也做了什么？""你怎么不还手？""你怎么不躲开？""为什么人家不欺负别人就欺负你？"这几句会让话题当场关掉。

**先不急着说方案。** 先让他把"我信了"接收到，再谈怎么办。倾听时先承认感受、不否定、不抢着讲道理，是让孩子继续说下去的前提［B1］。

### 二、孩子不主动说的时候：用间接的问法

直接问"有人欺负你吗"，孩子多数会答"没有"。换成具体、不给压力的问法：

> "你们课间一般玩什么？谁跟谁一组？"
> "午饭你坐哪儿，旁边是谁？"
> "最近有没有谁老是让你不舒服？不用现在说，想到了随时告诉我。"

一次问一点，问了没答也没关系，隔天再问。

### 三、不教打回去

明确一条：**不针对人教他用拳头解决。** 三个原因：

1. 力量本就不对等，"打回去"等于让他去打一场会输的架，通常升级而不是结束；
2. 教"打回去"，他会理解成"我被欺负是因为我没还手，是我的错"；
3. 一旦他动手，事情就变成"你孩子先动手"，原本占理的一方反而被动。

替代的是针对**能立刻脱身的现场**的三步，在家里练熟：

1. **停**：大声、短促地说"停下"；
2. **走**：说完立刻离开，不留在原地理论；
3. **找大人**：马上找最近的老师或值班人员。

可以照说：

> "这件事不用你自己解决，是大人该管的。"
> "他再来的时候，你大声说'停'，然后马上走开去找老师。你不需要打赢他。"

"大声说停"只用于能立刻脱身的场景，不是让他正面对抗。

### 四、记录

从今天起，记这六项：**时间、地点、在场的人、说了什么做了什么、有没有伤或损失、告诉过谁、对方什么反应。** 用手机给伤处、损坏的物品拍照并记下日期。记录是两件事的凭据：跟学校沟通，以及万一要走法律流程。没有记录，沟通时容易变成"各说各话"。

### 五、和学校沟通（按顺序）

1. **先约班主任当面谈**，不隔空发消息吵。带记录去。
2. **说清三件事**：我知道的事实、孩子的状态、我要求学校做什么。
3. **要求一个明确答复**：由谁负责、怎么处理、什么时候反馈。
4. **没有回应或情况继续**，逐级往上（年级组 → 德育处 → 校长），每一级都留记录。
5. **全程留痕**：每次沟通的时间、对象、内容。

可以照说的开场：

> "老师，我来是想和你对一下孩子最近在学校的情况。我这边记了几件事，想请你帮我一起看看怎么处理。"
> "我需要学校给一个明确的处理办法，还有一个什么时候反馈给我的时间。"

推进学校介入的依据是：学校层面的系统干预能实际降低欺凌发生率［1］，这不是"麻烦学校"，是走它本来就该走的流程。

### 六、稳住孩子这一侧

- **保持日常稳定**：作息、吃饭、睡觉尽量不变，稳定本身就说明"家是安全的"。
- **不反复追问细节**。你自己也别一遍遍让他讲，反复复述会加重痛苦。
- **给他能做的事**：运动、和信任的人待在一起、玩他擅长的东西，重建"我能掌控"的感觉。
- **用游戏和身体活动重建连接**：比讲道理更容易让他松下来［B3］。
- 青春期孩子对同伴评价高度敏感，被排斥会带来真实的痛苦，这不是"太脆弱"［B2］。

## 边界

- **不教打回去，不斥责"你怎么不还手"。**
- **不当着别人复述他的遭遇**（老师、对方家长、亲戚面前），他会觉得被二次暴露。
- **不私下找对方孩子或对方家长"算账"**——会升级冲突，也可能让事情反转。
- **不说**"这有什么大不了的""你自己也有问题""忍忍就过去了"。
- **不因为"不想把事闹大"就替他决定忍**。要不要升级，先和孩子商量。
- **不承诺"我保证明天就解决"**——做不到，他以后更不会说。
- **不追着问细节**。已知道的记下来，不逼他反复讲。
- **不把"被欺负"变成他的人格标签**，也不在家反复讨论"你是不是好欺负"。
- 这一份不用于紧急现场。孩子正在被围堵、正有危险时，先保人安全、先报警，见下节。

## 升级信号

下面任何一种出现，**都不该再"观察几天"**：

- 身上有伤（哪怕看起来不重），或财物被反复拿走、被索要钱；
- 孩子出现不想活、自伤、持续说"活着没意思" → 立即走 `07-safety/危机信号识别.md`，紧急打 **110／120**；
- 已经持续两周以上不见缓解，或孩子开始回避上学、装病不去；
- 发生在校外，涉及围堵、威胁、影像传播，或转向网络上的持续骚扰；
- 涉及与性有关的言语挑逗或不当触碰 → **不追问细节**，先就医留证，直接走 `07-safety/校园欺凌与人身伤害的法律处理.md`；
- 你已经向学校反映，问题仍在继续，或学校不按流程处理；
- 对方是一个群体、力量长期不对等，孩子已经不敢单独出门。

这些情况下，重点从"教孩子应对"转到"家长走流程"：留证据、找学校、必要时报警、就医。具体步骤和措辞见 `07-safety/校园欺凌与人身伤害的法律处理.md`。

等待观察的每一天都有成本：同伴受害会持续影响孩子的情绪和社交预期［3］。

## 依据说明

本份属外圈层机制与做法层。

- **证据分级 A**：学校反欺凌项目能降低欺凌发生率［1］（元分析）、师生情感关系与学生投入／成绩的稳定关联［2］（元分析）、同伴受害与社交焦虑的双向关联［3］（23 项前瞻研究的系统综述与元分析）——均为高等级证据。孩子不求助的常见障碍类型（难堪、怕被贴标签、倾向自己扛、不知有哪些帮助与向谁求助）［4］（系统综述，多为横断与非临床样本，只能读成常见原因分布）。
- **证据分级 C**：冲突／孤立／欺凌三分框架，属常见分类与经验说法，本份只用它做分流，不对孩子作任何定性、不给贴标签；倾听时承认感受、不否定，对应［B1］。青春期同伴评价敏感［B2］、用游戏与身体活动重建掌控感［B3］，均属成熟育儿框架。
