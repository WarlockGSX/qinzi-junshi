# 可写入字段与黑名单

> 适用对象：家长
> 生态层：纵向（时间）（记录与追踪）
> 适用时机：预防促进
> 一句话范围：字段白名单 + 内容黑名单（原话／逐字稿／可识别信息一律不存）。
> 相关文件：08-archive/记忆同意与启停.md；08-archive/对话档案（每次一条记录）.md；00-frame/亲子沟通判断维度.md

## 机制

### 一、档案只存"结构"，不存"内容"

- **结构** = 能放进固定字段、能量化或分类的东西（日期、状态、感受词、观察摘要）。
- **内容** = 原话、逐字稿、录音、可识别信息。

档案只存结构。这一条是整份文件的根。

### 二、字段白名单

**对话记录字段：**

| 字段 | 含义 | 上限 |
|---|---|---|
| 日期 | 沟通发生的日期 | — |
| 简述 | 这次聊了什么 | 200 字 |
| 沟通状态 | 八选一 | 16 字 |
| 家长的感受 | 你这一侧的当下感受 | 120 字 |
| 孩子那侧的观察 | 你看到的行为 | 200 字 |
| 一个变化点 | 跟上次比动了什么 | 200 字 |

**档案字段：** 孩子的年龄段与学段、青春期阶段、家长的角色与理念、家长的自评、场景标签、历次等级。这些是描述背景用的粗粒度字段，不含具体身份信息。

**白名单之外的字段，一律拒写。** 不是"建议"，是拒绝。

### 三、内容黑名单

只要字段名或取值里出现下面这些词，一律拒绝写入：

| 类别 | 词 |
|---|---|
| 原话与录音 | 原话、逐字稿、录音 |
| 身份 | 姓名、名字、生日、出生、身份证 |
| 位置与联系 | 学校、班级、地址、电话、手机号、微信、QQ |
| 医疗定性 | 诊断 |

道理：这些词指向的是"内容"和"可识别信息"，不是"结构"。

### 四、把可识别信息挡在外面的理由

三个理由：

1. **最小必要。** 处理个人信息应限于实现目的的最小范围［L1］。目标是"看状态走向"，不需要姓名和学校。
2. **降低泄露的后果。** 只存结构，即使数据被看到，也拼不出"哪个孩子、哪个学校"；隐私与个人信息受法律保护［L3］。
3. **保护孩子。** 涉及未成年人的信息要按"最有利于未成年人"处理［L2］；孩子的学校、生日属于他本人的信息，不是家长可以随手留存的内容。

被看到、被议论带来的难堪，本身就是阻碍儿童青少年求助的因素之一［3］——把可识别信息挡在外面，也让这套记录更容易被放心使用。

### 五、"逐字材料"的去向：不进档案

逐字材料（录音转写、聊天截图原文）只用于单次复盘：它能看到细节，在 `00-frame/亲子沟通判断维度.md` 里处理掉，结论落成结构化字段。**逐字材料本身不入库。**"记录细节"和"保存原话"是两回事。若你打算录音，先确认符合当地法律，并让孩子知情、同意。

### 六、字段名和取值都挡

黑名单对字段名和字段值都生效。哪怕字段名合法、值里夹带了姓名，也一样拒写。所以"孩子那侧的观察"里写"小明今天没说话"会被挡；写"今天没说话"就可以。

## 识别

### 一、可以写与不可以写的内容

| 你想写的 | 能不能写 | 改成 |
|---|---|---|
| "他说'我讨厌你'" | 不能（原话） | 观察："说了一句很冲的话" |
| "在××小学三年级" | 不能（学校／班级） | 用年龄段／学段字段 |
| "他生日是 3 月 5 日" | 不能（生日） | 不写；年龄用"年龄段"字段 |
| "他的诊断是 ADHD" | 不能（诊断） | 不写；涉及注意力问题走 `05-outside/上课走神与学习困难.md` |
| "今天聊完他就不说话了" | 能 | 直接写进"孩子那侧的观察" |
| "我很累" | 能 | 写进"家长的感受" |

### 二、想记原话时的做法

**不要把原话写进档案。** 想复盘原话，单独做一次单次复盘：有录音时走 `00-frame/亲子沟通判断维度.md`，用完后原话不保留。档案里只留这次复盘得到的状态、感受、变化点。

### 三、拿不准的时候

一律按"不写"处理。少存一句话的损失很小，存了不该存的损失很大（不可逆）。

## 做法

### 一、写之前先过表

写任何一个字段前，先看三件事：

1. 这个字段在不在白名单里？（不在 → 不写）
2. 这条值里有没有黑名单词？（有 → 改写或删掉）
3. 有没有超过字数上限？（超了 → 精简）

### 二、把"原话"改写成"观察"

| 原话 | 改写成观察 |
|---|---|
| "你怎么又这样，我都说多少遍了" | （家长侧不记原话）记我"上来了" |
| "我讨厌你" | 他说了一句很冲的话 |
| "随便吧，你说了算" | 他用了告别式的话，停止表达 |

只写看到、听到的、可复核的部分，不写解释，就是"区分观察与评价"［B1］［B3］。同一表现，不同来源（家长、老师、孩子自己）给出的结果往往不一致［1］，同一个人在不同情境里的观察也会跟着情境变［2］；所以只固定记录你看到的那一侧。

### 三、把"可识别信息"换成"粗粒度字段"

- 具体学校 → 学段（学前／小学低年级／小学高年级／初中／高中）
- 具体生日 → 年龄段
- 具体姓名 → "孩子"

### 四、不确定就不写

需要时问自己一句："这条信息，除了我，还有谁能用它找到这个孩子？"答案是"能"，就不写。

## 边界

- **白名单之外一律拒写。** 不是"建议"，是拒绝。
- **黑名单是硬挡，不是提醒。** 字段名和取值都查。
- **不存原话、逐字稿、录音。** 逐字材料只服务单次复盘，不入档案。
- **不存可识别信息。** 姓名、学校、生日、住址、联系方式、账号一律不进。
- **不存医疗定性。** "诊断"类内容不写；涉及就医走 `07-safety/就医与专业转介指征.md`。
- **不把档案当孩子的记录本。** 涉及未成年人的信息按最有利于未成年人的原则处理［L2］；档案里不给孩子贴标签，尊重其人格尊严［L2］。
- **不因为"字段空着可惜"就硬填。** 空着，比填可识别信息好。只写你自己真实看到的那一侧，也是对你自己诚实［B2］。

## 依据说明

本份属档案层，白名单／黑名单为本套材料自定，法律要求依据现行法规。

- **证据分级 A**：《个人信息保护法》关于个人信息处理限于实现目的最小范围的规定［L1］；《未成年人保护法》关于最有利于未成年人与尊重人格尊严的规定［L2］；《民法典》关于隐私权与个人信息保护的规定［L3］——均为现行法律。多信息源评估中不同来源一致性不高［1］、跨情境特异性［2］——元分析与经典评估研究；难堪等障碍与求助行为的关系［3］（系统综述）。
- **证据分级 C**：区分观察与评价、只写可复核的部分，对应到书［B1］［B2］［B3］。
- **证据分级 D**：字段白名单、黑名单清单、字数上限、三个过表步骤，均为本套材料自定。
