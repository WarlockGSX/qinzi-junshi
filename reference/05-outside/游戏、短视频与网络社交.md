# 游戏、短视频与网络社交

> 适用对象：家长
> 生态层：外圈层（学校与外部）
> 适用时机：预防促进
> 一句话范围：切用途不切设备；数字时代的真实边界。
> 相关文件：06-scenes/屏幕与手机.md；06-scenes/游戏充值与非理性消费.md；04-family/家庭规则的制定与执行.md；03-bond/奖励与惩罚的分寸.md；03-bond/设边界的句式.md

## 机制

### 一、"切用途"不"切设备"

把"手机""平板"当成一个整块去限制，几乎一定失败。因为它同时装着学习、联系、娱乐、社交、创作，你一刀切，孩子会觉得"你什么都反对"，于是规则守不住。

要按**用途**分，不同用途用不同规则：

| 用途 | 例子 | 规则方向 | 谁主导 |
|---|---|---|---|
| **工具型** | 查资料、上网课、导航、支付、拍照记录 | 不限时长，但看是不是真在用 | 用途本身不重要，时长也不必治 |
| **社交型** | 和同学聊天、群消息、语音通话 | 限时段，不限总量 | 这是真实的社交需要 |
| **娱乐型** | 短视频、游戏、追剧、刷帖 | 定时长、定场景 | 这是唯一需要立硬边界的一类 |
| **创作型** | 剪视频、编程、画画、写东西、做视频 | 通常要保护，不要误伤 | 往往被家长一起禁掉了 |

家长的常见错误是**把四类当成一类一起管**。孩子分不清你为什么反对，就干脆全部偷偷进行。

### 二、短视频和游戏"停不下来"的原因

- **不确定的奖励最抓人。** 每次往下滑、每次开一局，都可能有新东西，也可能没有。这种"有时有、有时没有"的反馈，比固定的奖励更能维持行为。
- **"下一条"是设计出来的。** 自动连播、无限下滑、连续签到，都是为了让停下来的那一刻往后推。停不下来不是他"没出息"。
- **青春期的大脑还没长好控制这部分。** 负责奖励与情绪的系统先成熟，负责控制的前额叶要到二十岁出头才逐步成熟，这是发育规律［3］［4］。所以指望他纯靠意志力关掉，是不现实的——需要外部结构（闹钟、规则、物理距离）来帮忙。

### 三、"多"的尺度：不是越少越好

一项对 5 万余名韩国青少年的分析显示：每天用手机超过 4 小时，与更高的压力、自杀想法、物质使用相关；但每天用 1–2 小时的孩子，遇到的问题反而比**完全不用手机**的孩子还少［1］。

这说明"一刀切地禁"未必是好答案。关键在**结构和时长**，不在"碰不碰"。（属关联研究，不能读成因果。）

### 四、大人自己的用法也在起作用

对 2260 名中国青少年的两波交叉滞后研究显示：家长"只顾看手机、不理孩子"（家长低头行为）与孩子的问题性手机使用存在关联，并且问题性手机使用与学习倦怠之间会互相强化，形成循环［2］。

也就是：**你想让孩子放下手机，你自己先放下，效果比讲道理大。** 你一边刷短视频一边催他学习，规则实质上是失效的。

### 五、线上社交是真实的社交

对青春期孩子来说，线上的朋友常常**就是**朋友。切断线上社交，等于切断他的社交，不是"减少娱乐"。所以规则要区分"聊天"和"刷无意义内容"。

同时网络交往有真实风险：暴露个人信息、被拉进不合适的群、被陌生人接近、被网暴、被要求发照片。这部分要立硬边界，见做法与升级信号。

### 六、未成年人网络保护条例：法定的底线

《未成年人网络保护条例》对平台设了责任：限制未成年人使用时长、规定网络游戏的服务时段、要求提供未成年人模式（青少年模式）等［L1］。

家长可以做的：**要求孩子使用的平台开启未成年人模式**，这不是你多事，是平台本来就该提供的。

## 识别

### 一、先分清是哪一类问题

| 现象 | 更像 | 方向 |
|---|---|---|
| 一玩就停不下来，但他自己也说"知道不该玩这么久" | 娱乐型过载 | 定时长、定场景 |
| 用手机是为了和同学联系，断了就焦虑、怕被落下 | 社交需要 | 不限社交总量，只限时段 |
| 说在查资料，其实在刷别的 | 用途混淆 | 把时段分开，别混着用 |
| 不玩手机就烦躁、睡不着、发脾气 | 可能已影响生活 | 见升级信号 |
| 关起门长时间不上学、只在网上有交往 | 可能伴随其他问题 | 走 `07-safety/就医与专业转介指征.md` |

### 二、判断"是不是真的成了问题"

用四条参照，**不要用"成瘾""网瘾"给孩子定性**：

1. 停不下来，且明显影响睡眠、吃饭、上学；
2. 因为手机和家人反复冲突，藏手机、撒谎、偷拿钱充值；
3. 不玩的时候烦躁、情绪差，只有玩的时候正常；
4. 社交、运动、兴趣都被它挤掉。

**出现三条以上、且持续两周以上**，再往"需要外部帮助"的方向考虑。一两条偶尔出现，属正常波动。

### 三、分龄

| 学段 | 屏幕使用的样子 | 你的重点 |
|---|---|---|
| **学前 3–6** | 还分不清虚拟和现实，模仿性强 | 尽量由你陪着看、看短、看完就关；内容你自己先过一遍 |
| **小学低年级 6–9** | 容易被短视频拉走；开始提"同学都有" | 定"什么时候"，用闹钟；不把设备放卧室 |
| **小学高年级 9–12** | 有游戏和群聊；开始在意同伴话题 | 教他分用途；开始把规则交给他自己管 |
| **初中 12–15** | 娱乐型和社交型同时增多；最容易被拉长 | 一起定规则、写下来；保护社交时间，砍娱乐时长 |
| **高中 15–18** | 基本能自管；可能用手机处理学习与社交 | 退到协商位置；关注是否影响睡眠与状态，不逐条查 |

## 做法

### 一、切用途的四步

1. **和他一起把"屏幕时间"分成四类**（工具、社交、娱乐、创作），让他自己认。
2. **不同类不同规则**：工具不限时但看是否真用；社交限时段；娱乐限时长限场景；创作保护。
3. **规则写下来、贴在能看见的地方**，全家包括大人一起守。
4. **用"设备放公共区域 + 到点设备离开房间"代替"盯着他"。** 物理距离比监视有效，也不伤关系。

### 二、定规则的具体做法

- **定"什么时候"比定"多久"更管用。** 比如"作业写完到饭前可以玩，饭后到睡前不碰"。
- **总时长 + 单次时长一起定**：单次不超过一个数，中间必须起身。
- **到点由闹钟或他自己关，不由你喊。** 你喊就是把你变成开关。
- **定一个"无屏幕时段"和"无屏幕区域"**：吃饭时、睡前一小时；餐桌、卧室。

### 三、可以直接照说的原句

> "手机不用收走。我们只把'刷视频'这一段定个时间。你想玩多久？"

> "你可以自己设闹钟，到点你自己关；没关的话，明天这一段就没了。你选。"

> "我不是不让你和同学聊天。聊天不算在游戏时间里。"

> "吃饭的时候我们都把手机放桌上，包括我。"

### 四、替代，不只是禁止

只禁不给替代，孩子只会偷偷玩。要给"更好玩的事"：

- 一起玩的真人游戏［B1］；
- 需要身体的活动：球、骑车、游泳；
- 和孩子一起玩他玩的游戏（哪怕你玩得菜）——**共玩比监控有效**；
- 有明确"完成感"的事：做饭、拼模型、养植物。

### 五、涉及网络社交的具体边界

- 不透露真实姓名、学校、住址、带定位的照片；
- 不加陌生人；
- 群里出现不合适的内容，先退出，再告诉家长；
- 被威胁、被要照片、被约见面 → **保留证据、不删，马上找家长**；
- 遇到网上骂人、造谣 → 截图留证，不自己回骂。

先承认屏幕对孩子有真实的作用，再谈规则，他更可能一起守［B2］。

## 边界

- **不用"成瘾""网瘾"给孩子贴标签。** 这是描述，不是诊断。贴了标签，他会觉得"我本来就是这样的人"，反而放弃了。
- **不把"没收手机"当唯一的办法。** 一收，冲突就开到最大，而且常常你输——他总有办法再拿到。
- **不偷偷查他手机、装监控软件**，除非已经确认有安全风险。被发现一次，信任很难补回来。
- **不在他正玩的时候突然抢手机。** 这是最容易触发正面对抗的动作。
- **不把屏幕时间当成奖惩的唯一工具**（见 `03-bond/奖励与惩罚的分寸.md`）。
- **不用"别人家孩子都不玩"这种比较。**
- **不假设"线上朋友都是假的"。** 对他是真的。
- **不指望一次改掉。** 习惯要几周才形成，中途反复是正常的。
- **家长自己一直刷手机，规则会失效**［2］。

## 升级信号

- **每天使用数小时、已影响睡眠和上学，自己调也调不动** → 走 `07-safety/就医与专业转介指征.md`。
- **不玩就强烈烦躁、攻击家人、自伤，或情绪明显低落** → 走 `07-safety/危机信号识别.md`；有自伤或不想活的话，立即打 **110／120**。
- **涉及网络上的威胁、勒索、要求发照片、被陌生人约见** → 立即保留证据并报警，见 `07-safety/法律与权利边界.md`。
- **长期不上学、只在网上有交往、昼夜颠倒** → 走 `07-safety/就医与专业转介指征.md`。
- **网暴、性引诱等超出家长处理能力的网络风险** → 保留证据、联系平台、必要时打 **110**。

以上涉及平台责任的部分，可以据此要求平台开启未成年人模式、配合处置［L1］。

## 依据说明

本份属外圈层机制与做法层。

- **证据分级 A**：现行规定为——未成年人网络保护条例对平台时长限制、网络游戏服务时段、未成年人模式的要求［L1］。
- **证据分级 B**：每天手机使用时长与青少年健康结果的关联［1］（5 万余人横断面调查、倾向得分匹配；属关联，不能读成因果）；青春期双系统发育——奖励系统先成熟、控制系统后成熟［3］［4］（理论／叙述性综述）；家长低头行为与孩子问题性手机使用的交叉滞后关联，以及问题性手机使用与学习倦怠的循环［2］（2260 名中国青少年、两波测量；属关联）。
- **证据分级 C**：共玩优于监控、先承认需要再谈规则，对应［B1］［B2］，属成熟育儿框架。
