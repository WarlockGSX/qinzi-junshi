# 分龄-小学低年级6-9

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：预防促进
> 一句话范围：6–9 岁：要求切成能做完的小事、肯定落在事上、先拿到注意力再开口。
> 相关文件：00-frame/分龄-学前3-6.md；00-frame/分龄-小学高年级9-12.md；03-bond/鼓励与表扬（落在过程上）.md；04-family/家庭规则的制定与执行.md；06-scenes/写作业与拖延.md；05-outside/上课走神与学习困难.md

## 机制

### 一、抽象指令的启动成本很高

"去把作业写了""收拾一下房间""你认真点"这类话没有说清做哪一件、做多少、从哪一步开始。小学低年级的孩子还不会自己把笼统要求翻译成第一步动作，所以看起来像不动、像拖拉。同一个要求，换成"先把数学那三道做了"，他就能启动。

### 二、注意力与自我调节还在发育

这个年龄的注意力维持时间短、抑制冲动弱、容易被旁边的东西拉走，这是发育阶段，不是态度［2］。所以需要外部结构：明确的一小步、具体的时间点、可见的进度，而不是反复催。教养方式与孩子的学业成绩之间存在关联（元分析，效应量偏小），但这是关联，不是因果，也不能反过来当成你的分数［4］。

### 三、他仍然需要你在旁边

这一段的"陪伴"不是监工，是陪启动。你在场、但不盯每一步，他更容易进入状态。全程盯着会让他把注意力放到"你在不在看我"上，反而更慢。

### 四、肯定的落点决定他做事的动机

有实验提示（研究对象为 10–12 岁儿童）：肯定落在"聪明""考得好"上，遇到难题时动机反而下降；落在过程与努力上，才守得住［1］。同一件事，你说"你刚才自己把书包收好了"，比说"你真棒"更能让他重复这个行为。家长的回应方式与孩子后续的行为和情绪有关（98 对母子、孩子 6–8 岁的纵向研究，属关联）［3］。

### 五、先拿到注意力再开口

他正忙着看动画、玩游戏时，你在另一个房间喊话，他常常是真没接收。要先把他的注意力拿过来，再给要求；指令发出后要看到他有反应，才算送达。

### 六、老师的话开始有分量

这一年龄，老师的评价第一次明显影响他怎么看自己，也可能影响他在某一科上的投入。所以"老师说你怎样"这句话，既能推他，也能压垮他。转述老师的话时，只转具体的事，不转成对他的评价。

## 识别

### 一、这一份的使用时机

- 说了很多遍，他像没听见；
- 一让写作业就开始磨、开始哭"我不会"；
- 做对的时候你不说，做错的时候你才开口；
- 你越是隔空喊，他越不动。

### 二、先分清是哪一类问题

| 现象 | 判断 | 先处理 |
|---|---|---|
| 只要你陪着开始，他就能做下去 | 启动问题 | 只切小第一步、陪启动 |
| 讲过的题转身又不会、同类题反复错 | 能力或方法问题 | 换方法，必要时走 `05-outside/上课走神与学习困难.md` |
| 叫他没反应，走近了才理你 | 注意力没收到 | 先走近、先拿到注意力 |
| 一做就哭"我不会" | 怕做错 | 先接住怕，再挑最简单的一道 |

### 三、分清"这一件"和"他这个孩子"

肯定与批评都要落在具体的事上，不落在人品上。说"你这次把字写整齐了"优于"你是个好孩子"；说"这三道你做错了"优于"你怎么这么粗心"。

### 四、判断你的话是不是太长

一个简单口径：说完这句话，他能不能复述出"现在要做的第一件事是什么"。复述不出来，就是说得太长或太抽象，要再切一刀。

## 做法

### 一、先记住一条：话越长，越难被执行

这一年龄处理一句话里的多个要求有困难。一次只放一个要求；先说这一件，做完了再说下一件。你一口气说五句，他通常只记住最后一句——往往还是你最气的那一句。

### 二、开口前的三步

1. **走过去。** 站到他旁边，不隔空喊。
2. **拿到注意力。** 等他看你、或轻轻碰一下他，再说。
3. **一次只给一件能做完的事。** 说清做哪一件、做多少。

### 三、可以直接照说的原句

**先拿到注意力：**
> "我看看你。好，我说一件事。"

**把要求切成能做完的一小步：**
> "先把数学那三道做了，做完告诉我。"

**给一个具体时间点，让他自己按：**
> "现在开始，还是十分钟后开始？你自己设个闹钟。"

让他自己按的闹钟、自己选的时间，比你的提醒更管用；把结果交给他的选择带来，比由你施压更能减少对抗［B3］。

**肯定落在事上、落在过程上：**
> "你自己把书包收好了，这是你刚才做到的。"

**把"怕做错"接住：**
> "你是怕做错，对吗？我们先做最简单的那道。"

**只谈当下这一件：**
> "我们就看今天这一页，不说昨天。"

**陪启动，不盯全程：**
> "你先把第一道读出来，我坐旁边。等你要我，我再过来。"

**看过程，不只看分数：**
> "这次你自己检查了一遍，比上次多查了一道。"

### 四、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| 隔空喊他不动 | 走近再说 | "我过来跟你说。就一件事。" |
| "等一下！" | 给一个具体时间 | "好，十分钟。到点你自己关。" |
| "我不会"就哭 | 先接怕，再挑最简 | "不用一下做完，就做这一道。" |
| 写两句就跑去玩 | 把休息排进计划 | "再写五行，就休息三分钟。" |
| 你把错的地方全划出来 | 只指第一个 | "这里再看一眼，你先自己找。" |
| 他做对了你不吭声 | 当场说出他做的那件事 | "你刚才是自己想的，没用我提醒。" |

鼓励具体到行为、给予有限选择，是这一段能用得上的做法［B1］［B2］。

### 五、把一天里的三个高频点固定说法

| 场景 | 固定说法 |
|---|---|
| 起床 | "我说一遍：穿衣、刷牙、吃饭。做完一件跟我说一声。" |
| 收书包 | "睡前三样：文具、书、水壶。你去放，放完报给我。" |
| 睡觉 | "现在八点半，看二十分钟书，九点关灯。" |

## 边界

| 不要做 | 原因 |
|---|---|
| 隔空喊话、反复喊 | 抽象指令收不到，最后只剩你的音量 |
| 只在结果好时才回应 | 他会把做事和"证明我行不行"绑在一起［1］ |
| 一次给一串要求 | 超出一小步，他启动不了 |
| 坐在旁边全程盯着 | 压力让他更慢 |
| 写错就当场打断纠正 | 打断一次，他要重新启动一次 |
| 贴"笨""懒""粗心"的标签 | 标签落在人身上，不是事上 |
| 用"你再这样我就不管你了" | 他会理解为被丢下 |
| 一次想改掉很多毛病 | 一段只挑一个高频场景改 |
| 转述老师的话时带上评价 | 会把一件事变成对他这个人的判定 |

**核心：这一段的要诀是"切小"和"落点"——把要求切到能做完，把肯定落在具体的事上。**转述老师的话时，只说他做了什么、下次可以做什么，不加"老师说你不认真"这类判定。

## 升级信号

- **明显的学习困难**：读题长期吃力、同类题反复不会、某一科长期远低于其他科、上课完全坐不住 → 走 `05-outside/上课走神与学习困难.md`，考虑专业评估。
- **持续的情绪问题**：连续两周以上情绪低落、频繁哭闹、拒绝上学、明显睡不好 → 走 `07-safety/就医与专业转介指征.md`。
- **长期被同伴排斥或欺负**：不愿提学校、身上常有说不清的小伤 → 走 `05-outside/校园欺凌与同伴冲突.md`。
- **出现自伤或说"活着没意思"** → 立即走 `07-safety/危机信号识别.md`；紧急情况拨 110／120，心理援助热线 12356。

## 依据说明

本份属机制层，是分龄五份中的小学低年级一段。

- **证据分级 A**：教养方式与孩子学业成绩的关系［4］——元分析（关联非因果，效应量偏小）。
- **证据分级 B**：自我调节与注意力随发育逐步形成并受环境影响［2］（综述）；评价性反馈与动机的关系［1］（以 10–12 岁儿童为对象的实验研究）；家长回应方式与孩子后续行为情绪的关系［3］（98 对母子、孩子 6–8 岁的纵向研究，属关联）。
- **证据分级 C**："具体指令""鼓励优于表扬""给有限选择""陪启动不陪全程""把结果交给他的选择带来"，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**："先拿到注意力再开口"这一步序、"愿／不能"的四类分流、本段的原句与边界，为本套材料自定。
