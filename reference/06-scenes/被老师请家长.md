# 被老师请家长

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：事后修复
> 一句话范围：从学校回来，怎么跟孩子开这个口——进门到谈完这一幕怎么走。
> 相关文件：05-outside/与老师沟通（被请家长）.md；03-bond/倾听与提问的技术.md；03-bond/风暴中的当场话术.md；03-bond/平复后的修复话术.md；02-parent/家长情绪急救.md；05-outside/校园欺凌与同伴冲突.md；07-safety/危机信号识别.md；07-safety/就医与专业转介指征.md

## 机制

### 一、你在办公室当了一小时"被告"，回家容易变成"法官"

被请家长会先触发三层反应：身份威胁、防御、转嫁（完整解释见 `05-outside/与老师沟通（被请家长）.md`）。这三层不会因为你出了校门就消失，它们会跟着你回家，决定你开口的第一句话。**回家这一刻真正的任务，是别把在学校受的气，变成对孩子的第一句质问。**

### 二、孩子这时候的第一反应是"我要被审判了"

他不知道你和老师谈了什么，只能从你的脸色、语气、进门动作去猜。你越沉默着挂包、越拧着脸，他心里编的版本越严重。他这时候问的其实是两件事：**这件事有多大、你会怎么处理我。**

### 三、你和老师、和他，看到的是三件不完全一样的事

同一个孩子在家和在校的表现是系统性不同的；老师、家长、孩子三方的说法一致度通常偏低，各自反映不同情境下的信息，谁都不能单方面否掉谁［1］［2］。所以回家第一件事不是"核对哪边对"，是**先把他的版本收到手**。

### 四、你和老师是站在一边还是对立，会经由孩子起作用

师生之间的情感关系和孩子的投入、成绩稳定相关［3］。你和老师是站在一起，还是当场对立，与老师对孩子的态度和投入有关，也和他之后在学校的投入有关。所以"做合作者不做被告"不只是礼貌问题，它有实际后果。

### 五、开口的方式，决定他下次还说不说

孩子在学校的困难，很多不会主动说。不求助的常见原因有：怕难堪、怕被贴标签；倾向自己扛；不知道该找谁帮忙［4］。你这次开门的方式，关系到他下一次还说不说。

### 六、分龄：同一个"老师找我了"，不同年龄听到的是不同的事

| 学段 | 他最先想到的 | 你开口的落点 |
|---|---|---|
| **学前 3–6** | "我是不是做错事了" | 不用"老师告状"吓他，只讲具体一件事 |
| **小学低年级 6–9** | 怕被罚 | 先问事实，帮他分清"老师不满意的是哪件事" |
| **小学高年级 9–12** | 怕丢面子、怕当众 | 单独谈，不翻旧账 |
| **初中 12–15** | 怕被定性、被管 | 先听后说，不当传话筒，不替老师定性 |
| **高中 15–18** | 觉得被干涉 | 从"监工"退到"后盾"，问需要不给安排 |

## 识别

### 一、进门先判断：今天该谈还是不该谈

| 情况 | 做什么 |
|---|---|
| 已经很晚、他刚睡下或刚回来极度疲惫 | 今天不谈，只说一句"明天我们聊一件事" |
| 涉及人身安全（被打、打人、被孤立、被不当触碰） | 当天就谈，先问安全 |
| 你自己还没从办公室的情绪里出来 | 先不谈，按下一节先把自己放下来 |

### 二、判断你现在能不能开口

| 你的信号 | 说明 | 先做什么 |
|---|---|---|
| 一进门就想质问 | 你把在学校的气带回来了 | 先不进他房间，自己坐十分钟 |
| 已经想好怎么训 | 你会听不全他的版本 | 强制自己先说"我听你说" |
| 太阳穴发紧、声音发颤 | 你可能会当场失控 | 见 `02-parent/家长情绪急救.md` |

### 三、判断这次要谈的是"一件事"还是一个"定性"

老师说的是某一次具体的事，就只谈那一次；老师给的是一句定性（"他就是懒""他就是坐不住"），先把定性翻译成具体行为再谈（翻译方法见 05 那一份），**别把一句评价原样带回家。**

## 做法

### 第一节 · 进门前十分钟：先把自己放下来

在车里、楼道里、进门前，做三件事：

1. 把老师说的**事实**和老师说的**评价**分两栏，在心里过一遍；
2. 对自己说一句："我今天是来听他自己说的，不是来定罪的。"
3. 定一个开场方式：不隔空喊、不站在门口、不进他房间就质问他。

### 第二节 · 进门：先不谈那件事

先恢复日常，让他有个缓冲。**不要**一进门就把书包一放、脸一沉："老师今天跟我说了你的事。"

> "我回来了。先吃饭／先歇会儿。"

先把日常那一步走完，再找一个两个人能坐下来的时间。

### 第三节 · 开口：先说事实，不先复述老师的评价

找一个能坐下的时间，用平常的语气。请他坐下，你也坐下。

> "老师今天跟我说了学校的一件事，我想先听你说说是怎么回事。"
> "我不是来定你罪的。你先说，我等你。"

说观察、不直接给评价，是这类沟通能推进的前提［B2］。**不要**开头就复述老师的原话，尤其带定性的（"老师说你上课老讲话"）——那句话会立刻把他推到防守位置。把人当人、而不是当下结论的对象，是对话还能继续的基础［B1］。

### 第四节 · 听他的版本：三问

1. "当时发生了什么？从你的角度看。"
2. "老师说的那个环节，你记得吗？"
3. "这件事里，你觉得哪一步可以不一样？"

**三问的共同点是：先要事实，再要他的判断。** 倾听与提问的具体做法见 `03-bond/倾听与提问的技术.md`。他的版本和老师的版本对不上时，**先不下结论**，记下来，回头再和老师对一次。

### 第五节 · 他说这些时的接法

说事实和感受、不评价人，是这类话能降级而不是升级的关键［B3］。

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "老师就是针对我" | 不当场站边，也不否认 | "这个我先记着。你先说说当时具体怎么发生的。" |
| "又不是我的错" | 不辩论对错，先要事实 | "我先不判谁对。你把过程说一遍。" |
| 立刻炸、摔门 | 停，转当场处理 | 走 `03-bond/风暴中的当场话术.md`，事留到平复后 |
| 一声不吭 | 不追问到底，留门 | "你现在不想说也行。明天再说，这事我会等你。" |
| 委屈地哭 | 先接情绪，不急着问 | "你先难受会儿。等你想说，我听着。" |
| 完全承认、很沮丧 | 别顺势加码 | "你愿意说实话，这件事就好办。我们一起想办法。" |

### 第六节 · 谈完：给一个"结束了"，再给一个下一步

不管谈得怎么样，收尾要给一个明确的"这件事先到这"：

> "今天就说到这儿。明天你去学校，先做一件事——[具体的某一小步]。过两天我问问老师有没有变化。"

把"和善"与"坚定"一起给到，比单靠施压更能让他配合［B4］。给了具体时间点，孩子会理解为"这件事有边界"；不给，他会理解为"这事一直悬着"。

### 第七节 · 分龄的一句

| 学段 | 开场一句 | 收尾一句 |
|---|---|---|
| **学前 3–6** | "老师说了一件事，我想问问你。" | "知道就行，明天见到老师打个招呼。" |
| **小学低年级 6–9** | "老师跟我说了一件事。你先说，我听着。" | "这件事我们这样定。" |
| **小学高年级 9–12** | "我想单独跟你聊两句。" | "这事就到这儿，我不再提。" |
| **初中 12–15** | "老师说的我先听着，你的版本我也想听。" | "你自己想想怎么弄。需要我做什么你说。" |
| **高中 15–18** | "这事你怎么看？" | "你定，我来兜底。" |

### 第八节 · 隔一周回访老师

一句话确认进展："上次说的那件事，这一周有没有变化？"（回访与办公室那一侧的做法见 `05-outside/与老师沟通（被请家长）.md`。）

## 边界

- **不在孩子面前复述老师的评价**，尤其是带定性的（"老师说你懒"）。
- **不在老师面前替孩子认罪**，也不当场承诺"回去一定收拾他"——那会同时毁掉你和孩子、你和老师两条线。
- **不把"老师说的"当唯一事实**——三方的观察会不一致，都要收着［1］［2］。
- **不把被请家长当成你的成绩单**——教养与孩子表现有关联，但关联不等于因果。
- **不用"老师要请家长了"吓孩子**，那会把他和学校、被惩罚绑在一起。
- **一次只推进一件事**，别把一学期的账翻出来。
- **不当场逼他认错**——你要的是他下次肯开口，不是这一次低头。
- **不越过老师直接找别的家长对质**，先和老师把事实对齐。

## 升级信号

- 老师的描述涉及**人身安全、疑似欺凌、疑似不当对待** → 当天按 `05-outside/校园欺凌与同伴冲突.md` 处理，涉法律走 `07-safety/` 对应文件。
- 孩子开始**拒学、出现持续躯体不适（头痛、肚子痛）而不上学** → 见 `07-safety/就医与专业转介指征.md`。
- 你自己**每次去学校都情绪崩溃、事后长时间缓不过来** → 先处理你这一侧，见 `02-parent/家长情绪急救.md`。
- 孩子说"活着没意思"或出现自伤 → 立即停止学校话题，走 `07-safety/危机信号识别.md`；紧急 **110／120**，全国统一心理援助热线 **12356**。

## 依据说明

本份属情景脚本层（机制与办公室那一侧见 `05-outside/与老师沟通（被请家长）.md`）。

- **证据分级 A**：不同信息源一致度有限、行为有情境特异性、需多来源共同评估［1］［2］（均为元分析）；师生情感关系与孩子投入／成绩的稳定关联［3］——元分析（99 项研究）。孩子不求助的常见原因（怕难堪被贴标签、倾向自己扛、不清楚能去哪里求助）［4］（系统综述，多为横断与非临床样本，只能读成常见原因）。
- **证据分级 C**："先谈事实、不谈评价""先听他的版本再核对"，属成熟沟通做法，对应到书［B1］［B2］［B3］［B4］。
- **证据分级 D**：进门前三件、进门不谈、三问、收尾给时间点、分龄开场与收尾句，为本套材料自定。
