# 叫不动与拖延

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：当场应对
> 一句话范围：喊很多遍不回应：走到身边再说一遍。
> 相关文件：06-scenes/写作业与拖延.md；03-bond/设边界的句式.md；05-outside/上课走神与学习困难.md；04-family/家庭规则的制定与执行.md；02-parent/家长情绪急救.md

## 机制

"吃饭了""来洗澡""把玩具收了"——喊了五遍，他像没听见。这一幕的对象不是作业（作业另走 `06-scenes/写作业与拖延.md`），是日常里所有"叫了不动"的时刻。

### 一、隔空喊，对正在专注的孩子基本无效

他可能真没听见，也可能听见了不想动。两种都不会靠"更大声"解决。

- **真没听见**：他在专心看、专心玩，注意力全在一件事上。这时候从另一个房间喊，声音进不去。注意与抑制能力是随发育逐步长出来的，受环境和经历影响，不是"喊一次就该会"［1］。
- **听见了不想动**：他在等你喊到第几遍才需要真的行动。这跟"听见"无关，跟你**喊到第几遍才真的跟进**有关。

### 二、喊得越多，他越习惯等

如果你每次都是喊到第三遍、第五遍才真的走过去处理，他学会的是"前几遍不用理"。你越勤，他越不需要反应。**"叫不动"有一半是被叫出来的。**

靠压制和强制型的叫法（"我数到三，一——二——"）当常规手段，与更差的结果相关；但相关的是"骂、罚、随意惩处"这一类强制做法，"坚定但直接"不算在内。这是对 87 个家庭从学前追踪到青春期的研究，属关联［2］。侵入式地盯、催、管，也和青少年（样本 13–25 岁）的内化、外化症状相关，管得越紧并不等于结果越好［3］。

### 三、"再说一遍"的正确做法

走到他身边 → 让他看见你 → 确认他注意到你 → 再说一遍。**缩短距离，比提高音量有用。**

一次说一件事，说清"做完长什么样"（"把积木收到盒子里"而不是"把这儿收拾干净"）。

### 四、分龄差异

| 学段 | 叫不动的样子 | 你该改的那一环 |
|---|---|---|
| **学前 3–6** | 进入游戏就出不来，没有时间概念 | 走到身边、身体带动、一次一件事 |
| **小学低年级 6–9** | 能答应，转头就忘 | 给一个明确的下一步 + 看得见的提醒 |
| **小学高年级 9–12** | 会讨价还价"等一下" | 给具体时间、让他自己计时 |
| **初中 12–15** | 戴着耳机、锁着门，叫了不应 | 先让他注意到你，再说；不当众叫 |
| **高中 15–18** | 多半是"不想理"，不是没听见 | 说一句事实，把选择留给他，不追着叫 |

## 识别

### 一、先分是"没听见"还是"不想动"

| 表现 | 判断 | 做法 |
|---|---|---|
| 叫了没反应，走近他抬头看你 | 没听见 | 走到身边再说一遍 |
| 走近了也说"等一下"，然后一直不动 | 不想动 | 给具体时间 + 到点执行约定 |
| 叫"吃饭"没反应，叫"出去玩"立刻现身 | 选择性听见 | 不是听力问题，是动机问题 |
| 各种场合都反应慢、常说"没听清" | 可能听力或注意问题 | 走 `05-outside/上课走神与学习困难.md` |
| 只在你在家时叫不动，别人叫就动 | 你们之间形成了固定模式 | 改你的叫法，不改他 |

### 二、判断你自己现在是不是在"喊"

听你自己的声音：是不是隔着房间、是不是已经带火气、是不是这一句和上一句内容一样。中了任意一条，先停止，走过去再说。

### 三、判断这一件事值不值得今天处理

不是每件事都值得走完全程。真正的底线（安全、底线作息）才执行到底；其余的可以今天松、明天再来。

## 做法

### 一、当场四步

1. **停止隔空喊，走过去。** 手机可以放下，话可以说完，但人要先靠近。
2. **到他身边，先看他在做什么**，等一个自然的停顿，不硬打断。
3. **一次说一件事，说清"做完什么样"。** 不说"收拾一下"，说"把积木放进这个盒子"。
4. **到点没动，平静执行约定，给选择。** 不翻脸、不翻旧账。

### 二、可以直接照说的原句

**叫他吃饭**
> "（走到旁边，等他抬头）饭好了，洗手吃饭。"

**让他收玩具**
> "（蹲下来）这堆积木要收起来了。你想先收红的，还是先收蓝的？"

**叫他过来帮忙**
> "我需要你帮我把这个搬过去。现在，一分钟的事。"

**他说"等一下"**
> "好，五分钟。你自己看着时间，到点我再来叫你一次。"

**到点还没动**
> "到点了。我们说好的。你现在过来，不然这件事我只好自己做了。"（后果与这件事相关，不牵别的）

### 三、一个可复制的开场

> （走过去，坐下）"我打断你一下——不是坏事。有件事需要你现在做。"

三个要点：**靠近**（不隔空）、**一件事**（不一次说一串）、**让他回应**（他答应一句，而不是你没听见他应）。

### 四、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "等一下！" | 不贴"拖延"，给具体时间 | "好，几分钟？说个数。" |
| 装没听见 | 走过去，不加大音量 | "（到他跟前）我在这儿说。有件事要你停一下。" |
| "我在忙！" | 承认他的事，再给选项 | "我知道你在忙。这事一分钟。你现在做，还是五分钟后？" |
| 摘耳机／才听见 | 不指责"你故意不理我" | "你戴着耳机没听见。我下次先碰一下你。" |
| "凭什么叫我！" | 不辩论凭什么 | "这事得有人做。今天轮到你。" |

给有限的选择、用描述代替命令，是这类叫法更有效的前提［B1］［B2］。让结果跟着他的选择走，比你一次次推进，更不容易变成正面对抗［B3］。

## 边界

- **不要隔空反复喊。** 喊五遍不动的效果，和喊一遍不动是一样的，只是你更累、火更大。
- **不要用"我数到三"当常规手段。** 偶尔用可以，变成每天的固定台词就失效了，还把你变成那个"一直响的闹钟"。
- **不要一次给一串指令**（"把衣服脱了、书包放好、洗手、来吃饭"），一次一件。
- **不要在他专注时突然高声打断。** 先给一个预告："这局玩完就吃饭。"
- **不要把叫不动解释成"不尊重你"。** 它多半是注意力、动机和习惯的问题。
- **不要拿别的事当后果**（"再不来就不带你出门"）。后果要跟这件事相关，否则规则显得随机。
- **不要指望他从此一叫就动。** 习惯要几周，中途反复正常。

## 升级信号

- 各场合普遍反应慢、听不清、常要重复 → 先查听力，再看注意相关，见 `05-outside/上课走神与学习困难.md`。
- 叫不动同时伴随明显走神、坐不住、作业长期完不成 → 同上。
- 你每次都以吼或动手收场 → 先处理你这一侧，走 `02-parent/家长情绪急救.md`。
- 长期因此每天冲突、换过方法仍无变化 → 走 `04-family/家庭规则的制定与执行.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：侵入式教养与青少年内化／外化症状的关系［3］——三层元分析（样本为 13–25 岁）。
- **证据分级 B**：学前期的强制型教养做法与更差结果的关系［2］（单项纵向研究，87 个家庭，只标"强制型"一类）、自我调节随发育逐步形成并受环境影响［1］——机制综述。
- **证据分级 C**：描述问题代替命令、给信息、给有限选择、自然后果，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：当场四步、距离对照、可以照说的原句、分龄差异表、"喊得越多他越习惯等"的表述，为本套材料自定。
