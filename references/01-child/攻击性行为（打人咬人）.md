# 攻击性行为（打人咬人）

> 适用对象：家长
> 生态层：个体层（孩子自身）
> 适用时机：当场应对
> 一句话范围：打人咬人的成因（语言不够用、情绪过载、被侵犯、求关注）与可替代的动作，以及为什么不给孩子贴"爱打人"的标签。
> 相关文件：06-scenes/打人咬人的现场.md；06-scenes/抢玩具与同伴冲突现场.md；01-child/情绪爆发的机制.md；03-bond/设边界的句式.md；03-bond/风暴中的当场话术.md；03-bond/平静期的预防与预演.md；05-outside/校园欺凌与同伴冲突.md；04-family/手足冲突.md

## 机制

### 一、打人咬人在幼儿期很常见，多数会自己降下来

身体攻击不是"学坏"的结果，是很早就出现的动作。追踪研究发现，多数孩子在婴儿期就开始出现身体攻击；学前期是学会用其他方式替代的关键阶段，多数孩子会在进入小学前逐渐减少，只有一小部分持续偏高（一项从 5 个月随访到 42 个月、随机抽取 572 个家庭的研究中，约 14% 落在高攻击轨迹上）［1］。婴儿从大约 6 个月起就会对别人用身体推、抓，并随理解"东西是谁的"逐渐转为有意的攻击；这类个体差异从 6 个月起就能观察到［2］。

所以：**学前期出现打人、咬人，本身不等于"这孩子有问题"，多数属于发展过程的一部分。**

### 二、四种常见的出现条件

打人咬人很少是凭空的，通常出现在这几种条件里：

| 条件 | 现场的样子 |
|---|---|
| **语言不够用** | 他说不清"我要""我不要""还给我"，手先动了 |
| **情绪过载** | 太累、太吵、太兴奋，管不住动作（见 `01-child/情绪爆发的机制.md`） |
| **被侵犯** | 玩具被抢、被打、被插队，用武力"讨回来" |
| **求关注／求连接** | 打一下你就立刻来，他记住了这个开关 |

这几种要分开处理。语言不够用和情绪过载，要教替代动作、降强度；被侵犯，要教怎么用言语和求助；求关注，要把关注给到别的时候。孩子的行为常常在表达一个目的（想被看见、想有掌控感），看目的比看表面动作有用［B1］。

### 三、标签会把它固定下来

一遍遍说"他就是爱打人"，会变成两边都认的事实：他被按这个位置对待，你在冲突里只看这个行为。孩子会把它当成身份。**这一份不给孩子贴"爱打人""暴力"这类标签。**

### 四、不是越严越好

教养方式和孩子的外部化行为（攻击、对抗等）之间有稳定关联；整体上，**"高要求 + 高回应"（有边界也有温度和解释）比"高压 + 低回应"更少带来外部化问题**［3］。所以处理打人，不是靠加重惩罚，而是靠"同样清楚地把边界立住，同时给替代动作和情绪出口"。

## 识别

### 一、先分是"哪一类"，再决定当场做什么

| 现场 | 更像 | 当场先做 |
|---|---|---|
| 抢玩具时打人 | 被侵犯／工具性 | 拦动作 + 教说法，先不判谁对谁错 |
| 又累又吵时抓人咬人 | 情绪过载 | 先带离、降刺激，事后再说 |
| 说不清就动手 | 语言不够用 | 补句子："你是想说'轮到我'吗？" |
| 打了你就看你反应 | 求关注 | 少反应、冷处理，把关注给到别的时候 |
| 只针对某一个人 | 关系或情境问题 | 查那一段关系里发生了什么 |

### 二、分清"冲突中打人"和"反复欺负人"

| | 冲突中打人 | 反复欺负／持续攻击 |
|---|---|---|
| 对象 | 通常是争同一个东西 | 常针对特定的人，且有强弱关系 |
| 目的 | 抢回／表达 | 让对方难受／控制 |
| 事后 | 后悔或不知所措 | 不后悔、还会重复 |
| 处理 | 这一份 | 走 `05-outside/校园欺凌与同伴冲突.md` |

### 三、盯"频率和趋势"，不盯单次

单次打人不说明什么。要看的是：**是不是越来越频繁、力度是不是变大、是不是只针对某个人、有没有其他方式可用却仍然只有打。** 后面几条越明显，越要往升级信号那一节看。

## 做法

### 一、当场四步（按顺序）

1. **先拦住动作，保护人，不羞辱他。** 抓住手、把人分开，语言短、不评价。
2. **只命名行为，不贴标签**：说"你打人了"，不说"你怎么这么坏"。
3. **把关注先给被打的一方**：先看有没有受伤、先安抚被碰到的孩子——这也顺手削弱了"打人=立刻得到你全部注意"的开关。
4. **立边界 + 给替代**：动作不能做，但需求可以说出来。

可以直接照说：

> （拦住手）"我不会让你打人。"

> （把两个人分开）"你们都先松开。被碰到的先看我这里。"

> （对被抢的那个）"你是想说'还给我'吗？跟我说这句话。"

> （对打人的那个，事后）"你刚才很急。急的时候可以说'还给我'，或者来找我。手不能动。"

### 二、教替代动作，而不是只说"不许"

只说"不许打"不够，他会不知道还能做什么。提前教，并且当场帮他用：

| 他原来的动作 | 替代做法 |
|---|---|
| 抢东西时打人 | 说"轮到我了""还给我"，或举手找大人 |
| 生气时咬人 | 咬牙抱枕、跺脚、说"我生气了" |
| 兴奋时推人 | 原地跳几下、拍手心 |
| 说不清时抓人 | 拉你的手往那个方向指，或说"我想……" |

替代动作要在平静时反复练（见 `03-bond/平静期的预防与预演.md`），当场才有得用。

### 三、情绪过载引起的：先降强度，事后才谈

他正处在情绪风暴里时，负责理性与自控的那部分脑功能暂时不工作，讲道理没用、逼他道歉也没用［B2］（见 `03-bond/风暴中的当场话术.md`）。先带离、关小、少说话，等平复后再复盘：

> （事后）"刚才你太累了。累的时候我们早点回家。刚才那样打人，我们下次用说的，好吗？"

### 四、事后复盘：说清四件事

平静后，用最短的话说清：**发生了什么、他的感受是什么、边界是什么、下次可以做什么**。

> "刚才弟弟拿了你的车，你很气，你推了他。推人不行，他会疼。下次你可以说'这是我的'，或者来叫我。"

### 五、让后果来自行为，不来自你的怒气

边界要稳定。每次打人都对应同样的、可预期的后果（比如当场结束这个游戏），而不是看你心情。用稳定、可预期的自然后果／逻辑后果代替随情绪起伏的惩罚，更少制造"你针对我"的对抗［B3］（见 `03-bond/设边界的句式.md`）。

### 六、分龄：同一个动作，在不同年龄含义不同

| 学段 | 打人咬人的常见样子 | 你该改的那一环 |
|---|---|---|
| 学前 3–6 | 多半是语言不够用或情绪过载 | 教替代动作、降刺激，不罚 |
| 小学低年级 6–9 | 常和争抢、规则不清有关 | 说清规则，教用话说和求助 |
| 小学高年级 9–12 | 多为关系或面子冲突 | 私下谈，帮他看冲突里能做的选择 |
| 初中 12–15 | 少见真动手，多为言语攻击和推搡 | 不接球，事后谈，关注背后是否被欺负 |

## 边界

- **不给孩子贴标签**：不说"你就是爱打人""你天生暴力"。标签会变成自我实现的预言。
- **不逼当场道歉**：情绪里逼出来的道歉没有意义，还会教他"嘴上认错就能过关"。
- **不动手"让他尝尝"**：以打止打只会教他"力气大的人可以打人"。
- **不当众审问、不当众羞辱**：伤害更大，也不解决问题。
- **不翻旧账**：只谈这一次。
- **不把打人美化成"男孩子都这样"**：性别不能给伤害行为开脱。
- **不忽略被打的一方**：他的安全和感受同样要处理。

## 升级信号

出现下面这些，超出"发展过程中的常见行为"，按 `07-safety/就医与专业转介指征.md` 评估：

- 频率和力度持续上升，用了替代方法也不减；
- 反复针对同一个人，带有强弱和控制关系（见 `05-outside/校园欺凌与同伴冲突.md`）；
- 打人已经让人受伤，或同时出现对动物、对自己的伤害；
- 伴随持续的说谎、破坏、对规则完全无反应，且持续**六个月以上**；
- 孩子自己说"我控制不住""我也不想这样"。

## 依据说明

本份属机制 + 当场做法层。

- **证据分级 A**：多数孩子在婴儿期已出现身体攻击、学前期是学习替代方式的关键期、仅约 14% 持续偏高（5–42 个月纵向追踪、572 个家庭的随机样本）［1］；教养维度与外部化行为的关系、"高要求 + 高回应"优于"高压 + 低回应"［3］（元分析，效应量偏小）。
- **证据分级 B**：婴儿从约 6 个月起出现使用武力的行为，随理解占有权逐渐转为有意攻击；个体差异从 6 个月起可见［2］——综述性研究，读作"常见发展规律"。
- **证据分级 C**：把出现条件分为语言不够用／情绪过载／被侵犯／求关注，属常见框架，用于分流，不作诊断；行为背后的目的框架［B1］、情绪过载时先接情绪［B2］、用自然后果代替惩罚［B3］，对应到经典育儿书。
- **证据分级 D**：当场四步、替代动作对照表、事后四句话、稳定后果的做法，为本套材料自定。
