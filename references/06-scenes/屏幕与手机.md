# 屏幕与手机

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：当场应对
> 一句话范围：约的是"哪个时段能用"而不是"一天总共能玩多久"；以及"现在，把手机还给我"这一幕怎么走。
> 相关文件：05-outside/游戏、短视频与网络社交.md；06-scenes/游戏充值与非理性消费.md；03-bond/奖励与惩罚的分寸.md；04-family/家庭规则的制定与执行.md

## 机制

### 一、约"时段"而不是约"总量"的原因

"一天总共能玩多久"在当场没法执行：你查不到他到底玩了多久，他也没法边玩边算。这句话最后一定会变成"我觉得你玩太久了"。

换成时段就变成两件当场能核的事：**从几点到几点可以玩**，以及**到点设备放哪儿**。这两件事你能看见，他也能自己管。

### 二、收回手机是全场对抗的最高点

它同时触发了三件事：正玩到一半被打断、"下一条"的机制被硬停、以及"你不讲道理"的判断。短视频和游戏的反馈是"有时有、有时没有"，这种不确定的奖励最能把人留住，"自动连播""无限下滑"就是为了把"停下来的那一刻"往后推。

所以**收手机的难度不在意志力，在那一刻有没有一个事先说好的时间点**。事先说了时段，收手机是执行约定；事先没说，收手机就是你单方面打断他——他会理解为后一种，然后开始争。

### 三、指望他自己关不现实

负责奖励与情绪的系统先成熟，负责控制的前额叶要到二十岁出头才逐步成熟，这是发育规律［2］［3］。这个阶段靠的不是意志力，是**外部结构**：闹钟、事先约定的时段、设备放在公共区域。

### 四、你喊，就是把自己变成开关

一旦每次都由你开口收，你在他的体验里就等同于"游戏结束"这件事。你越喊，他越把注意力放到"你在不在看"。**到点由闹钟响、由他自己按，你只在没执行时出面。**

### 五、守作息底线的理由

急性、不可控的压力会让负责自控的前额叶功能快速下降，这是生理过程，不是态度［4］。屏幕时段挤占的常常是睡眠；睡不够，第二天他更没有余量去自控。所以"睡前一小时、卧室"这两条底线值钱，不是因为屏幕本身有害，是因为它挤掉了睡眠。

### 六、切的是用途，不是设备

手机同时装着学习、联系、娱乐、创作。娱乐型才需要立硬边界，社交型对他是真实需要，工具型和创作型不该一起禁。**四类分别立什么规，见 `05-outside/游戏、短视频与网络社交.md`；这一份只讲"当场要收回手机"这一幕怎么走。**

屏幕里也确实有有用的部分：已有系统综述与元分析显示，生成式 AI 心理支持聊天机器人平均能减轻抑郁、焦虑等问题［1］。这同样是不要一刀切切设备的原因。但这类研究多在成人中开展、纳入试验少，只说明"屏幕里的工具不全是坏的"，不能读成屏幕对孩子有某种因果影响，更不能推出具体的屏幕时段建议。

## 识别

### 一、先分清现在这个"要收"是什么情况

| 当下的样子 | 更像 | 用手法 |
|---|---|---|
| 事先有时段约定，他到点没关 | 执行问题 | 走做法一，平静执行约定 |
| 事先没约定，你现在要收 | 规则还没立 | 先收这一次，事后补规则，见做法四 |
| 他正和同学在群里说事 | 社交被误伤 | 让这一段说完，或另约时段 |
| 他正在剪片子／写东西 | 创作被误伤 | 这一类不该收，先问清在做什么 |
| 你一边自己刷手机一边要他放下 | 规则已失效 | 先改你这一侧 |

### 二、"该守底线了"的判断信号

出现下面任一条，底线优先，不必等商量结果：影响睡眠（睡前一小时还在玩、设备进卧室）、吃饭时不放下、因为手机持续冲突、藏手机或撒谎。**只有一两条偶尔出现，属正常波动，不用升级成规则大战。**

### 三、分龄：同一句"把手机给我"，在不同年龄是不同的事

| 学段 | 收回的难度 | 你的做法 |
|---|---|---|
| **学前 3–6** | 不懂"等一会儿"，中断即哭 | 由你陪着看、看完就关；提前一句"看完这个，我们一起去洗手" |
| **小学低年级 6–9** | 能听懂时间但自控弱 | 闹钟 + 事先说的时段；到点你先按闹钟，再伸手 |
| **小学高年级 9–12** | 开始讨价还价 | 约"什么时候"、把设备放公共区域；让他自己关 |
| **初中 12–15** | 冲突最激烈；社交和娱乐同时在线 | 一起定、写下来；到点由他关，你只处理没执行 |
| **高中 15–18** | 基本能自管 | 退到协商位置；守"卧室"和"睡前"两条，其他不逐条查 |

## 做法

### 一、当场要收回手机：五步

**第 0 步：能提前的都在提前。** 到点前 5–10 分钟，一次提示：

> "还剩十分钟，这一局差不多够吗？到点闹钟响。"

**第 1 步：闹钟响，给一个明确的收尾点**，不用"立刻"：

> "闹钟响了。这局打完／这段看完，就放桌上。"

不要求他在最刺激的中间点停。允许收尾，是让"停下来"这件事可执行。

**第 2 步：到点还没放，平静说执行，不评价人**：

> "时间到了。手机放桌上，明天这段还留着。"

**第 3 步：他要还在拖，把选择摆出来，让他选**：

> "你可以现在放，明天照旧；或者放到我这儿，明天这段就没了。你选。"

给有限的选择、让后果由他自己的选择带来，比单方面施压更能减少对抗［B1］［B3］。

**第 4 步：他情绪上来了，先停，别在那一刻讲规则。** 情绪风暴中讲道理无效，先按 `03-bond/风暴中的当场话术.md` 处理，规则留到平复后（`03-bond/平复后的修复话术.md`）。**不要在他正在玩的时候突然抢手机**——这是最容易点着正面对抗的动作。

**第 5 步：收完不补刀。** 不说"你就是不自觉""以后别想玩了"。一句评价会把这次执行变回一场关于他是什么人的争论。

### 二、可以直接照说的原句

**到点前的提示（6–9 岁）**
> "还有十分钟。你自己定，是玩到闹钟响，还是现在就停、明天多五分钟？"

**到点，他还在拖（6–9 岁）**
> "闹钟响了。我知道这一局没完。你自己关，还是我帮你关？明天这一段还在。"

**他开始讲条件（9–12 岁）**
> "今天不加时间。你要加，我们周末坐下来改规则，不是现在改。"

**他抛社交理由（12–15 岁）**
> "和同学聊天不算游戏时间。你可以先把这段聊完，说一句'我妈叫我吃饭'再放。"

**你要收，他说你也在玩（各年龄）**
> "你说得对。吃饭的时候我也放桌上，包括我。"

**已经在吵了（12–15 岁）**
> "我先不收了，今晚就到这儿。明天晚饭后我们把时间重新说一遍。"
> （这一句是止损，不是放弃——事后必须真的谈，见做法四。）

### 三、守作息底线的两条，只守两条

1. **睡前一小时不娱乐型使用**；
2. **设备不进卧室**（充电在客厅，全家一样）。

这两条不看当天表现、不做例外。其余时段可以商量、可以调整；这两条一旦松动，第二天早上你会付账。

### 四、事后补规则：三步

1. **和他一起分用途**，让他自己认哪一段是娱乐、哪一段是社交、哪一段是正事（分类见 `05-outside/游戏、短视频与网络社交.md`）。
2. **只写"时段 + 设备放哪儿"**，写下来贴在能看见的地方。不写"每天不超过几小时"。
3. **定一个复查时间**："这两条我们下周日再看要不要调。"有结束点的规则，比一次定死的规则守得住。

没有替代活动，只禁不给，他只会偷偷玩。给一件更好玩或有完成感的事（一起打球、做饭、拼东西），是这套规则能落地的前提［B2］。

另外：不要用"少玩就给奖励"来换。外部奖励——尤其可预期的有形奖励——会削弱本来就有的内在动机，对孩子影响更大［5］。想让他在别处投入，靠的是那件事本身有意思，不是靠你给的条件。

### 五、你这一侧

你自己一直刷手机，规则实质上是失效的。**吃饭时全家把手机放桌上，是最省力的一条示范。** 你不需要表演，只要不双标。

## 边界

| 不要做 | 原因 |
|---|---|
| 约"一天总共能玩多久" | 当场没法执行，最后变成你的主观判断 |
| 突然伸手抢手机 | 直接触发最激烈的正面对抗 |
| 用"再玩就没收一星期"加码 | 一次加码，规则就不再是规则，是威胁 |
| 偷偷装监控、翻聊天记录 | 被发现一次，信任很难补回来（另见 `06-scenes/青春期关门对抗.md`） |
| 把"没收手机"当唯一办法 | 冲突开到最大，而且你常常输 |
| 把屏幕时间当奖惩的主要工具 | 会把它变成永久的战场（见 `03-bond/奖励与惩罚的分寸.md`） |
| 用"网瘾""成瘾"给他定性 | 这是描述，不是诊断；贴了标签，他容易放弃 |
| 一边自己刷一边催他放下 | 规则失效 |
| 把线上社交一律当"不是正经事" | 对他来说线上朋友常常就是朋友 |

**核心：这一份管的是"到点该怎么把设备放下"，不是"他该不该碰屏幕"。**

## 升级信号

- **每天使用数小时、已影响睡眠和上学，自己调也调不动** → 走 `07-safety/就医与专业转介指征.md`。
- **涉及游戏内大额消费、偷偷扣款** → 走 `06-scenes/游戏充值与非理性消费.md`。
- **网络上的威胁、勒索、要求发照片、被陌生人约见** → 立即保留证据，不删，打 **110**，并见 `07-safety/法律与权利边界.md`。
- **不玩就强烈烦躁、攻击家人、自伤，或情绪明显低落** → 走 `07-safety/危机信号识别.md`；有自伤或不想活的话，立即打 **110／120**。
- **长期不上学、昼夜颠倒、只在网上有交往** → 走 `07-safety/就医与专业转介指征.md`。

涉及平台责任的部分（限时、未成年人模式、游戏服务时段），家长有权要求平台配合，这不是你多事［L1］。

## 依据说明

本份属做法层。

- **证据分级 A**：外部奖励对内在动机的削弱（对儿童更强）［5］（128 项实验的元分析）；生成式 AI 心理支持聊天机器人平均能减轻成人抑郁、焦虑等问题［1］（系统综述与元分析，研究对象多为成人、纳入试验少，只支持"数字形态本身不全是有害的"，不支持任何具体屏幕时段建议，不能读成因果）。
- **证据分级 A**：未成年人网络保护条例（现行法规）——平台限时、未成年人模式、网络游戏服务时段的规定［L1］。
- **证据分级 B**：青春期双系统发育——奖励系统先成熟、控制系统后成熟［2］［3］（叙述性／理论综述）；急性、不可控的压力会让前额叶功能快速下降［4］（机制综述）；
- **证据分级 C**：给有限选择、自然后果、替代活动优于单纯禁止，属成熟育儿框架，对应到书［B1］［B2］［B3］。
