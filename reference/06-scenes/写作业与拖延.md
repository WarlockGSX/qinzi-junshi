# 写作业与拖延

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：当场应对
> 一句话范围：叫孩子写作业他说"等一下"、坐下来一直磨、你一催他就顶——这一幕从头到尾怎么走。
> 相关文件：03-bond/奖励与惩罚的分寸.md；03-bond/分龄说法要点.md；01-child/挫折耐受与韧性.md；03-bond/风暴中的当场话术.md；04-family/家庭规则的制定与执行.md；05-outside/上课走神与学习困难.md

## 机制

写作业的冲突通常出现在两个环节：**启动不了**，和**拖到很晚**。这两个环节的原因不同，处理方式也不同，用同一种办法对待一定有一个治不好。

### 一、"启动不了"的机制

**任务太大、太模糊。** "去写作业"没有说写哪一科、写多少、从哪道开始。对小学阶段的孩子，抽象指令的启动成本很高。换成"先把数学那三道做了"，他才能启动。分龄化、可完成的指令比笼统要求有效，这一点在家长管理类做法里是一致的［B1］。

**开始比做完难。** 一件事最难的部分是启动，不是持续。

### 二、"拖到很晚"的机制

**任务超出当下能力或状态。** 他确实做不完。这时要改的是量或方法，不是催的质量。

**拖延是表达。** 烦、怕做错、不想被盯着，都会表现为拖。其中"怕做错"最常见——被反复纠正过的孩子，不动就不会错。家长的侵入式管控与青少年的内化、外化症状存在稳定关联（元分析样本为 13–25 岁），管得越紧并不等于结果越好［3］［4］。

### 三、三个会让情况变差的做法

1. **催得越勤，他越把写作业和你绑在一起。** 一次没被催、自己坐下来的经验，比十句"快去写"管用。
2. **桌面上东西太多。** 只留这一科要用的，比堆着一摞书更容易启动。
3. **全程盯着。** 被注视时他更慢，也更容易把注意力放到"你在不在看我"上。

### 四、表扬落点决定他写作业的动机

肯定落在"聪明"这类能力评价上，会在遇到难题时削弱动机；肯定落在过程与努力上，才维持得住［2］。这是"写作业期间看过程不看结果"这条做法的依据。

### 五、分龄：同一句催促，在不同年龄是不同的事

孩子的自我调节能力（包括注意力、抑制冲动、自己启动）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［6］。所以同一句要求，在不同学段要做成不同样子。

| 学段 | 拖延的常见原因 | 你该改的那一环 |
|---|---|---|
| **学前 3–6** | 通常还没有"作业"概念；若有，多是任务超出当下能力 | 单次不超过 10 分钟，中间安排身体活动 |
| **小学低年级 6–9** | 抽象指令启动不了；注意力本身还在发育 | 把指令切到一道题；陪启动，不陪全程 |
| **小学高年级 9–12** | 有自我管理意愿，但计划能力弱；容易被整块任务吓住 | 让他自己列清单、自己设时间；你只看流程 |
| **初中 12–15** | 科目多、量确实大；也可能是情绪或关系问题的出口 | 先分清是"量太多"还是"不想学"；不接管、不当监工 |
| **高中 15–18** | 基本自理；拖延常连着更大的焦虑或方向问题 | 退到后盾位置：问需要，不给安排 |

拖延同时伴随明显的注意力困难、读题困难，或某一科长期远低于其他科时，已经超出"催"能解决的范围，走 `05-outside/上课走神与学习困难.md`。

## 识别

### 一、先分清是哪一个环节

| 现象 | 环节 | 处理方向 |
|---|---|---|
| 你说了他还不动 | 启动不了 | 切小任务、给具体时间 |
| 他坐下来还在磨、越写越慢 | 拖到很晚 | 改量或方式，不是继续催 |
| 一坐下就哭"我不会" | 怕做错 | 先接住怕，再挑最简单的一道 |
| 十点还没写完 | 量确实超了 | 拆作业或和老师沟通，不是加催 |

### 二、判断是"不想"还是"不能"

| 表现 | 判断 | 做法 |
|---|---|---|
| 只要开始就能做完 | 不想（启动问题） | 只处理启动 |
| 做了很久也做不完、同一道卡很久 | 不能（能力或量的问题） | 减少量、换方法、考虑评估 |
| 特定一科特别拖、别的科正常 | 可能是这一科的基础或方法问题 | 走 `05-outside/上课走神与学习困难.md` |

### 三、分清是谁的事

孩子的学业表现和家长的教养方式有稳定关联（元分析，效应量偏小），但关联不等于因果，也不能反过来当成家长的评分［1］。所以判断口径是：**你能改的是回应方式和节奏，不是替他改成绩。**

## 做法

### 一、当场六步

1. **先走过去，不隔空喊。** 拍拍肩，看一眼他正在做的事，接一句。
2. **要一个具体时间，让他自己设闹钟。** 把"现在"变成"十分钟后"，并且让他自己按。他按的闹钟比你的提醒有效。
3. **把任务切到能启动的一小步。** 不说"把作业做完"，说"先做这三道题"。关键是"能做完"，不是"做得多"。
4. **到点还没动，平静执行约定，给选择。** 不翻脸、不翻旧账，把后果说清，让他选。让后果由他自己的选择带来，比由你来施压更能减少对抗［B3］。
5. **写作业期间看过程，不只看结果。** 他坐下来了、比昨天快——这比分数更能让他坚持［2］。
6. **卡住了先给方法，不先给答案。** "这道题你打算从哪儿开始？"

### 二、一个可复制的开场

> （走过去，坐下）"还有多少没写？……数学还剩几道？"
> "那我们先做三道，做完你告诉我。剩下的一会儿再看。"

三个要点：走到身边（不隔空）、只谈一小步（三道题）、让他报告（他告诉你，不是你去查）。

### 三、可以直接照说的原句

**第一次提醒（6–9 岁）**
> "嘿，你看的这个挺有意思的。还有多久看完这一集？"

**他说"看完就去"（6–9 岁）**
> "好，这集还剩多久？十分钟？那我们说好十分钟后开始。我帮你设个闹钟，到点你自己关，好吗？"

**到点还没动（6–9 岁）**
> "时间到了。我知道你还想看，但我们说好了。遥控器先放这儿，写完你还能再看十五分钟。"

**还是不动，给他选（9–12 岁）**
> "你可以现在开始，写完还有时间看；或者再等一下，但今天的屏幕时间就用完了。你选。"

**切小任务（6–9 岁）**
> "先把数学那三道做了，做不完我陪你看看卡在哪儿。"

**看过程（6–12 岁）**
> "你已经写了三行了，不错的开始。还剩几道？要不先专注十五分钟，休息五分钟吃个水果？"

**让他自己排（9–12 岁）**
> "今天几样作业？你自己排个顺序，排完告诉我大概几点能收工。要是不合适我们再一起调。"

**他嫌你烦（12–15 岁）**
> "行，我不盯着了。九点前你告诉我一句'写完了'就行，有卡住的地方你叫我。"

（不再补一句"你可别光玩手机"——那会把约定变回监视。）

**真写不完（12–15 岁）**
> "今天这门确实多。你是想现在挑一部分做、剩下的明天早上补，还是我先跟老师说明情况？"

给有限的选择，而不是命令或威胁，是这类说法能让他配合的前提［B2］。

### 四、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| 立刻炸："我就是不想写！" | 退一步，只处理启动 | "那我们先做最小的一件事，就一道题。做完你告诉我。" |
| 嘴上答应，实际不动 | 不贴"不守信用"，按约定平静执行 | "这条卡在哪儿了？" |
| 一直拖到很晚 | 改量或方式 | "今天是不是太多了？我们看看怎么减。" |
| 一坐下就哭"我不会" | 先接住怕，不讲题 | "你是怕做错，对吗？我们先做最简单的这道。" |
| 写到一半跑来跑去 | 把休息排进计划 | "再写五道，就休息三分钟。" |
| 你一说他就哭 | 可能把"写作业"和"我做不好"绑在一起了 | 走 `03-bond/鼓励与表扬（落在过程上）.md` |

他已经进入情绪风暴时，这一份先停，走 `03-bond/风暴中的当场话术.md`，作业留到平复后再说。他情绪上来时，负责理性与语言的那部分脑功能暂时不工作，先接情绪、再讲道理才有用［B4］。家长自己的情绪状态与孩子的情绪状态有关，你先稳住，这一步才有意义［5］。

## 边界

| 不要做 | 原因 |
|---|---|
| 隔空喊"快去写作业" | 抽象指令，他启动不了 |
| 只在结果好时才回应 | 他会把学习和"证明我行不行"绑在一起［2］ |
| 催得越勤越紧 | 越催越把写作业和你绑在一起 |
| 一次没做到就升级规则 | 把具体的事变成对抗 |
| 用手机／电视做奖惩 | 会把它变成你们之间的战场（见 `03-bond/奖励与惩罚的分寸.md`） |
| 翻旧账 | 谈当下这一件就好 |
| 坐在旁边全程盯着 | 压力会让他更慢 |
| 写错就当场打断纠正 | 打断一次，他要重新启动一次 |

**核心：切的是"启动"，不是"态度"。**

另外：不要指望他每天都自己启动。习惯要几周才形成，中途反复是正常的。

## 升级信号

- **持续两周以上、每天因此冲突**，且换过方法仍无变化 → 先看 `04-family/家庭规则的制定与执行.md`，再考虑是否需要外部评估。
- **某一科长期远低于其他科、读题明显吃力、上课也坐不住** → 走 `05-outside/上课走神与学习困难.md`。
- **写作业总以你失控收场**（吼、摔东西、动手）→ 先处理你这一侧：`02-parent/家长情绪急救.md`。
- **孩子说"我不想活了"或出现自伤** → 立即停止作业议题，走 `07-safety/危机信号识别.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：教养方式与学业成绩的关系［1］（元分析，效应量偏小）、教养维度与外部化问题的关系［4］、侵入式教养与青少年内化外化症状的关系［3］（样本 13–25 岁）——均为元分析。
- **证据分级 B**：能力表扬削弱动机［2］（单项实验）；自我调节随发育逐步形成并受环境影响［6］、家长情绪调节与孩子情绪调节的纵向关联［5］（98 对母子，间接路径未达显著）。
- **证据分级 C**：自然后果与逻辑后果、鼓励优于表扬、给有限选择、具体指令，属成熟育儿框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**："启动不了／拖到很晚"两环节的拆分、当场六步、分龄差异表、可复制开场，为本套材料自定。
