# 教养底层框架

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：预防促进
> 一句话范围：三根支柱（安全感／自主感／价值感），为什么连接优先于纠正、允许优先于压制。
> 相关文件：03-bond/亲子互动的底层机制.md；01-child/行为是需求的信号.md；00-frame/依恋模式与关系底色.md；00-frame/情绪共调节.md

## 机制

### 一、孩子长期需要的三样东西

家长做的事绝大多数可以归到三样上：安全感、自主感、价值感。这三样不是表现好才给的奖励，是长期稳定提供的基本条件。哪一样长期缺，行为问题就从哪一样上出。

| 支柱 | 是什么 | 日常里的说法 | 长期缺时的样子 | 你提供它的方式 |
|---|---|---|---|---|
| 安全感 | 我做错了、我失控了，这段关系也还在 | "你生气的时候我也不会走" | 黏人、反复试探、怕被丢下 | 稳定的回应；不拿"不要你了""不爱你了"当话 |
| 自主感 | 有一部分事是我说了算的 | "这件事你来定" | 阳奉阴违、拖延、无所谓、什么都靠催 | 在安全范围内给真实的选择权 |
| 价值感 | 我这个人本身是值得的 | "不管考多少，你都是我们家的人" | 讨好、怕失败、放弃、"我不行" | 无条件接纳；肯定过程，不只肯定结果 |

三根会互相牵连。安全感不足时，孩子会用自主感去试探——"我顶一下，你会不会就不要我了"。价值感不足时，他会用成绩或讨好去换一个位置。所以三根里只补一根，通常稳不住，另外两根会把缺口显出来。

依恋安全感来自家长稳定的、可预期的回应，而不是某个单次事件；回应的敏感程度与依恋安全有稳定关联［1］。早期照护关系会形成相对稳定的内部模式，影响一个人后来在关系里的反应方式，这也是"关系底色"说法的来源［B1］。价值感这一根，落点在"不带条件地接纳他本来的样子"，这是改变能发生的前提［B4］。

### 二、连接优先于纠正的原因

纠正（讲道理、指错、提要求）要起作用，前提是孩子还处在"和你连在一起"的状态里。顺序不能反：

1. 先连上：他知道你看见他了，你不是来否定他这个人的；
2. 再纠正：这件事哪里不对、下一次怎么改。

孩子处在对抗状态时，纠正的内容会先被接收成"她在说我不好"，然后才是"她在说什么"。情绪唤起冲上来时，负责听懂语言、组织回应、想到后果的那部分脑功能会明显下降，这是生理过程，不是态度［2］。在这种状态下的"纠正"，落进去的是否定，不是信息。

家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［3］；先接住情绪、再谈行为的顺序，是情绪辅导类做法的共同前提［B2］。高要求同时高回应的教养方式，孩子的适应结果好于高要求低回应；而"有要求但没回应"和"有回应但没要求"都不是最优［4］［5］。连接不是纠正的对立面，是纠正能不能生效的开关。

### 三、允许优先于压制的原因（自主感）

压制（用命令、威胁、惩罚、撤回关爱来让孩子服从）换到的是短期听话，代价落在自主感上。

- 管得越紧、越用内疚和收回关爱去控制（心理控制），与孩子的抑郁、焦虑水平相关［6］；
- 侵入式的管控（不放手、替他决定、盯着他做）与孩子的内化、外化症状存在稳定关联，管得越紧并不等于结果越好［7］；
- 用高压、威权方式推进的要求，长期看与更差的适应结果相关［8］。

压制还有一个更隐蔽的代价：它替代了孩子自己长出来的能力。自我调节（注意力、抑制冲动、自己启动）是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［9］。每一次都由你来压，等于每一次都替他做了一遍；他练的机会被拿走了。

"允许优先于压制"不是不设边界。它的意思是：**在安全的范围内，先让他自己试、自己承担后果，你只在触到边界时才介入。**

### 四、允许不是放任，纠正不是指责：一条分界线

| | 连接优先 | 压制 |
|---|---|---|
| 出发点 | 这件事怎么解决 | 他怎么这么不听话 |
| 对象 | 行为 | 人 |
| 手段 | 说事实、给选择、让他担后果 | 命令、威胁、比大声、撤关系 |
| 短期 | 慢一点 | 快 |
| 长期 | 他自己会做 | 你不催就不动 |

分界线是**对象**：处理行为，不评判人。同一句话里，"你把牛奶洒了，我们一起擦"和"你怎么这么笨"是两件完全不同的事。

## 识别

### 一、先判断当前最缺的是哪一根

一次只处理一根，不要同时上三根。

| 你观察到的 | 大概率缺 |
|---|---|
| 他反复确认你还在不在；一被批评就崩；怕你走开 | 安全感 |
| 什么都要你催；嘴上答应、实际不动；"随便" | 自主感 |
| 怕失败不敢开始；一考差就否定自己；讨好别人 | 价值感 |

### 二、各份的适用时机

| 你的问题 | 去哪一份 |
|---|---|
| "他为什么不信任我说的'我会回来'" | `00-frame/依恋模式与关系底色.md` |
| "他一哭我就慌，接不住" | `00-frame/情绪共调节.md` |
| "具体这句话怎么说" | `03-bond/亲子互动的底层机制.md`、`03-bond/话术总原则.md` |
| "他这么做到底要什么" | `01-child/行为是需求的信号.md` |

### 三、三根支柱的加载有先后

安全感排在最前面。安全感不稳的时候，你在自主感和价值感上做的努力会被反复试探掉：他先要确认"你还在不在"，才顾得上"我能不能自己决定"。所以如果三根都在报警，先做安全感。

### 四、分清"缺支柱"和"一时闹"

不是所有不顺都指向支柱缺口。一次考试失利、一次和同学闹别扭，属于当下的具体事件，处理事件本身即可。以下情况才往支柱这一层看：**同一类问题跨情境重复出现、换过几种方法都不动、持续两周以上。**

## 做法

### 一、每一根支柱对应一个最小动作

| 支柱 | 最小动作 | 可以直接说 |
|---|---|---|
| 安全感 | 冲突后主动确认关系还在 | "刚才我们都气得不轻。这件事要谈，但我不走。" |
| 自主感 | 把一条命令换成两个真实选项 | "现在就收，还是再玩五分钟收？你定。" |
| 价值感 | 把肯定落在过程上 | "你今天自己坐下来了，比昨天快。" |

### 二、连接优先：冲突中先做减法，再谈事

当场（他正在情绪里）：
1. 降到比他小：他喊，你用比平常低的音量说；
2. 身体退半步，不正对，不用手指；
3. 只给一句最短的话，不推进话题。

> "我们先停一下。"

事后（都平静下来）：
1. 先承认事实和感受："你刚才特别生气。"（不评价人）
2. 再谈边界："我不会让你摔东西，但你想发火可以。"
3. 最后才谈方法："下次你气到这样，先告诉我一句，行不行？"

连接优先不等于当场不处理。它意味着：**当场处理的是关系，事后处理的是行为。** 顺序倒了，两边都做不成。

### 三、允许优先：把三条常见命令改成选择

| 命令 | 改成（给真实、有限的选项） |
|---|---|
| "快去写作业" | "先做数学还是先做语文？你自己排。" |
| "马上关电视" | "你想看完这一集关，还是现在就关、明天多看十分钟？" |
| "不许这样跟我说话" | "你生气我听得见。换一种说法，我就能接着听。" |

给有限的选择而不是命令或威胁，是这类说法能换来配合、又不伤自主感的前提［B3］。

### 四、允许承担自然后果

在安全、可承受的范围内，让后果由他自己的选择带来，而不是由你来施加。后果发生后，不补一句"我早说过"，只帮他看一遍这次的因果。

> "水壶忘在学校了。明天要喝水，你打算怎么办？"

### 五、按学段把三根的重心挪一挪

| 学段 | 最需要先稳的 | 你的重心 |
|---|---|---|
| 学前 3–6 | 安全感 | 稳定在场、及时回应、少讲道理 |
| 小学低年级 6–9 | 安全感 + 自主感 | 陪启动，逐步把选择权放出去 |
| 小学高年级 9–12 | 自主感 | 让他排自己的事，你只看流程 |
| 初中 12–15 | 自主感 + 价值感 | 不接管、不当监工；肯定落到人本身 |
| 高中 15–18 | 价值感 | 退到后盾位置：问需要，不给安排 |

## 边界

- **连接优先不是永远不纠正、不生气。** 家长会生气是正常的。要改的是"生气时撤走关系"（说"我不要你了""你别叫我妈"）和"生气时攻击人"。生气本身不需要消灭。
- **安全感不是有求必应。** 是回应，不是答应。可以回应他的情绪，同时不给那个东西。
- **自主感不等于放任。** 涉及安全、健康、法律和他人的事，边界由你定；其余的事，把选择权让出去。
- **价值感不是夸。** 频繁的空夸（"你真棒"）落不到他身上；肯定要具体，落在过程和努力上，而不是落在他这个人聪明不聪明上［10］。
- **三根支柱不是评分表。** 它是给你判断"该处理哪一端"的，不是用来给孩子打分，或者评价自己的育儿成绩。
- **不要同时上三根。** 一次只动一个，观察两周再看下一根。
- **这一份是机制层。** 具体某一场冲突怎么说，见 `03-bond/` 下对应文件；情景类的完整脚本在 `06-scenes/`。

## 依据说明

本份属机制层，给出三根支柱的定义与"连接优先、允许优先"的方向判断。

- **证据分级 A**：家长回应的敏感度与依恋安全的关系［1］（元分析）；心理控制与孩子抑郁焦虑的关系［6］（元分析）；侵入式管控与孩子内化外化症状的关系［7］（元分析）。
- **证据分级 B**：情绪唤起对前额叶功能的抑制［2］（机制综述）；高要求高回应的教养方式与更好的适应结果［4］［5］（均为青少年样本，属关联）；家长的情绪回应方式与孩子之后的情绪处理有关［3］（情绪社会化研究综述）；自我调节随发育逐步形成并受环境影响［9］（发展心理学综述）；威权式推进的要求长期与更差适应结果相关［8］（学龄前父母管教，追踪到青少年）。
- **证据分级 C**：三根支柱（安全感／自主感／价值感）的划分、"连接优先于纠正、允许优先于压制"的说法，属成熟育儿框架的归纳，对应到书［B1］［B2］［B3］［B4］；不作临床分类使用。
- **证据分级 D**：三根支柱的日常判断表、最小动作表、"把命令改成有限选择"的对照、允许承担自然后果的说法、分龄重心表，为本套材料自定。
