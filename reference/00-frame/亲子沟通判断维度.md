# 亲子沟通判断维度

> 适用对象：家长
>
> 生态层：底座（横切）（原理与分龄）
>
> 适用时机：事后修复
>
> 一句话范围：五个维度（倾听／开放／支持／真诚／连接）。仅当手里有逐字材料时使用，口述路径不适用。
>
> 相关文件：00-frame/沟通等级与封顶.md；00-frame/卡点清单.md；08-archive/对话档案（每次一条记录）.md；03-bond/开口与演练.md

## 机制

### 一、五个维度

手里有一段对话的逐字记录（录音转写、聊天记录、你复盘时写下来的原话）时，用这五个维度看这段对话。每个维度看的是"这一段里有没有"。

| 维度 | 看的是              | 有它的样子          | 缺它的样子             |
| -- | ---------------- | -------------- | ----------------- |
| 倾听 | 你是在回应他说的，还是在等你说话 | 接他的话头、复述、追问一句  | 各说各的、抢话、只等他闭嘴     |
| 开放 | 你有没有留出他自己想的空间    | "你怎么看""还有呢"    | 只给标准答案、直接下结论      |
| 支持 | 你站在他这一边，还是站在问题那边 | "这事不好办，我跟你一起看" | "早跟你说过了""这是你自己的事" |
| 真诚 | 你说的和你实际的状态一致     | "我现在有点烦，但我愿意听" | 嘴上说没事，身体和语气全是拒绝   |
| 连接 | 这段对话下来，他离你近了还是远了 | 结束时会看你一眼、说点别的  | 结束时走开、关门、不看你      |

五个维度不是并列平分。**连接是结果，其余四个是过程。** 前四个维度的状态，最后都会落在"他离你近了还是远了"上。

### 二、只适用于有逐字材料的情况

口述复盘里，家长记得的通常是"我说了什么"和"他怎么顶我"，很难记得"我有没有接他的话头""我有没有留空间"。而这些恰恰是四个过程维度要看的东西。凭记忆评这五个维度，等于拿被改过的材料做判断。

逐字材料的意义在于：它把"我记着的样子"和"实际说的话"分开。多信息源评估里的共识是，同一个孩子的表现，不同来源（家长、老师、孩子自己）之间的一致性常常不高［1］［2］，所以不看原始材料、只凭一方记忆下结论，容易偏。这一条是"要有逐字材料"的依据。

### 三、五个维度的选取标准

这五个来自对几种成熟沟通框架的归纳：

- **倾听、真诚、无条件接纳**——以人为中心的关系核心条件：真正的倾听、内外一致、不带条件的接纳，是关系能起作用的前提［B1］；
- **支持、开放**——家长对孩子情绪是支持还是否定、是留空间还是压制，与孩子长期怎么处理自己的情绪有关［3］；高要求同时高回应的方式，孩子的适应结果更好［4］；
- **连接**——先连接、再讲道理，是情绪辅导类做法的共同前提［B2］。

这五个维度是本套材料的归纳工具，不是某个既有的量表。

### 四、五个维度不是评分表

它是拿来找"这一段里缺哪一块"的。目的不是给家长打分，是定位下一次能改的那一处。给一次对话打总分、然后据此判断"我是不是个好家长"，是这个工具最常见的误用。

## 识别

### 一、先判断"能不能用"

**能用**（有逐字材料的任一形式）：对话录音转写、聊天记录截图、你复盘时逐句写下的原话。

**不能用**（口述路径）：

- 你只记得大意："我说了半天他都不听"；
- 你要处理的是"我现在很气，下次怎么说"——这类走 `03-bond/` 下的做法文件；
- 材料只有一方的话（只有你的转述，没有他的原话）。

材料不足时，**不要硬套五个维度**，改用 `00-frame/卡点清单.md` 找模式，或直接走情景脚本。

### 二、判断材料的完整度

| 材料      | 能看哪几个维度          |
| ------- | ---------------- |
| 只有你说的部分 | 开放、真诚（看不到他的反应）   |
| 有来有回的一段 | 全部五个             |
| 只有他的原话  | 只能反推倾听与连接，参考价值有限 |

### 三、和相邻工具的分流

| 你手里的问题       | 去哪一份                  |
| ------------ | --------------------- |
| "这段对话整体在哪一级" | `00-frame/沟通等级与封顶.md` |
| "我总卡在同一类地方"  | `00-frame/卡点清单.md`    |
| "下次具体怎么开这个口" | `03-bond/开口与演练.md`    |

## 做法

### 一、逐句标注，不跳步

1. **一句一行**：把材料按说话人整理成"你一句／他一句"。
2. **只标有／无**：对每一句问"这一句里，五个维度哪个在、哪个不在"。不评好坏，只标在不在。
3. **找集中缺口**：把没标上的地方圈出来，看是不是集中在同一件事上（比如都缺"开放"，一开口就想给答案）。
4. **只挑一个**：选一个出现最多、又最容易改的维度。
5. **改成一句能说出口的话**：把这个维度的缺口，落成一句下一次可以照说的话。

### 二、每个维度给一个"改法"

| 缺的维度 | 常见原因        | 下一次改成                   |
| ---- | ----------- | ----------------------- |
| 倾听   | 你在准备自己的下一句  | 先复述他一句："你是说……对吧？"       |
| 开放   | 你急着给答案      | 问一句："你想让我听着，还是一起想办法？"   |
| 支持   | 你站在问题那边     | "这事是不好办。我跟你一起看看。"       |
| 真诚   | 你压着自己的情绪说没事 | "我现在有点急，我先喘一口，你接着说。"    |
| 连接   | 你只在处理事      | 结束时加一句关系话："谢谢你愿意跟我说这个。" |

复述、命名感受、给选择这类具体技术，在"倾听"这一维度上最常用［B3］；说事实而不评价人、说自己的感受而不指责对方，是"真诚"与"开放"这两维度落地的关键［B4］。

### 三、几个可以直接照着标的例子

**例子一（缺倾听）**

> 孩子："今天体育课我被换到最后一排了。"
>
> 你："那你就多跟老师说啊，你老是不吭声。"

标：倾听、开放都缺——你没接他的话，也没问他怎么看。改成：

> "被换到最后一排，你当时什么感觉？"

**例子二（缺支持）**

> 孩子："数学这次没考好。"
>
> 你："我早说了让你多做两套题。"

标：支持缺——你站在成绩那边。改成：

> "你自己也不好受。先说说，是哪一块卡住了？"

**例子三（缺真诚）**

> 孩子："你是不是不爱我了。"
>
> 你：（烦躁）"胡说，我怎么会不爱你。"

标：真诚缺——你说的是话，没说你现在的状态。改成：

> "你刚才那句话吓了我一下。我一直在，这点没变。"

### 四、标完只做一件事

每段材料标完，只改一处。下一次对话里，只盯你选的那一个维度。改动了再动下一个。一次五个一起来，通常一个都改不动。

## 边界

- **没有逐字材料就不要用。** 凭记忆套五个维度，结论不成立。
- **不给孩子贴标签。** 标注的对象是这段对话，不是孩子的性格。
- **不是评分表。** 不给自己打总分，不拿它当育儿成绩单。
- **不要把标注结果拿去给孩子看。** 它是给你自己复盘用的。
- **一次只改一个维度。** 五个一起上，等于没改。
- **材料要合法、要知情。** 录音需符合当地法律，并让孩子知道你在录。相关口径见 `08-archive/记忆同意与启停.md`。
- **它不解决当期冲突。** 冲突当下的处理走 `03-bond/风暴中的当场话术.md`；这一份是事后的复盘工具。

## 依据说明

本份属判断工具层。

- **证据分级 A**：多信息源评估中不同来源之间一致性不高［1］［2］；
- **证据分级 B**：高要求高回应的教养方式与更好的适应结果［4］（约 4,100 名 14–18 岁青少年的横断自我报告，属关联）。家长对孩子情绪的支持／否定方式与孩子处理情绪的方式有关［3］（情绪社会化研究，多为关联与纵向设计）。
- **证据分级 C**：倾听、真诚、无条件接纳（以人为中心的核心条件）［B1］；先连接再讲理［B2］；倾听与表达的具体技术［B3］［B4］——属成熟框架。
- **证据分级 D**：五个维度（倾听／开放／支持／真诚／连接）的划分、逐句标注五步、每维度的改法、三个标注例子，均为本套材料自定，不是既有量表。
