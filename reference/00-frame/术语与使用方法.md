# 术语与使用方法

> 适用对象：家长
> 生态层：底座（横切）
> 适用时机：全时机
> 一句话范围：称呼口径、每份文件的骨架与段落标题、加载与去重规则。
> 相关文件：08-archive/可写入字段与黑名单.md

## 机制

这份文件定义本 skill 的统一写法和读法，供上层模型按照执行。

## 识别

### 一、称呼口径

- **一律称"家长"**。不区分是爸爸、妈妈、祖父母、其他亲属还是老师——**不给使用者贴身份标签，不追问亲缘关系**。
- 正文里对家长用**"你"**。
- **不问、不存**孩子姓名、学校、班级、生日、住址、联系方式。

### 二、每份文件的骨架

所有 reference 用同一套段落标题（**不用"怎么理解""怎么做"这类引导词**）：

| 段落 | 写什么 |
|---|---|
| `## 机制` | 为什么会这样、条件是什么 |
| `## 识别` | 怎么判断、什么时候用哪一条 |
| `## 做法` | 分步做法 + **可以直接照说的原句** |
| `## 边界` | 不能做什么、常见失败 |
| `## 升级信号` | 什么时候该转介／就医（仅相关文件写） |
| `## 依据说明` | 每条依据的 A/B/C/D 分级；本套材料自定的做法标 D 级 |
| `## 参考文献` | 论文／书／法规条目（GB/T 7714），每条在正文都要有角标 |

文件头部的五行元信息：**适用对象 / 生态层 / 适用时机（预防促进·当场应对·事后修复）/ 一句话范围 / 相关文件**。

### 三、写法要求

- **不做修辞与比喻**，直接说事实、条件和动作。
- **用最短、最直接的话**，一句话能说清就不写三句；表格能替代段落就用表格。
- **不增加认知负担**：目标读者是 AI 模型和家长，两边都要一眼能懂。
- 每条重要判断后面**给依据**（末尾 `## 依据说明` 与 `## 参考文献` 两节），但不编造文献。

### 四、加载与去重规则

- **只读当前问题直接需要的 1–2 份**，不批量加载。
- 路由走 **SKILL.md 唯一一张表**，按域定位，域内按文件名选；**没有任何索引文件**。
- **去重规则**：层级域（`01`–`05`）讲机制与通用做法；`06-scenes` 只放"这一幕从头到尾怎么走"的完整脚本。**同一套原句只在 `06-scenes` 里出现一次。**
- 依赖关系（原理 → 读懂 → 怎么说 → 情景）是**概念依赖**，不是加载顺序，运行时不需要按顺序读。

## 做法

需要判断某个问题该读哪一份时，按 `SKILL.md` 的按需加载表定位域，再在该域目录里按文件名选。

## 边界

- 不复述孩子原话、不保存可识别信息。
- 不给未成年人贴标签、不做测评。

## 依据说明

本份是**元规则文件**：它规定本套材料怎么称呼、怎么排版、怎么加载，不主张任何关于儿童发展的结论。因此其内容整体属**本套材料自定（D 级）**；其中**分域主轴**的依据来自生态系统理论，出处完整列在 `00-frame/生态层次与参考依据.md`，本份不重复列条目。

## 参考文献

本份不列文献条目。理由：本份只定义本套材料的书写规则与加载规则（称呼口径、段落骨架、去重规则），不引用任何关于亲子沟通或儿童发展的外部结论；其分域依据的出处见 `00-frame/生态层次与参考依据.md` 的 `## 参考文献`。
