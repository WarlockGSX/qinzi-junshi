# 风暴中的当场话术

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：当场应对
> 一句话范围：孩子正在情绪风暴里（喊、哭、摔、说狠话）的那十几分钟，你该说什么、不该说什么、什么时候停止说话。
> 相关文件：03-bond/当场校准.md；03-bond/三种时机剧本.md；01-child/情绪爆发的机制.md；01-child/情绪风暴还是要挟.md；02-parent/家长情绪急救.md；03-bond/平复后的修复话术.md

## 机制

### 一、风暴中，孩子听不进道理

情绪冲上来之后，有一段时间，孩子的心跳快、呼吸浅、脸热、手抖。这段时间里"听懂一句话 → 理解意思 → 组织回应 → 想到后果"这条链无法正常工作；情绪唤起会直接抑制前额叶的功能，这是生理过程，不是态度［1］。孩子从情绪里恢复的能力与依恋安全关系更稳定；回避型的孩子情绪反应偏低（看起来像"没反应"），矛盾型偏高，混乱型反应高且恢复难［4］。

所以在这个时间窗里，你说的每句话作用不是教育，是影响他的身体状态。**音量、语速、你离他多近，比你说什么重要。** 先接住情绪、再谈行为的顺序，也是情绪辅导类做法的共同前提［B1］。

这一份的全部目标是：**让这一轮停止升级。** 讲通道理、分出对错、让他认错，当场都做不到，硬做只会把这段时间拉长。

### 二、三个会互相加强的因素

| 因素 | 怎么发展 | 你能做的 |
|---|---|---|
| **音量** | 他越大声，你本能也想更大声，两边一起上去 | 他升你降。降到比他还小 |
| **身体位置** | 往前压、正面对着、用手指人，会加强他的被攻击感 | 退半步，身体放松，不正对，不用手指 |
| **语言** | 一句带评价的话（"你就是故意的"）会立刻引发第二轮 | 只说事实和感受，不评价人 |

三个因素里，**音量最容易控制**：你降下来，他通常会跟着降。

### 三、当晚的失控常常不是当天造成的

长期处在压力状态（睡眠不足、工作压力、长期冲突）会让负责自控的前额叶功能下降，自控力变弱、更容易一点就着，和这件事本身关系不大［1］。家长的情绪调节与孩子的情绪调节之间存在纵向关联（98 对母子、孩子 6–8 岁；属关联，不能读成因果）［3］，家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［5］。所以处理"当场"，往往要先处理"你最近的状态"。

### 四、目标不是"让他立刻不气"

你做不到，也不需要。能结束的时候自然会出现信号（见下节）。在此之前推进任何话题都是白费，而且他会记成"我情绪最差的时候你还在逼我"。

## 识别

### 一、先分三种当下

| 当下 | 判断依据 | 先做什么 |
|---|---|---|
| **孩子情绪上来了** | 声音高、身体绷着、开口就攻击你 | 走第一节：只做减法 |
| **你自己快失控了** | 太阳穴发紧、下巴咬住、声音发颤或拔高、脑子里冒出"我今天非得治治他" | 走第二节：先离开并交代 |
| **两个人都停不下来** | 都在说，没人听 | 走第三节：拆开现场 |

**"你自己快失控"排在最前。** 很多升级的真正起点不是孩子的情绪，是你的失控；你稳住了，他那段往往自己就过去了。

### 二、"停下来了"的判断信号（三个信号，出现两个就算）

1. 声音从喊变成说；
2. 呼吸和肩膀松下来；
3. 内容从攻击你变成说他自己的事。

出现两个以上，可以进入平复后的那一段（`03-bond/平复后的修复话术.md`）。在这之前只做减法，不推进话题。

### 三、分清"情绪风暴"和"有目的的要挟"

| | 情绪风暴 | 要挟 |
|---|---|---|
| 情绪来源 | 真的过载，他自己也停不下来 | 是工具，目标是你手里的东西 |
| 你不在场时 | 一样会闹 | 你不在他就不闹 |
| 事后 | 常觉得"我刚才怎么了" | 记得很清楚 |

不确定时**按风暴处理**（先接情绪、不翻旧账）。把风暴当要挟处理的代价更大：孩子会形成"我说什么你都不信"。详细区分见 `01-child/情绪风暴还是要挟.md`。

## 做法

### 第一节 · 孩子风暴中：做三件事，别做四件事

**做的三件：**

1. **降到比他小**：他喊，你用比平常低的音量说话。
2. **身体放松、退半步**：不正对，不用手指。
3. **给一句最短的话当出口**（十个字以内）：

> "我们现在都停一下。"

**不要做的四件：**

| 别做 | 后果 |
|---|---|
| 当场讲道理（"我这是为你好"） | 他听不进去，只会觉得你在否定他，进入第二轮 |
| 追问原因（"你到底为什么这么大脾气"） | 等于要他立刻解释，他没有这个能力 |
| 翻旧账（"你每次都这样"） | 把一件事变成一场总账 |
| 用离开当惩罚（"我不管你了"） | 他会理解为被丢下 |

**他说什么，你接什么：**

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| 哭得厉害 | 不说话，坐近，递纸巾 | （不说话，把手放在他背上） |
| "我恨你""我讨厌你" | 接情绪，不辩论爱不爱 | "你现在特别气我。我知道了。" |
| 翻旧账："你上次也答应我了！" | 承认一句，把范围拉回来 | "你说的那件事也是真的。一件一件来，先说你刚才这件。" |
| 摔东西 | 先移开危险物，再立一条边界 | "我不会让你摔东西。你想发火可以，东西不能摔。" |
| 打人／咬人 | 拦住动作，不羞辱 | "我不会让你打人。我也不会走开。" |
| 沉默、不理你 | 停止追问，给不带要求的在场 | "不想说就先不说。我在这儿。" |

接情绪的字面、不接字面的攻击，是给孩子示范"情绪可以被说出来"的直接方式［B2］［B3］。

### 第二节 · 你快失控：停嘴、交代、打断身体

**先认你自己的信号**：太阳穴发紧、下巴咬住、声音发颤或拔高、脑子里冒出"我今天非得治治他"、手已经抬起来。

出现任何一个，三步：

1. **停嘴。** 不要再说完这一句，哪怕说到一半。半句停下，比说完再走好。
2. **离开，并交代。** 没有交代的离开，孩子会理解为被丢下：

> "我现在有点上来了，我出去待一会儿。十分钟，我回来的时候还是在的。"

3. **做一件打断身体的事**：洗把脸、喝口凉水、下楼走两圈、数呼吸到二十。**不要刷手机**——刷手机不降级，只是把情绪往后推。

**走之前不要留最后一句评价**（"你自己好好想想""等我想通再说"）。这一句会把"我去冷静"变成"我在罚你"。

**如果已经抬手：** 立刻把手放下，转身走出房间。手抬起来就已经不属于沟通范围，属于安全范围——后面按 `03-bond/事后修复话术.md` 的"动手之后"处理。

### 第三节 · 两个人都停不下来：拆开现场

- **分开空间**：各回一个房间，或一个人出门。这是让两个身体都降下来，不是冷战。
- **降要求**：当下不要求任何一方先道歉、先说清楚。
- **给一个明确的再谈时间**：

> "今晚都先睡，明天吃完晚饭我们再说这件事。"

给了具体时间，孩子会理解为暂停；不给，他会理解为被丢下。差别就在有没有那个时间点。

- **如果是肢体冲突**：先保人的安全，把人分开比对错重要；有人受伤先处理伤。

### 现场对照表

| 你看到 | 通常的冲动 | 这一秒改做 |
|---|---|---|
| 他声音拔高、拍桌子 | 比他更大声压回去 | 降到比他小，说"我们停一下" |
| 他摔门进房间 | 追上去把门拍开 | 让他关。隔十几分钟再敲："我在门外，你想说的时候我听着。" |
| 他哭 | 说"这有什么好哭的" | 不说话，坐近一点，递纸巾 |
| 他说狠话 | 用更狠的话回敬 | "你现在特别气我，我知道了。" |
| 你自己声音开始颤 | 说完这最后一句 | 停嘴，离开并交代 |
| 你手已经抬起来 | 打下去 | 立刻放下，转身走出房间 |
| 他沉默到底 | 一直问到他说 | 停下，给一句出口："不想说就先不说，我在这。" |
| 你们都红了眼 | 逼出一句道歉 | 分开空间，定一个明天再谈的时间 |

说事实而不评价人、说自己的感受而不指责对方，是这一类说法能降级而不是升级的关键［B4］。

### 分龄差异

| 学段 | 风暴的样子 | 你的话往哪儿靠 |
|---|---|---|
| **学前 3–6** | 生理性过载，讲道理基本无效 | 靠身体在场：蹲下来、抱着、少说话。语言只用来命名——"你很生气。" |
| **小学低年级 6–9** | 能听一点道理，但仍在情绪里出不来 | 先命名情绪，再给两个具体选项——"你可以去房间待一会儿，或者坐这儿喝口水。" |
| **小学高年级 9–12** | 开始要面子，当众说会加倍反弹 | 少说、别当众。给他一个能下台的出口："等你想说的时候，我随时在。" |
| **初中 12–15** | 强度上升，低落常表现为易怒 | 不接球。不辩论、不追问、不当场定对错，说一句事实然后撤："我听见了。这事我们晚点说。" |
| **高中 15–18** | 更会藏，情绪常装在"事情"里 | 尊重他的独处权：门开着比问清楚重要。留一句："我在客厅，你想聊再叫我。" |

青春期情绪强度高，是因为负责奖励与情绪的系统先成熟，而负责控制的前额叶要到二十岁出头才逐步成熟，这是这个阶段的规律，不是针对你［7］。孩子的自我调节能力是随发育逐步长出来的，受环境和经历影响，不是"说过一次就该会"［2］。

## 边界

- **对照表不是台词本。** 挑最贴近的一句，用你自己平时会用的词说出来。用你家的语气，才不是背来的。
- **当场能做到的只是不升级。** 解决在事后那一段，见 `03-bond/平复后的修复话术.md`。
- **不要把上一次没解决的事带进下一次。** 每次都在"上次你还没给我交代"上开场，关系就一直停在那场没结束的冲突里。
- **目标不是让他当场听话。** 压力下的服从不是成长，只是把情绪往后推。
- **如果每次冲突都由你的失控触发**，问题不在"当场怎么接"，在你最近的状态——见 `02-parent/家长情绪急救.md`、`02-parent/撑不住时的自我照顾.md`。
- **这一份不用于危机场景。** 出现自伤、动手致伤、持续威胁时直接走 `07-safety/危机信号识别.md`。

## 升级信号

- **当场升级**：孩子有伤害自己或他人的动作、你说什么都不停且持续超过半小时、出现"我不想活了"这类话 → 停止话术，先保安全，见 `07-safety/危机当下的应对.md`。
- **事后升级**：同一模式每周多次、持续两周以上，或你每次都以失控收场 → 见 `07-safety/就医与专业转介指征.md`。情绪调节方式与心理健康有稳定关联——以"重新理解"为主更有利，以"压住"为主更不利；长期处理不好时，优先求助而不是硬撑［6］。

## 依据说明

本份属做法层，动作背后有机制层依据。

- **证据分级 A**：依恋安全与孩子情绪反应／恢复的差异［4］（系统综述）；情绪调节方式与心理健康的关系［6］（元分析）。
- **证据分级 B**：急性、不可控压力让前额叶功能下降［1］（机制综述）；自我调节随发育逐步形成并受环境影响［2］；家长情绪社会化与孩子的情绪处理有关［5］；家长与孩子情绪调节的纵向关联［3］（单项纵向研究，98 对母子，间接路径未达显著）；青春期双系统发育（奖励系统先成熟、控制系统后成熟）［7］（叙述性综述）。
- **证据分级 C**：情绪辅导、先连接再讲理、说事实不说评价，属成熟育儿框架，对应到书［B1］［B2］［B3］［B4］。
- **证据分级 D**：三种当下的分流、现场对照表、分龄说法差异、离开并交代的话术，为本套材料自定。
