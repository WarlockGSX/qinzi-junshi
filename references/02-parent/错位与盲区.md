# 错位与盲区

> 适用对象：家长
> 生态层：个体层（家长自身）
> 适用时机：预防促进
> 一句话范围：我以为的和我实际做的之间的差距从哪里来。
> 相关文件：02-parent/自己的防御信号.md；02-parent/原生家庭与自己的成长课题.md；02-parent/常见误区-认知型.md；02-parent/自我观察与自评工具.md；02-parent/撑不住时的自我照顾.md；08-archive/关系状态的描述.md；08-archive/记忆同意与启停.md

## 机制

差距不是"我不够诚实"，是几层再正常不过的机制叠在一起。

### 一、你和孩子看的是同一件事的两个版本

对同一个孩子的行为与情绪问题，家长、老师、孩子自己分别给出的评价，彼此的一致性往往只有低到中等；这种不一致主要来自**情境特异性**——同一个孩子在不同场合的表现本就不同，各家看到的都只是一部分，并不等于谁不可靠［1］。因此在儿童心理评估里，普遍采用多信息源，并把各家的报告分开来解读［2］。

所以"我做的"和"他经历的"，不是同一份记录。这不代表谁在撒谎，是两个人站的位子不同。

### 二、我记住的和我实际做的之间

你记住的，通常是你**介入**的时刻：提醒、纠正、帮忙、陪着。你漏掉的，往往是**打断、替他做、没听他把话说完、说了算数又反悔**。

记忆按"我是个什么样的家长"来组织，不按事实逐条记。符合这个形象的事容易留下，不符合的容易被略过或改写成例外。

平时最容易被漏掉的几类动作：

- **打断**：他没说完你就接话；
- **代劳**：他还没试，你就替他做了；
- **没听完**：点头说"嗯"，其实在看手机；
- **落空的承诺**：答应了，又因为忙没做；
- **带着情绪进门**：上一件事的火，落到了这一件事上。

这五类不一定都是错。问题在于它们发生得频繁，却很少被记进"我平时都做了什么"里。

### 三、自我概念会挡住对不上的信息

人倾向于维持一个稳定的自我形象。当行为和"我是什么样的家长"冲突时，本能的反应是**重新解释行为**，而不是改行为——"这次情况特殊""我也是没办法"。

一个人的自我概念和真实经验之间一旦长期对不上，会成为不安和困扰的来源；让两者逐渐一致，本身就是改变的方向［B1］。这不是人品问题，是自我保护在起作用。

### 四、意图和效果的错位

心里控制类做法，动机常常是关心，但孩子体验到的是被管。心理控制被孩子感知到，与他的抑郁、焦虑相关［3］；侵入式教养与孩子的内化、外化症状相关［4］。

所以"我是不是关心他"和"他是不是被关心到了"，是两条线。你自认为的家庭规则，和孩子实际在遵守的规则，也经常是两套。

### 五、差距从三个地方来

| 来源 | 表现 |
|---|---|
| 视角差 | 你看到的是你的用意，他看到的是你的动作 |
| 记忆差 | 你记住自己介入的次数，漏掉自己打断的次数 |
| 防御 | 对不上的信息被改写成"情况特殊""我也是没办法" |

## 识别

### 一、四个能露出差距的信号

- 别人转述孩子的话，和你在场看到的不一样；
- 同一件事，伴侣、老师、孩子说法差得很远；
- 你说"我从没这样过"，但有人能举出具体的一两次；
- 你解释自己行为时，高频出现"情况不一样""我也是没办法"。

命中两条以上，值得往这个方向看。没有命中，也不代表没有——盲区本来就看不见。

### 二、常见的"我以为"

| 我以为 | 更可能的实际 |
|---|---|
| 我在陪他 | 我在他旁边做我自己的事 |
| 我听他把话讲完了 | 我听到了开头，就接上了我的结论 |
| 我让他自己决定 | 我让他从两个我定好的选项里挑一个 |
| 我脾气挺好的 | 我只是没喊，语气一直在压 |
| 我们家挺宽松的 | 规矩不少，只是没明说 |
| 我是提醒他 | 同一件事我今天说了四遍 |

这张表不是给你下结论，是用来看哪些"我以为"最常出现。

### 三、拿到"实际做的"的方法

不看动机，看可观察的动作。三个办法：

1. **录音。** 录一段真实的对话。须符合当地法律并获得孩子知情同意，见 `08-archive/记忆同意与启停.md`。
2. **复述。** 把一次对话原样写下来：谁先说了什么、原话是什么，不写"我当时想"。
3. **第三人。** 让在场的人只描述动作，不给结论。

### 四、分流

| 现象 | 去哪 |
|---|---|
| 我一被说就防守、就找理由 | `02-parent/自己的防御信号.md` |
| 每次都在同一处被触发 | `02-parent/原生家庭与自己的成长课题.md` |
| 想错的地方固定是那几种 | `02-parent/常见误区-认知型.md` |
| 想系统地记录和看变化 | `02-parent/自我观察与自评工具.md`、`08-archive/关系状态的描述.md` |

## 做法

### 一、"我以为 / 实际"两列表

拿最近一次冲突，两栏对着写：

| 我以为我做的 | 实际做的（写动作） |
|---|---|
| 我很耐心地听 | 他一说"我不会"，我就把题拿过来写了 |
| 我给了他选择 | 我给了两个选项，两个都是我要的 |
| 我没发火 | 我没喊，但我全程没看他 |

右边一栏必须是别人能看见的动作：说了什么、做了什么、持续多久、发生几次。

### 二、只看动作，不看动机

把行为写成别人能看见的样子。"我很关心他"不算；"他说话时我三次看了手机"算。区分观察和评论，是这一整套做法的基础［B2］。

### 三、一次对话的还原三问

1. 当时我说的第一句，原话是什么？
2. 他说的第一句，原话是什么？
3. 谁先停下来的？

三问写完，很多"我以为"会自己现形。

### 四、请一个"只描述不评价"的人

让伴侣或家里另一个人，只报动作、不给结论。他不说"你太急了"，只说"你刚才打断了他两次"。收到描述时不要立刻反驳，先记下来。

### 五、看到差距之后只做一件事

挑差距最大的一处，改成一句具体动作，连续做两周。不要同时改几处，也不要在两周内反复检查效果。

### 六、对自己念的两句

一个人、平静时念：

> "我看到的是我的版本，不一定是全部。"
> "先看动作，再看动机。"

### 七、把"我实际上做的"讲给孩子时，用描述不用评价

当你向孩子确认你自己做了什么，描述行为、不给他和自己贴标签［B3］：

> "刚才你说话的时候，我打断了你两次。这是我的问题。"

### 八、一周一次的记录

一周里挑三次对话，各写三行：他的原话、我的原话、谁先停下。周末翻一遍，看反复出现的是什么。

记的不是对错，是模式。写"他哭了我讲了道理"就够了，不必写"我应该更有耐心"。看条目多了，"我实际做的"会自己显出来。

## 边界

- **找到差距不是自我审判，是校准。** 目的是把"实际做的"看清楚，然后改一处，不是给自己定一个"不合格家长"的结论。
- **不要用"我都是为他好"挡住。** 动机是好的，不等于做法不用检查；这属于另一种想错，见 `02-parent/常见误区-认知型.md`。
- **别人的描述也可能是他那个版本。** 伴侣、老师、孩子说的同样是视角，不是全部事实。
- **只看动作也不能过头。** 动机不是没用，它只是不能代替动作。完全不看动机，会把一次紧张看成态度问题。
- **不要拿"我有盲区"当免责。** 承认看不见，不等于可以不改。
- **录音须合规。** 符合当地法律，并让孩子知道、同意。
- **差距不会一次补齐。** 盲区是长期形成的，先承认一处，改一处。

## 依据说明

本份属机制层。

- **证据分级 A**：不同信息源对同一孩子的行为／情绪问题评价一致性低，且主要是情境特异性，而非谁不可靠［1］（跨信息源元分析，119 项研究）；儿童心理评估普遍采用多信息源并分开解读各家报告［2］（元分析，341 项研究）。心理控制被孩子感知与抑郁、焦虑的关联［3］；侵入式教养与内化、外化症状的关联［4］——关联性证据，只能读成相关，不能读成因果。
- **证据分级 C**：自我概念与真实经验不一致是困扰来源、让两者一致是改变方向，取自人本取向的成熟框架［B1］；区分观察与评论［B2］、描述行为不评价人格［B3］，属成熟沟通框架。
- **证据分级 D**："我以为／实际"两列表、还原三问、请第三人只描述、两周改一处，为本套材料自定。
- 需要说明的是：本份列出的"视角差／记忆差／防御"是三种常见来源的描述性说法，不是临床分类，也不用于给家长作任何定性。
