# 撑不住时的自我照顾

> 适用对象：家长
> 生态层：个体层（家长自身）
> 适用时机：预防促进
> 一句话范围：耗竭型：倦怠、没信心、撑不下去时，先做什么。

## 机制

### 一、家长倦怠是一个可被测量的状态

长期照顾压力累积到一定程度，会出现一种被研究者称作"家长倦怠"的状态。在一项量表编制与验证研究里，它表现为三个方面：情绪与身体的耗竭、对孩子的情绪抽离、以及"我怎么做都不对"的自我效能感下降［1］。它描述的是一种状态，不是诊断，也不是"不够爱孩子"。

在这项研究中，家长倦怠与职业倦怠、育儿压力、抑郁之间只有低到中等相关，提示它可能是一个相对独立的状态，不等于其中任何一个［1］。在它的社区样本里，落在倦怠区间的家长比例约在 2% 到 12% 之间，具体数值随样本和测量方式而变［1］。

### 二、倦怠会影响到孩子，所以照顾自己不是自私

两项交叉滞后的追踪研究（分别约 918、822 位家长，一年内测三次）提示，家长倦怠会升高"想离开这个家"的念头，也会升高对孩子的忽视与暴力倾向；而且倦怠与忽视之间会互相加强，形成循环［2］。也就是说，你现在的状态不只关于你自己，它关系到你还能不能稳住对孩子的回应。

两条放在一起，结论清楚：**你把自己从耗竭里拉出来，其中一部分作用就是保护孩子。**

### 三、耗竭来自"要做的"长期多于"能拿出的"

有一套被广泛使用的工具，把"感知到的压力"定义成一个人觉得生活有多不可预测、不可控、多到应付不过来——也就是说，压力可以被当成一种主观评估来测量，而不只是数事情有多少［3］。同样一堆事，觉得"我还撑得住"和觉得"我肯定不行"，状态会不一样。耗竭型的撑不住，通常是资源长期入不敷出，而不是某一件事造成的。

所以处理方向要两边一起动：**一边降需求，一边补资源。** 只喊"再坚持一下"没有用，因为它只动"你怎么想"，不动那笔账。

### 四、自责会加快耗竭

对自己苛刻（"我真是个糟糕的家长"）与更高的抑郁、焦虑相关；对自己友善、把困难看作"很多人都会遇到"，与更低的不良情绪相关［4］。情绪调节的方式与心理健康之间也存在稳定关联——以"重新理解"（认知重评）为主与更好的指标相关，以"压住"（表达抑制）为主与更差的指标相关［5］。

自责不产生额外的力气，它只消耗你本来要用来应对的精力。这就是为什么"我快撑不住了"和"我很自责"经常一起出现，而且互相加重。

## 识别

### 一、先分清"累"和"倦怠"

| | 短期疲劳 | 倦怠 |
|---|---|---|
| 睡一觉或休息一天 | 明显好转 | 基本不恢复 |
| 情绪 | 烦，但还愿意陪孩子 | 对孩子提不起兴趣，想躲开 |
| 对自己的看法 | 就是累了 | "我怎么做都不对""我不是块当家长的料" |
| 持续 | 几天 | 几周以上 |

三条里中了两条以上，就按倦怠处理，不要继续用"再撑撑"应付。

### 二、先确认这是"我这一侧"的事

| 你常说的话 | 归属 | 去哪 |
|---|---|---|
| "我一看到他哭就烦""我不想跟他说话" | 我这一侧（耗竭） | 这一份 |
| "我爸妈当年也这么对我，我现在也这样" | 代际 | `02-parent/打破代际循环.md` |
| "他的问题让我觉得自己很失败" | 错位 | `02-parent/错位与盲区.md` |
| "我快失控了"（就在当下） | 当场 | `02-parent/家长情绪急救.md` |

### 三、判断要不要立刻走安全流程

如果出现"我不如消失""我活着是拖累"这类想法，或出现过想伤害自己、伤害孩子的念头，**不要停在自我照顾上**，直接跳到本份的"升级信号"。

## 做法

### 一、第一步不是加油，是减量

先列出你现在实际在做的所有事（照顾、家务、接送、辅导、老人、工作），逐条问一句：**这一周不做，会出大事吗？** 不会的，标为"可以降标准或交给别人"。只处理这一周。

可以照做的顺序：

1. 划掉一件非必需的事（哪怕只是这周不做一顿饭、不去一次班）。
2. 把一件事交给别人（伴侣、家人、朋友、邻居、小时工）。
3. 把一件事的标准降低（整洁、饭菜、作业检查的细度）。

### 二、把"最低标准"写下来

撑不住的时候，先只保住三条：

> 今天孩子安全、吃饱、有地方睡；今天我自己吃上一顿、睡上一段。

其它都排在这三条后面。这不是放弃，是给这一段时间划一个底线。

### 三、补资源要具体到动作，不做大计划

恢复不是"我要好好爱自己"这种话，是一件当天能做完的事。从下面挑一件，今天做完：

| 缺的是 | 当天可以做的一件 |
|---|---|
| 睡眠 | 今晚把一次夜醒交给别人，自己连续睡满四小时 |
| 独处 | 出门走十五分钟，不带孩子、不刷手机 |
| 被照顾 | 给一个能说话的人打个电话，只说你最近怎么样 |
| 身体 | 出门晒十分钟太阳，或做一件出汗的活动 |
| 支持 | 请一个人替你半天，就半天 |

**不要用刷手机、喝酒当恢复。** 这两样把情绪往后推，不降低耗竭。

### 四、把需求说出来

耗竭的人常默认"我不说，别人也该看见"。多数时候别人看不见。要的是**具体的人 + 具体的时间和事**：

> （对伴侣／家人）"我这段时间快撑不住了。我需要你每周替我两个晚上，我想先睡一觉。"

> （对朋友）"我不想聊怎么带孩子，我就想找个人坐一会儿。"

不要只说"你能不能多帮帮我"——这句话里没有时间、没有具体的事，对方接不住。

### 五、对自己说的一段话（一个人时念，不用念给人听）

> "我现在很累，这不是懒，也不是我不够爱他。"
> "我把自己缓过来，是在保住我还能照顾他。"
> "今天我只需要做一件事，让自己松一点。"

无条件接纳自己本来的样子，是改变能发生的前提；对自己友善不等于给自己找借口［B1］［B2］。用自责逼自己改变，通常撑不了几天就会反弹；先照顾好自己，照顾孩子的质量才有基础［B3］。

### 六、一次只恢复一小块

耗竭是长期攒出来的，不要指望一次翻盘。挑**一个**最缺的（睡眠／独处／支持／身体），这周只补这一个，看一周后有没有一点变化。有了一点，再动下一个。

## 边界

- **不做诊断。** "倦怠"描述的是一个状态，不是给你下的结论，也不是说你"有病"。
- **自我照顾不是自私。** 你把自己拖垮，代价会落到孩子身上；把自己拉出来，本身就是对孩子的照顾［2］。
- **不是"等有空再做"。** 不排进日程的休息不会发生。要把它当成必须做的一件事，写下来、定时间。
- **不用刷手机和酒顶替休息。** 它们不降低耗竭，只会让第二天的你更空。
- **不要对自己许大愿。** "从明天起早睡、运动、戒手机"通常三天就废。只做一件当天能完成的事。
- **不把耗竭转给孩子。** 撑不住时容易对孩子发火、冷处理或动手；一旦出现，先按当场应对处理，再回来补自己这一块［2］。
- **承认有些事你一个人控制不了**（经济、时间、有没有人搭手）。只动此刻能动的这一小块。

## 升级信号

**立即**（当天联系）：出现自伤或自杀念头、控制不住想伤害孩子的冲动、家里正在发生暴力 → 走 `07-safety/求助渠道与转介.md`。紧急情况拨 **110／120**，心理援助热线 **12356**。

**尽快**（一周内）：情绪低落或焦虑**持续两周以上**、已经影响上班或照顾孩子、睡眠持续紊乱、靠酒精或药物缓解情绪。

情绪调节的方式与心理健康之间存在稳定关联——以"重新理解"（认知重评）为主与更好的指标相关，以"压住"（表达抑制）为主与更差的指标相关［5］；长期停在上面这些状态时，优先按渠道求助，不要停在自我照顾上。指征细则见 `07-safety/就医与专业转介指征.md`。

## 依据说明

本份属机制层。

- **证据分级 A**：情绪调节方式与心理健康的关联［5］（元分析，48 项研究；以"重新理解"为主与更好指标相关，以"压住"为主与更差指标相关）。
- **证据分级 B**：「家长倦怠」的三维结构与样本中的比例区间［1］、感知压力可作为主观评估来测量［3］、自我友善与更低抑郁焦虑相关［4］——量表编制／验证与相关性研究，不作诊断用；倦怠与对孩子的忽视、暴力倾向、离开念头等问题被反复报告［2］（概念与后果综述，非元分析，后果多为关联）。
- **证据分级 C**：把"累"与"倦怠"分开的常见描述，属经验说法，用于自我觉察，不对家长作任何定性。书［B1］［B2］［B3］支撑"先接纳自己、先照顾自己"的方向。
- **证据分级 D**：减量顺序、最低标准三条、当天可做的恢复动作表、照说句、自我对话脚本、一次只补一块，均为本套材料自定；
