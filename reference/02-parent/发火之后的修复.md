# 发火之后的修复

> 适用对象：家长
> 生态层：个体层（家长自身）
> 适用时机：事后修复
> 一句话范围：四句话修复与完整流程；越线动手之后重点做什么。
> 相关文件：02-parent/家长情绪急救.md；02-parent/撑不住时的自我照顾.md；03-bond/事后修复话术.md；03-bond/平复后的修复话术.md；03-bond/道歉与修复的误区.md；01-child/羞耻感与自我价值.md；07-safety/法律与权利边界.md；07-safety/求助渠道与转介.md；07-safety/危机信号识别.md

## 机制

### 一、"都过去了"不成立

你觉得那件事过去了，孩子记得的比你以为的久。原因是：那次发火里，他记住的不是你说的道理，是你当时的样子和他自己的感觉。

长期的心理控制（用内疚、收回关爱、监视来推着孩子走）与孩子的抑郁、焦虑水平相关［1］；严厉、强制型的教养与孩子更多的外部化问题相关［2］。修复能改变的不是"那件事有没有发生"，是"它被记成什么"。同一件事，可以是"我妈失控了但她认账、会改"，也可以是"又是我不好"。

### 二、修复不是一句道歉

道歉只说了一个动作。完整修复有四个动作，顺序不能换：

| 顺序 | 动作 | 做不到会怎样 |
|---|---|---|
| 1 | 接住：承认刚才发生了什么 | 他会以为你在装没事 |
| 2 | 归责：把责任放回你这边 | 他会自己扛下这件事 |
| 3 | 不要求：不换他的原谅或保证 | 修复变成交易 |
| 4 | 给下一步：说清你下次会做什么 | 他会认为这只是又一次"下次不这样" |

缺第 3 条最常见：说了对不起，紧接着"但你刚才也不该……"，修复立刻作废。

### 三、动手是另一类问题

越线动手之后，重点不是话术，是四件事：**安全、定性、停止、求助**。管教和动手是两回事，权力压制型的教养做法与孩子更差的发展结果相关［3］，动手已经不属于沟通范围，属于安全范围。

《反家庭暴力法》规定家庭成员之间不得实施身体侵害，这不是"自家的事"［L1］；《未成年人保护法》要求监护人不得对未成年人实施家庭暴力［L2］。

### 四、修复做多了会变成套路

同样的道歉重复多次，行为一点不改，修复就从"修补"变成"预支下一次"——孩子会算出来：道歉很快会来，所以这次也不算什么。信誉只靠行为改，不靠话说得多好。

## 识别

### 一、先分清三种"发火之后"

| 情况 | 性质 | 做什么 |
|---|---|---|
| 只是声音大了、话说重了 | 关系损伤 | 四句话修复 |
| 骂了人格、翻旧账、当众羞辱 | 叠加羞耻 | 四句话修复 + 处理羞耻，见 `01-child/羞耻感与自我价值.md` |
| 动了手、摔了他的东西、把他关在门外 | 越线 | 走本份"越线动手之后"，不要停在话术上 |

### 二、说的时机

- 双方都冷静之后再说。他还在情绪里时，说多少都听不进。
- 睡前可以只短说一句；完整的修复放到第二天不赶时间的时候。
- 不要在饭桌上、不要在出门前、不要当着外人。

### 三、判断修复有没有做到

| 做到了 | 没做到 |
|---|---|
| 只说事实和自己的那部分 | 带着"但是你也……" |
| 不要求他回应 | 追着要他"说没关系" |
| 说了下次的具体动作 | 只有情绪，没有动作 |
| 说完就结束 | 顺势把作业、成绩一起讲一遍 |

## 做法

### 一、四句话（可以照着说）

> "刚才我发火了。"
> "那不是你的错，是我没管好自己。"
> "你可以生气，也可以现在不想理我。"
> "下次我再上来，我会先离开，等平静了再说。"

按顺序说，不加解释、不加"但是"。只描述行为、不评价他这个人，是这几句话能起作用的前提［B1］。

### 二、完整流程

1. **选时间、坐下来。** 不隔着一间屋喊，不在他写作业时说。
2. **说事实。** 说你做了什么，不说他当时怎么怎么样。
3. **归责。** 把责任放回自己这边："是我没管好自己。"
4. **给出口。** 允许他生气，允许他暂时不回应。
5. **说下一次。** 不是"我改"，是"我会先做什么"（例如先离开十分钟）。
6. **结束。** 说完就走开。不要顺带把上次没解决的事一起翻出来。

整套流程的核心是一致：你说"这是我的问题"，之后的行为要能对上。修复起作用靠的是这份一致，不是话说得多好［B3］。

### 三、他说这些时的接法

| 他说 | 你接 |
|---|---|
| "你每次都这样！" | "你说得对，这不是第一次。这次我先改我自己的。" |
| "我不原谅你。" | "你有权这样。我不需要你现在原谅我。" |
| "那你保证不再发火。" | "我不做保证。我说我会做什么，你看我做。" |
| 沉默、不理你 | "不想说就先不说。我说我的。" |
| "都是我的错行了吧。" | "不是你的错。是我把话说重了，这个我来收。" |

把话说到自己的感受和行为上、不推回给他，是这类修复能成立的关键［B2］。

### 四、越线动手之后的重点

1. **先确保安全。** 把人和危险物分开，确认没人受伤；有人受伤先处理伤、就医。
2. **停止，不再"教育"。** 不要再补一句"是你逼我的"。动手之后任何解释都是二次伤害。
3. **明确说清性质。** 那是越线，不是管教：
   > "刚才我动手了。这不对，这不是管教。"
4. **给他一个安全的下一步。** 说清他今天可以怎么找到你、或找谁。
5. **你自己那部分交给成年人。** 不把"我控制不住"讲给孩子听，找伴侣、朋友或咨询师，见 `02-parent/撑不住时的自我照顾.md`。
6. **需要时求助。** 见 `07-safety/求助渠道与转介.md`、`07-safety/法律与权利边界.md`。反复动手、动手致伤，不停在自我调整上。

### 五、如果他更生气、修复没接住

两种常见情况：

- **他说"你少来""别假惺惺"。** 不辩解，说一句就停："好，我不多说。我做的你能看到。" 然后用行为兑现，不用嘴兑现。
- **他哭着说"都是我的错"。** 这正是修复要防的结果。立刻把责任收回来："不是你的错，是我。" 不要顺着他的话往下讲。

如果他连着几天陷在自责、退缩、反复道歉里，见 `01-child/羞耻感与自我价值.md`。

### 六、修复之后的长期两件事

1. **找触发点。** 回到 `02-parent/家长情绪急救.md`，看这次是孩子的行为，还是碰到了别的什么。
2. **两周只改一个动作。** 连续两周盯着"下一次先离开"这一件事，改成了再动下一个。

## 边界

- **不要在情绪里修复。** 都还在气头上，说出来的道歉会夹着指责。
- **不要用道歉换他的保证。** "你以后也不许这样"会把修复变成交易。
- **不要"我错了，但是你也……"。** 一个"但是"就把责任推回去。
- **不要反复道歉却不改。** 那是预支下一次。
- **不要让孩子反过来安慰你。** 说"妈妈是不是很没用"，他接不住，还会以为自己该负责。
- **不要把动手说成"气急了都这样"。** 动手是越线，不是一类可以原谅的脾气。
- **不要相信"打了才长记性"。** "让他怕"和"让他愿意"是两条路，结果不同：高要求加高回应，好于高要求加低回应［3］。
- **修复一次不代表补上。** 长期的情绪回应方式，与孩子怎么处理自己的情绪关联更稳定［4］。

## 升级信号

**立即**（当天联系）：动手致伤、反复动手、家里正在持续发生暴力 → 紧急拨 **110／120**，见 `07-safety/危机信号识别.md`、`07-safety/法律与权利边界.md`。

**尽快**（一周内）：孩子出现自伤或"活着没意思"这类话；被骂之后持续两周以上回避你、退缩、成绩突然往下走；你自己反复失控、收不住 → 见 `07-safety/就医与专业转介指征.md`。

家长的情绪调节与孩子的情绪调节之间存在纵向关联（98 对母子、孩子 6–8 岁；属关联，不能读成因果）［5］；家长怎么回应孩子的情绪，和他日后怎么处理情绪的方式有关［4］。所以修复不只是"把这次哄好"，也是他学习怎么处理情绪的一个样本。

## 依据说明

本份属事后修复层。

- **证据分级 A**：心理控制与孩子抑郁、焦虑的关系［1］；教养维度与孩子外部化问题的关系［2］——均为元分析。家庭暴力的禁止性规定见［L1］［L2］，为现行规定。
- **证据分级 B**：权力压制型教养做法与发展结果的关系［3］（设计良好的单项纵向研究，属关联）；家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［4］；家长与孩子情绪调节的纵向关联［5］（单项纵向研究，98 对母子，间接路径未达显著）。
- **证据分级 C**：四句话修复与"接住—归责—不要求—给下一步"的顺序、只说行为不评价人格，属成熟育儿与沟通框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：三种"发火之后"的分流、修复是否做到的判据、越线动手的六步、长期两件事，为本套材料自定。
- "动手之后不停在话术上"是本套材料的立场：安全与责任优先于语言修复。
