# 游戏充值与非理性消费

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：事后修复
> 一句话范围：钱已经花出去了，这一场怎么收场、规则怎么补——先止损，再修复，最后才谈规则。
> 相关文件：06-scenes/屏幕与手机.md；05-outside/游戏、短视频与网络社交.md；04-family/家庭经济与物质状况.md；04-family/家庭规则的制定与执行.md；03-bond/奖励与惩罚的分寸.md；03-bond/事后修复话术.md

## 机制

### 一、"就再抽一次"有设计上的原因

抽卡、开箱、皮肤、道具，都属于"有时有、有时没有"的奖励。这种不确定的反馈比固定奖励更能维持继续投入。一项对 826 名 12–17 岁青少年的横断面调查显示，游戏内消费与游戏障碍筛查标准相关——有微交易支出的孩子，达到标准的几率约为没有的 3.8 倍，买过开箱的约为 4.6 倍；而且带模拟赌博成分的游戏（社交赌场、开箱等），比其他类型游戏的风险更高。这是横断面的关联，不能说成"充钱一定会上瘾"，也不能把一次充值读成成瘾，但足以说明**"再买一点"很少是终点**［1］。

所以他的问题不是"数学不好、不知道花了多少"，是他处在一个被设计成"停不下来"的结构里。

### 二、钱花出去之后，真正决定走向的是你怎么收场

这段是全场的关键。常见的三种收场都会把后面几个月的路堵上：

| 收场方式 | 他记下的结论 | 后面会发生什么 |
|---|---|---|
| 当众羞辱、告诉亲戚老师 | 我是坏孩子 | 更会藏，下次直接删记录 |
| 反复追讨、天天翻旧账 | 这笔债永远还不完 | 关系持续低位，规则谈不下去 |
| 全额兜底、假装没发生 | 出事有人扛 | 换一个平台或账号重来 |

钱已经不可能直接要回来（除走正规退款渠道）。**能拿回来的是"这件事之后你们还能不能一起管钱"。**

### 三、用羞辱和内疚收拾他，代价更大

用内疚和控制推动（心理控制），与孩子的抑郁、焦虑水平相关［2］；侵入式管控与青少年的内化、外化问题相关（三层元分析，样本为 13–25 岁青少年与青年，属关联）［3］。也就是说，你想用"你怎么对得起我们花的钱"把他掰回来，很可能得到的是更低的情绪状态和更多的隐瞒。

规则要有效，靠的是能力和结构，不是他感到多羞愧。

### 四、先止损，再谈规则

钱花出去以后最先该做的不是教育，是**让同一件事不再自动发生**：解绑支付、关掉免密、开启未成年人模式。这一步不需要他同意，也不涉及他"自不自觉"。

把两类东西分开管：
- **支付权限**：归你管，不归他管——不是惩罚，是结构；
- **使用时段**：还能继续谈、继续调（见 `06-scenes/屏幕与手机.md`）。

### 五、不用"充值＝奖励"来补的原因

"做完作业给你充十块""考好了给你买皮肤"属于外部奖励。外部奖励——尤其可预期的有形奖励——会系统性削弱本来就有的内在动机，对孩子影响更大［4］。想让他少花钱，用奖励去换，长期会让他更需要外部刺激才动。

### 六、分龄

| 学段 | 常见情况 | 你的重点 |
|---|---|---|
| **学前 3–6** | 基本是误点、乱点，或家长账号在玩 | 设备不绑支付，跟他解释不了就先改设置 |
| **小学低年级 6–9** | 不理解虚拟货币等于钱，易被诱导 | 支付权限彻底收回；把"钱和东西"的关系讲成具体的 |
| **小学高年级 9–12** | 开始被同学、活动、限定款拉着买 | 支付权限归你；教他看"这个多少钱、能用多久" |
| **初中 12–15** | 自主消费需求上升，也最容易被抽卡留住 | 给他一笔有限的、可自主的钱，超出要谈 |
| **高中 15–18** | 能算账，但同伴与社交压力在 | 从"管钱"转到"一起算账"；守住家庭金额底线 |

## 识别

### 一、先分清是哪一种"花了钱"

| 情况 | 更像 | 先做什么 |
|---|---|---|
| 一次性冲动，第二天自己也后悔 | 一次失控 | 止损 + 修复，不必升级成"成瘾" |
| 几个月持续小额，金额越滚越大 | 结构性问题 | 收回支付权限，必要时走升级信号 |
| 明显被诱导（限定活动、倒计时、同学都在买） | 外部设计 | 止损 + 保留证据，看能否走退款 |
| 你账号被盗刷、孩子不知情 | 财产安全 | 直接联系平台和银行，报警 |
| 充完还偷偷删记录、撒谎 | 已经进入隐瞒循环 | 先修"说了会不会被暴打"，再谈规则 |

### 二、分清现在最要紧的是哪一件事

**这三件不要混着谈：钱怎么止损、关系怎么修复、规则怎么补。** 混着谈，三件都做不成。顺序是**止损 → 修复 → 规则**。

### 三、先把事实摆出来（不审问）

只问必要的信息：哪几天、哪个平台、大概多少、钱从哪儿出、还有没有正在进行的自动续费。**先处理正在扣的钱，再说话。**

## 做法

### 一、收场三步

**第一步 · 止损（当天就做）**

1. 解绑银行卡、关掉免密支付和小额免验；
2. 查一遍自动续费和订阅；
3. 要求平台开启未成年人模式；查清能否按未成年人退款规则申请退款；
4. 涉及数额较大、疑似盗刷或诈骗 → 报警并保留证据。

**第二步 · 修复（24 小时内，两个人平静的时候）**

修复的目标不是让他认错，是让他知道**这件事可以说出来、说出来不会被打**。开场先把最怕的两件事拿掉：

> "钱的事我已经在处理了，我不打你，也不会跟别人说。"
> "我现在只想弄明白两件事：钱是怎么出去的，下次怎么不让它再出去。"

然后**只问、不评价**。他说的每一句，先接住，不追着挖。

**第三步 · 补规则（隔一两天，等他不是惊弓之鸟）**

规则不写"不许充钱"，写具体动作：**以后游戏类付款要经过你、设备不绑卡、要用钱跟你报一句。** 写下来，贴在能看见的地方。

### 二、可以直接照说的原句

**刚发现时（各年龄）**
> "我看到有一笔三百多的游戏付款。我先不改密码也不问细节，等我们都平静了再说这件事。"

**他以为要挨打（9–12 岁）**
> "我不打你。钱是我没管好支付这一步，这部分我认。你的部分是——以后要用钱先跟我说。"

**他开始辩解（12–15 岁）**
> "我不是来说你花钱不对。我想知道当时你是什么感觉，让你觉得非买不可。"

**你确实很气，但不想现在谈（各年龄）**
> "我现在很生气，这件事我明天再谈。今晚不翻账。"

**谈规则（12–15 岁）**
> "支付这一步以后归我。玩的时间还归我们商量。这两件事分开的，你不用因为这次把玩的时间也丢了。"

**想给他一个可自主的额度（12–15 岁）**
> "每个月你有固定的一小笔，你自己决定怎么花；花完就是这个月的。超了要提前跟我说。"

### 三、把"部分偿还"变成一个约定，不是惩罚

让他承担一部分后果，比全额兜底有效，也比罚站、断网更贴近真实后果：

- **分担**：从零花钱或压岁钱里分几个月还一部分他力所能及的比例；
- **参与**：让他一起查退款流程、一起写那几条规则；
- **有结束点**：说清还到什么时候为止，还完这件事就翻篇。没有结束点的偿还，会变成长期的精神负债。

让后果由他自己的选择带来、并且有明确边界，比家长单方面施压更能减少对抗［B1］［B2］。让他参与定规则、自己选方式，比替他决定更能让他真的守［B3］。

### 四、事后还要做一件事：把这件事和"他是什么人"切开

一次充值不等于"他这人守不住钱"。**分开说：这件事怎么补，和你是个什么样的人，是两件事。** 不评判地接住他说的东西，是让他愿意继续把实话讲给你的前提［B4］。

修复对话的具体技术见 `03-bond/事后修复话术.md`。

### 五、接下来一个月的三个观察点

1. 还有没有新的、你不知道的付款；
2. 他能不能自己说出"这次花在什么上、值不值"；
3. 因为钱这件事的冲突，是不是在变少。

三个都往好的方向走，说明止损和修复起了作用；只有第 2 项一直说不清，才需要考虑外部帮助。

## 边界

| 不要做 | 原因 |
|---|---|
| 当众羞辱、告诉亲戚老师 | 会把"犯错"变成"我是坏孩子"，之后只会更会藏 |
| 反复追讨、天天翻旧账 | 关系长期低位，规则永远谈不下去 |
| 全额兜底、当作没发生 | 他会换平台重来 |
| 全额索赔、让他"还清" | 一个孩子没有能力承担成人的金额，只会变成绝望 |
| 用"你怎么对得起我们"推他 | 心理控制与抑郁、焦虑相关［2］ |
| 用断网、没收手机当主罚 | 会把它变成长久的战场（见 `03-bond/奖励与惩罚的分寸.md`） |
| 用"再充钱就给你奖励"反过来劝 | 外部奖励削弱内在动机［4］ |
| 用"充值就有奖励"换作业 | 同上一行，且把两件事都搞坏 |
| 一次就说"你有网瘾／沉迷" | 这是描述，不是诊断，也不该由家长下结论 |
| 不复盘、不定结束点 | 这件事会一直挂在他头上 |

**核心：先止损，再修复，最后才是规则。三件事的顺序不能换。**

## 升级信号

- **持续数月、金额不断变大，或为了充值借钱、偷拿家里或同学的钱** → 走 `07-safety/就医与专业转介指征.md`。
- **被发现大额充值后出现强烈的羞耻、自伤行为或说"不想活了"** → 立即走 `07-safety/危机信号识别.md`，打 **110／120**。
- **涉及盗刷、诈骗、诱导未成年人消费的黑产** → 保留证据，报警，见 `07-safety/法律与权利边界.md`。
- **因此事家庭经济出现实际困难、或夫妻为此持续冲突** → 走 `04-family/家庭经济与物质状况.md`、`04-family/夫妻冲突与对孩子的影响.md`。
- **你们已经无法平静地谈钱，每次都以争吵收场** → 先处理关系与情绪，见 `03-bond/事后修复话术.md`、`02-parent/家长情绪急救.md`。

退款与未成年人模式的平台责任，可以据此要求平台配合处置［L1］。

## 依据说明

本份属事后修复类做法层。

- **证据分级 A**：外界用内疚和控制推动（心理控制）与孩子抑郁、焦虑水平的关联［2］、侵入式管控与青少年的内化、外化问题的关联［3］（三层元分析，样本为 13–25 岁青少年与青年，属关联）、外部奖励削弱内在动机（对儿童更强）［4］——均为元分析。
- **证据分级 A**：未成年人网络保护条例（现行法规）——网络游戏、未成年人模式及相关消费保护的规定［L1］。
- **证据分级 B**：游戏内消费（微交易、开箱等）与青少年达到游戏障碍筛查标准的关联，以及带模拟赌博成分的游戏风险更高［1］（826 名 12–17 岁澳大利亚青少年、横断面 logistic 回归，**属关联不能读成因果**，也不能据此给孩子下诊断）。
- **证据分级 C**：自然后果与逻辑后果、让他参与定规则、修复优于惩罚，属成熟育儿框架，对应到书［B1］［B2］［B3］［B4］；"先止损再修复后规则"也是常见处理顺序。
