# 分龄-高中15-18

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：预防促进
> 一句话范围：15–18 岁：更会藏、情绪装进具体的事里，家庭从管理者转为后盾。
> 相关文件：00-frame/分龄-初中12-15.md；00-frame/关键过渡期.md；03-bond/倾听与提问的技术.md；05-outside/考试焦虑与成绩落差.md；05-outside/转学与升学适应.md；07-safety/就医与专业转介指征.md

## 机制

### 一、控制力还在长，但他比初中更会藏

负责控制与判断的前额叶要到二十岁出头才逐步成熟［1］。所以这个年龄的冲动和情绪波动仍在，只是表达方式变了：初中会当场炸，高中更常是不说、走开、用一句"没事"带过。看起来更稳，不代表里面更稳——**更会藏，不等于问题变少了。**

### 二、这一阶段的核心任务是"我是谁、我要去哪"

高中生在建立自己的判断和方向：选什么科、交什么朋友、以后做什么。这个过程中，家长的权威自然下降，同伴和自己的判断上升。这不是不孝，是这个阶段该发生的分化。你还站在原地当管理者，他就只能用关门来把这件事做完。

### 三、情绪常常装进具体的事里

这一年龄很少直接说"我难过""我焦虑"，更常说"这科没意义""老师针对我""不想去了""反正努力也没用"。**情绪被装进了具体的事。** 你只处理那件事本身（"那你更得好好学"），就错过了下面那层。听法要改：他谈事的时候，先听他这一步的情绪。

### 四、从管理者转后盾

纵向研究提示，"高要求 + 高回应"的权威型做法下，青少年的适应结果长期更稳，优于高压型、放任型和忽视型［2］［3］。到了高中，"要求"更多变成信任和要求他自己负责，"回应"更多变成支持他的选择，而不是替他做选择。教养方式与学业成绩之间也有稳定关联，但这是关联，不是因果，也不能反过来算成你的分数［4］。

### 五、他不会主动开口

青少年不求助，常见原因是想自己扛、怕被贴标签、不清楚该找谁帮忙［5］。所以这一段最要紧的是**把通道留着**：让他知道你有空、你在、你不会追问，而不是等你问他才出现。

## 识别

### 一、这一份的使用时机

- 你一问，他就"没事""还行""随便"；
- 你说的每一句关心，他都当成要管他；
- 家里的话越来越少，门关得越来越早；
- 他谈事情带着情绪（烦躁、厌倦、没意义），你只回事情本身。

### 二、情绪装在事里：把"事"和"情绪"分开听

| 他说的是事 | 底下可能是 | 先接哪一层 |
|---|---|---|
| "这科没意义，学了也没用" | 挫败、看不到回报 | 先接挫败，不辩论有没有意义 |
| "反正努力也没用" | 长期用力后没效果 | 先认这句感受，再谈方法 |
| "他们都很幼稚" | 也许是被排挤，也许是孤独 | 先问他跟谁走得近 |
| "不想去了" | 累、怕、或真有事 | 先问累还是怕，不先讲道理 |
| "你别管我" | 想自己试，怕被否定 | 退一步，留一句"要我时说" |

### 三、看藏起来的信号

他嘴上说没事时，看行为：有没有还愿意做的事、还联系的朋友有没有断、吃饭睡觉稳不稳、成绩有没有断崖式下滑、有没有开始把自己关得更死。行为比话更可信。你看到的和他自己感受的常常对不上，两边都要听，不要用一个视角定死［6］。

## 做法

### 一、总位置：站到后盾位

后盾的意思是：**方向他自己定，你负责在他需要时接住。** 你不再安排、不再代劳，但你说清"我在"。这比任何一句道理都重要。

### 二、可以直接照说的原句

**先问需要，不给安排：**
> "这件事你打算怎么办？我能帮上什么？"

**不代劳，只陪跑：**
> "报名、咨询这些你自己来，要跑腿我陪你。"

**谈未来不施压：**
> "你先说你自己的想法，我不急着给意见。"

**留门，不追问：**
> "你想聊再叫我，我在客厅。"

**承认他的判断：**
> "这是你的决定，我尊重。真出问题了，我们一起想办法。"

**谈成绩落到人，不落到名次：**
> "分数我看到的是结果，我更想知道你现在累不累。"

**他惹了事，先站他这边：**
> "先把事解决，别的一个一个说。我们一起想。"

**不逼问，但有底线：**
> "你不想说也行。但如果这件事会伤到你，我必须知道。"

**肯定落在选择和过程上：**
> "这件事是你自己扛下来的，这不容易。"

先接情绪、再谈事情，是这一段能用得上的做法［B1］；无条件接纳他本来的样子，是他敢把真实想法说出来的前提［B2］；说事实和感受、不评价人，是让对话不升级的关键［B3］。

### 三、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "没事，别问了" | 停问，留门 | "行，我不问了。想说的时候我在。" |
| "这没意义，我不想学了" | 先接这层情绪 | "你最近是不是特别累？先说说。" |
| "反正我说了你也不懂" | 不争懂不懂 | "那你多讲两句，我尽量听懂。" |
| 你想要他的行踪 | 换成彼此的约定 | "不用实时报，但让我知道你在哪儿就行。" |
| 他做了你不认同的选择 | 先认这是他的选择 | "我不完全同意，但这是你的决定。要我兜底就说。" |
| 他把自己关起来 | 不拍门，留通道 | "饭在桌上。你出来吃，不用说话。" |

## 边界

| 不要做 | 原因 |
|---|---|
| 还当管理者，替他安排一切 | 分化是他的任务，你越代替他，他越关门 |
| 用"我们为你付出这么多"施压 | 把爱变成债务，他会用沉默还 |
| 偷看手机、查行踪、翻东西 | 越查越藏，把通道彻底堵上 |
| 否定他的人生选择和判断 | 他要么放弃想法，要么连你一起放弃 |
| 只在他出事时才出现 | 关心只连着问题，他就不把日常告诉你 |
| "他没说就当他没事" | 他不会主动求助，沉默不等于好［5］ |
| 把分数当成他这个人 | 关联不等于因果，别把成绩算成评价你或他［4］ |

**核心：把位置从管理者退到后盾。方向交给他，但不撤走你的人。**

## 升级信号

- **持续两周以上的改变**：情绪低落或易怒、兴趣减退、睡眠和饮食明显改变、把自己关得更死 → 走 `07-safety/就医与专业转介指征.md`。
- **拒绝上学、休学、突然与所有朋友断开** → 走 `05-outside/校园欺凌与同伴冲突.md`，并尽快做专业评估。
- **出现自伤、或提到"活着没意思"** → 立即走 `07-safety/危机信号识别.md`，不要停在话术上。
- **他不会主动开口**：不要等他自己说。主动创造"不用开口也能被你看见"的通道（固定的一起吃饭、接送、散步），比问有用［5］。

紧急情况拨 110／120，心理援助热线 12356。

## 依据说明

本份属机制层，是分龄五份中的高中一段。

- **证据分级 A**：教养方式与学业成绩的关系（元分析，关联非因果）［4］、青少年不愿求助的常见原因（系统综述）［5］。多信息源评估之间不一致属常见现象（多信息源效度的综述研究）［6］。
- **证据分级 B**：青春期前额叶逐步成熟（双系统；叙述性综述）［1］、权威型做法下青少年长期适应更稳（单项纵向研究）［2］［3］。
- **证据分级 C**："后盾位""留门不追问""先接情绪再谈事"，属成熟做法，对应到书［B1］［B2］［B3］。
- **证据分级 D**："情绪装在事里"的听法、把位置从管理者退到后盾的判断、本段的原句与边界，为本套材料自定。
