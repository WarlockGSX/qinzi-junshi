# 青春期关门对抗

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：当场应对
> 一句话范围：他把门关上、你说什么都不接的那一晚，怎么不把关系砸掉——不接球、留门缝；别去撬门、别偷看手机。
> 相关文件：01-child/沉默与回避.md；03-bond/顶嘴与对抗的应对.md；03-bond/设边界的句式.md；02-parent/家长情绪急救.md；07-safety/危机信号识别.md

## 机制

### 一、关门是空间需求，不是宣战

青春期要一块不归你管的地方，这是发育带来的正常需求。负责情绪与奖励的系统先成熟，负责控制与规划的前额叶要到二十岁出头才逐步成熟，所以他的反应强度和控制能力暂时对不上［4］［B1］。

**同一个孩子在家关上门、出门话很多，是常见现象。** 行为在不同情境下本来就不一致，不能只凭他在你面前关门这一件事下结论［5］。

### 二、撬门和偷看换来的不是知情，是更深的隐藏

家长对孩子情况的了解，主要来自孩子**主动说出来**，而不是监控和追问。一项对 703 名瑞典 14 岁青少年及其家长的研究发现，父母的知情主要来自子女主动披露，追踪、监视并不是获得知情的好办法［1］（属关联，非因果）。**你越查，他能给你的反而越少**——删记录、换账号、把手机清一遍再回家。

### 三、用控制把他拉回来，代价落在他的状态上

用内疚和控制推动（心理控制），与孩子的抑郁、焦虑水平相关［2］；侵入式管控与青少年与青年（13–25 岁）的内化、外化症状相关［3］（均属关联）。你想用"我是你妈／爸，我有什么不能看"把他拉回来，很可能得到的是更低的情绪状态、更少的实话。

### 四、"不接球"的含义

不接球＝**不接他抛给你的挑衅，也不把自己变成第二个情绪源**。具体是三件事：

- 不当场辩论对错；
- 不追进房间、不隔着门喊话；
- 不在他摔门的那一刻追一件旧账。

不接球不等于不管。你只是不在他最不需要沟通的那十分钟里沟通。

### 五、"留门缝"的含义

留门缝＝**给他一个确定的、但不需要他立刻回应的在场**。它有两个条件：

1. **确定**：他知道你还在，你没有走开、没有不管他；
2. **不带时限要求**：不是"你现在就说"，是"你想说的时候我在"。

有具体时间点的暂停，孩子会理解为"暂停"；没有任何说明的走开，他会理解为"被丢下"。区别就在有没有那句说明。早期照护关系会形成相对稳定的内部模式，影响一个人后来在关系里怎么反应、"什么事能说给谁听"［B2］。

### 六、分龄：同一个关门，在不同年龄是不同的东西

| 学段 | 关门的样子 | 你的位置 |
|---|---|---|
| **学前 3–6** | 基本没有"关门"这件事，多是躲、闹 | 用玩和画画替他说，别追问 |
| **小学低年级 6–9** | 生气躲进房间，门常常不真锁 | 隔几分钟敲一次，给一个不用开口的出口 |
| **小学高年级 9–12** | 开始要面子、要独处 | 不当众说；私下、并排时开口 |
| **初中 12–15** | 强度和频率都上来，最容易撬门 | 不接球、留门缝；守住"不进他房间翻东西" |
| **高中 15–18** | 更会藏，常觉得"你帮不上" | 尊重判断力，摆出"要什么我配合"的位置 |

## 识别

### 一、先分清是哪一种关门

只问三个问题：

1. **他只对你关门，还是对所有人都退？** 只对你 → 关系里的空间问题；对所有人都退 → 先排查有没有具体的事。
2. **他在别处说不说？** 说 → 他把话拿到别处去了（支持外移，见 `01-child/沉默与回避.md`）；不说 → 更可能是情绪或压力。
3. **是最近才这样，还是一直这样？** 最近才这样 → 先找变化点；一直这样 → 是长期形成的模式。

### 二、先排除三件不能当"青春期正常"的事

| 要排除的 | 线索 |
|---|---|
| **有具体的事不敢说** | 被欺凌、被威胁、被不当触碰、犯了怕被罚的错——这类退避带着怕 |
| **情绪已经低下去** | 不只是关门，还睡不好、吃不下、对以前喜欢的没兴趣、常说累 |
| **关系里长期没人接** | 他试着说过，被打断、被否定、被拿去处理过 |

第二类、第三类直接走 `07-safety/危机信号识别.md`。

### 三、摔门和静静关门要分开

摔门带着挑衅，是抛球；静静关门多数是退开。**对摔门可以不接球（不追、不辩），对静静关门连话都不要多说**——你多说一句，就等于把他退开的那一步又拉回来。

## 做法

### 一、关门那一刻：三步，全程不超过两句话

1. **退半步，不去挡门。** 手别放在门上，人别站在门口正中。
2. **只说一句事实 + 一个出口，说完就走。** 说事实而不评价人，是这类话不升级的关键［B3］。
3. **走开。** 走开不是不管，是把这十分钟让给两个人。

> "行。门是你的。我一会儿在客厅，你想说再叫我。"

**不要做：** 拍门、撬门、反复敲门、隔着门讲道理、站在门口等他出来认错。

### 二、再去的时机与方式

- **给它半小时到一晚。** 情绪在的时候，任何内容都进不去。
- **换一个场景再开口**：并排（开车、散步、一起洗碗）比面对面坐着好开口。描述你看到的事实、不评价他这个人，比追问更能让他把话说下去［B4］。
- **只谈一件事，且只问不管**，开场不翻账：

> "下午的事我还没弄明白。我不是来要你说清楚的，就是想问问你现在怎么样。"

**如果他继续不说，就真的不问了。** 说了不问、问了不要，是这条通道还开着的唯一条件。

### 三、可以直接照说的原句

**他摔门进房间（12–15 岁）**
> "你生气了，我不追。东西别砸，门可以关。我在客厅。"

**他在屋里很久不出声（12–15 岁）**
> （在门外，一句话，说明白就走）"我热了杯牛奶放门口了。你不用出来，也不用回答我。"

**他嫌你老站在门口（12–18 岁）**
> "好，我以后不站门口。我给你一条规则：真遇上自己扛不住的，让我知道。"

**你想定一条双方都认的边界（12–18 岁）**
> "你的房间我进之前敲门，你同意我再进；你的手机我不翻。这两条我做到。对应的一条是——你要用的东西、要出门、要花钱，先跟我说一声。"

**你之前撬过门／翻过手机，想修（12–18 岁）**
> "上次你不在的时候我翻了你手机。这事是我做的，不是你该防我的理由。以后我不会了。你要是愿意，可以把门锁上。"

**他抛出挑衅要跟你吵（12–18 岁）**
> "这句话挺重的。我现在不接。等你不想吵了我随时在。"

### 四、手机：不偷看，但可以立"公开可见"的约定

不偷看是底线，但这不是让你什么都不过问。可以做的是**事先约定，而不是事后翻查**：

1. 说清哪些属于你会在意的（安全风险：陌生人约见、被要照片、被威胁）；
2. 约定一个"可以随时看的位置"——比如屏幕使用记录、家庭共享，**并且你也让他看你的**；
3. 一旦发现安全风险，直接按 `07-safety/法律与权利边界.md` 处置，不再讲"但我说过不看你手机"。

**顺序不能反：先立约定，才有查看的依据；先翻后问，等于告诉他"说了不算数"。**

### 五、你自己这一侧

很多升级的真正起点不是他关门，是你被关门激起的失控感。认清自己的信号（太阳穴发紧、手已经放到门把手上），先离场并交代：

> "我有点上头了，我去阳台待十分钟。我不是不管你，我是怕我说错话。"

你每一次"算了，不说了"的静一静，都比一次撬门更接近你想要的知情。这一部分见 `02-parent/家长情绪急救.md`。

## 边界

| 不要做 | 原因 |
|---|---|
| 撬门、拆门锁 | 用身体手段破边界，他会升级成更激烈的对抗 |
| 趁他不在翻手机、翻书包、翻抽屉 | 一次被发现，信任很难补回来；而家长对孩子情况的了解，主要来自他主动说［1］ |
| 站在门口反复讲道理 | 等于不接球的反面，会把关门变成一场持久战 |
| 隔门喊"你不说我就不走" | 用压力换来的往往是假话或半句话 |
| 让另一位家长去"撬" | 两个人围堵，会同时弄坏两条通道（见 `01-child/沉默与回避.md`） |
| 把"关门"讲给亲戚老师听 | 他会记很久，是支持外移最快的一步 |
| 用"你不出来我就……"威胁 | 用恐惧换来的话没有价值 |
| 当场定对错、逼他道歉 | 他正在情绪里，做不到，只会把时间拉长 |
| 把对这件事的不满算到别的事上 | 把一件事变成一场总账 |
| 一次没成功就判定"没用" | 留门是要攒"说了有用"的经验，攒够才开 |

**核心：你要的不是"必须跟我说所有事"，是"他身边一直有一个能接住他的人"。**

## 升级信号

- **持续性退避，同时睡眠紊乱、食欲变化、对爱好失去兴趣、常说累，持续两周以上** → 走 `07-safety/危机信号识别.md`。
- **退避是怕被罚、怕报复**（被欺凌、被威胁、被不当触碰）→ 先保安全，走 `07-safety/危机信号识别.md`。
- **身边一个能说话的人都没有**（对同伴、老师、家长全都沉默）→ 优先处理，走 `07-safety/就医与专业转介指征.md`。
- **摔门升级到动手、砸物、扬言伤害自己或他人** → 立即走 `07-safety/危机当下的应对.md`；打 **110／120**。
- **你自己每次都以失控、撬门、翻手机收场** → 先看 `02-parent/家长情绪急救.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：行为在不同情境下表现不一致，单一情境的观察不足以判断［5］（元分析）；心理控制与孩子抑郁、焦虑水平的关联［2］（元分析）；侵入式管控与青少年与青年（13–25 岁）内化、外化症状的关联［3］（三层元分析）。
- **证据分级 B**：家长对孩子的了解主要来自孩子主动披露，监控与追问不是有效路径［1］（单项研究，703 名瑞典 14 岁青少年及家长，属关联）；青春期双系统发育——奖励与情绪系统先成熟、控制系统后成熟［4］（叙述性综述）。
- **证据分级 C**："不接球""留门缝"的表述、摔门与静静关门的区分、说事实不评价人、并排沟通优于追问，属常见育儿框架与经验说法，用于选择应对方式，不对孩子作任何定性，对应到书［B1］［B2］［B3］［B4］。
- **证据分级 D**：三个排查问题、三步做法、隔多久再去、手机"先约定后查看"的口径、可照说原句，为本套材料自定。
