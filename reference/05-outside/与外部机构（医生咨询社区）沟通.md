# 与外部机构（医生咨询社区）沟通

> 适用对象：家长
> 生态层：外圈层（学校与外部）
> 适用时机：预防促进
> 一句话范围：就医前准备、怎么向专业人员描述情况。
> 相关文件：07-safety/就医与专业转介指征.md；07-safety/求助渠道与转介.md；08-archive/对话档案（每次一条记录）.md；08-archive/关系状态的描述.md；05-outside/与老师沟通（被请家长）.md

## 机制

### 一、就诊不是"带孩子去看病"，是"你和医生把情况拼完整"

不同人看到的是不同场景：你看到的是家里的样子，老师看到的是学校的样子，孩子自己知道的是心里的样子。这三份信息都不完整，合起来才接近全貌。

父母、孩子、老师看到的是不同情境下的表现，各自提供的信息都有用，但彼此只**部分重叠**，谁单独看都不完整；把它们分开呈现，比合成一个“统一说法”更有信息量［1］。所以就诊时，家长一个人的描述不够，要尽量把多方信息带齐。

### 二、一致度低是正常的，不是谁在撒谎

不同场景下行为本来就不同：孩子在家沉默、在学校闹，或反过来，都是常见情况。跨信息源报告之间的一致度通常偏低，这反映的是**情境特异性**，不是某一方说错［2］。

所以当你听到"老师说的跟我看到的不一样"，不要觉得被冤枉。这恰好是有用的信息，要如实告诉医生，不要为了"统一说法"而改口。

### 三、到了诊室反而"说不清"的原因

两种常见失败：

- **只说最扎眼的一句**："他就是不想上学。"医生拿到的是一个结论，不是可判断的信息。
- **一口气说很久**：把最近半年的事全倒出来，医生抓不到重点。

医生真正需要的是这几项：**什么时候开始、多久一次、什么情况下出现或缓解、造成了什么影响、你们试过什么、有没有相关病史**。这几项准备好了，"说清"就不难。

### 四、孩子不说，是常见现象

孩子到了诊室说“没事”，或不吭声，很常见。孩子不愿求助，常见原因有几类：怕被贴标签、觉得难堪；倾向自己扛；对心理问题了解少、也不知道能找谁［3］。

这不是他"不配合"，是求助本身的阻力。你的做法不是当场逼他说，而是把"我看到的"如实补上，并且**给医生和他单独说话的空间**。

### 五、你是信息的提供者，不是被审判的人

很多家长带着"会不会被说是我没教好"的紧张去，于是要么防御（什么都推给孩子），要么漏说关键的。目标只有一个：**把情况描述准确，让专业人员去判断。** 承认自己只看到一部分、也不夸大，是最有用的姿态。

## 识别

### 一、该去的时候（本份只给方向）

- 情绪低落或焦虑**持续两周以上**，已影响上学、吃饭、睡觉；
- 睡眠、饮食长期紊乱；
- 注意力、学习、社交长期明显异常；
- 身体症状反复、查不出原因；
- **出现自伤、说"活着没意思"这类话 → 立即走安全流程，不要走常规预约。**

详细的分档与科室表见 `07-safety/就医与专业转介指征.md`。本份不负责判断该不该去。

情绪与行为问题的评估，要走“症状识别＋结构化评估工具（量表、结构化访谈）”这条路［4］；家长能做的，是把在家里看到的、时间线和频率如实讲清楚［1］［2］。这也是为什么“把情况讲清楚”这件事本身有价值。

### 二、先分清该找谁（方向，不是诊断）

| 去哪 | 什么情况 | 备注 |
|---|---|---|
| **精神科／心理科** | 情绪、行为、睡眠、自伤、明显异常 | 可评估、可开药、可转介 |
| **儿科／儿保** | 身体症状、发育、生长 | 常是第一步，儿科也能转介 |
| **学校心理老师** | 学校范围内的情绪、适应、同伴关系 | 第一手学校信息在这里 |
| **心理／家庭咨询** | 不涉及药物时的谈话支持 | 通常需要先评估 |
| **热线（12356）** | 紧急时的即时支持 | 不替代就诊 |

挂什么号拿不准时，先问学校或社区医生，不要因为"不知道挂哪个"就不去。

### 三、出门前自检三句

1. 我能不能用三句话说出"什么时候开始的、多久一次、什么情况下最明显"？
2. 我有没有带上老师和孩子不同的说法？
3. 我有没有把想问的问题先写下来？

三句都能，就准备好了。

## 做法

### 一、就诊前：写一页纸

按这七个字段写，一页以内：

- **主诉**：最困扰的一件事，什么时候开始的；
- **频率与时长**：多久一次、每次多长、已持续多久；
- **场景**：什么时候最明显，什么时候好；
- **影响**：睡觉、吃饭、上学、朋友、家里关系，各受了什么影响；
- **试过什么**：做过哪些尝试，有效没效；
- **身体情况**：相关病史、在吃什么药、睡眠饮食；
- **想问的**：你最想问的 3 个问题。

### 二、把"多方信息"带齐

- **孩子自己的说法**：哪怕他说"没事"，也照实转述"他说没事，但我在家看到……"；
- **老师／学校的观察**：有的话，带一两句**具体**的；
- **家里的记录**：按 `08-archive/对话档案（每次一条记录）.md` 的方式记。

不一致的信息**不要合并**。医生需要从差异里看情境［1］［2］。

### 三、向专业人员描述的具体法则

| 不要说 | 改说 |
|---|---|
| "他特别叛逆" | "上周有三次摔门，三次都是我叫他写作业之后" |
| "他总是这样""从来不" | "这个月大概十几次""这周只有两天没有" |
| 一堆形容词 | 举一个最近的具体例子 |
| "就是他妈妈惯的" | "我看到的和老师说的不一样，我先把两边都说一下" |

要点：**说行为不说评价，说频率不说"总是"，给具体例子，分开说"我看到的／老师说的／他自己说的"。** 说得不全没关系，先说有的，再补充。

### 四、诊室里可以直接照说的原句

> "我想说三件事：什么时候开始的、多久一次、什么情况下最明显。"

> "我先说我不确定的部分，再说我确定的。"

> "他刚才说没事，但我在家看到他……"

> "这个问题我没搞明白，能不能请你解释一下？"

### 五、走之前务必问清三件事

1. "我们现在最需要做的是什么？"
2. "什么情况下要马上再来？"（**这条最重要**，等于拿到一条复诊的红线）
3. "下次复诊前，我们记录什么最有用？"

### 六、看诊之后

- **当场记，或出门立刻记**医生说的话，别靠回忆。
- **按时复诊**，把复诊当成"对上一次判断的校正"，不是"没用"。
- **不擅自停药、加量、减量。**
- 用 `08-archive/对话档案（每次一条记录）.md` 记录变化，复诊时带上。

### 七、孩子这一侧：三件事

1. **去之前如实告诉他**"去见谁、要做什么、大概多久"，不要骗他"就是去玩"。
2. **不在诊室里数落他**，也不当场翻旧账。
3. **事后不反复问"医生跟你说什么了"**，也不拿医生的话压他（"你看医生都说你有病"）。

如果他要求单独和医生说话，尊重他——这是评估的一部分，不是他在瞒你。先让他感到被理解、不被评价，他才愿意说真话，这个原则在共情式沟通里是一致的［B1］；家长先稳住自己的情绪，描述才不容易变味［B2］。

## 边界

- **不把就诊当成"证明我有理"或"证明他有病"的工具。**
- **不在诊室里当着孩子给你自己"伸冤"**，也不列他的"罪状"。
- **不隐瞒重要信息**（家里正在发生的事、他有没有自伤过）——隐瞒会误导判断。
- **不夸大也不缩小。** 为了"引起重视"而添油加醋，同样误导判断。
- **不替孩子下诊断**，也不要求医生按你的结论下诊断。
- **不擅自停药、加量。**
- **不在孩子面前讨论**"要不要住院""是不是精神病"这类让他恐惧的话题——这些留到医生在场时谈。
- **不因为一次"没用"就放弃求助。** 换渠道不等于放弃。
- **不把机构当成裁判**，让它给你们家打分。它的作用是提供判断和工具。
- **不求一次问到底。** 看诊时间有限，把最要紧的三件说清，剩下的下次带记录来。

## 升级信号

本份**不做就诊指征判断**。什么时候该去、多快、去哪一科，见 `07-safety/就医与专业转介指征.md`。

**紧急情况**（自伤、自杀、伤人、意识不清、行为异常）→ **直接打 110／120**，或就近急诊，不走常规预约。求助渠道清单见 `07-safety/求助渠道与转介.md`。

## 依据说明

本份属外圈层做法层。

- **证据分级 A**：多信息源各自有效、只部分重叠，宜分开解读而非合成单一结论［1］（方法学元分析，341 项）；跨信息源一致度偏低反映情境特异性、不是某一方说错［2］（元分析，119 项研究）；孩子不求助的障碍类型［3］（系统综述）。
- **证据分级 B**：儿童青少年抑郁的识别与评估综述［4］（叙述性综述）。
- **证据分级 C**：共情式沟通——先被理解、不被评价，再说真话，对应［B1］［B2］。
- **证据分级 D**：就诊一页纸的七字段、多方信息带齐、四条描述法则、诊室照说句、走前问医生三件事、孩子这一侧的三件事，均为本套材料自定。

本份**不诊断、不测评**，只做"怎么把情况讲清楚"的准备；判断交给专业人员。
