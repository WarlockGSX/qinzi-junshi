# 校园欺凌与人身伤害的法律处理

> 适用对象：家长
> 生态层：横切（覆盖全层）（安全兜底）
> 适用时机：事后修复
> 一句话范围：学校、报警、证据；什么时候不该"再观察几天"。
> 相关文件：05-outside/校园欺凌与同伴冲突.md；07-safety/法律与权利边界.md；07-safety/危机信号识别.md；07-safety/求助渠道与转介.md

## 机制

### 一、该走法律与行政渠道的情形，而不是"再观察几天"

判断口径只有一句：**有伤、有重复、有力量不对等、有威胁或传播，就不再是"小孩的事"。** 这一类靠学校流程、报警、留证处理，不靠"再谈谈"。

### 二、学校有法定的保护与处置义务

- **《中华人民共和国未成年人保护法》**：学校应当建立学生欺凌防控制度，对实施欺凌的未成年学生依法加强管教；对严重的欺凌行为，学校不得隐瞒，应当及时向公安机关、教育行政部门报告并配合处理。任何组织或个人发现不利于未成年人身心健康的情形，可以劝阻、制止或向有关部门提出检举、控告；密切接触未成年人的单位及其工作人员发现未成年人受到侵害或面临危险，应当立即向有关部门报告［L1］。

**你要求学校启动流程，不是"麻烦学校"，是学校本来就该做的事。** 有元分析显示，学校系统性的反欺凌措施整体上能降低欺凌发生率［1］。

### 三、人身伤害的定性

- **《中华人民共和国民法典》**：未成年人在学校等教育机构受到人身损害，教育机构未尽到教育、管理职责的，应当承担相应责任；损害由第三人造成的，由第三人承担侵权责任，教育机构未尽到管理职责的承担相应的补充责任［L2］。
- **《中华人民共和国反家庭暴力法》**：家庭内的人身伤害同样适用；学校、医疗机构等发现未成年人遭受或疑似遭受家庭暴力，应当及时向公安机关报案［L3］。

### 四、网络传播是另一条线

- **《未成年人网络保护条例》**：任何组织和个人不得通过网络以文字、图片、音视频等形式对未成年人实施侮辱、诽谤、威胁或恶意损害其形象等网络欺凌行为；未成年人及其父母或其他监护人有权通知网络服务提供者采取删除、屏蔽、断开链接等措施［L4］。

涉及影像传播的，学校线、报警线之外，还要走"通知平台删除"这一条，并固定证据。

### 五、等待本身有成本

同伴受害与之后更高的社交焦虑相关，且两者双向关联［2］。长期被欺凌与孩子对"关系安不安全"的预期变化有关，等待本身有成本。

## 识别

### 一、从"教孩子应对"转到"家长走流程"的时机

出现下面任何一条就转：

- 有伤，或财物被反复拿走、被索要钱；
- 故意、重复、力量不对等三者同时成立；
- 经历围堵、威胁，或对方是群体；
- 涉及影像传播、线上持续骚扰，或与性有关的不当触碰；
- 孩子出现不想活、自伤一类信号 → 立即走 `07-safety/危机信号识别.md`，紧急打 **110／120**（有过自伤与之后更高的自杀风险相关，属关联、预测力有限，出现即不再等待［4］）。

### 二、证据清单

从今天起记这六项：**时间、地点、在场的人、说了什么做了什么、有没有伤或损失、告诉过谁、对方什么反应。** 另外：

- 给伤处、损坏的物品、相关界面**拍照并记日期**；
- 就医的**病历、诊断、缴费凭证**都留好；
- 聊天记录、录音等，**先确认符合当地法律**再保存和使用，见 `07-safety/法律与权利边界.md`。

记录是两件事的凭据：跟学校沟通，以及万一要走法律流程。没有记录，沟通时容易变成各说各话。

## 做法

### 一、学校线：按顺序推进

1. **先约班主任当面谈**，不隔空发消息吵，带记录去；
2. **说清三件事**：我知道的事实、孩子的状态、我要求学校做什么；
3. **要求一个明确答复**：由谁负责、怎么处理、什么时候反馈；
4. **没回应或情况继续**，逐级往上（年级组 → 德育处 → 校长），每一级都留记录；
5. **全程留痕**：每次沟通的时间、对象、内容。

可以照说的开场：

> "老师，我想和你对一下孩子最近在学校的情况。我记了几件事，想请你帮我看看怎么处理。"

> "我需要一个明确的处理办法，还有一个什么时候反馈给我的时间。"

### 二、报警线：报警的时机与方式

- **什么时候报**：有伤、有威胁、有围堵、涉及财物被索要、涉及与性有关的触碰、涉及影像传播、学校不处理［L1］；
- **怎么报**：打 **110**，就近到派出所做笔录，说事实、给证据、说清诉求；
- **报完做什么**：把报警回执、笔录情况留好，同步通知学校，要求学校配合。

### 三、就医线：先看伤，同时留证

有人受伤先处理伤。到正规医院就诊，**如实说明受伤经过**，保留病历与票据。需要伤情鉴定时，按办案机关或医生的指引进行。孩子同时出现情绪、睡眠、恐惧等反应，按 `07-safety/就医与专业转介指征.md` 评估。

### 四、网络线：存证 + 通知平台

1. **先把证据固定下来**（截图、链接、时间、发布者），不要先对骂；
2. **通知平台删除、屏蔽、断开链接**［L4］；
3. 情节严重的，同时走报警线；
4. **不让孩子自己去线上对线**，也不让他反复看那些内容。

### 五、涉及与性有关的不当触碰

- **不追问细节。** 只问三件事：在哪、什么时候、还有谁知道；
- **先保安全、先就医留证**，直接走报警线，其余交给专业人员。

### 六、孩子这一侧：三件事

1. **先信、先谢、不追问**："谢谢你告诉我。你说的我都信。这不是你的错。"孩子遇到这种事常常不主动开口，阻力多在怕被评价、想自己扛、不知道向谁求助［3］；先承认感受、不否定、不抢着讲道理，是让他继续说下去的前提［B2］。
2. **保持日常稳定**：作息、吃饭、睡觉尽量不变，稳定本身就说明"家是安全的"；
3. **不反复让他复述**，用运动和身体活动重建"我能掌控"的感觉，比讲道理更容易让他松下来［B1］［B3］。

## 边界

- **不教打回去，不斥责"你怎么不还手"。** 力量不对等，"打回去"通常是升级。
- **不私下找对方孩子或对方家长"算账"。** 会升级冲突，也可能让事情反转。
- **不当着别人（老师、对方家长、亲戚）复述他的遭遇。**
- **不承诺"我保证明天就解决"。** 做不到，他以后更不会说。
- **不因为"不想把事闹大"就替他决定忍。** 要不要升级，先和孩子商量。
- **不自行定性法律问题。** 伤害定性、责任划分以办案机关和专业法律渠道为准。
- **不删证据。** 记录、照片、聊天记录、就诊材料，在事情了结前不要清理。
- 涉及录音、录像、截图的：**先确认符合当地法律**，并**让孩子知情同意**，见 `07-safety/法律与权利边界.md`。

## 升级信号

下面任何一条出现，**都不该再"观察几天"**：

- 身上有伤、财物被反复拿走或被索要钱；
- 围堵、威胁、群体对一人、力量长期不对等；
- 涉及影像传播或线上持续骚扰 → 同时走网络线与报警线；
- 涉及与性有关的不当触碰 → 不追问细节，先就医留证，直接报警；
- 孩子出现不想活、自伤、持续说"活着没意思" → 立即走 `07-safety/危机信号识别.md`，紧急打 **110／120**；
- 向学校反映后问题仍在继续，或学校不按流程处理；
- 孩子已经不敢单独出门、开始回避上学。

渠道与转介方式见 `07-safety/求助渠道与转介.md`；同伴冲突与欺凌的区分、跟孩子怎么谈，见 `05-outside/校园欺凌与同伴冲突.md`。等待观察的每一天都有成本：同伴受害与之后更高的社交焦虑相关（元分析，两者双向关联）［2］。

## 依据说明

本份属安全兜底层，涉及法律的部分以现行规定为准（A 级），研究与做法部分分级如下。

- **证据分级 A**：未成年人保护法的学校防控制度、强制报告与不得隐瞒［L1］；民法典关于教育机构责任与第三人侵权的规定［L2］；反家庭暴力法的家庭内人身伤害与强制报告［L3］；未成年人网络保护条例关于网络欺凌与通知删除［L4］。学校反欺凌项目整体上能降低欺凌发生率［1］（元分析）；同伴受害与社交焦虑的双向关联［2］（系统综述与元分析）；求助／不求助的障碍分布［3］（系统综述）；自伤史与之后更高的自杀风险相关、预测力有限［4］（纵向研究元分析，用于把"出现自伤信号"列为立即升级）。
- **证据分级 C**：先信先谢、用身体活动重建掌控感，对应［B1］［B2］［B3］。
- **证据分级 D**：六项证据清单、学校线顺序、报警线细则、网络线三步、性相关情形只问三件事，为本套材料自定；法律定性以办案机关为准，本份不作法律意见。
- 本份**不诊断、不评估**未成年人，也不复述敏感细节。
