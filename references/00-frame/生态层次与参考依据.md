# 生态层次与参考依据

> 适用对象：家长
> 生态层：底座（横切）
> 适用时机：全时机
> 一句话范围：本 skill 的分域依据（生态系统理论）与分域规则，以及支撑这套依据的文献出处。
> 相关文件：00-frame/术语与使用方法.md；01-child/孩子的保护性因素.md；04-family/家庭经济与物质状况.md

## 机制

### 一、按"生态层次"分域，不按学科分

绝大多数育儿资料按**学科**切：健康、行为、教育、心理……结果同一件事会在好几个类别里各出现一遍，读者永远不知道该查哪一类。

本 skill 换一个切法：**按"这件事发生在谁身上、在哪一层"切**。同一件事只落在一层，不重复。

五层互斥，判得出来就不会再出现"这份该放哪"的纠结：

| 层 | 对应域 | 装什么 |
|---|---|---|
| 个体层（孩子自身） | `01-child` | 情绪、行为、气质、表达信号 |
| 个体层（家长自身） | `02-parent` | 家长自己的情绪、创伤、误区、恢复 |
| 关系层（亲子之间） | `03-bond` | 互动机制与全部话术 |
| 家庭层（家庭内部） | `04-family` | 氛围、规则、手足、隔代、夫妻、结构与变故 |
| 外圈层（学校与社会） | `05-outside` | 老师、同伴、学业、网络 |

### 二、这套分域的理论来源

儿童不是孤立的个体，而是嵌在层层环境里，每一层都在影响他。这个看法由布朗芬布伦纳（Bronfenbrenner）在 1970 年代系统提出［1］，此后又经历了从"生态学"到"生物生态学"的三个阶段演进［2］。其奠基出版物是 1979 年的《人类发展生态学》［B1］，该书出版当年即由《科学》刊出专文评介［4］。

后来的研究者检查了 25 篇自称基于该理论的实证研究，发现其中 21 篇沿用的是早期版本，仍在讲"环境单向影响儿童"，漏掉了这一理论的核心——**人与其近身环境的持续互动过程**［3］。本 skill 只借用它**分域**的这一层用处，不涉及该理论的完整主张。

生态框架在家庭理论谱系里也是独立的一支，与系统、冲突、生命历程等并列［B2］。

### 三、九域与四条支撑轴

五层之外，另加四条支撑轴：

| 轴 | 域 | 作用 |
|---|---|---|
| 底座 | `00-frame` 原理与分龄 | 被五层共同引用 |
| 横切 | `06-scenes` 情景脚本 | 跨层，按具体一幕组织 |
| 横切 | `07-safety` 安全兜底 | 覆盖全层，最高优先 |
| 纵向 | `08-archive` 记录与追踪 | 跨时间 |

"横切"这两条不是按层切，而是按**使用的场合**切：`06-scenes` 收的是一幕从开口到收尾的完整脚本，`07-safety` 收的是任何一层出现危险信号时都要走的那条路。

### 四、每份文件头部的"适用时机"标签

每份文件标一个**适用时机**：预防促进／当场应对／事后修复。这个三分口径取自《中华人民共和国精神卫生法》关于心理健康促进、精神障碍预防、治疗与康复的分段规定［L1］，并与国际通行的干预分类（预防／治疗／康复）对应。

标签的作用是让读者一眼知道"这份是平时读的，还是此刻翻的"：

| 标签 | 什么时候翻 |
|---|---|
| 预防促进 | 事情还没发生，或者日子平顺、想打底 |
| 当场应对 | 此刻正在发生，需要现在就说点什么／做点什么 |
| 事后修复 | 事情刚过或已经过去，要把它翻过去 |

### 五、保护性因素的三个层次

发展研究里通行的一种观察方式，是把支持孩子的因素分三层看：**生物因素**（身体与自控的底子）、**心理因素**（社会情感能力、心理弹性、自尊）、**社会经济因素**（家庭条件与外部资源）。本 skill 把它落成了 `01-child/孩子的保护性因素.md` 与 `04-family/家庭经济与物质状况.md`。

这是**观察清单**，不是诊断分类。

## 识别

### 一、一件事的层次归属

按"这件事发生在谁身上、你和他在哪个场里"问一句，答案就是所属域：

| 问 | 落点 |
|---|---|
| 是他自己的反应（情绪、行为、表达方式）？ | `01-child` |
| 是我自己的状态（我的火、我的旧伤、我的误区）？ | `02-parent` |
| 是我和他之间怎么一来一回？ | `03-bond` |
| 是家里其他人的事（手足、祖辈、夫妻、结构变化）？ | `04-family` |
| 是家外面的人或事（老师、同伴、学业、网络）？ | `05-outside` |
| 是这一幕具体怎么走完？ | `06-scenes` |
| 是安全问题？ | `07-safety`（最高优先） |

判不准时看一条：**先问"是谁的事"，再问"是机制还是这一幕"。** 机制进层级域（`01`–`05`），这一幕的完整走法进 `06-scenes`。

### 二、不进本 skill 的内容

医疗、照护、中医、早教、政策一律不做，只给一句话方向。遇到时说明本 skill 聚焦沟通与互动，指一条路即可，不展开。

## 做法

### 一、上层模型使用这套分域的方式

1. 按 `SKILL.md` 的**唯一一张路由表**定位域；
2. 在域目录里**按文件名**选那一份（文件名即内容锚点）；
3. **一次只读 1–2 份**，不批量加载；
4. 域内仍判不准时，读 `00-frame/术语与使用方法.md` 的加载与去重规则。

### 二、四条支撑轴的使用顺序

- 命中危险信号 → 先走 `07-safety`，**暂停常规沟通分析**；
- 有跨次记录时 → 结合 `08-archive` 看状态走向；
- 其余情况 → 层级域给机制，`06-scenes` 给这一幕的走法。

## 边界

- 分域是**本套材料的组织方式**，不是理论主张。**不要用它去判断某个家庭"属于哪一层"、更不要据此给孩子或家长定性。**
- 本份只解释分域依据，不承担任何关于儿童发展的具体结论；具体结论在各域文件里，并各自带上依据。
- 不引用未核实的文献，不编造页码、年份、DOI 与 ISBN。

## 依据说明

- **证据分级 A**：《精神卫生法》关于心理健康促进与精神障碍预防、诊断、治疗、康复的分段规定［L1］（现行法规）。
- **证据分级 B**：生态系统理论的三阶段演进及其理论分析［2］［3］（同行评议的理论综述；其中［3］指出 25 篇实证研究里 21 篇沿用早期版本，属该理论的易被误用）；理论的早期奠基论述［1］（理论文章）与同期书评［4］。
- **证据分级 C**：理论专著《人类发展生态学》［B1］与家庭理论谱系中的定位［B2］，属通行理论框架；"适用时机"三分（预防促进／当场应对／事后修复）与现行法规的干预分段口径对应，属框架性借用；保护性因素的"生物／心理／社会经济"三层分类是通行框架，本套材料借用它做观察清单，不作诊断依据。
- **证据分级 D**：本 skill 的**九域划分**、四条支撑轴、每份文件头部的"适用时机"标签落法，均为本套材料自定的组织规则。
