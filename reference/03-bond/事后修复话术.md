# 事后修复话术

> 适用对象：家长
> 生态层：关系层（亲子之间）
> 适用时机：事后修复
> 一句话范围：事情过去了、要正式把这页翻过去时的完整道歉；只修自己那一半，他那一半另开一次。
> 相关文件：03-bond/平复后的修复话术.md；03-bond/道歉与修复的误区.md；03-bond/三种时机剧本.md；03-bond/设边界的句式.md；02-parent/发火之后的修复.md；07-safety/危机信号识别.md

## 机制

### 一、正式修复的目标是"把这一页翻过去"，不是让他服气

事情过去、双方都回到基线之后，才能做正式修复。它的目标只有一个：把这件事从"没结束"变成"结束"，让你们能往下走。它不负责分出对错，也不负责让他承认什么。

修复不是"翻篇就不许再提"。真正的翻篇是：这件事谈过一次、说清了、以后怎么办也定了，之后不再拿它当武器。

### 二、只修自己那一半

你只对你做的那部分负责。你替他认错，他就没有机会处理自己那部分；你只认自己那部分，反而给他留了位置。

"他那一半"——他做错的行为、他要不要改、他要不要道歉——另开一次谈，不塞进你道歉的同一段里。两件事挤在一起，他会把注意力全放在防守上，你那半的道歉就白说了。

### 三、一个完整的道歉有五个部分

| 部分 | 作用 | 例 |
|---|---|---|
| 说清做了什么 | 具体到行为，不笼统 | "我昨天把你的本子摔了。" |
| 说清对他的影响 | 让他知道你看见了他的感受 | "那一下你肯定又吓又难受。" |
| 不辩解 | 任何"但是""我也是为了你"都会抵消前面 | （不说"我也是急"） |
| 说下次做什么 | 给一个具体、可查的动作 | "以后我再急，也会先把东西放下。" |
| 把选择留给他 | 原不原谅，由他说了算 | "你现在不想理我，也行。" |

缺任何一块，道歉都会打折：缺前三块像敷衍，缺第四块像空话，缺第五块像施压。

"说清做了什么—说清影响—说下次做什么"这个顺序，和"观察—感受—需要—请求"这一套是一致的［B1］。

### 四、修复效果的来源

家长的敏感回应与孩子的依恋安全感相关（元分析，效应量为小到中等）［1］；依恋安全与孩子从情绪里恢复的能力关系更稳定（系统综述，15 项研究）［2］；家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关［3］。修复本身就是一次高质量的回应：你在他被伤到之后回来，把关系接上，他学到的是"关系断了可以修"，而不是"关系断了就没了"。

"高要求＋高回应"的教养方式，与孩子更好的适应结果相关［4］——修复正是"高回应"里最难也最关键的一种。

## 识别

### 一、可以做正式修复的时候

三个条件同时满足：

1. **双方都回到基线**：能正常说话、能坐在一起；
2. **有完整时间**：不是在出门上学前，也不是在他马上要考试时；
3. **不是下一次冲突马上要发生**。

三个里缺一个，就先回到 `03-bond/平复后的修复话术.md`。

### 二、谈"他那一半"的时机

另开一次，通常在你修复完之后、过一段时间。原则：

- 不在你道歉的同一段里提；
- 不是接着你的道歉追问"那你呢"；
- 谈的时候说具体行为，不翻总账。

边界句式见 `03-bond/设边界的句式.md`。

### 三、不能只修自己那一半的情况

涉及安全的问题不算"修复题"：动了手、打伤、威胁、持续的伤害行为。这些先按 `07-safety/危机信号识别.md` 处理，不能靠一次道歉带过。

## 做法

### 一、五步

1. **挑时间，提前说一声。** "晚上吃完饭，我想跟你聊两句。"（不突然开始，让他有准备）
2. **只说你的那半。** 从"我"开头，不出现以"你"开头的指责。
3. **按五个部分说。** 做了什么 → 对他的影响 → 不辩解 → 下次做什么 → 把选择留给他。
4. **说完就停。** 不等他表态、不追问感受。
5. **做到你说的那件事。** 下次同样情境，按你说的做；做不到，这次道歉就作废。

### 二、一段可以直接照说的完整示范

> "昨天那件事，我想跟你说说。先说我的那部分。"
> "我昨天当着你的面把你的本子摔了。"
> "那一下你肯定又吓又难受。我不该那样。"
> "我不解释。摔本子这件事，是我做错了。"
> "以后我再生气，也会先把手里的东西放下，先离开那个房间。"
> "你现在不想说话，或者还生我的气，都可以。你什么时候想理我了，我在。"

六个句子里：第一句定范围（只说我的那部分），第二句说行为，第三句说影响，第四句堵掉辩解，第五句给可查的动作，第六句把选择还给他。

### 三、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "你就是假装的" | 不辩论，用行动回答 | "你可以不信。你看着就行。" |
| "不用你管" | 不追、不受伤表演 | "好。那我不说了。我在。" |
| "那你也答应我……" | 不把道歉变交换 | "这两件事分开。我先做我说的，你的事我们另外谈。" |
| 他哭了 | 不阻止，不趁机讲理 | （不说话，坐近一点） |
| 他也开始认自己那半 | 接住，但不上纲 | "你说的那部分也对。那件事我们下次单独说。" |
| "算了"（敷衍应付） | 不追要一句"我原谅你" | "好。我不需要你现在说什么。" |
| 他一句话不说 | 不逼 | "你不用现在回我。我该说的说完了。" |

用描述性的说法、把选择留给孩子，是这类接法能让他继续谈的前提［B3］。

### 四、他那一半：另开一次的做法

等这件事落下来之后，找一个日常时机，说具体行为，只谈这一件：

> "上次摔本子是我的事。还有一件，我们说说：你把作业本撕了那一下。"
> "你当时是气什么？"

- 只谈一个具体行为，一次一件；
- 先听他的原因，再谈边界；
- 不把这件事和你那次道歉绑在一起算账。

先把事实说清、不给孩子贴标签，是让他愿意承担自己那部分的前提［B2］。

### 五、分龄：修复的说法

| 学段 | 修复的重点 | 一句可以说的话 |
|---|---|---|
| **学前 3–6** | 靠动作＋一句话，别讲长 | "刚才是妈妈声音太大了。过来抱一下。" |
| **小学低年级 6–9** | 一句一动作，说清下次 | "我昨天不该吼你。下次我先走开一下。" |
| **小学高年级 9–12** | 尊重他，不用哄小孩的口气 | "昨天是我不对。跟你说声对不起。" |
| **初中 12–15** | 短、直接、不追问 | "昨天那事我说重了，对不起。就这样。" |
| **高中 15–18** | 平等，把话说完就走 | "我昨天的反应过了，是我的问题。你不用急着回我。" |

分龄说法本身的差异见 `03-bond/分龄说法要点.md`。

## 边界

- **不要用"但是"收尾。** 前面道歉后面辩解，等于没道歉（`03-bond/道歉与修复的误区.md`）。
- **不要逼他现在就原谅。** 原谅是他的事，不是你要来完成的任务。
- **不要用道歉换条件。** "我道歉了，你别玩手机了"是交易，不是道歉。
- **不要重复道歉。** 同一件事反复道歉，会从诚意变成套路，反而让修复失效。
- **道歉不能替代改变。** 说了下次做什么，就要真的做；光道歉不改，信任会继续掉。
- **不要表演式地自责。** 把道歉说成"我真是个糟糕的家长"，会把焦点从"我做了什么"拉到"你来安慰我"，等于把负担递给他。
- **涉及安全不能只靠道歉。** 见 `07-safety/危机信号识别.md`。

## 升级信号

- 同一件事反复发生、你反复道歉仍无变化 → 见 `07-safety/就医与专业转介指征.md`。
- 出现自伤、动手致伤、持续威胁 → 走 `07-safety/危机当下的应对.md`。

## 依据说明

本份属做法层。

- **证据分级 A**：家长敏感回应与依恋安全感的关系（元分析，效应量为小到中等）［1］、依恋类型与孩子情绪反应／从情绪恢复的差异（系统综述）［2］。
- **证据分级 B**：家长怎么回应孩子的情绪，与孩子怎么处理自己的情绪有关（叙述性综述）［3］；"高要求＋高回应"与孩子更好的适应结果相关（单项长期纵向研究，T3 样本 139 名青少年，样本以中产、受教育程度较高的白人家庭为主）［4］。
- **证据分级 C**：完整道歉的要素、把选择留给对方，属成熟冲突修复框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：五步流程、示范脚本、"他那一半另开一次"的操作、分龄修复表，为本套材料自定。
