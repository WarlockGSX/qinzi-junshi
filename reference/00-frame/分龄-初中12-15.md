# 分龄-初中12-15

> 适用对象：家长
> 生态层：底座（横切）（原理与分龄）
> 适用时机：预防促进
> 一句话范围：12–15 岁：情绪强度上去了、出口变窄，低落常表现为易怒（最容易被读错）。
> 相关文件：00-frame/分龄-小学高年级9-12.md；00-frame/分龄-高中15-18.md；01-child/青春期身心变化.md；06-scenes/青春期关门对抗.md；07-safety/危机信号识别.md；07-safety/就医与专业转介指征.md

## 机制

### 一、情绪强度上去了，是因为两个系统发育不同步

青春期负责奖励和情绪的系统先成熟，负责控制与判断的前额叶要到二十岁出头才逐步成熟。两边不同步，结果是情绪反应更快、更大，抑制和权衡更慢［1］［2］。这是这一阶段的发育规律，不是针对你，也不是他变坏了。

### 二、压力会让这套系统更不稳定

长期处在压力状态（睡眠不足、学业压力、持续冲突）会让负责自控的前额叶功能下降，更容易一点就着，和眼前这件事的关系其实不大［4］。所以一个长期睡不够、压力大的初中生，情绪的底线本来就比别人低。

### 三、出口变窄

这个年龄，同伴和网络成了主要出口，对家长的门开始关上。同一种难过，他更可能跟朋友说、发在网上，而不是跟你说。这不是不信任你，是这个阶段的常态。代价是：**你看到的部分，比他实际承受的少。**

### 四、低落常常表现为易怒——这一段最容易被读错

青少年抑郁的"低落"不一定是"蔫下来"，也可能是烦躁、易怒、一点就炸，或身体不舒服（头痛、肚子痛、睡不好、吃不下）［3］。家长最容易把这些读成"叛逆""态度差""青春期就那样"，于是用更硬的方式去管，越管越紧。识别口径要放宽：**先不急着定性，先记一段时间里的变化。**

### 五、你看到的和他感受的，常常不一样

家长和青少年对同一段时间的状态评价，经常对不上：家长看到的是"在家挺好"，他自己经历的可能是另一回事；反过来也一样。不同信息源之间的不一致是常见现象，不是谁在说谎［5］。所以判断时不能只凭一个来源。

### 六、他很少主动求助

青少年不愿开口，常见原因是想自己扛、怕被贴标签、怕失去自主、担心隐私［6］。所以"你没说我就当你没事"是最危险的默认。

## 识别

### 一、三段分类：发育中的正常与需要警觉

| 表现 | 通常的理解 | 该做什么 |
|---|---|---|
| 想要独处、关门、话变少 | 这一阶段常见 | 尊重独处，留一个能敲开的门 |
| 偶尔顶嘴、情绪来得快 | 发育中的情绪强度 | 不接球、不辩论、事后再说 |
| 持续两周以上的易怒、烦躁 | 可能是低落的表达 | 认真对待，不急着定性，先记变化 |
| 兴趣减退、睡不好、吃不下、总说身体不舒服 | 要警觉 | 走专业评估，见 `07-safety/就医与专业转介指征.md` |

关键线：**变化持续两周以上、明显影响吃饭睡觉上学，就不当"青春期"处理。**

### 二、分清"关门"和"出问题"

关门是这一阶段的形式；要看的不是门关不关，而是门里的人还在不在正常运转——有没有朋友、有没有还愿意做的事、吃饭睡觉是不是基本正常。形式一样的关门，内容可以差很远。

### 三、不要只凭你的观察下结论

你在家看到的是"挺好"，可能只是因为他在你面前收着。孩子自己说"没事"，也可能只是不想麻烦你。两边都对不上的时候，多听一个来源（另一位家长、老师，或他愿意说的人），不要用一个视角定死［5］。怎么听、怎么问，见 `06-scenes/青春期关门对抗.md`。

## 做法

### 一、三个总原则

1. **不接球。** 他抛出攻击性的话，你不接、不辩论、不当场定对错。
2. **不追问。** 把"你到底怎么了"换成"你想说的时候我在"。
3. **只谈一件、只谈当下。** 不翻旧账、不把一件事扩成一场总账。

### 二、可以直接照说的原句

**给一句事实然后撤：**
> "我听见了。这事我们晚点说。"

**不追问，留出口：**
> "你不想说就先不说。需要的时候，我在。"

**把易怒当成可能的信号，而不是挑衅：**
> "你最近好像很容易烦。是累了，还是有什么一直搁着？"

**尊重独处，但留一个能敲开的门：**
> "门可以关，但我要能敲门找得到你。"

**先不争对错：**
> "我们先不争这个。等都不气了再讲。"

**只谈一件：**
> "刚才那件事，就那一件，别的先不说。"

**表达担心而不评价：**
> "我担心的是你最近睡太晚，不是要管你这个人。"

**具体的在场，比"有事跟我说"有用：**
> "需要接送、需要我出面、需要我闭嘴，你都跟我说哪个。"

**承认他要长大的事实：**
> "你的事你自己拿主意，我只是问一句要不要帮忙。"

先接情绪、再谈事情，是这一段能用得上的做法［B1］；不评价人、只说事实和感受，是让对话不升级的关键［B3］；接住他的情绪而不是压制它，长期看更有利于他自己学会处理［B2］。

### 三、他说这些时的接法

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| "烦死了，别问了！" | 停问，给空间 | "好，我不问了。你想说的时候我在。" |
| "你根本不懂我" | 不辩解，先认这句 | "你说的可能是对的。你多讲一点。" |
| 摔门进房间 | 不追着拍门 | 隔十几分钟敲："我在门外，你想说再说。" |
| 一整天不出房间 | 不一上来就查 | "你今天一天没吃东西，我给你拿点进来。" |
| "无所谓，随便。" | 不逼他表态 | "那我先不定，等你想好了告诉我。" |
| 说"我朋友都这样" | 不否定他的朋友 | "你们这样想我能理解。我担心的是你的睡眠。" |

## 边界

| 不要做 | 原因 |
|---|---|
| 把易怒一律当"叛逆""态度差" | 这会把可能的低落读反，越管越紧［3］ |
| 当众说、当众教育 | 这一年龄最大的雷区，反弹加倍 |
| 追查手机、翻书包、盯行踪 | 越查越藏，把出口彻底堵上 |
| 用成绩和未来反复施压 | 压力让本就脆弱的自控更弱［4］ |
| 跟他的面子对着干 | 你赢了面子，输掉的是他还愿意说话 |
| 每一次关门都当对抗处理 | 关门是形式，要看他还在不在运转 |
| "他没说就当他没事" | 青少年很少主动求助，沉默不等于好［6］ |
| 只靠你一个人的观察下结论 | 你看到的和实际常常不一致［5］ |

**核心：先别把易怒都当态度问题。先把它当可能的信号，记一段时间的真实变化。**

## 升级信号

- **持续两周以上的情绪改变**：易怒或低落、兴趣减退、睡眠和饮食明显改变、成绩突然大幅下滑 → 走 `07-safety/就医与专业转介指征.md`。
- **出现自伤、或提到"活着没意思""消失算了"** → 立即走 `07-safety/危机信号识别.md`，不要停在话术上。
- **退缩到不出门、拒绝上学、被欺凌** → 走 `05-outside/校园欺凌与同伴冲突.md`。
- **要不要直接问自杀？** 有研究提示，直接询问不会诱发自杀念头，反而常常是他在等的那个出口［7］。可以平实地问："你最近有没有想过伤害自己？"

紧急情况拨 110／120，心理援助热线 12356。

## 依据说明

本份属机制层，是分龄五份中的初中一段。

- **证据分级 A**：青少年不愿求助的常见原因（系统综述）［6］；多信息源评估之间不一致属常见现象（经典研究，指向情境特异性）［5］。
- **证据分级 B**：青春期双系统发育（奖励系统先成熟、控制系统后成熟；叙述性综述／理论综述）［1］［2］、压力抑制前额叶功能（机制综述）［4］；直接询问自杀不会诱发自杀念头（证据综述）［7］；青少年抑郁的情绪低落可表现为易怒而非难过（综述）［3］。
- **证据分级 C**："不接球、不追问、只谈一件"属成熟做法，对应到书［B1］［B2］［B3］。
- **证据分级 D**：三段判断表、"关门 ≠ 出问题"的区分、本段的原句与边界，为本套材料自定。
