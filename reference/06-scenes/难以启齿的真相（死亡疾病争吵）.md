# 难以启齿的真相（死亡疾病争吵）

> 适用对象：家长
> 生态层：横切（跨层）（情景脚本）
> 适用时机：预防促进
> 一句话范围：孩子怕的是茫然与无助，不是真相本身——开口那一刻怎么走，四步真话法。
> 相关文件：04-family/丧亲与重病.md；04-family/夫妻冲突与对孩子的影响.md；01-child/恐惧与焦虑.md；03-bond/平复后的修复话术.md；02-parent/撑不住时的自我照顾.md；07-safety/危机信号识别.md；07-safety/求助渠道与转介.md；07-safety/就医与专业转介指征.md

## 机制

### 一、孩子怕的不是真相，是"不知道"和"没人管我了"

权威指南指出：对孩子回避死亡（把它当禁忌、什么都不说）帮不了他应对丧失；按他能理解的程度，如实、简单地告诉他，用准确的词，把他纳入告别，并反复给"你会被照顾好"的确定感，这些对他有帮助［1］。孩子在丧失后最常见的担心是三类：是不是我造成的、会不会也轮到我、以后谁来管我——这三点都要被正面回答。也就是说，**问题不是"要不要说"，是"怎么说、说多少"。**（完整机制、孩子对死亡的理解如何分年龄长出来，见 `04-family/丧亲与重病.md`。）

### 二、你迟迟开不了口，通常不是不知道说什么，是怕自己先崩

开口那一刻最难的往往不是内容，是你要一边说、一边管住自己。孩子对信息的承受力，很大程度取决于**大人是不是稳的**——指南也提醒，正在哀伤的父母可能顾不上孩子，这时需要一个熟悉的大人接手［1］。所以开口之前，先确认你自己有没有人接着。早期分离与丧失的经验，会影响一个人后来在关系里的反应方式，这也包括你现在面对孩子时的紧张［B1］。

### 三、你不说，他会自己填一个版本

孩子在信息真空里会自己填空，填出来的版本通常比事实更可怕——尤其当大人表现得很反常，却什么都不说的时候。他会把"大人最近不对劲"解释成"是不是我做错了什么"。

### 四、三类"难以启齿"的真相，难度不一样

| 类型 | 最难的一步 |
|---|---|
| **死亡**（刚去世） | 用"死"这个词，并说清"接下来你怎么办" |
| **重病**（人还在） | 说清"很重"但不过度，留一个"有进展我会告诉你"的通道 |
| **争吵／关系变化**（离婚、分居、长期冲突） | 说清"是大人的事、不是你的错、你仍然有两个大人"，不给细节 |

家里要变这件事上，父母之间的**冲突水平和持续性**，与孩子适应的差异有关［4］。也就是说，孩子受影响的关键不是"你们离不离"，是"这场变化有没有把孩子卷进去、有没有给他一个稳定的交代"。

### 五、分龄：同一个真相，不同年龄听懂的是不同的部分

儿童对死亡概念的三项成分——不可逆性、普遍性、功能停止——是分步获得的，多数健康儿童在 5–7 岁之间逐步掌握，不是一次听懂［2］。

| 学段 | 大致理解 | 你的话往哪儿靠 |
|---|---|---|
| **学前 3–6** | 常以为死亡是暂时的、可逆的；会反复问 | 简短、具体，反复回答同一个问题，用"死"这个词 |
| **小学低年级 6–9** | 开始明白不可逆；容易把责任揽到自己 | 明确说"不是因为你"，给出日常安排 |
| **小学高年级 9–12** | 接近成人，会问细节，也可能藏情绪 | 给信息、允许提问、给他一件能做的事 |
| **初中 12–15** | 明白，但可能表现为愤怒、疏离、否认 | 不逼谈，留一句"你想说的时候我在" |
| **高中 15–18** | 理解完整，会担心"这对我的以后意味着什么" | 给关于以后的确定信息，允许他悲伤也允许他继续生活 |

## 识别

### 一、先分清是哪一类真相，再决定说什么

| 情境 | 你要先确定的一件事 |
|---|---|
| 家人刚去世（几天内） | 用清楚的话告知，并说清他接下来住哪、谁管 |
| 家人重病（还在治） | 给确定的信息，设一个"有进展我会告诉你"的约定 |
| 家里要变（离婚、分居、长期分开） | 说清"这不是你的错""你仍然有两个大人" |
| 孩子在追问（"你会不会也死"） | 接住恐惧，给诚实的安慰，不糊弄 |

### 二、判断他是不是已经感觉到"有事"

**已经知道了的信号**：最近反常地黏人／突然变得很乖／反复问"你是不是不高兴"／偷听大人说话／夜里睡不好。出现这些，说明他已经在自己填空，越早给一个准确的版本越好。

### 三、判断现在是不是开口的时机

**可以开口**：有一段安静、不被打断的时间；你自己大致稳得住；说完之后你有时间陪他。

**先别开口**：正赶着出门、当着一屋子人、你自己刚哭过还没收住、他正在情绪里。**开口不是越早越好，是越稳越好。**

## 做法

### 四步真话法

**第一步 · 预告一句，让他有准备。**
不要在他玩到一半时突然开口，也不要铺垫太久。走到他身边，坐下，用平常的语气起头：

> "有件事我要认真跟你说一下。就我们俩，现在说。"

**第二步 · 一次只说一件事，用他听得懂的词。**
一句一句说，说完一句停一下，看他的反应再往下。不谈两件事（"爷爷去世了，而且爸妈要离婚"——分开说，中间隔几天）。

**第三步 · 用"死"这个词，说清能确定的事，并接着说他怎么办。**

- 用"死"／"去世"，**不要用"睡着了""走了""去很远的地方旅行了"**——幼儿会字面理解，然后怕上床、怕你出门；权威指南提示，这类委婉说法会让孩子误解，要用准确的词［1］；对死亡的生物性理解越成熟，孩子的死亡恐惧越低（访谈研究，90 名 4–8 岁儿童，属相关）［3］；
- 只说能确定的，不确定的说"还不知道，知道了我会告诉你"；
- **不承诺你做不到的**（"我永远不会离开你"）；
- 说完立刻接"你接下来怎么办"——住哪、谁管、还上不上这个学，这是他最想知道的。

**第四步 · 说完停住，然后闭嘴听。**
允许他哭、允许他没反应、允许他接着问、也允许他转身去玩——**当场没有大哭，不等于不难过**。他问十遍，就答十遍，这是他在慢慢消化。

### 三类真相的开场（可照着改）

**亲人去世：**
> "我要告诉你一件很难过的事。外婆今天去世了。去世就是，身体不再工作了，不会再醒过来，也不会再回来。这件事不是因为你，也不是你做错了什么。"

**家人生重病：**
> "有一件重要的事我要告诉你。爸爸生病了，这个病比较重，现在正在治。我会把每一步进展都告诉你，你有任何问题都可以问，不管多难回答的。"

**家里要变（离婚／分居／长期分开）：**
> "有件事我和妈妈商量好了，要告诉你。以后我们会分开住。这是我们大人之间的事，不是因为你，也不是你做错了什么。不管怎样，你都有我们两个，这件事不会变。"

（说完这三句，都要立刻接一句"接下来你怎么办"。）

### 说完之后：他这样反应时的接法

哀伤不是一条直线，遇到纪念日、生日、开学，情绪可能又来一次，这不是"退步"或"还没走出来"［1］。

| 他说／做 | 接法 | 可以照说 |
|---|---|---|
| 反复问"他什么时候回来""你会不会也死" | 不敷衍、不解释过多，平静重复 | "他去世了，不会回来了。我知道你很想他。" |
| 说"是不是因为我" | 直接、明确地解除归因 | "不是因为你。这不是你做错什么造成的。" |
| 完全不哭、照常玩 | 不催他哭，也不说他"冷血" | "你什么时候想说他，我都听。" |
| 突然发脾气、打人 | 接住情绪，不惩罚情绪 | "你特别气、特别难过。气可以，打人不行。" |
| 退行（尿床、要抱、不敢独处） | 当成需要的信号，多陪 | "这几天你想跟我睡就跟我睡。" |
| 你说的过程中他哭了 | 停下，先陪，不急着讲完 | "难受就先哭。剩下的我们慢慢说。" |

接住情绪、不评价情绪，是这些接法的共同点［B2］；把强烈情绪当成一个需要，而不是一个问题，是这一段的底线［B3］。

### 分龄的一句

| 学段 | 开口后可以补的一句 |
|---|---|
| **学前 3–6** | "你现在住哪儿、谁管你，都不变。" |
| **小学低年级 6–9** | "这不是你的错。你的事还是照常。" |
| **小学高年级 9–12** | "你想问什么都行，问多少遍都行。" |
| **初中 12–15** | "你不用马上说什么。想说的时候我在。" |
| **高中 15–18** | "以后的安排，我会跟你一起商量。" |

### 你自己：先找一个大人接住

> （孩子过来安慰你）"谢谢你。这是大人的难过，我会处理，也有人陪我。你不用管。"

长期撑不住时，见 `02-parent/撑不住时的自我照顾.md`；需要外部帮助时，见 `07-safety/求助渠道与转介.md`。

## 边界

| 不要做 | 原因 |
|---|---|
| 用"睡着了""去远方了"代替"死" | 幼儿会字面理解，产生睡怕、分离怕 |
| 一次把几件事一起说完 | 他消化不了，只会记得"世界塌了" |
| 说"你要坚强，不许哭" | 情绪被堵住，会从别处冒出来 |
| 把孩子支开、什么都不告诉他 | 他会在信息真空里编一个更可怕的版本［1］ |
| 让孩子替你扛（"你要照顾好妈妈"） | 把成人的重量压到他身上 |
| 承诺做不到的（"我永远不会离开你"） | 空头保证一旦落空，破坏信任 |
| 把争吵的细节、谁对谁错讲给他 | 他会以为要选边、要负责 |
| 把"他看起来很坚强"当成他没事 | 藏起来的情绪也会累积 |

**核心：如实，但有分寸——不隐瞒事实，也不把成人的恐惧和细节全交给他。**

## 升级信号

- **立即（当天）**：孩子说"活着没意思""我想去找他"，或出现自伤动作 → 先保安全，联系 **110／120**；全国统一心理援助热线 **12356**。见 `07-safety/危机信号识别.md`。
- **尽快（一周内）**：持续半年以上功能明显受损（拒学、吃睡长期紊乱、退到不出门）、长期麻木或强烈回避 → 见 `07-safety/就医与专业转介指征.md`、`07-safety/求助渠道与转介.md`。
- **大人自己长期撑不住** → 见 `02-parent/撑不住时的自我照顾.md`。
- **家里出现暴力、威胁、动手** → 先保安全，走 `07-safety/危机信号识别.md`。

## 依据说明

本份属情景脚本层（机制与"五步告知法"的细节见 `04-family/丧亲与重病.md`）。

- **证据分级 A**：回避死亡帮不了孩子，按发育水平如实告知、用准确的词、把孩子纳入告别有帮助，以及丧失后常见的三类担心［1］（权威机构指南）；哀伤反应会反复、多数随时间减轻（同一指南）。
- **证据分级 B**：儿童对死亡概念三项成分（不可逆、普遍、功能停止）的理解分步获得，多数在 5–7 岁之间逐步掌握［2］（叙述性综述）；对死亡的生物性理解越成熟、死亡恐惧越低［3］（访谈研究，90 名 4–8 岁儿童，属相关）；父母冲突的水平与持续性，与孩子适应的差异有关［4］（研究综述）。
- **证据分级 C**：三类真相的分流、用"死"这个词、不替孩子承诺，属成熟做法与经验框架，对应到书［B1］［B2］［B3］。
- **证据分级 D**：四步真话法、三类开场原句、"他这样反应你接什么"对照表、分年龄说法差异，为本套材料自定。
